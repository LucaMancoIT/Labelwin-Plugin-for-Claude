Versionen

Die aktuelle Programmversion von Labelwin nennen wir V5. Es handelt sich um die Version 5 - also die 5. Programmgeneration.

Bei einigen Kunden ist allerdings noch die vorherige Version V4 im Einsatz. Beide Versionen funktionieren natürlich tadellos, allerdings werden Neuerungen nur noch in der V5 Version umgesetzt. Wir raten daher jedem mit der neueren V5 Version zu arbeiten.

Hinweis: Die Installation der V5 Version erfolgt nicht automatisch per Update, sondern muss gesondert erfolgen. Die Installationsanleitung finden Sie im Kapitel V5 Installation.

Labelwin V5

Programmstart:

|

[Bild]

|

Anwahl des Hauptprogrammes über die lila Labelwin-Fahne. Es öffnet sich der V5 Programmbaum.

Start der einzelnen Module über Doppelklick auf den entsprechenden Eintrag im Programmbaum.

Programmbaum

|

[Bild]

Bild: Labelwin Programmbaum (V5)

|

Das Programmpaket besteht aus einzelnen Modulen, die im Labelwin Programmbaum untereinander aufgelistet sind. Die Anzahl der sichtbaren Module ist je nach Nutzer unterschiedlich, weil nicht jeder alles braucht.

Über den Menüpunkt [Optionen - Programmbaum anpassen] lässt sich die Liste der Module verändern.

[Bild]

Die Programme sind über die Icons zwar separat anwählbar, rufen sich jedoch zum Teil gegenseitig auf. Wenn Sie die Programme über die Iconebene aufrufen, hat dies den Vorteil, dass Sie zwischen ihnen über die Windows-Umschaltung (ALT+TAB-Taste, Taskmanager) umschalten können. Ausgefuchste Nutzer schalten sich gleichzeitig das Projekt-Programm, das Adressprogramm und die Auftragsverwaltung aktiv. Nutzern mit nur einem (kleinen) Monitor, empfehlen wir allerdings, sowenig Fenster wie möglich aufzuhalten, um den Überblick nicht zu verlieren.

Tipp: Über der Modulliste befindet sich eine Filterzeile, um ein Modul ggf. schneller zu finden und zu starten.

Es gibt einen Standard-Programmbaum, der für alle Benutzer greift, bei denen kein spezieller Programmbaum vorhanden ist. Der Programmbaum dürfte in der Regel aber individualisiert werden, da jeder Anwender andere Module für sein Aufgabengebiet benötigt. Direkt im V5 Programmbaum kann über den Menüpunkt [Optionen - Programmbaum anpassen] die Liste der Module verändert werden.

Hinweis: Über die Rechteverwaltrung kann gesteuert werden, ob der Programmbaum vom Anwender verändert werden darf.

Neben den Label-Modulen können Sie hier auch beliebige andere Programme einbinden. Selbst die Einbindung von Dateien wie z.B. Excelmappen (.xls) oder Wordtexten (.doc) ist möglich, wenn die Bearbeitungsprogramme auf dem Rechner passend eingerichtet sind.

Übertragen Sie per Doppelklick (oder mit den Pfeil-Knöpfen in der Mitte) die Module aus der linken Liste in den Programmbaum. Der neue Eintrag wird immer ans Ende angefügt, kann aber mit den Pfeil-Knöpfen an jede andere Stelle geschoben werden

Über den Knopf ‚Vorlage wählen’ kann der Programmbaum eines anderen Users übernommen werden.

Einrückungen im Programmbaum / Oberpunkte

[Bild]

Oben im Bild sind einige Programme eingerückt und mit dem Oberpunkt TOOLS versehen.

Dies erreichen Sie indem Sie den Knopf ‚Neu’ betätigen und die gewünschte Beschriftung erfassen. Mit dem Knopf ‚Bild suchen’ können Sie auch dazu irgendein Icon auswählen.

Mit den Pfeilknöpfen können Sie dann die Programme zum Unterpunkt machen.

Weitere Programme einbinden

Weitere Programme werde ebenfalls mit dem Neu-Knopf eingetragen. In diesem Fall müssen Sie aber zusätzlich mit dem Knopf ‚Programm suchen’ das Programm auswählen.

[Bild]

Ob Sie ein Bild dazu wählen, bleibt Ihnen überlassen. Leider ist es bisher nicht möglich, die Icons der Programme selbst zu verwenden. Wenn Sie irgendwo auf der Festplatte ein Bild auswählen, so wird dieses automatisch in das Verzeichnis Labelwin\vorlage\icon kopiert.

Statt eines Programms (.exe) können Sie auch eine Datei wie z.B. eine Excel-Tabelle wählen. Ob der Aufruf später klappt, hängt davon ab, ob der Rechner aufgrund der Extension (.xls) das Bearbeitungsprogramm erkennt. In der Regel ist dies der Fall. Wenn sich bei einem Doppelklick auf die Datei das passende Programm öffnet, klappt es auch im Startcenter.

Auswertungscenter (V5)

Im Auswertungscenter können verschiedene Auswertungen angezeigt werden. Die Einrichtung des Auswertungscenters wird im Kapitel Auswertungscenter (V5) / Startcenter (V4) beschrieben.

Das Auswertungscenter kennen alle Labelwin Anwender, die bereits mit der V4 Version gearbeitet haben, noch aus dem Startcenter. In der V5 Version ist das Auswertungscenter vom Programmbaum entkoppelt worden und muss bei Bedarf separat gestartet werden. Der Start kann dabei entweder über den Programmbaum oder direkt mit Start von Labelwin erfolgen. Die Option zum automatischen Starten befindet sich im Programmbaum-Menü unter [Optionen - Auswertungscenter automatisch starten].

Startcenter (V4)

Die Labelwin Programme können nicht nur über den Windows Ordner "Label für Windows" geöffnet werden, sondern auch über das Startcenter. Sie haben auch hier die Möglichkeit eine für Ihre Anwendungen angepasste Auswahl der Programme zu treffen. Die Auswahl erfolgt über den Menüpunkt [Datei - Programmbaum anpassen].

[Bild]

Bild: Startcenter V4

Aus dem Startcenter heraus können Sie die einzelnen Module starten. Zusätzlich hat das Startcenter den Vorteil, dass einige statistische Werte (auf der rechten Seite) sichtbar geschaltet werden können.

Die Einrichtung des Startcenters wird im Kapitel Auswertungscenter (V5) / Startcenter (V4) beschrieben.
