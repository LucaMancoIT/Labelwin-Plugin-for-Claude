2.2.3 KD-Checklisten

Die Kundendienst-Checkliste ist für alle Firmen wichtig, die Wartungen und Inspektionen vornehmen. Im KFZ-Handwerk gibt es schon seit Jahren keine Inspektion ohne Checkliste. Auch in der Haustechnik wird sich dies zum Standard entwickeln. Hier wird es immer wichtiger, die Arbeiten nachzuweisen. Zum einen, damit der Kunde weiß, für was er Geld bezahlt, zum anderen auch, um im Schadensfall einen Nachweis führen zu können.

Ein großer Unterschied zum KFZ-Handwerk ist jedoch, dass in der Haustechnik jede Anlage individuell ist.

Bei der Vielzahl der heute vorzufindenden Geräte hat ein Kundendiensttechniker kaum eine Chance, alle erforderlichen Reinigungsarbeiten und Prüfarbeiten zu kennen. Falls das Handbuch vom Hersteller vorhanden ist, so ist dies in der Regel nicht auf die Wartungssituation angepasst. Hierbei können spezielle Vorlagen helfen, die auf die Besonderheiten der Geräte eingehen.

Dazu müssen die einzelnen Leistungen für die entsprechende Vorlage erfasst werden.

[Bild]

Bild: Erfassung der Leistungen

[Bild]

1 Vorlage: Hier werden alle bereits erfassten Vorlagen angezeigt und Sie können aus der Liste eine Vorlage auswählen.

[Bild]

2 Neue Vorlage F3: Durch Betätigen dieses Knopfes können Sie eine neue Vorlage anlegen. Die neue Vorlage muss einen eindeutigen Namen erhalten.

[Bild]

[Bild]

3 Anzeige Vorlagetext: Hier wird Ihnen der Vorlagetext der gewählten Vorlage angezeigt.

[Bild]

4 Vorlagetext: Über diesen Knopf können Sie einen Vorlagetext erfassen bzw. ändern. Der Vorlagetext kann formatiert werden.

[Bild]

5 Liste: In dieser Liste werden alle bereits erfassten Leistungen angezeigt.

[Bild]

[Bild]

6 Zeilenart: Diese Kennzeichen dienen dazu festzulegen, welches Merkmal die einzelnen Zeilen erhalten sollen.

- Inaktiv: Aktivieren Sie diesen Feld wenn die Zeile später in der Kd-Checkliste nicht sichtbar aber trotzdem dabei sein soll. Bei Bedarf können sie später aktiviert werden. Sinnvoll ist dieses beispielsweise bei einer Bestandsaufnahme. Wenn üblicherweise ein Bauteil per Hand bedient wird, kann die Prüfung der elektronischen Steuerung nicht anwählbar sein. Nach einem späteren Umbau kann man diese Zeile auch vor Ort aktivieren.

- Aktiv: Dieses Merkmal ist für Zeilen, die in der KD-Checkliste sichtbar sind.

- Überschrift: Wenn Sie in Ihrer Vorlage eine Zwischenüberschrift einfügen möchten, müssen Sie dieses Feld aktivieren.

- Anmerkung: Wählen Sie dieses Merkmal, wenn die erfasste Zeile als Anmerkung gelten soll.

[Bild]

7 Reihenfolge: Legen Sie hier die Reihenfolge fest, in welcher Stelle in der Liste (Nr. 5) die Leistung erscheinen soll.

[Bild]

8 Merkmal: Bei diesem Feld handelt es sich um ein 5-stelliges nummerisches Feld. Ein Merkmal kann nur einmal pro Vorlage vergeben werden.

[Bild]

9 hochzählen: Wenn Sie mit fortlaufenden Nummern (Merkmalen) arbeiten möchten, aktivieren Sie dieses Feld. Das erspart Ihnen das erneute Eintippen des Merkmals für den nächsten Eintrag.

10 Werkzeugleiste für Textformatierung: Hier können Sie die Formatierung für Ihren Leistungstext bestimmen.

[Bild]

1: Schriftart

2: Schriftgröße

3: fett

4: kursiv

5: unterstrichen

6: linksbündig

7: rechtsbündig

8: zentriert

9: Blocksatz

10: Zoomfaktor

11: Nummerierung

12: Aufzählungszeichen

13: Tabstopp

14: Formatierungssymbole ein- oder ausblenden

[Bild]

11 Leistungstext: Hier erfassen Sie Ihren Leistungstext. Über die Werkzeugleiste (Nr. 11) können Sie den Text formatieren.

[Bild]

12 Neu F2: Durch Betätigen dieses Knopfes wird das Feld (12) geleert und Sie können eine neue Leistung erfassen.

[Bild]

13 Speichern: Durch Betätigen dieses Knopfes für die erfasste Leistung gespeichert und erscheint in der Liste (Nr. 5).

[Bild]

14 Löschen: Durch Betätigen dieses Knopfes können Sie eine in der Liste (Nr.5) markierte Zeile löschen.

[Bild]

15 Drucken: Hier können Sie eine gewählte Vorlage ausdrucken.

[Bild]

16 Ende: Durch Betätigen dieses Knopfes wird die Maske geschlossen.

Datei

Drucken

Bearbeiten

Schriftart

Über diesen Menüpunkt gelangen Sie in das nachstehende Fenster – hier können Sie wie bei Word viele Merkmale einstellen.

[Bild]

Absatzformatierung

Stellen Sie sich an den Anfang eines Textabsatzes und wählen Sie die gewünschte Formatierung aus, z.B. kursiv. Die Formatierung wird auf den gesamten Absatz übernommen.

[Bild]

Aufzählungen

Unter diesem Menüpunkt können Sie die Nummerierungs- und Aufzählungs-vorgaben ändern.

[Bild]

Tabulatoren ändern

Unter diesem Menüpunkt haben Sie die Möglichkeit, die Tabulatoren zu ändern, zu erweitern oder zu löschen.

[Bild]

Suchen

Unter diesem Menüpunkt können Sie nach einem bestimmten Wort suchen.

[Bild]

Suchen und Ersetzen

Unter diesem Menüpunkt können Sie ein Wort suchen und durch ein anderes ersetzen

Sonderzeichen

Hier haben wir die wichtigsten Sonderzeichen hinterlegt, so dass Sie diese schnell im Zugriff haben.

[Bild]

Vorlagen

Neue Vorlage

Gleiche Funktion wie Knopf ‚Neue Vorlage‘ oder F3

Vorlage speichern als neu

Unter diesem Menüpunkt können Sie eine vorhandene Vorlage als neu abspeichern und dann Änderungen vornehmen. Das ist vor allem dann sinnvoll, wenn sich in der Vorlage nur wenige Leistungen ändern.

Vorlage löschen

Unter diesem Menüpunkt können Sie eine Vorlage löschen.

Vorlage exportieren

Unter diesem Menüpunkt kann eine Vorlage im XML-Format exportiert werden.

Vorlage importieren Labelformat

Unter diesem Menüpunkt kann eine Vorlage im XML-Format importiert werden.

Vorlage Textdatei importieren

Hier können Sie einfache Textdateien als Vorlage verwenden!

Folgendes ist dabei zu beachten:

- der Name der Checkliste wird durch 2 Doppelpunkte erkannt

- Überschriften / Textzeilen werden durch einen Doppelpunkt erkannt

- Artikelzeilen mit =Artikelnr;KatalogNr;Menge:Beschreibung

- es können beliebig viele Checklisten aus einer Text-Datei angelegt werden.

Beispielaufbau:

::Kesseltyp xyz

:Reinigung

Brenner reinigen

Flammüberwachung säubern

Pumpenfilter reinigen

=Filter1234;9;2;Filter

:Einstellungen

Brenner einstellen

::Brauchwasserspeicher

Opferanode kontrollieren

Probe entnehmen
