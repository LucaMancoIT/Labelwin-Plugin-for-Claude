Postbox - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Datei

Liste aktualisieren (F5 )

Durch Die Wahl dieses Menüpunkts wird die Dokumentenliste aktualisiert.

Umbenennen (Strg+U)

Durch die Wahl dieses Menüpunkts können Sie eine in der Liste markierte Datei umbenennen. Diese Funktion ist nur sinnvoll, wenn Sie die Datei nicht selbst ablegen wollen, sondern jemandem in seine Postbox schieben wollen. Dann kann es sinnvoll sein, der Datei zuvor einen passenden Namen zu geben.

Löschen

Durch die Wahl dieses Menüpunkts können Sie aus der Auswahlliste das markierte Dokument löschen.

Verweis auf Pfad speichern

Hier können Sie den Verzeichnispfad, den Sie über den Verzeichnistyp ‚Freie Auswahl‘ eingetragen haben, speichern. Damit kann z. B. der Buchhalter seine eigenen Verzeichnispfade speichern, die für niemand anderen sichtbar sind.

Verweis auf Pfad löschen

Hiermit können Sie den gespeicherten Verzeichnispfad löschen. Damit wird lediglich der Eintrag in der Auswahlliste gelöscht, nicht jedoch der Pfad selbst.

Mandant wechseln

Durch die Wahl dieses Menüpunkts können Sie den Mandanten wechseln. Der Menüpunkt ist nur sichtbar, wenn Sie das Modul Mandantenversion erworben haben.

|

Ablage

Neues Scan-Dokument (F2)

Durch die Wahl dieses Menüpunkts öffnet sich die Dokumentenanlage. Es ist die gleiche Funktion wie der Knopf ‚Neues Dokument F2‘

Neue Eingangsrechnung (F3)

Durch die Wahl dieses Menüpunkt können Sie eine neue Eingangsrechnung erfassen. Das markierte Dokument wird dann diesem Eintrag zugeordnet. Es ist die gleiche Funktion wie der Knopf ‚Neue Eingangsrechnung F3‘

Eingangsrechnung zuordnen (STRG+F3)

Wenn Sie eine Eingangsrechnung als pdf-Datei erhalten, können Sie diese über die Postbox einer bereits erfassten Eingangsrechnung nachträglich zuordnen. Es ist die gleiche Funktion wie der Knopf ‚Eingangsrechnung zuordnen‘.

Neuer KD-Auftrag mit Pdf als Scan (F4)

Durch die Wahl dieses Menüpunkts wird zum gewählten Dokument aus der Auswahlliste ein Auftrag angelegt, z.B. zur Nacherfassung eines Notdienstauftrags. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen. Es ist die gleiche Funktion wie der Knopf ‚Neuer Auftrag, Pdf als Scan‘

Neuer Auftrag, Pdf-Dokument (Strg + F4)

Durch die Wahl dieses Menüpunkts wird ein neuer KD-Auftrag angelegt. Das in der Auswahlliste gewählte pdf-Dokument wird im Auftrag als zugeordnetes Dokument abgelegt. Es ist die gleiche Funktion wie der Knopf ‚Neuer Auftrag, Pdf-Dokument‘

Vorhandener Auftrag, Pdf als Scan (Umschalt + F4)

Durch die Wahl dieses Menüpunkts wird die gewählte Pdf-Datei einem vorhandenen Auftrag als Bild zugeordnet. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen. Es ist die gleiche Funktion wie der Knopf ‚Vorh. Auftrag, Pdf als Scan‘

An Dokument eines Projektes als Scan (F6)

Durch die Wahl dieses Menüpunkts können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im Projekt zuordnen (z. B. zu einer Auftragsbestätigung, zu der Sie nun das unterschriebene Dokument erhalten haben). Es ist die gleiche Funktion wie der Knopf ‚An Dokument eines Projektes‘

An Dokument eines Auftrages als Scan (Umschalt + F6)

Durch die Wahl dieses Menüpunkts können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im KD-Auftrag zuordnen (z.B. zu einem Lieferschein, zu dem Sie das unterschriebene Dokument vom Kunden erhalten haben). Es ist die gleiche Funktion wie der Knopf ‚An Dokument eines Auftrages‘

Wareneingang buchen (Umschalt + F3)

Über diesen Menüpunkt können Sie einen Wareneingang erfassen. Die markierte PDF wird als Lieferschein automatisch zugeordnet. Es ist die gleiche Funktion wie der Knopf ‚Wareneingang buchen‘ .

Dieser Menüpunkt ist nur sichtbar, wenn das Modul Lager oder Bestellüberwachung im Einsatz ist.

Verschieben in andere Postbox (F7)

Durch die Wahl dieses Menüpunkts können Sie eine andere Postbox wählen. Es ist die gleiche Funktion wie der Knopf ‚In andere Postbox (F7)‘

Verschieben in zuletzt genutzte Postbox (F8)

Durch die Wahl dieses Menüpunkts werden die markierten Dokumente in die Postbox geschoben, die Sie zuvor ausgewählt haben. Es ist die gleiche Funktion wie der Knopf ‚In Postbox <name> (F8)‘

KD-Stapelablage (F9)

Wenn die gescannten KD-Aufträge mit bestimmten Namen versehen sind, kann die Zuordnung über diesen Durchlauf auf einen Rutsch stattfinden.

Die Auftragsnummer muss so verschlüsselt sein, wie sie auch beim Druck mit Strichcode aufgebaut ist. Vorangestellt sind 4 Nullen und der Bindestrich fällt weg.

Beispiel: Bei Auftrag 18-1234 muss die Datei 0000181234.pdf heißen. Bei Folgeauftrag 18-1234.1 muss sie 0000181234.1.pdf heißen.

KD-Ablage per OCR

Diese Funktion ermöglicht eine automatische Stapelablage von gescannten KD-Aufträgen. Voraussetzung hierfür sind durchsuchbare PDF-Dateien und eine eindeutige Kennung auf dem KD-Formular (die sogenannte SCANID). Details erfahren Sie im Kapitel KD-Aufträge automatisch ablegen.

|

Hinzufügen

Scannen mit Profilfrage (F11)

Durch die Wahl dieses Menüpunkts öffnet sich das Fenster mit den Scan-Profilen. Nach der Wahl eines Scan-Profils können Sie die Dokumente wie gewohnt einscannen.

Scannen (F12)

Durch die Wahl dieses Menüpunkt wird der Scanvorgang direkt gestartet, ohne dass eine Nachfrage zum Profil erfolgt. Es ist die gleiche Funktion wie der Knopf ‚Scannen F12‘

|

Info
