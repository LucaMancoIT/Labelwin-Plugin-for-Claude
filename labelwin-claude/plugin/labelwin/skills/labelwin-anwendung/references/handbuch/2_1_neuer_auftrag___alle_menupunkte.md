2.1 Neuer Auftrag - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Datei

OK Speichern/Schließen

Mit dieser Funktion wird der Kundendienstauftrag gespeichert und geschlossen. Es ist die gleiche Funktion wie der OK-Knopf.

Speichern + Aktiv lassen (Strg+S)

Mit dieser Funktion speichern Sie den Kundendienstauftrag und er bleibt geöffnet.

An Laptop exportieren

Mit dieser Funktion übergeben Sie den aktiven Auftrag an einen Laptop. In der aufsteigenden Maske müssen Sie die entsprechende Notebook-Nr. auswählen. Diese Funktion ist nur mit dem Zusatzmodul KD-Mobil Notebook verfügbar.

An PDA übergeben

Mit dieser Funktion übergeben Sie den aktiven Auftrag an einen PDA. In der aufsteigenden Maske müssen Sie den entsprechenden PDA auswählen, sofern Sie mehrere PDA-Lizenzen erworben und im Einsatz haben. Diese Funktion ist nur mit dem Zusatzmodul KD-Mobil PDA verfügbar.

Export an iDeXs

Mit dieser Funktion senden Sie einen Auftrag an iDeXs. Diese Funktion ist nur verfügbar, wenn das Zusatzmodul iDeXs im Einsatz ist.

Export an TomTom (Strg+Umschalt+F7 )

Mit dieser Funktion senden Sie einen Auftrag an ein TomTom-Gerät. Diese Funktion ist nur verfügbar, wenn Sie das Zusatzmodul TomTom erworben haben.

Nachricht an TomTom (Strg+F7 )

Hier haben Sie die Möglichkeit, eine Nachricht an ein TomTom Gerät zu senden. Dieser Menüpunkt ist nur anwählbar, wenn Sie über das Zusatzmodul TomTom verfügen.

Abstand zu Fahrzeugen

Mit dieser Funktion haben Sie die Möglichkeit, den Abstand von Ihren Fahrzeugen zur Baustelle des aktiven Auftrags zu ermitteln. Bei einem Notfall können Sie so die Monteureinsätze in der Nähe finden und ggf. den Monteuren mit dem kürzesten Weg schicken. Diese Funktion ist nur mit dem Zusatzmodul TomTom verfügbar.

Telefonnummern (Strg+W )

Hier werden Ihnen die Telefonnummern angezeigt, die bei der Objektadresse auf der Karteikarte ‚Zugeordnete Adressen’ sowie unter ‚Weitere Adressen’ hinterlegt sind. Hier haben Sie ach die Möglichkeit, einen vorhandenen Eintrag über den Knopf ‚Speichern als neu‘ zu kopieren und entsprechend abzuändern, wenn nur geringe Änderungen nötig sind.

Drucken

Mit dieser Funktion lösen Sie den Druck des Kundendienstauftrags aus. Es ist die gleiche Funktion wie der Knopf ‚Drucken’.

Ende/Abbruch

Dieser Menüpunkt schließt die Maske

|

Bearbeiten

Material eintragen

Hier haben Sie die Möglichkeit, Material einzutragen. Sie können den Materialzettel genauso erfassen, wie Sie ein Angebot oder eine Rechnung usw. erfassen. Es ist die gleiche Funktion wie der Knopf ‚Material’.

LEC_Daten erfassen

Ist die LEC Schnittstelle aktiv, können hier die LEC Daten erfasst werden.

Monteur-Anmerkung

Dieser Menüpunkt ist nur sichtbar, wenn Sie mit dem Zusatzmodul KD-Mobil arbeiten. Hier kann der Monteur Anmerkungen zur Anlage eintragen. Auf den ersten Blick scheint es so, als wenn er diese auch in die ‚normale’ Anmerkung eintragen kann, aber dort wird es mit den Hinweisen des Büros vermischt.

Hintergrund: Hier wurde ein definierter Platz geschaffen, in dem der Monteur für den TGM-Bereich (Technisches Gebäude Management) besondere Anlagenhinweise hinterlegen kann. Gerade bei den ersten Wartungen einer neu hinzu genommenen Anlage stellt sich oft heraus, dass manche geplante Leistungen entfallen und andere hinzukommen müssen. Im mobilen Bereich sollen solche Informationen auch papierlos an das Büro übermittelt werden können.

Weitere Monteure

Hier können Sie dem Kundendienstauftrag weitere Monteure zuordnen. Die Funktion ist die gleiche wie beim Knopf ‚Monteure’.

Zeiten buchen

Mit dieser Funktion können Sie die Zeiten für den KD-Auftrag erfassen. Es ist die gleiche Funktion wie der Knopf ‚Zeiten buchen’.

Erledigt/Rechnung

Durch die Wahl dieses Menüpunkts wird der KD-Auftrag erledigt und eine Rechnung geschrieben. Die Funktion ist die gleiche wie beim Knopf ‚Erledigt/Rechnung’.

Zugeordnete Dokumente

Mit dieser Funktion öffnet sich die Liste der evtl. bereits vorhandenen Dokumente. Sie können dort auch neue Dokumente anlegen. Es ist die gleiche Funktion wie der Knopf ‚Zugeord. Dokum.’.

Neues Dokument (F2)

Mit dieser Funktion starten Sie ein neues Dokument. Das Fenster für die Dokumentenanlage öffnet sich und Sie können wie im Projekt auch ein Dokument anlegen.

Neue Bestellung (STRG+B)

Dieser Menüpunkt legt ein neues Dokument vom Typ Bestellung an.

Scannen (F12)

Die Funktion steht Ihnen nur zur Verfügung, wenn Sie das Zusatzmodul ELO-Anbindung erworben haben. Hier haben Sie die Möglichkeit, zu dem Kundendienstauftrag einen unterschriebenen Auftragszettel, eine Notiz, einen Lieferschein usw. zu scannen. Die gescannten Dokumente finden Sie dann in der Dokumentenliste unter zugeordnete Dokumente wieder.

Neues Dokument (Vorgabe Scannen) (Strg+F2)

Wenn Sie das Zusatzmodul ELO-Anbindung erworben haben, können Sie durch die Wahl dieses Menüpunktes zum bestehenden Auftrag ein Dokument einscannen.

Annahmetermin ändern (F7)

Mit dieser Funktion aktivieren Sie das Feld Annahmetermin und haben so die Möglichkeit, den Termin zu ändern. Anderenfalls ist dieses Feld ausgegraut und nicht änderbar.

E-Mail Antwort

Dieser Punkt ruft die Kunden Info aus. Es kann eine E-Mail oder SMS an die Objekt- oder Rechnungsadresse geschickt werden.

Auftrag sperren (Strg+F8)

Mit dieser Funktion können Sie einen Auftrag sperren. Dieses wird Ihnen dann im KD-Auftrag angezeigt. Damit ist es nicht mehr möglich, für diesen Auftrag, Material einzutragen, Zeiten zu buchen oder eine Rechnung zu schreiben. Sie können in einem solchen Auftrag nichts verändern. Erst durch einen erneuten Klick auf diesen Menüpunkt wird der Auftrag entsperrt und die Funktionen sind wieder verfügbar.

Status ändern / Storno (STRG+T)

Dieser Menüpunkt öffnet die Maske zur Umsetzung des Auftragsstatus.

Adressmonteur --> Monteur (STRG+P)

Diese Funktion trägt den in der Adresse unter Kundendienstvorgaben hinterlegten Monteur als Monteur des Auftrages ein. Das funktioniert natürlich nur, wenn auch ein Monteur in der Adresse hinterlegt ist.

Werkzeug Rückgabe

Wenn das Zusatzmodul Werkzeugverwaltung im Einsatz ist, können über diesen Punkt die auf einen Auftrag gebuchten Werkzeuge zurückgebucht werden.

Auftragsnr. kopieren

Die Auftragsnummer wird in die Zwischenablage kopiert und kann dann in ein beliebiges Textfeld innerhalb oder außerhalb von Label eingefügt werden.

Anlagen

Mit dieser Funktion kommen Sie zu der/den Anlage/n der Objektadresse. Es ist die gleiche Funktion wie der Knopf ‚Anlagen’.

Anlagenzuordnung entfernen

Mit dieser Funktion wird eine im Auftrag gewählte Anlage wieder abgewählt.

KD-Checkliste

Dieser Menüpunkt ist nur sichtbar, wenn Sie das Modul KD-Checkliste erworben haben. Eine nähere Beschreibung finden Sie im Handbuch unter KD-Checklisten.

Termine

Dieser Menüpunkt ist nur sichtbar, wenn für den KD-Auftrag ein Wartungstermin gewählt wurde. Es ist die gleiche Funktion wie der Knopf ‚Termine’.

Checkliste

Mit dieser Funktion kommen Sie in die hinterlegte Checkliste eines KD-Auftrags. Es ist die gleiche Funktion wie der Knopf ‚Checkliste’.

TGM Zuordnung

Mir dieser Funktion öffnet sich ein Fenster und zeigt Ihnen die Suchergebnisse der TGM-Zuordnung. Es ist die gleiche Funktion wie der Knopf ‚TGM’.

TGM Leistungen bearbeiten

Mit dieser Funktion haben Sie die Möglichkeit, die TGM-Leistungen zu ändern. Eine ausführliche Beschreibung finden Sie in unserem Handbuch unter TGM - Wartung und Instandhaltung.

|

Ansicht

Text groß anzeigen (F6)

Mit diesem Menüpunkt wird der Auftragstext groß angezeigt. Dieses Fenster ist frei einstellbar, das heißt Sie können es vergrößern oder verkleinern. Es ist die gleiche Funktion wie der Knopf ‚Text groß’.

Terminübersicht

Mit dieser Funktion öffnen Sie die Terminübersicht. Es ist die gleiche Funktion wie der Knopf ‚Termine’.

KD-Mobil Status

Wenn Sie mit dem Modul KD-Mobil arbeiten, können Sie über diesen Menüpunkt den aktuellen Status des Auftrags ansehen. Es ist die gleiche Funktion wie der Knopf ‚Protokoll’.

Gescannten Auftrag anzeigen (F4)

Mit diesem Menüpunkt können Sie sich einen eingescannten Auftrag anzeigen lassen. Voraussetzung hierfür ist jedoch, dass Sie das Zusatzmodul ELO Anbindung erworben haben.

Internet Stadtplan (Strg+I)

Mit diesem Menüpunkt wird GoogleMaps gestartet. Hier wird Ihnen der Standort der Objektadresse angezeigt.

Internet Routenplan (Strg+R)

Mit diesem Menüpunkt starten Sie GoogleMaps und es wird Ihnen die Route vom Ausgangspunkt zum Endziel angezeigt.

Kartenansicht Techniker (STRG+ALT+F12)

Mit diesem Menüpunkt startet die Google Kartenansicht mit den Standorten aller markierten Aufträge. So lässt sich anschaulich darstellen wo sich die Monteure befinden. Voraussetzung ist der Erwerb des Moduls "Google Karte".

Eingangsrechnungen

Mit diesem Menüpunkt erhalten Sie eine Liste der Eingangsrechnungen, die zum aktiven Kundendienstauftrag gebucht wurden.

Abschlagsliste

Mit diesem Menüpunkt erhalten Sie eine Liste der bereits gestellten Abschlags- und Teilrechnungen für den aktiven Kundendienstauftrag.

Wareneingang zeigen

Über diesen Menüpunkt erhalten Sie die Artikelliste der bereits eingegangenen Waren. Voraussetzung hierfür ist, dass Sie das Zusatzmodul Bestellüberwachung oder das Modul Lager erworben haben. Beim Wareneingang werden dann automatisch Eingangslieferscheine erzeugt. Die darin enthaltenen Artikel werden hier angezeigt.

Lagerentnahmen zeigen

Über diesen Menüpunkt erhalten Sie die Artikelliste aller erfassten Lagerentnahmen.

Fotos zeigen

Dieser Punkt öffnet die Foto Maske

Zeiten zeigen

Über diesen Menüpunkt werden alle bisher auf diesen Auftrag gebuchten Zeiten aufgeführt.

Zugeord. Dokumente zeigen

Wer viel mit zugeordneten Dokumenten arbeitet, und dessen Bildschirm groß genug ist, kann sich nun zusammen mit dem Auftrag eine Tabelle mit den zugeordneten Dokumenten anzeigen lassen. Die Tabelle wird im unteren Bereich der Maske platziert. Die Auftragsmaske ist nun in der Größe veränderbar, um den Platz für die Tabelle zu schaffen.

Objektadresse

KD-Logbuch

Über diesen Menüpunkt erreichen Sie das Kundendienst-Logbuch. Es ist die gleiche Funktion wie der Knopf ‚Logbuch’.

Berechnete Artikel

Zeigt Ihnen die berechneten Artikel der Objektadresse an. Es ist die gleiche Funktion wie der Knopf ‚Rg.-Artikel’.

Dokumente

Über diesen Menüpunkt erreichen Sie die Dokumentenliste der Objektadresse. In dieser Liste werden alle Dokumente der Baustellenadresse gezeigt.

Liegenschaft aktivieren

Über diesen Menüpunkt aktivieren Sie eine Liegenschaft, sofern der Rechnungsadresse eine Liegenschaft zugeordnet ist. Ansonsten ist dieser Menüpunkt nicht anwählbar. Gibt es mehrere Liegenschaften, erscheint eine Auswahlliste. Bei nur einer Liegenschaft wird diese direkt in die Objektadresse eingetragen.

Adressen gleicher Liegenschaft

Hier werden Ihnen alle Adressen angezeigt, die der gleichen Liegenschaft zugeordnet sind.

Rg-Adresse beim Objekt eintragen (F3)

Wenn bei einer Objektanschrift die Rechnungsadresse hinterlegt ist, wird dieses bei neuen Aufträgen automatisch vorgeschlagen. Wenn eine solche Verknüpfung noch nicht existiert, kann sie ‚Nnebenbei‘ erstellt werden. Interessant ist diese Funktion besonders für Neuanfänger mit konvertierten Adressen.

Kunden Info E-Mail senden

Dieser Punkt öffnet eine E-Mail. Es wird die an die Objektadresse herangezogen

Kunden Info SMS senden

Dieser Punkt öffnet eine SMS. Es wird die an die Objektadresse herangezogen

|

Rechnungsadresse

OP-Liste

Zeigt Ihnen alle Rechnungen der Rechnungsadresse an. Es ist die gleiche Funktion wie der Knopf ‚OP-Liste’.

Dokumente

Mit diesem Menüpunkt erhalten Sie die Dokumentenliste der Rechnungsadresse.

Mieteradressen dieser RG-Adr.

Zeigt Ihnen eine Liste der Mieteradressen der aktiven Rechnungsadresse. Es ist die gleiche Funktion wie der Knopf ‚Mieter’.

Mieteradressen dieser Vers.-Adr.

Zeigt Ihnen eine Liste aller Mieteradressen, die mit der im Feld Rechnungsadresse angezeigten Versandadresse verknüpft ist. Es ist die gleiche Funktion wie der Knopf ‚Versand’.

Liegenschaften dieser RG-Adr.

Zeigt alle Liegenschaften der Rechnungsadresse an. Es ist die gleiche Funktion wie der Knopf ‚Liegen.“.

Eigentümer als RG-Adr. (Strg+F6 )

Wenn Sie diesen Menüpunkt anwählen, wird der Eigentümer als Rechnungsadresse eingetragen.

Kunden Info E-Mail senden

Dieser Punkt öffnet eine E-Mail. Es wird die an die Rechnungsadresse herangezogen

Kunden Info SMS senden

Dieser Punkt öffnet eine SMS. Es wird die an die Rechnungsadresse herangezogen

|

Info

Dieser Menüpunkt zeigt wie in allen Hauptmodulen das Handbuch, die Version und das Erstellungsdatum des Moduls, die Maske für eine Supportanfrage sowie die Internet Fernsteuerung.
