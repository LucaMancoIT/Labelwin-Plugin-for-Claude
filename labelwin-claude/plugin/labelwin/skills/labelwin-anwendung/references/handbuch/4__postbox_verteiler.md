4. Postbox-Verteiler

In die Postbox können Sie beliebig viele Dokumente scannen oder per Drag & Drop ablegen. Die Dokumente können dann von dort aus abgelegt werden. Abgelegt heißt, dass Sie die Pdf beim Kundendienstauftrag hinterlegen können, eine Eingangsrechnung damit erfassen können und den Scann bei einem beliebigen Labelwin-Dokument hinterlegen können. Genauso gut können Sie die Pdf aber auch in die Postbox eines anderen Anwenders verschieben, damit der sie ablegt.

Am Besten stellen Sie sich das wie einen Briefkasten vor, aus dem Sie die Post in verschiedene Fächer legen oder sofort abarbeiten. Im Gegensatz zum Briefkasten werden Sie hier die Dokumente allerdings meist selber ‚einwerfen‘, indem Sie das Dokument scannen

Einrichtung:

Zunächst muss im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Archiveinstellungen> <Scannarchiv> der Pfad der Postbox festgelegt werden. Unter diesem Pfad wird für jeden Mitarbeiter ein spezieller Ordner mit seinem Namen angelegt Wenn Sie die Möglichkeit nutzen wollen, dass jemand Pdf’s / Scanns in dieses Verzeichnis schiebt, muss der Pfad für alle erreichbar sein.

[Bild]

Anwendung:

Die Postbox wird mit der PboxVert.exe gestartet. Richten Sie am Besten eine Verknüpfung auf dieses Programm-Modul ein oder tragen Sie es im Startcenter ein.

[Bild]

[Bild]

1 Verzeichnistyp: Tragen Sie hier, ob die eigene Postbox oder ein anderes Verzeichnis gewählt werden soll.

[Bild]

2 Pfad: Dieser Pfad ist nur sichtbar, wenn Sie den Verzeichnistyp ‚Freie Verzeichnisauswahl‘ gewählt haben. Tragen Sie hier den Pfad der Postbox ein, die Sie anwählen möchten.

[Bild]

3 Dokumentenliste: Hier werden die Dokumente angezeigt, die in der ausgewählten Postbox vorhanden sind.

[Bild]

4 Neues Dokument (F2): Durch Betätigen dieses Knopfes startet das Fenster der Dokumentenanlage. Hier können Sie wie gewohnt die notwendigen Eingaben wie Projekt-Nr., Adresse, Objektadresse usw. vornehmen. Die Dokumentenart ist bereits vorbelegt und kann nicht geändert werden.

[Bild]

5 Neue Eingangsrechnung (F3): Wenn Sie eine Eingangsrechnung als pdf-Datei erhalten, können Sie diese in der Postbox speichern. Markieren Sie dann diese Rechnung und betätigen Sie den Knopf ‚Neue Eingangsrechnung‘. Das Rechnungsausgangsbuch wird gestartet und Sie können wie gewohnt die Eingangsrechnung erfassen. Das entsprechende Dokument ist dann bereits hinterlegt.

[Bild]

6 Neuer Auftrag, Pdf als Scan: Durch Betätigen dieses Knopfes wird zum gewählten Dokument aus der Auswahlliste ein Auftrag angelegt, z.B. zur Nacherfassung eines Notdienstauftrags. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen.

[Bild]

7 Neuer Auftrag, Pdf-Dokument: Durch Betätigen dieses Knopfes wird ein neuer KD-Auftrag angelegt. Das in der Auswahlliste gewählte pdf-Dokument wird im Auftrag als zugeordnetes Dokument abgelegt.

[Bild]

8 Vorh. Auftrag, Pdf als Scan: Durch Betätigen dieses Knopfes wird die gewählte Pdf-Datei einem vorhandenen Auftrag als Bild zugeordnet. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen.

[Bild]

9 An Dokument eines Projekts: Durch Betätigen dieses Knopfes können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im Projekt zuordnen (z. B. zu einer Auftragsbestätigung, zu der Sie nun das unterschriebene Dokument erhalten haben).

[Bild]

10 An Dokument eines Auftrags: Durch Betätigen dieses Knopfes können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im KD-Auftrag zuordnen (z.B. zu einem Lieferschein, zu dem Sie das unterschriebene Dokument vom Kunden erhalten haben).

[Bild] [Bild] [Bild]

11 In andere Postbox (F7): Durch die Wahl dieses Knopfes erhalten Sie eine Auswahl der vorhandenen Postboxen. Durch die Wahl einer Postbox wird unterhalb dieses Knopfes ein weiterer Knopf sichtbar.

[Bild]

12 In Postbox <name> (F8): Dieser Knopf ist nur sichtbar, wenn Sie zuvor eine andere Postbox gewählt haben. Dadurch haben Sie nun die Möglichkeit, direkt Dokumente in diese Postbox zu verschieben.

[Bild]

13 Automatich zeigen: Standardmäßig ist dieses Feld aktiviert, damit die Dokumene sofort angezeigt werden können. Dazu ist jedoch erforderlich dass Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Vorlagen> <Andere Dokumente> <Dokumententypen erfassen> das entsprechende Programm für eine PDF-Datei hinterlegt haben.

14 Datei zeigen: Dieser Knopf ist nur sichtbar, wenn Sie das Feld ‚Automatisch zeigen‘ deaktiviert haben. Sie können sich damit die in der Liste gewählte Pdf-Datei anschauen.

[Bild]

15 Scannprofil: Wenn Sie Dateien in Ihre Postbox scannen möchten, müssen Sie hier ein Scann-Profil auswählen. Die Scann-Profile werden im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Archiveinstellungen> <Scannarchiv> erfasst.

[Bild]

16 Drag & Drop: Wenn Sie vorhandene pdf-Dokumente in Ihrer Postbox hinterlegen möchten, können Sie diese einfach mit gedrückter linker Maustaste auf dieses Feld ziehen. Sobald Sie die Maustaste los lassen, erscheint in Datei in der Dokumentenliste.

[Bild]

17 Scannen F12: Durch Betätigen dieses Knopfes wird der Scanvorgang mit dem aktuellen Scanprofil gestartet.

[Bild] 18 Anzeige Mandant: Wenn Sie das Modul Mandantenversion erworben haben, wird Ihnen hier angezeigt, in welchem Mandanten Sie gerade arbeiten.

[Bild] 19 Ende: Durch Betätigen dieses Knopfes wird die Maske geschlossen.

Die Menüpunkte im Einzelnen:

Datei

Liste aktualisieren F5

Durch Die Wahl dieses Menüpunkts wird die Dokumentenliste aktualisiert.

Umbenennen Strg+U

Durch die Wahl dieses Menüpunkts können Sie eine in der Liste markierte Datei umbenennen. Diese Funktion ist nur sinnvoll, wenn Sie die Datei nicht selbst ablegen wollen, sondern jemandem in seine Postbox schieben wollen. Dann kann es sinnvoll sein, der Datei zuvor einen passenden Namen zu geben.

Löschen

Durch die Wahl dieses Menüpunkts können Sie aus der Auswahlliste das markierte Dokument löschen.

Verweis auf Pfad speichern

Hier können Sie den Verzeichnispfad, den Sie über den Verzeichnistyp ‚Freie Auswahl‘ eingetragen haben, speichern. Damit kann z. B. der Buchhalter seine eigenen Verzeichnispfade speichern, die für niemand anderen sichtbar sind.

Verweis auf Pfad löschen

Hiermit können Sie den gespeicherten Verzeichnispfad löschen. Damit wird lediglich der Eintrag in der Auswahlliste gelöscht, nicht jedoch der Pfad selbst.

Mandant wechseln

Durch die Wahl dieses Menüpunkts können Sie den Mandanten wechseln. Der Menüpunkt ist nur sichtbar, wenn Sie das Modul Mandantenversion erworben haben.

Ablage

Neues Scan-Dokument F2

Durch die Wahl dieses Menüpunkts öffnet sich die Dokumentenanlage. Es ist die gleiche Funktion wie der Knopf ‚Neues Dokument F2‘

Neue Eingangsrechnung F3

Durch die Wahl dieses Menüpunkt können Sie eine neue Eingangsrechnung erfassen. Das markierte Dokument wird dann diesem Eintrag zugeordnet. Es ist die gleiche Funktion wie der Knopf ‚Neue Eingangsrechnung F3‘

Neuer KD-Auftrag mit Pdf als Scan F4

Durch die Wahl dieses Menüpunkts wird zum gewählten Dokument aus der Auswahlliste ein Auftrag angelegt, z.B. zur Nacherfassung eines Notdienstauftrags. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen. Es ist die gleiche Funktion wie der Knopf ‚Neuer Auftrag, Pdf als Scan‘

Neuer Auftrag, Pdf-Dokument Strg + F4

Durch die Wahl dieses Menüpunkts wird ein neuer KD-Auftrag angelegt. Das in der Auswahlliste gewählte pdf-Dokument wird im Auftrag als zugeordnetes Dokument abgelegt. Es ist die gleiche Funktion wie der Knopf ‚Neuer Auftrag, Pdf-Dokument‘

Vorhandener Auftrag, Pdf als Scan Umschalt + F4

Durch die Wahl dieses Menüpunkts wird die gewählte Pdf-Datei einem vorhandenen Auftrag als Bild zugeordnet. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen. Es ist die gleiche Funktion wie der Knopf ‚Vorh. Auftrag, Pdf als Scan‘

An Dokument eines Projektes als Scan F6

Durch die Wahl dieses Menüpunkts können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im Projekt zuordnen (z. B. zu einer Auftragsbestätigung, zu der Sie nun das unterschriebene Dokument erhalten haben). Es ist die gleiche Funktion wie der Knopf ‚An Dokument eines Projektes‘

An Dokument eines Auftrages als Scan Umschalt + F6

Durch die Wahl dieses Menüpunkts können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im KD-Auftrag zuordnen (z.B. zu einem Lieferschein, zu dem Sie das unterschriebene Dokument vom Kunden erhalten haben). Es ist die gleiche Funktion wie der Knopf ‚An Dokument eines Auftrages‘

Verschieben in andere Postbox F7

Durch die Wahl dieses Menüpunkts können Sie eine andere Postbox wählen. Es ist die gleiche Funktion wie der Knopf ‚In andere Postbox (F7)‘

Verschieben in zuletzt genutzte Postbox F8

Durch die Wahl dieses Menüpunkts werden die markierten Dokumente in die Postbox geschoben, die Sie zuvor ausgewählt haben. Es ist die gleiche Funktion wie der Knopf ‚In Postbox <name> (F8)‘

Hinzufügen

Scannen mit Profilfrage F11

Durch die Wahl dieses Menüpunkts öffnet sich das Fenster mit den Scanprofilen. Nach der Wahl eines Scanprofils können Sie die Dokumente wie gewohnt einscannen.

Scannen F12

Durch die Wahl dieses Menüpunkt wird der Scanvorgang direkt gestartet, ohne dass eine Nachfrage zum Profil erfolgt. Es ist die gleiche Funktion wie der Knopf ‚Scannen F12‘
