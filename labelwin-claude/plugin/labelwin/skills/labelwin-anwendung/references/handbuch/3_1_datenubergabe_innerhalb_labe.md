3.1 Datenübergabe innerhalb Labe

Die Daten können innerhalb des Label-Systems automatisch in Kundendienstrechnungen und Projektdokumente übernommen werden.

1. Kundendienstrechnung:

Bei der Rechnungsschreibung ist das Ankreuzfeld ‚Zeitbuchungen übernehmen’ als Vorgabe schon gesetzt, so dass die gebuchten Zeiten als Artikelpositionen übernommen werden.

[Bild]

Es findet keine Verdichtung der Daten statt, sondern jede Zeitbuchung erzeugt eine Position. Bei Bedarf kann über die Funktion ‚Gleiche Artikel zusammenfassen’ (Menü Option) eine Verdichtung durchgeführt werden. Wenn in Ihren Texten der Monteurname und das Datum eingetragen wird, ist eine Verdichtung unsinnig.

Bei einer erneuten Aktivierung der Rechnung über den Kundendienstbereich erfolgt die Warnung, dass ggf. Daten erneut übernommen werden.

2. Projektbereich:

In der Maske der Dokumentenerstellung kann unter dem Menüpunkt ‚Vorlagen’ eine Übernahme der für das Projektzeiten erfolgen.

[Bild]

Es werden nur alle Daten des Projektes übertragen, zu dem das aktive Dokument gehört. Es besteht die Möglichkeit alle oder nur die mit dem Kennzeichen „Regie“ versehenen Buchungen zu übernehmen.

[Bild]

Bei der Übernahme wird ein Kennzeichen gesetzt, so dass Buchungen in der Regel kein weiteres Mal übernommen werden
