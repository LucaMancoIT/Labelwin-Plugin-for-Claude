Matrix - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Matrix

Andere Tabelle

Hierdurch wählen Sie eine andere Tabelle. An dieser Stelle ist es auch möglich, die Erstellung einer neuen Tabelle anzuwählen.

Änderung speichern

Wenn Sie im Erstellmodus einer Tabelle sind, so können Sie durch diesen Menüpunkt die Speicherung auslösen. Beim Verlassen der Tabellenauswahl oder bei der Wahl einer anderen Tabelle wird die Speicherung ohnehin abgefragt.

Aufräumen Gruppen

Durch die Wahl dieses Menüpunktes haben Sie die Möglichkeit, nicht benutzte Gruppen zu löschen. Sie werden allerdings vor dem Löschen noch einmal gefragt, ob Sie die nicht benutzten Gruppen löschen möchten.

Artikel prüfen

Hier wird in allen Tabellen geprüft, ob die hinterlegten Artikel existieren. Der Durchlauf kann nicht abgebrochen werden. Während der Suche erfolgt keine Anzeige. Nicht existierende Artikel werden im Modus Tabelle erstellen/ändern in blau dargestellt.

Beenden

Durch Wahl dieses Menüpunktes schließen Sie die Tabellenmaske.

|

Optionen

Neue Gruppe einbinden

Wenn Sie den Erstellmodus einer Tabelle aktiv haben, so können Sie hier die Erstellung einer neuen Gruppe erreichen. Diese Funktion wird automatisch gestartet, wenn Sie eine komplett neue Tabelle anlegen.

Vorhandene Gruppe einbinden

Hierdurch erreichen Sie, dass auf einer Tabelle eine bereits vorhandene Gruppe eingetragen wird. Gruppen sind mehrfach verwendbar. So ist es z. B. möglich, eine Gruppe für eine Rohrauswahl in einer Heizkörpertabelle und einer Sanitärtabelle zu verwenden.

Artikelaufruf starten

Durch die Wahl dieses Menüpunktes starten Sie den Artikelaufruf des hinterlegten Kataloges. Über die Eingabe eines Suchbegriffs werden dann in der Liste die für den Suchbegriff gefundenen Artikel des Kataloges angezeigt und ein Artikel kann ausgewählt werden.

Artikel zeigen

Durch die Wahl dieses Menüpunktes werden die Artikelstammdaten des markierten Artikels angezeigt.

Tabelle erstellen/ändern

Durch die Wahl dieses Menüpunktes wird der Bearbeitungsmodus gestartet bzw. beendet.

Katalognummer ändern

Diesen Menüpunkt benötigen Sie, wenn Sie aus den Vorlagen eine Tabelle kopiert haben. Standardmäßig verweisen unsere Vorlagentabellen auf den Katalog 9 und sind der GC-Gruppe angepasst. Hier haben Sie dann die Möglichkeit, den Verweis auf die Ihren GC-Katalog zu ändern.

|

Gruppe bearbeiten

Diese Funktion ist nur dann anwählbar, wenn Sie sich im Erstell- und Änderungsmodus befinden. Sie erreichen das folgende Menü auch, indem Sie im Erstellmodus die rechte Maustaste betätigen.

Zeile löschen

Die Zeile mit der gerade aktiven Gruppenzelle wird entfernt.

Zeile anhängen

An die gerade aktive Gruppe wird eine weitere Zeile angehängt.

Zeile einfügen

Es wird in die gerade aktive Gruppe unterhalb der markierten Stelle eine Zeile eingefügt.

Spalte löschen

Die Spalte mit der gerade aktiven Zelle wird aus der Gruppe entfernt.

Spalte anhängen

An die gerade aktive Gruppe wird eine weitere Spalte angehängt.

Spalte einfügen

Es wird in die gerade aktive Gruppe nach der markierten Stelle eine Spalte eingefügt.

Spaltenbreite ändern

In der Tabellenauswahl war früher die Anzeigebreite der Spalten unveränderbar. Damit musste man die Beschreibung eventuell abkürzen, so dass sie ggf. unverständlich wurde. Die Breite kann nun für jede Tabelle individuell festgelegt werden.

Menü entfernen

Das Menü wird geschlossen

|

Gruppeneinträge

In dieser Liste sind alle vorhandenen Gruppen der Tabelle eingetragen. Um an eine bestimmte Gruppe sehr schnell zu gelangen, kann diese über dies Menü gewählt werden. Die gleiche Funktion wird erreicht, indem Sie im Aufrufmodus die rechte Maustaste betätigen.

|

Vorlagen deaktivieren

Durch die Wahl dieses Menüpunktes kehren Sie wieder zu den bisherigen Tabellen zurück.

Vorlagen kopieren

Die Menüpunkt nutzen Sie, wenn Sie eine Tabelle in den ‚normalen’ Bereich übernehmen möchten. Damit wird nur die gerade aktive Tabelle kopiert. Zuvor oder danach sollten Sie die hinterlegte Katalognummer ändern. Dazu wählen Sie den Menüpunkt <Optionen> <Katalognummer ändern>. Unsere Vorlagetabellen verweisen auf den Katalog 9. Setzen Sie den Verweis auf Ihren GC-Katalog. Wenn Sie nicht mit GC arbeiten, so können Sie unsere Tabellen selbst auf den Großhändler Ihrer Wahl umsetzen. Dazu aktivieren Sie den Bearbeitungsmodus und rufen die Artikel nacheinander auf.
