7.19 Usereinstellung

Um für einen anderen User Einstellungen vornehmen zu können, können Sie diesen User unter diesem Menüpunkt eintragen. Beachten Sie jedoch, dass Sie z.B. keine Drucker-Vorgaben setzen können, wenn diese nicht auch auf dem aktiven Rechner eingerichtet sind. Alle Einstellungen, die die Hardware betreffen, können hier nicht gemacht werden.
