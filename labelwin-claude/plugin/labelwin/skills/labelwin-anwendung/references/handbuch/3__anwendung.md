3. Anwendung

Nach der erfolgreichen Einrichtung können Sie aus einem x-beliebigen Modul heraus die Druckausgabe als PDF-Datei im Labelwin hinterlegen.

|

[Bild]

|

Das Programm PDFAblag.exe startet automatisch nach der Druckausgabe und bietet folgende Möglichkeiten an:

1) Neuer Auftrag: Anlage eines neuen Kundendienstauftrages mit der PDF-Datei als ‚Zugeordnetes Dokument’

2) Neues Dokument: Ablage als neues Dokument in einem Projekt

3) Speichern: Speichern der PDF in einem beliebigen Verzeichnis mit frei zu bestimmenden Namen

4) Anzeigen: Anzeige der PDF-Datei mit einem PDF-Reader

5) E-Mail: Email mit Dateianhang der PDF-Datei

6) Abbruch: Abbruch (die gerade erzeugte PDF-Datei wird wieder gelöscht)

Optionen (Achtung: für beide Optionen muss PDFTK installiert sein)

7) Folie hinterlegen: Es besteht die Möglichkeit der erzeugten PDF-Datei eine Folie zu hinterlegen. Besonders interessant ist diese Funktion, wenn man Druckformulare ohne Firmenlogo verwendet, dem Kunden aber eine PDF mit seinem Briefpapier zukommen lassen möchte.

Um in dieser Maske auf eine Folie zugreifen zu können, muss eine PDF-Datei (z.B. vom Briefpapier) erzeugt werden und in einem fest definierten Unterordner von Labelwin abgelegt werden. Der Zielordner dieser Datei lautet z.B. L:\labelwin\Vorlage\layer\..

Damit aus der erzeugten PDF und der gewählten Folie eine PDF erstellt werden kann, wird das Programm PDFTK benötigt. Die Einrichtung können Sie unter PDFTK einrichten nachlesen.

8) KD-Scan anhängen: Dieses Ankreuzfeld erscheint immer dann, wenn es sich um eine Kundendienstrechnung handelt und der Arbeitsbericht mit unserem Modul Scan-Archiv hinterlegt wurde. Bei gesetztem Kreuz wird der Arbeitsbericht an die aktive PDF angehängt (siehe unten).

8) Kundendienst Rechnung mit KD-Scan

Beim Drucken von Rechnungen zu KD-Aufträgen kann die PDF-Datei des Auftrages mit an die Rechnungs-Datei angehängt werden. Dies funktioniert auch, wenn der KD-Auftrag Folgeaufträge hat.

Es werden automatisch auch alle PDF-Dateien von vorhandenen Folgeaufträgen mit angehängt, wenn das Kreuz bei "KD-Scan anhängen" gesetzt wird (siehe Screenshot oben)..

Voraussetzung für ein erfolgreiches Anhängen der KD-Scans ist eine erfolgte Installation des kostenlosen Tools PDFTK. Die Einrichtung können Sie hier nachlesen: PDFTK einrichten

Hinweis: Wenn Sie direkt aus der Druckmaske heraus über die Hinterlegung "als Email" arbeiten, werden ebenfalls alle PDFs angehängt, wenn der Haken auch bei "KD-Bericht" markiert bleibt. Das Verhalten ist also auf beiden Wegen identisch.
