3. Erfassung

Bevor wir im Folgenden die Erfassung im Detail erklären, einige grundsätzliche Anmerkungen:

Die Erfassung erfolgt von oben nach unten. Die nächste Ebene kann erst erfasst werden, wenn die vorige gespeichert wurde. Die folgenden Ebenen können jedoch bis zur Anlage übersprungen werden, wenn Sie einen Haken bei dem Feld ‚Anlagen direkt bearbeiten’ setzen.

Um Ihnen Tipparbeit zu ersparen, werden manche Informationen auf die jeweils nächste Ebene ‚vererbt’. Dort können sie zwar verändert werden, aber häufig werden sie wohl identisch bleiben. Eine solche Vererbung finden Sie z.B. bei den auf jeder Ebene zu hinterlegenden Adressen, den Zusatzinformationen und den Wartungsperioden.

Bei den kalkulierten Arbeitszeiten erfolgt eine Vererbung in der anderen Richtung. Die bei dem jeweiligen Anlagenteil zu hinterlegenden Zeiten werden für die nächsthöhere Ebene aufaddiert und dort in einem Feld ‚Errechnete Zeit’ gezeigt. Allerdings kann die Zeit auf einer Ebene verändert werden, da die einfache Summierung der Teilzeiten ggf. nicht passt. Ein Beispiel: Eine Anlage besteht aus einem Register von 10 gleichen Bauteilen. Wenn nun ein Bauteil standardmäßig eine Wartungszeit vom 10 Minuten hat, so wird die Wartung aller 10 Bauteile wahrscheinlich schneller als 100 Minuten erfolgen, weil immer das gleiche Werkzeug verwendet wird und sich eine gewisse Routine einstellt. Statt nun bei jedem Unterelement eine niedrigere Zeit einzutragen setzen Sie einfach die Zeit der Anlage auf 90 Minuten. Damit wird dann automatisch die Zeit für alle Unterelemente entsprechend reduziert, in diesem Fall also auf 9 min. Natürlich entstehen dabei in der Praxis total krumme Zeiten, aber wenn man den Hintergrund kennt, ist eine Wartungszeit von 8,67 min kein Problem. Es geht schließlich um die Vorkalkulation!

Bei den Zusatzinformationen handelt es sich um 10 Felder, deren Beschriftung und Inhalt Sie selbst festlegen können. Diese Felder können als Auswahlliste oder freies Eingabefeld gestaltet werden. Die Festlegung erfolgt im Programmmodul EINSTELLUNGEN unter den Menüpunkten Programmbereiche – Anlagedaten- TGM – TGM-Zusatzfelder
