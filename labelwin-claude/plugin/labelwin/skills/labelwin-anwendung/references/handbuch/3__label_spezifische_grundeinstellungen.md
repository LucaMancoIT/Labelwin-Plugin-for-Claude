3. Label-spezifische Grundeinstellungen

Im Modul Einstellungen muss jeder Nutzer unter dem Menüpunkt <Programmbereiche> <Elo-Grundeinstellungen> den Archivnamen eintragen. Der Archivname ist mandantenabhängig. Wichtig ist, dass Sie beim Archivnamen exakt das gleiche eintragen, wie bei der Anlage des Archivs im Elo. Auch die Groß-/Kleinschrift ist zu beachten.

Wenn Sie mit mehreren Mandanten arbeiten, so sollte der Archivname für jeden Mandant unterschiedlich sein. Allerdings kann die Grundversion von Elo nur mit 5 Archiven arbeiten, in denen jeweils 100.000 Dokumente abgelegt werden können. Für einen normalen Betrieb sollte das für viele Jahre ausreichend sein.

[Bild]

Auf der linken Seite der Maske können Sie jetzt die Standardregister, die immer automatisch angelegt werden erweitern oder verändern. Siehe Bereich Register für die Anlage von Dokumenten aus Labelwin

Im rechten Teil können Sie die automatische Ablage im ELO aktivieren.

Für jede Dokumentenart können Sie hier unabhängig von den Standardregistern ein Ablageregister angeben. Alle Drucke, denen ein solches Register hinterlegt wird, werden beim Drucken automatisch als Kopie im Elo abgelegt. Es werden dabei die gleichen Regeln verwendet, wie bei der Neuanlage eines ELO-Dokumentes. Die ELO-Ablage erfolgt bei jedem Druck, der nicht auf den Bildschirm erfolgt, automatisch. Dieser Vorgang wird bei mehrfachen Druck auch mehrfach durchgeführt, so dass auch im ELO eine Historie der Ausdrucke existiert. Damit ist es dann möglich, dem Kunden ein Exemplar erneut auszudrucken ( Er hat seine Rechnung unauffindbar abgelegt), ohne im Labelwin einen Druckvorgang starten zu müssen. Sie drucken dann das Dokument aus ELO heraus.
