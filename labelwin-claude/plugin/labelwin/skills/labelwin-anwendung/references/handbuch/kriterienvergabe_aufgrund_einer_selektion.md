Kriterienvergabe aufgrund einer Selektion

Ähnlich dem zuvor beschriebenen Verfahren können Sie auch in allen Adressen aufgrund einer Selektion ein Kriterium eintragen lassen. Auf den ersten Blick scheint dieses unsinnig, weil die Kriterien ja letztlich nur der Suche dienen und man sie ja über eine Selektion herausfiltern muss, um das Kriterium zu vergeben. Der Sinn liegt darin, dass man über ein Kriterium sehr schnell eine einzelne Adresse finden, über die Selektionen dagegen relativ aufwändig nur eine Liste von Adressen ausgeben kann.

Grenzen Sie die entsprechenden Adressen mit der Selektion ein, gehen dann auf die ‚Bildschirmausgabe’ und wählen den Menüpunkt <Bearbeiten> <Kriterium vergeben> an. In der dann erscheinenden Maske wählen Sie das Kriterium aus, wobei Sie ggf. auch zuvor ein neues definieren können.
