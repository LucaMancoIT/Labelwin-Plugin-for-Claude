2. Digitale Bauakte eines Projektes einrichten

|

Wichtig: Bevor die digitale Bauakte genutzt werden kann, müssen Register eingerichtet sein!

|

1. Register für dieses Projekt aktivieren

-

Rufen Sie das Projektdatenblatt auf und klicken auf die Schaltfläche <Register>. In dem sich öffnenden Fenster werden im linken Feld die von Ihnen zuvor angelegten Register angezeigt. Verschieben Sie die Register, die Sie in diesem Projekt verwenden möchten, mit den Pfeiltasten in das rechte Feld.

-

Im Rechten Feld "Zugewiesene Projektregister" setzen Sie bei dem Register der freigegeben werden soll einen Haken unten Bauakte.

-

Bestätigen Sie mit <OK, speichern>.

-

Verlassen Sie das Projektdatenblatt mit einem Klick auf <OK>.

2. Einen neuen Nutzer anlegen

Ein Nutzer der digitalen Bauakte wird angelegt indem im Adressmodul einem Ansprechpartner Zugangsdaten zugeteilt werden.

-

Öffnen Sie das Adressmodul und rufen Sie die Adresse der Partei, der Sie Zugang zur digitalen Bauakte geben möchten, auf.

|

[Bild]

|

-

Öffnen Sie den Reiter Telefon um die Ansprechpartner dieser Adresse aufzurufen.

-

Stellen Sie sicher, dass eine aktive E-Mail-Adresse des Ansprechpartners bzw. der Ansprechpartnerin im E-Mail-Feld eingetragen ist.

-

Tragen Sie im Feld Benutzername Digitale Bauakte den Benutzernamen mit dem diese Person sich in der digitalen Bauakte anmelden kann ein. Dieser muss eindeutig sein, es kann keine zwei Nutzer mit dem selben Namen geben.

-

Bestätigen Sie den Vorgang mit einem Klick auf <Speichern>.

-

Sobald diesem Benutzer ein Dokument in der digitalen Bauakte freigegeben wird, wird eine Einladung zum ersten Log-In an diese E-Mail-Adresse gesendet. Beim ersten Log-In muss der Anwender oder die Anwenderin sich selbst ein Passwort für zukünftige Log-Ins einrichten.

|

3. Das Projekt für die digitale Bauakte freigeben

-

Klicken Sie in dem betreffenden Projekt auf die Schaltfläche <Datenblatt>.

-

Hier klicken Sie auf die Schaltfläche <Digitale Bauakte>.

-

Stellen Sie sicher, dass oben rechts in dem sich öffnenden Fenster ein Haken bei Freigabe Digitale Bauakte gesetzt ist.

-

Bestätigen Sie mit einem Klick auf <Ende mit Speichern>.

|

4. Einen Nutzer für ein Projekt freigeben

-

Klicken Sie in dem betreffenden Projekt auf die Schaltfläche <Datenblatt>.

-

Hier klicken Sie auf die Schaltfläche <Digitale Bauakte>.

-

Wählen Sie aus der Liste der angelegten Nutzer unten rechts den Nutzer aus, den Sie diesem Projekt zuteilen möchten und klicken auf <Freigeben>.

-

Bestätigen Sie mit einem Klick auf <Ende mit Speichern>.

|

5. Ein Dokument freigeben

-

Rufen Sie im Projektmodul das Projekt auf, dessen Dokument Sie freigeben möchten.

-

Stellen Sie sicher, dass das betreffende Projekt für die digitale Bauakte freigegeben ist.

-

Stellen Sie sicher, dass das betreffende Dokument einem Register zugeordnet ist, der für die digitale Bauakte freigegeben ist. Falls das Dokument noch keinem freigegebenen Register zugeordnet ist, klicken sie mit der rechten Maustaste auf das Dokument und wählen <Register zuordnen>. In dem sich öffnenden Fenster sind alle Register, die für die digitale Bauakte freigegeben sind mit einem "DB" markiert.

-

Klicken Sie mit der rechten Maustaste auf das Dokument und dann auf <Freigabe digitale Bauakte>. Wenn Sie mehrere Dokumente gleichzeitig freigeben möchten, markieren Sie diese und klicken dann mit der rechten Maustaste darauf um dieses Fenster zu öffnen.

-

Mit einem Haken bei Dokument ist für alle Projekt-Beteiligen zugelassen geben Sie allen Projektbeteiligten Zugang zu dem Dokument. Dabei ist zu bedenken, dass auch nachträglich für das Projekt freigeschaltete Nutzer Zugriff auf dieses Dokument haben werden.

-

Sie können einzeln bestimmen welche Nutzer auf das Dokument zugreifen können, indem Sie diese Nutzer aus den Projekt-Beteiligten heraus mit den Pfeiltasten in das rechte Feld verschieben.

-

Bestätigen Sie mit <OK>.

|

[Bild]

|

Sie können einem Nutzer das Zugriffsrecht für ein Dokument entziehen indem Sie ihn aus dem rechten Feld entfernen oder den Haken bei "Dokument ist für alle Projekt-Beteiligen zugelassen" entfernen, falls dieser gesetzt ist.
