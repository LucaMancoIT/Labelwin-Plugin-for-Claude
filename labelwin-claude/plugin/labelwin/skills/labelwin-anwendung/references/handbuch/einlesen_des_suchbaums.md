Einlesen des Suchbaums

Wie bereits oben erwähnt, kann der Suchbaum auch aus einer Datei eingelesen werden. Dies geschieht im Katalogmodul unter den Menüpunkten ‚Einlesen, Suchbaum’

[Bild]

Hier können 3 Formate eingelesen werden:

1) Daten im Labelformat

Diese Daten können erzeugt werden, indem Sie im Suchbaum an einen beliebigen Knoten markieren und die Menüpunkte ‚Option, ebene exportieren’ anwählen. Die Möglichkeit wurde geschaffen, damit sich Labelwin-Anwender ggf. austauschen können oder wir Ihnen einen neuen Suchbaumbereich zukommen lassen können.

2) Der Suchbaum von TGP und EDS (wird auf CD mit ausgeliefert)

Die Datei befindet sich auf der Cd von TGP oder EDS und wird immer komplett eingelesen werden. Da eigene Änderungen beim Suchbaum einspielen verloren gehen, sollten Sie im TGP / EDS -Bereich keine Änderungen vornehmen.

3) Der mit Excel erzeugte KD-Mobil Suchbaum

Damit der für die mobile Lösung erzeugte Suchbaum auch im Büro verwendet werden kann, können Sie hier die CSV-Datei einspielen. Allerdings werden dann alle in der CSV vorhandenen Artikel zu einem Katalog zugeordnet.
