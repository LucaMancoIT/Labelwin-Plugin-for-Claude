Artikelinfo

Bevor es die IDS-Shop Schnittstelle gab, hatten erste Händler einen direkten Zugriff auf Artikeldaten ermöglicht. Heutzutage wird diese Verfahrensweise quasi nicht mehr genutzt.

Hinweis: Die IDS-Schnittstelle enthält eine Artikelinfo Funktion. Die Beschreibung finden Sie im Kapitel IDS-Shop Anwendung.

Diese in der EDV Deeplink genannte Möglichkeit bedeutet, dass Sie mit einem Internetzugang nicht auf der Startseite, sondern tief im System landen. Hier geht es darum, mit einem Artikel aus Labelwin heraus direkt an die beim Lieferanten gespeicherten Informationen gelangen. Diese Information kann die Verfügbarkeit, der aktuelle Preis, ein Bild, eine Maßzeichnung usw. sein. Was und wie es dort angeboten wird, hängt vom Lieferanten ab..

[Bild]

Die URL-Adresse können Sie nur von Ihrem Lieferanten erfahren.

Beispiel GC-Gruppe:

http://www.gconline.de/artd/?[artnr]

Beispiel R+F Gruppe:

https://www.ruf-online.de/fis/fisesales/login_auto.htm?c_user=@username@&c_pwd=@password@f&c_matnr=[artnr]

Ihnen stehen hier 3 Schlüsselworte zur Verfügung, die beim Absetzen des Kommandos vom Programm getauscht werden:

[artnr] = Die Artiklenummer

@username@ = Ihr Benutzername ebim GH

@password@ = Ihr dazu passendes Passwort
