Die Auswertungsmaske

[Bild]

[Bild]

1 Makro: In dieser Liste finden befinden sich selbst erstellte Makros. Wenn Sie hier ein bestimmtes Makro anwählen, so wird die abgespeicherte Selektion aktiviert. Ein selbst erstelltes oder verändertes Makro wird unter dem Menüpunkt <Makro> <Makro speichern> oder <Makro speichern als neu> dauerhaft abgelegt.

[Bild]

2 Auswertungsdaten: Entscheiden Sie hier, ob Sie vorhandene Daten verwenden oder neue Auswertungsdaten erzeugen möchten. Wenn Sie mit Kostenstellen arbeiten und diese mit ausgewertet haben möchten, müssen Sie dieses Feld aktivieren. Beim Ausdruck kann mit bestimmten Formularen nach Kostenstellen sortiert werden.

Bei der Erzeugung der Auswertungsdaten kann ein weiteres Datum an der Oberfläche eingesetzt werden, mit dem im Erzeugungsfilter automatisiert eine weitere Eingrenzung möglich ist. Die Auswirkung ist die gleiche, als wenn man im Erzeugungsfilter eine Eingrenzung mit Datum direkt eingibt. Das hat aber den Nachteil, dass der Filter jedes Mal angepasst werden muss.

Im Filter setzt man einen Vergleichswert mit …datum = Zusatzdatum ein und bei jeder Eingrenzung wird das Wort ‚Zusatzdatum‘ durch das an der Oberfläche eingesetzte Datum ersetzt.

[Bild]

[Bild]

[Bild]

3 Auswertung: In der Liste werden Ihnen alle zuvor erzeugten Auswertungsläufe angeboten. Wenn Sie unter ‚Auswertungsdaten‘ <Auswertungs-Daten erzeugen> gewählt haben, können Sie entweder eine komplette neue Auswertung starten oder einen Filter setzen, so dass nur die Projekte ausgewertet werden, auf die der Filter zutrifft.

[Bild]

4 Auswertung löschen: Durch Betätigen dieses Knopfes kann eine in der Liste (Nr. 3) gewählte Auswertung gelöscht werden.

[Bild]

5 SQL zeigen: Durch Betätigen dieses Knopfes wird Ihnen der SQL für die zuvor gewählte Auswertung angezeigt.

[Bild]

[Bild]

6 Von Datum bis Datum: Wenn Sie die Auswertung auf einen bestimmten Zeitraum eingegrenzt haben, wird Ihnen dieser hier anzeigt.

[Bild]

7 Ausgabe: Entscheiden Sie hier, ob Sie die Ausgabe als Formular oder Excel-Tabelle erhalten möchten.

[Bild]

8 Datenfilter: In dieser Liste finden sich fertig hergestellte Suchschemen. Wenn Sie hier ein bestimmtes Schema anwählen, so wird die abgespeicherte Selektion aktiviert.

[Bild]

9 Filter ändern: Über diesen Knopf können Sie die Selektion ggf. ergänzen oder anderweitig verändern.

[Bild]

10 Summen von Unterprojekten dem Hauptprojekt zuschlagen: Aktivieren Sie dieses Feld, wenn Sie die Summen der Unterprojekte den Hauptprojekten zuordnen möchten.

[Bild]

11 Sortierung nach: Geben Sie hier die Sortierung vor, wie sie auf dem Ausdruck erscheinen soll. In den Auswahlboxen werden Ihnen die Bereiche angezeigt, die Sie auswählen können.

[Bild]

12 Formular: Wählen Sie aus der Liste das Druckformular aus, auf dem Ihre Daten ausgegeben werden sollen. Falls Sie unter Ausgabe ‚Excel‘ gewählt haben, können Sie hier die Excel-Vorlage wählen, die mit Daten gefüllt werden soll.

[Bild]

13 Report aktualisieren: Durch Betätigen dieses Knopfes kann das gewählte Formular aktualisiert werden. Dieses ist manches Mal erforderlich, wenn Formulare geändert wurden, z.B. durch Einfügen von weiteren Datenbankfeldern.

[Bild]

14 Report versenden: Falls Sie Änderungswünsche zu dem gewählten Formular haben, können Sie durch Betätigen dieses Knopfes dieses Formular direkt per Email zu uns senden. Bitte bedenken Sie, dass für Sie individuell angepasste Formulare kostenpflichtig sind.

[Bild]

15 OK ausgeben: Durch Betätigen dieses Knopfes wird die Ausgabe gestartet.

[Bild]

16 Ende: Durch Betätigen dieses Knopfes wird die Selektionsmaske geschlossen. Falls Sie ein kompliziertes Suchschema zusammengestellt haben, denken Sie bitte daran, dass Sie es rechtzeitig abspeichern.
