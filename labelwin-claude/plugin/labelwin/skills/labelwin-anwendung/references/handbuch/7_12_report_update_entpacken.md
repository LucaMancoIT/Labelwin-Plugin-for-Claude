7.12 Report Update entpacken

Wenn wir für Sie Reports angepasst oder geändert haben, erhalten Sie von uns eine Datei mit dem Namen repakt.zip. Damit Ihre Reports an die richtige Stelle kommen und Sie sie auch verwenden können, muss diese Datei entpackt werden. Kopieren Sie die Datei dazu ins Verzeichnis labelwin\update. Über diesen Menüpunkt wird die Datei entpackt und die Reports in das richtige Verzeichnis kopiert.
