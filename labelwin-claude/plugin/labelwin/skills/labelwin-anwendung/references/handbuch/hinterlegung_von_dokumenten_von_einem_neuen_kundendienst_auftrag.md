Hinterlegung von Dokumenten von einem neuen Kundendienst-Auftrag

Wenn Sie z.B. bei einem Kundengespräch den unterschriebenen Auftrag erhalten haben und dieses Dokument dann im Elo gescannt wurde, können Sie dieses Dokument direkt einem neuen Kundendienstauftrag zuordnen. Wählen Sie dazu in der ELO Postbox das entsprechende Dokument aus und betätigen Sie den Knopf ‚4‘. Es wird automatisch ein neuer Kundendienstauftrag erzeugt und das Dokument ist dann diesem Auftrag hinterlegt.
