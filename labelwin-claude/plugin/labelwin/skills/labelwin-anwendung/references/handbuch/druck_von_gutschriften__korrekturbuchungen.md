Druck von Gutschriften, Korrekturbuchungen

Seit Anfang 2013 gibt es eine Gesetzesänderung für negative Rechnungen, die allgemein als Gutschrift bezeichnet werden. Es soll jedoch nur noch dann von Gutschrift geredet werden, wenn der Leistungsempfänger das Dokument erstellt, obwohl eigentlich der Leistungserbringer eine Rechnung schreiben müsste.

Beispiel:

[Bild]

Wir können an dieser Stelle keine Empfehlung geben, welche Überschrift bei einer negativen Rechnung zu wählen ist. Bitte sprechen Sie dieses mit Ihrem Steuerberater ab.

Im Labelwin gibt es eine Möglichkeit, die Überschrift für das Dokument bei der Druckausgabe schnell und einfach festzulegen.

Hier gibt es einen Knopf, mit dem die Überschrift gewählt werden kann.

[Bild]

Wenn Sie die Überschrift nicht gewählt haben, wird die Auswahl bei negativen Rechnungen beim Drucken abgefragt. Somit ist sichergestellt, dass Sie es nicht vergessen können, die ‚richtige‘ Überschrift zu wählen.

Die angebotenen Texte können Sie selbst festlegen. Dieses geschieht im Modul EINSTELLUNGEN unter dem Menüpunkt <Prorammbereiche> <Druckausgabe> <Druck-Überschriften>.

Dieses Verfahren gilt übrigens für alle Druckausgaben. So kann man auf diese Art z.B. bei Angeboten auch die Überschrift ‚Kostenschätzung‘ ausdrucken.
