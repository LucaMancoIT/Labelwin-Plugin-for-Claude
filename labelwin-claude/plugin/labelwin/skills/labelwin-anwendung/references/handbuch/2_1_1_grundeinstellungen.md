2.1.1 Grundeinstellungen

Firmen-Einstellungen - Vorgaben für neue Adressen

[Bild]

Bild: Adressen – Vorgaben für neue Adressen

Bei der Neuanlage von Adressen erwartet das Programm einige Eingaben von Ihnen, die Sie an dieser Stelle vorbelegen können. Durch diese Eingaben definieren Sie Ihren Standardfall. Zusätzlich können Sie über das Menü einige Werte für alle vorhandenen Adressen ändern.

|

Hinweis: Wenn Sie mit Musteradressen arbeiten, sind die Vorgaben für neue Adressen (1-8) unwirksam.

1. Kalkulationseinstellung für Projekt: Wählen Sie hier aus der Liste der Kalkulationseinstellungen eine Standardeinstellung aus. Diese Einstellung wird nicht nur für Angebote verwendet, sondern auch bei der Dokumentenerstellung von Rechnungen, Lieferscheinen, Bestellscheinen usw. vorgeschlagen. Wenn eine Rechnung über das Kundendienstmodul entwickelt wird, so wird diese Einstellung nicht verwendet sondern die im nächsten Eingabefeld.

2. Kalkulation Kundendienst-Rg.: Die hier zu wählende Kalkulationseinstellung wird im Kundendienstbereich verwendet. Sie kommt zum Tragen, wenn Sie einen Materialzettel erfassen oder eine Kundendienstrechnung aus einem Kundendienstauftrag heraus beginnen.

3. Zahlungsbedingung Proj.-Rg.: Tragen Sie hier aus der Liste der Zahlungsbedingungen eine Standardeinstellung ein, die für Projektrechnungen verwendet werden soll.

4. Zahlungsbedingung Angebot: Tragen Sie hier aus der Liste der Zahlungsbedingungen eine Standardeinstellung ein, die für Angebote verwendet werden soll.

5. Zahlungsbed. Kundendienst: Tragen Sie hier aus der Liste der Zahlungsbedingungen eine Standardeinstellung ein, die für Kundendienstrechnungen verwendet werden soll.

6. Zahlungsbed. Auftragsbestäti-gung: Tragen Sie hier aus der Liste der Zahlungsbedingungen eine Standardeinstellung ein, die für Auftragsbestätigungen verwendet werden soll.

7. Preisliste Zeitwirtschaft: Die Zeitwirtschaft arbeitet grundsätzlich mit Preislisten, bei denen für die unterschiedlichen Lohngruppen Preise hinterlegt sind. Bei größeren Projekten wird die Preisliste grundsätzlich über das Projekt definiert. Bei Kundendienstaufträgen wird jedoch häufig ein Sammelprojekt genutzt, dessen Preisliste nicht unbedingt die richtige ist. Bei jeder Adresse können Sie eine kundenspezifische Preisliste hinterlegen, die bei der Einbuchung von Kundendienstzeiten verwendet werden soll. Hier wählen Sie die Preisliste, die standardmäßig bei neuen Adressen vorgeschlagen wird.

8. Kundenhistorische Preise setzen: Setzen Sie hier ein Kreuz, wenn Sie mit kundenhistorischen Preisen arbeiten möchten.

9. Ok: Die von Ihnen gewählten Eingaben werden abgespeichert

10. Abbruch: Die Einstellungen werden verworfen und es bleiben weiterhin die bisherigen Einstellungen aktiv.

11. Änderungslauf: Mit diesen Menüpunkten können Sie bei allen Adressen den bisherigen Wert auf den der Vorgabe für neue Adressen umsetzen.

Firmen-Einstellungen - Sonstige Firmeneinstellungen

[Bild]

Bild: Adressen – Sonstige Firmeneinstellungen

1. Max. Länge Debitornr./Kreditornr.: Geben Sie hier die maximale Länge der Debitoren- und Kreditorennummern ein.

2. neue Postregel: Wenn Sie nach der neuen Postregel arbeiten möchten (keine Leerzeile zwischen Straße und Ort), müssen Sie dieses Feld aktivieren.

3. Übernahme Ortsteil-Name: An dieser Stelle können Sie entscheiden, ob Sie den Ortteilnamen übernehmen möchten oder nicht. Wenn Sie es von Fall zu Fall entscheiden möchten, markieren Sie hier ‚Fragen’.

4. weitere Telefonnummern ggf. mit kopieren: Wenn Sie hier ein Häkchen setzen, werden beim Kopieren von Adressen die weiteren Telefonnummern mit kopiert.

5. Mandant für Standardmonteur: Einer Objektadresse kann ein Monteur zugeordnet werden. Für Kunden, die mehr als einen Mandanten mit Labelwin verwalten, kann einer Adresse jedoch nur für einen Mandanten dieser Monteur hinterlegt werden. Hier wird der Mandant festgelegt, für den der Monteur hinterlegt werden soll.

6. Anrede mit Herrn: Da einige Kunden der Meinung sind, dass die Anrede nicht "Herrn" sondern "Herr" lauten müsse, haben wir ein entsprechendes Ankreuzfeld eingeführt. Der Standard ist auf "Herrn" und wer das Kreuz wegnimmt, bekommt künftig bei der Eingabe von "h" den Text "Herr" vorgeschlagen.

Der Vollständigkeit halber wollen wir hier noch erwähnen, dass alle diese Eingabekürzel bei der Adresserfassung anpassbar sind und auch erweitert werden können. So können die Kollegen aus Luxemburg z.B. mit ma den Text ‚Mademoiselle‘ erzeugen. Das geschieht mit dem Editor Notepad (nicht Word nehmen!) in der Datei \labelwin\global.ini unter der Gruppe [adresskuerzel]

1. weitere Anzeige bei der Adressensuche: Wählen Sie hier aus der Liste, welche weitere Anzeige bei der Adressensuche aktiv sein soll. Diese Einstellung ist mandantenabhängig.

Benutzer-Einstellungen - Allgemeines

[Bild]

Bild: Adressen – Allgemeines

1. Vorgabe Drucker Etiketten: Während das Programm, wie alle Windows-Programme, meistens den Standarddrucker vorschlägt, kann hier ein Drucker für den Etikettendruck vorgewählt werden. Da Etiketten nur selten auf dem Standarddrucker ausgedruckt werden, schien uns diese Vorgabe sinnvoll.

2. Label CRM – Aktivieren Knopf startet neues Label CRM: Wenn im Label CRM eine Adresse aktiv ist, werden die damit verbundenen anderen Adressen aufgelistet. Mit den ‚Aktivieren'-Knöpfen wird bei hier nicht gesetztem Schalter die aktive Adresse gewechselt.

Wenn Sie dieses Feld aktivieren, wird stattdessen ein neues Label CRM-Fenster mit der angewählten Adresse geöffnet.
