Dokumenten-Export / Import [16]

Hier geht es um den Austausch von Angeboten, Rechnungen, LV’s zwischen zwei Labelwin-Systemen. Es können hier nur Dokumente auf der Basis von Artikeln übertragen werden.

Auf beiden Systemen muss der gleiche Programmstand installiert sein!

Export

Zum Export wird das zu übertragende Dokument markiert und der Menüpunkt ‚Dokumente’, ‚Dokument exportieren’ oder der mit der rechten Maustaste der Punkt ‚Dokument exportieren‘ angewählt. Oder markieren Sie das Dokument in der Dokumentenliste und wählen Sie dann den Menüpunkt ‚Extern’, ‚Dokument exportieren’.

Bild: Dokument exportieren

Das Programm erzeugt eine Datenbank mit der gleichen Struktur wie unsere fern ausgelagerten Dateien. Unter ‚Pfad + Dateiname’ müssen Sie den Speicherort und den Dateinamen eingeben. Wenn Sie das hier manuell eintragen, achten Sie bitte darauf, dass Sie als Dateiendung .mdb verwenden.

Über den Knopf ‚Durchsuchen’ haben Sie die Möglichkeit, den Speicherort direkt anzuwählen, und in dem sich öffnenden Fenster können Sie den Dateinamen eingeben. Hier wird Ihnen als Dateiendung bereits .mdb schon vorgeschlagen. Wenn Sie dann auf den Knopf ‚Speichern’ drücken, wird die Pfadangabe und der Dateinamen direkt in das Feld geschrieben. Mit OK starten Sie den Export.

Je nach gewählter Option bei ‚Dokument übertragen‘ kann der Text im Hauptrechner weiter bearbeitet werden oder ist blockiert, bis er wieder eingelagert wird.

1. Hauptrechner an Hauptrechner: Bei dieser Wahl wird im exportierenden System keine Registrierung vorgenommen. Der Text kann wie gewohnt weiter bearbeitet werden. Falls der Text nur im Laptop am Wochenende weiter bearbeitet werden soll, sollte Sie diesen Weg nicht wählen.

2. Hauptrechner an Nebenrechner: Hier wird im exportierenden System eine Eintragung vorgenommen, dass der Text exportiert ist und nicht mehr weiterverarbeitet werden kann, bevor er nicht zurückgespielt ist. Diese Methode ist für die Wochenendarbeit auf dem Laptop geeignet.

3. Nebenrechner an Hauptrechner: Dieser Modus muss auf dem Laptop gewählt werden, wenn der Text später wieder an die gleiche Stelle im Hauptrechner gesetzt werden soll.

Falls die Blockade ‚Dokument ist exportiert‘ weggesetzt werden muss, geschieht dies nach markieren des Dokumentes unter ‚Dokumentinfo‘ und dem Menüpunkt ‚Sonderfunktionen‘, ‚Auslagerung löschen‘.

Import

Zum Importieren öffnen Sie das Modul PROJEKTE und gehen Sie nun auf den Menüpunkt ‚Extern’, ‚Dokument importieren’ oder starten Sie das Modul IMPORT. Die Funktion ist bei beiden Möglichkeiten die gleiche.

In dieser Maske wird festgelegt, in welchem Projektordner der Text eingetragen werden soll. Falls es sich um einen Export von Nebenrechner an Hauptrechner handelt, wird das richtige Projekt vorgeschlagen.

Über den Knopf ‚Durchsuchen‘ kann die zu importierende Datei gesucht werden.
