7.5 Datenaustausch per Cloud

[Bild]

Anstatt den Datenaustausch zwischen Zentrale und Notebook per E-Mail vorzu-nehmen, können die Daten auch per Cloud wie z.B. Dropbox übertragen werden. Für die Einrichtung von Dropbox etc. ist Ihr Hardwarebetreuer zuständig.

Im Labelwin muss in der Zentrale im Modul Einstellungen unter dem Menüpunkt <Programm-bereiche> <Kundendienst> <Laptop Grundeinstellungen> zusätzlich das Feld „Auftrag nicht per E-Mail, nur in Verzeichnis kopieren“ aktiviert werden.

Über die Cloud werden die Verzeichnisse auf zwei oder mehreren PC‘s oder Smartphones abgeglichen. Die Verzeichnisstruktur könnte z.B. so aussehen:

L:\dropbox\Laptop1\An Laptop\

In dieses Verzeichnis kommen die von der Zentrale exportierten Aufträge, also die labelnb-Dateien.

L:\dropbox\Laptop1\An Zentrale\

In dieses Verzeichnis kommen alle vom Notebook exportieren Aufträge, also die labelze-Dateien.

In der Zentrale müssen dann die Dateien labelze per Doppelklick oder Statusimport eingelesen werden. Die Beschreibung finden Sie in Kapitel Büroabwicklung

L:\dropbox\Laptop1\Sonstiges\

Dieses Verzeichnis wird - im Unterschied zu den obigen beiden - nicht zwingend benötigt. In dieses Verzeichnis können alle zusätzlichen auszutauschenden Dateien wie z.B. PDF, JPG etc. abgelegt werden, die keinem Auftrag zugeordnet wurden. Denkbar wäre z. B. eine allgemeingültige PDF eines Herstellers.

|

Info: Alle Fremddokumente (PDF, JPG etc.), die über die „Zugeordneten Dokumente“ einem Auftrag hinterlegt sind, werden automatisch ausgetauscht. Dazu ist kein gesonderter Cloud-Ordner erforderlich.

Die Cloud-Dienste lassen sich in der Regel so konfigurieren, dass auf jedem Notebook nicht alle Ordner synchronisiert werden, sondern nur die Ordner des jeweiligen Monteurs.

Im Modul Einstellungen nun für jeden Techniker festgelegt werden, in welchem Verzeichnis die Daten für ihn abgelegt werden sollen. Dazu muss unter dem Menüpunkt <Personal><Personal erfassen> auf der Karteiseite „Zuordnung“ der „Pfad Export“ und „Pfad Import“ eingetragen werden:

[Bild]

Auf dem Laptop muss dann in den Grundeinstellungen das Feld „Auftrag nicht per E-Mail, nur in Verzeichnis kopieren„ aktiviert und der „Kopierpfad Export“ eingetragen werden.

[Bild]

Für jeden Techniker sollte ein eigener Pfad definiert werden, in dem er die erledigten Auftragsdaten ablegt. Innerhalb dieses Monteurpfades empfehlen wir eine weitere Untergliederung in einen Import- und einen Exportpfad

Damit findet der Datenaustausch über das Internet statt. Weitere Einstellungen sind im Labelwin dazu nicht erforderlich.
