Ablage von Eingangsrechnungen, die als Datei vorliegen

Ziehen Sie die PDF-Dateien der Rechnungen in Ihre Postbox.

Markieren Sie eine PDF-Datei und betätigen Sie im Elo auf der Postboxseite den Knopf ‚5’.

Es öffnet sich das Rechnungseingangsbuch und Sie können die Daten der Rechnung wie gewohnt erfassen.

Wenn Sie die Rechnung im Rechnungseingangsbuch speichern, wird automatisch die PDF-Datei aus der Postbox in das Archiv verschoben.

Dieser Vorgang muss für jede Rechnung wiederholt werden.
