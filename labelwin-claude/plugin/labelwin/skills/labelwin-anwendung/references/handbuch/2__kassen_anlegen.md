2. Kassen anlegen

[Bild]

Bild: Kassen ändern und anlegen

Neben dem Anlegen der Kassen erfolgt in diesem Bereich auch die Vergabe der nächsten Belegnummer. Bitte beachten Sie, dass über die Belegnummern keine Prüfung auf doppelte Vergabe stattfindet. Sie müssen also den Aufsatzpunkt immer so setzen, dass die doppelte Vergabe nicht möglich ist.

Das Fibu-Konto wird für die Übergabe an eine Finanzbuchhaltung benötigt und sollte auf jeden Fall eingetragen werden.

Eine Kasse kann nicht mehr gelöscht werden, nachdem eine Buchung auf ihr erfolgt ist.
