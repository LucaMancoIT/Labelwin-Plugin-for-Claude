7.1 Ladenkassen-Protokoll

Über den Menüpunkt <Auswerten> <Auswerten Ladenkasse> erhalten Sie eine Aufstellung aller Kassenvorgänge für einen definierten Zeitraum. Sollten Sie mit mehr als einer Kasse arbeiten, kann das Protokoll auf eine Kasse eingegrenzt werden.

[Bild]

Nur für Österreich: Wenn Sie mit Signatureinheiten arbeiten, bekommen alle Kassen eine eindeutige ID. Bitte wählen Sie in diesem fall die Kasse über die ID aus.

|

Info: Die Buttons „Export DEP.CSV“ und „Export DEP.JSON“ sind nur sichtbar, wenn in den Grundeinstellungen, Reiter „Allgemein“, die Option „Datenerfassungsprotokoll anzeigbar“ aktiviert ist. Eine Aktivierung dieser Option ist bisher nur in Österreich erforderlich.

[Bild]

Mit Klick auf „Protokoll anzeigen“ wird das Ladenkassen-Protokoll in einer Bildschirmliste erzeugt. Die Auflistung kann über den Excel Button an Excel exportiert werden.

[Bild]
