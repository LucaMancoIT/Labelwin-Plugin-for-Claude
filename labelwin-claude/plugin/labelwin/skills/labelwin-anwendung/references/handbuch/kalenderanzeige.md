Kalenderanzeige

Wenn Sie die Kalender/Balkenanzeige/Blockanzeige als reine Anzeige nutzen möchten (Sie können dann keine Änderungen vornehmen), können Sie das Modul "Anzeige Kalender" verwenden. Dazu müssen Sie das Modul in den V5 Programmbaum einbinden. Das Modul hat übrigens den Vorteil, dass es bei der Anzahl der Labelwin-Lizenzen nicht mitgezählt wird.

[Bild]

Hinweis: In V4 wurde die reine Anzeige über die Datei ‚kalzeige.exe’ gestartet. Legen Sie hierzu entweder eine Verknüpfung auf diese Datei in Ihren Label-für-Windows-Ordner an oder richten Sie eine neue Verknüpfung im Startcenter ein.

Zum Beispiel können Sie das Modul für den Übersichtplan auf einem großen Flachbildschirm nutzen. Das Modul lässt keine Änderungen zu, sondern dient lediglich der Anzeige. Aktivieren Sie das Feld ‚Automatisch aktualisieren‘ und geben Sie einen Intervall ein. Damit stellen Sie sicher, dass die Anzeige immer aktuell ist. Sie haben die Möglichkeit auch auf die Tagesliste oder den Kalender zu wechseln.

[Bild]

Per Doppelklick auf einen Auftrag können Sie sich die Details dazu ansehen. Sie können aber auch hier keine Änderungen vornehmen.

[Bild]

Erweiterte Kalenderanzeige

Wir haben eine Erweiterung der reinen Kalenderanzeige vorgenommen, die durch einen Schalter aktiviert werden kann. Wenn der Schalter gesetzt ist, kommt bei einem Doppelklick auf einen Eintrag diese Maske:

[Bild]

In der neuen Maske sehen Sie im unteren Bereich 3 Tabellen mit dem Kundendienstlogbuch, die für die Objektadresse berechneten Artikel und die Anlagen der Objektadresse. Zusätzlich gibt einen Knopf, mit dem die zu der Objektadresse gehörigen Bilder angezeigt werden können.

Diese Anzeige kann im Einstellmodul unter <Programmbereiche>, <Kundendienst>, <Grundeinstellungen> auf der Seite ‚Allgemein‘ im Block "Anzeige" aktiviert werden. Bitte beachten Sie, dass bei dieser Einstellung eine Lizenz verbraucht, während die alte Anwendung kostenlos verwendbar ist.
