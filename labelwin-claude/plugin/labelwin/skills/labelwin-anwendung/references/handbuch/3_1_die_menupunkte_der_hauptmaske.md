3.1 Die Menüpunkte der Hauptmaske

Bearbeiten

Ändern F6

Wenn in der Tabelle der übernommenen Artikel einer markiert ist, so wird er mit dieser Funktion geändert. Mit einem Doppelklick auf die Zeile erreichen Sie dieselbe Funktion.

Löschen

Artikel

Eine in der Anzeigetabelle markierte Zeile wird gelöscht

Alle Artikel

Bei der Wahl dieses Menüpunkts müssen Sie entscheiden, ob Sie alle Artikel oder das gesamte Dokument mit allen Einstellungen (Adressen, Kalkulationseinstellung, Zahlungsbedingung usw.) löschen wollen.

[Bild]

Gleichzeichen vor Suchwort Strg+G

Durch die Wahl dieses Menüpunkts wird das Gleichzeichen vor dem Suchwort dauerhaft gesetzt.

Summen neu rechnen Strg+S

Bei der Verwendung von Zuschlägen und Nachlässen kann hiermit eine neue Berechnung erzwungen werden. Beim Drucken des Beleges erfolgt automatisch die Berechnung, so dass diese Funktion in der Regel überflüssig ist.

Pos-Nr. neu vergeben

Durch die Wahl dieses Menüpunkts werden die Positionsnummern neu vergeben. Bei der Druckausgabe erfolgt allerdings ohnehin die neue Nummerierung der Artikel.

Neurechnen mit Kalk.-Einstellung

Mithilfe dieses Menüpunktes können Sie die Verkaufspreise der Positionen des aktuellen Beleges mit der gewählten Kalkulationseinstellung neu rechnen lassen.

Gleiche Artikel zusammenfassen

Falls ein Artikel mehrfach aufgerufen wurde, kann hiermit eine Verdichtung erfolgen. Es gilt der Preis des ersten gefundenen Artikels.

Katalog Reihenfolge

In dieser Maske legen Sie fest, welche Kataloge aktiv sind und in welcher Reihenfolge sie durchsucht werden.

Drucken F12

Es ist die gleiche Funktion wie der Drucken-Knopf an der Oberfläche, die Druckmaske öffnet sich.

Drucken Drucker2 Umschalt+F12

Dieser Menüpunkt ist nur vorhanden, wenn der DOS Bondruck in den Grundeinstellungen aktiviert ist. Es öffnet sich die Druckmaske.

Knopfdruck neue Rolle

Dieser Menüpunkt ist ebenfalls nur sichtbar, wenn der DOS Bondruck in den Grundeinstellungen aktiviert ist. Wird auf einen Bon-Drucker gedruckt, muss dieser Menüpunkt immer nach einem Rollenwechsel angewählt werden, damit ein Druck des Firmenkopfs erfolgt. Der Firmenkopf wird immer nach einem Belegdruck für den nächsten Beleg gedruckt. Bei einer neuen Rolle fehlt der vorherige Druck.

Mandant wechseln Strg+M

Wird eine Mandantenversion eingesetzt, kann hier der Mandant gewechselt werden.

Beenden

Hiermit wird das Modul LADENKASSE geschlossen.

Vorlage

UGS-Datei übernehmen Strg+U

Hier kann eine wie auch immer erzeugte UGS-Datei in den Kassenbeleg übernommen werden. Die UGS-Datei kann z.B. von Technikprogrammen, diversen Katalog-Auswahlprogrammen oder über einen Strichcode-Scanner erzeugt worden sein. Es wird eine Auswahl aller vorgefundenen UGS-Dateien angeboten. Da diese nach der Übernahme gelöscht wird, sind nur die aktuellen UGS-Dateien da.

Standard Kassen UGS F8

Dieser Punkt hat die gleiche Funktion, wie der zuvor beschriebene Punkt. Es wird lediglich keine Auswahl angeboten, sondern automatisch eine Datei K.ugs gesucht und ggf. verarbeitet.

Vorlage einfügen F7

Durch die Wahl dieses Menüpunkts können Sie ein Dokument, das für die gewählte Objektadresse bereits erstellt wurde, als Vorlage übernehmen. Es erscheint die Dokumentenliste, aus der Sie dann das entsprechende Dokument wählen können.

Dokument über Nummer suchen F4

Durch die Wahl dieses Menüpunkts haben Sie die Möglichkeit ein Dokument anhand der Angebots- oder Rechnungs-Nr. zu suchen.

Abrechnung

Tagesabrechnung

Für die Tagesabrechnung stehen diverse Formulare zur Verfügung, mit denen das Tagesprotokoll ausgedruckt werden kann. Lesen Sie auch Punkt 6.1 in Abrechnung.

Übergabe an Kassenbuch (Z-Bon)

Über diesen Menüpunkt können die Tageswerte der Ladenkasse als Eingang im Modul KASSENBUCH übergeben werden. Es werden nur bisher nicht übertragene Daten übergeben. Wenn Sie die Übergabe nicht täglich durchführen, werden die summierten Werte übertragen. Details erfahren Sie im Kapitel Abrechnung unter Punkt 6.2.

Z-Bon Nachdruck

Über diesen Menüpunkt kann ein Z-Bon nachgedruckt werden (Vgl. Abrechnung 6.3).

Kassenbestand zählen

Geben Sie hier die Menge der Einer, Zweier, Fünfer usw. ein und das Programm zeigt die Gesamtsumme. Zum Vergleich wird der protokollierte Bestand inkl. Wechselgeld und eine sich ggf. daraus ergebende Differenz angezeigt. Lesen Sie hierzu auch das .

Sonderbelege

Kunde zahlt Rechnung F3

Über diese Funktion können Rechnungen aus dem Rechnungsausgangsbuch auf bezahlt gesetzt werden. Die eingetragenen Werte erhöhen zwar den Kassenbestand, aber nicht den Kassenumsatz. Bei der Tagesabrechnung werden sie separat ausgewiesen. Details können Sie im Kapitel Kunde zahlt eine Rechnung nachlesen.

Bargeld an Kassenbuch Strg+D

Von Zeit zu Zeit wird Geld aus der Kasse entnommen und bei der Bank eingezahlt. Eine solche Kassenentnahme muss erfasst werden, um den korrekten Kassenbestand fortzuschreiben. Über diesen Menüpunkt wird eine Position mit dem Text „Bargeld-Entnahme an Kasse“ erzeugt. Der Beleg muss noch gedruckt werden, damit die Entnahme auch gebucht wird. Die Buchung erfolgt in diesem Fall umgehend, also ohne die „Übergabe an Kassenbuch (Z-Bon)“ durchzuführen. Details können Sie im Kapitel Bargeldentnahmen und Bargeldauffüllung nachlesen.

Bargeld entnehmen

Dieser Menüpunkt hat im Grunde die gleiche Funktion wie der vorherige, nur mit dem Unterschied, dass eine Position mit dem Text „Sonstige Bargeld-Entnahme“ erzeugt wird und, dass keine Gegenbuchung im Kassenbuch erfolgt. Details können Sie im Kapitel Bargeldentnahmen und Bargeldauffüllung nachlesen.

Gutscheinverkauf

Durch die Wahl dieses Menüpunkts können Sie einen Kassenbeleg für einen Gutscheinverkauf erzeugen. Details finden Sie in Kapitel Gutscheinverkauf.

Nachdruck Strg+N

Durch die Wahl dieses Menüpunkts können Sie einen Kassenbeleg nochmals ausdrucken. Hierzu ist die Nummer des Kassenbelegs erforderlich. Eine Änderung der Artikel, der Adresse oder des Verkäufers sind dabei nicht möglich. In erster Linie ist der Punkt dazu entwickelt, um bei einem Druckerproblem problemlos neu drucken zu können. Vergleichen Sie Kapitel Nachdruck.

Storno / Rücknahmen

Über diesen Menüpunkt lässt sich ein Kassenbeleg sinngemäß stornieren. Hierzu muss nur die Belegnummer eingegeben werden. Alle Positionen des Beleges werden automatisch mit der negativen Menge versehen. Der Beleg muss abschließend gedruckt werden. Details finden Sie in Kapitel Storno / Rückgaben.

Startbeleg

Diesen Menüpunkt benötigen Sie derzeit nur für Österreich . Hiermit wird bei Nutzung einer Signatureinheit ein zwingend notwendiger Startbeleg erzeugt. Details können Sie im Kapitel Startbeleg nachlesen.

Monatsbeleg

Diesen Menüpunkt benötigen Sie derzeit nur für Österreich . Hiermit wird bei Nutzung einer Signatureinheit am Ende des Monats ein zwingend notwendiger Monatsbeleg erzeugt. Details können Sie im Kapitel Monatsbeleg nachlesen.

Sammelbeleg defekte Signatureinheit

Diesen Menüpunkt benötigen Sie derzeit nur für Österreich . Hiermit wird bei Nutzung einer Signatureinheit ein Sammelbeleg gedruckt, nach eine ausgefallene Signatureinheit wieder verfügbar ist. Details können Sie im Kapitel Sammelbeleg defekte Signatureinheit nachlesen.

Optionen

Kalkulationseinstellung F11

Hier legen Sie fest, mit welcher Kalkulationseinstellung die nachfolgend aufgerufenen Artikel kalkuliert werden.

Grundeinstellungen

Über diesen Menüpunkt werden wichtige Grundeinstellungen für die Ladenkassen Nutzung eingestellt.

Konten festlegen

Durch die Wahl dieses Menüpunkts erhalten Sie die Anzeige des Einkaufspreises,

Runden Strg+R

Über diesen Menüpunkt haben Sie die Möglichkeit, sich den Betrag der Rundung noch einmal anzuschauen und ggf. zu korrigieren. Die Rundung ergibt sich gem. der Rundungstabelle, die Sie in den Grundeinstellungen festgelegt haben. Wenn Sie die Eingabe mit OK bestätigen, wird in der Artikelliste ein weiterer Artikel mit der Rundung angelegt.

Basis zeigen Strg+B

Durch die Wahl dieses Menüpunkts erhalten Sie die Anzeige des Einkaufspreises, die bei Bedarf über die Grundeinstellungen dauerhaft eingestellt werden kann. Die Anzeige wird nun bei einer freien Artikelerfassung automatisch eingeblendet. Sobald ein gespeicherter Artikel aufgerufen wird, verschwindet das Eingabefeld wieder. Um es für den zufälligen Zuschauer undurchsichtiger zu machen, wurde die Beschriftung ‚EK’ in ‚Basis’ umbenannt. Darüber hinaus wurde die Eingabe so verschlüsselt, dass der Einkaufspreis nicht mehr sofort erkennbar ist. Anstelle des Kommas wird eine zufällige Zahl gedruckt.

|

Beispiel: Sie geben ein 12,45 und das Programm schreibt hin 12845. Sie müssen also die drittletzte Stelle als Komma interpretieren, obwohl dort eine x beliebige Zahl sichtbar ist. Die Eingabe in diesem Feld muss allerdings nun zwingend immer mit zwei Nachkommastellen erfolgen – anderenfalls nimmt das Programm die Eingabe nach einer entsprechenden Warnung nicht an.

Wechselgeld-Bestand eintragen

Dieser Menüpunkt ist im Januar 2017 neu hinzugekommen. Er muss einmalig angewählt werden, um den aktuellen Kassenbestand zu erfassen. Das ist erforderlich, um von da an zu jedem Beleg den Barbestand der Kasse und den Barumsatz aufzeichnen zu können. In Österreich wird die Aufzeichnung je Beleg zwingend verlangt. Deutschland wird folgen. Der Barumsatz muss kontinuierlich aufgezeichnet werden. Achtung: Diese Funktion sollte nur einmal aufgerufen werden.

Ausführliche Beschreibung im Kapitel Wechselgeld-Bestand eintragen.

Auswerten

Gesamtsumme aktueller Beleg F9

Durch die Wahl dieses Menüpunkts wird Ihnen die Gesamtsumme des aktuell erfassten Beleges in der Ladenkasse angezeigt.

Kurzauswertung

Hier erhalten Sie eine Zusammenfassung, in der neben der Gesamtsumme auch die Ertragswerte gezeigt werden.

Auswerten Ladenkasse

Über diesen Menüpunkt können Sie die Ladenkasse für einen bestimmten Zeitraum auswerten. Die Auswertung wird auf ein zur Auswahl stehendes Formular gedruckt.

Ausführliche Beschreibung im Kapitel Auswertungen.

Wichtig für Österreich : Dort werden auch die gesetzlich vorgeschriebenen Protokolle ausgegeben.
