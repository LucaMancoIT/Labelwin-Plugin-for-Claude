Nutzung der App

|

Starten Sie die App nachdem Sie diese aus dem Apple App-Store oder Google Playstore heruntergeladen und installiert haben. Oder starten Sie die Web-Version über die Adresse https://www.labelmobile.de.

In der Anmeldemaske benötigen Sie vier Informationen:

-

Die URL des Label Mobile Webservers ist https://www.labelmobile.de/. Hier noch mal der Hinweis, dass unser Webserver nur Postbote spielt. Die Anfragen der App und die Antworten Ihres Labelwin-System liegen nur Sekundenbruchteile auf unserem Webserver und werden nicht ausgewertet und nicht protokolliert.

-

Die Kunden- bzw. Lizenznummer. Diese 7-stellige Nummer finden Sie über den Menüpunkt <Info>, <Info> in der Zeile „Label Mobile (Lizenz 3000401) ist aktiv“

-

Die Identnummer des Mitarbeiters aus dem Personalstamm (Hinweis: In der ersten ios_Version wird die Nummer als Personalnummer bezeichnet. Das ist falsch, es ist die im Personal angezeigte Identnummer.)

-

Das im Personalstamm hinterlegte Passwort

|

[Bild]

|

Nach dem erfolgreichen Anmelden befinden Sie sich im Hauptmenü.

Nach einem Neustart der App oder des Browsers gelangen Sie ohne die Login-Maske direkt ins Hauptmenu. Das dient dem Komfort, damit man sich nicht immer wieder anmelden muss. Bei Nutzung der Webanwendung müssen Cookies aktiviert sein. Sie können sich in der App aber auch abmelden. Klicken Sie dazu unten rechts auf das „Einstellrad“ und dann auf den Link „Abmelden“. Eine automatische Abmeldung erfolgt auch nach 7 Tagen Inaktivität. Der Benutzer kann auch aus Labelwin heraus zwangsabgemeldet werden. Mehr dazu später.

Sollten der Benutzer die Zugangsdaten vergessen haben, so muss er in der Login Maske auf „Passwort vergessen“ klicken. Er benötigt in der Folgemaske mindestens seine die Kunden-/Lizenznummer, sowie entweder seine Identnummer oder seine im Personalstamm hinterlegte E-Mail Adresse. An diese E-Mail wird ein neues automatisch generiertes Passwort gesendet.

Hinweis: Wir verzichten zunächst darauf alle Icons und Funktionen einzeln vorzustellen, da sie meistens intuitiv und verständlich sind.

Modul Adressen

Beim Start bekommen Sie sofort eine Liste aller Adressen, die der App-Nutzer als Favorit gekennzeichnet hat. Beim ersten Start gibt es bereits einen Favoriten – die eigene Firmenadresse. Allerdings nur, wenn in Labelwin im Modul „Einstellungen“ unter <Grundeinstellungen>, <Firmendaten> bei „Eigene Adresse“ etwas hinterlegt hat.

In der Suchzeile kann man Adressen suchen. Es gelten die gleichen Suchregeln, wie auch in Labelwin. Also Kurzname, weitere mit Leertaste getrennte Begriffe, @-Suche, Straßensuche mit # etc. Es werden maximal 200 Adressen angezeigt.

Mit einem Klick auf die gefundene Adresse gelangt man in die Detailmaske. Mit einem Klick auf die Straße bzw. den Ort wird die Adresse in Google Maps angezeigt. Mit einem Klick auf die Telefonnummer wird gewählt und mit einem Klick auf die E-Mail Adresse geht der E-Mail Client des Gerätes auf – sofern vorhanden.

Über die Menüleiste unten rechts kommt man eine Liste von Kontakten dieser Adresse (Telefonreiter in Labelwin), eine Liste aller Aufgaben zu dieser Adresse und eine Liste aller Dokumente, wo diese Adresse als Objektadresse eingetragen ist.

Über das Icon „Mehr“ öffnet sich ein Untermenü, über das man die die Anlagenliste, die Liste von Dokumenten, wo diese Adresse als Anschreiben­adresse hinterlegt ist und die Adress-Hinweisfelder gezeigt bekommt. Außerdem kann man diese Adresse zur Liste der Favoriten dazu fügen oder wieder entfernen kann.

Modul Aufgaben

Hier bekommen Sie eine Liste aller ihrer offenen Aufgaben. Innerhalb der Liste kann man filtern, d.h. die Liste begrenzen auf Einträge, in der das eingegebene Wort auftaucht. Durch einen Klick auf die Aufgabe kommt man in eine Detailmaske. Über das Icon „Bearbeiten“ unten rechts kann die Aufgabe inhaltlich geändert als auch auf erledigt gesetzt werden.

Über das Icon „Neu“ rechts unten in der Aufgabenliste können Sie eine neue Aufgabe für sich oder einen Kollegen anlegen.

Modul Kalender

Hier bekommen sie eine Liste aller Kalendereinträge. Zuerst Ihre Kalendereinträge für den heutigen Tag. Über die Kalenderleiste können Sie einen anderen Tag auswählen oder durchblättern. Genauso können Sie einen anderen Mitarbeiter auswählen.

Über das Icon „Neu“ rechts unten in der Aufgabenliste können Sie eine neue Aufgabe für sich oder einen Kollegen anlegen.

Modul Projekte

Das Modul startet mit einer Liste aller Projekte, die Sie als Favorit gekennzeichnet haben. Die Favoritenliste entspricht der persönlichen Favoritenliste in Labelwin. Auch in der App können Sie Projekte zu den Favoriten hinzufügen oder deaktivieren.

Sie können Projekte suchen. Dabei ist es egal, ob Sie die Projektnummer, den Projektnamen, Suchwort oder Ort eingeben. Mit einem Klick auf das gefundene Projekt öffnet sich das Projektdatenblatt.

Über die Icons unten rechts bekommen Sie die weiteren zugeordneten Adressen sowie eine Liste der Dokumente angezeigt.

Bei einem Klick auf das Dokument bekommen Sie die Dokumenteninfo angezeigt. Von hier aus können Sie über die Icons unten rechts das, sofern vorhanden, hinterlegte PDF-Dokument anschauen, die Hinweis-Felder sehen und, sofern es sich um ein Dokument auf Positionsbasis handelt, die Dokumentensummen und Positionen sehen. Selbstverständlich reagiert Label Mobile auf die hinterlegten Benutzerrechte, so dass ggf. Einkaufspreise oder Lohnminuten nicht sichtbar sind.

Leider können nicht alle Dokumententypen angezeigt werden. Wir arbeiten daran, das zu verbessern. Wer das Scan- oder Druckarchiv nutzt, kann die erzeugten PDFs in der App ansehen.

Einstellungen

Über das Icon „Einstellungen“ in der Hauptmaske können Sie sich abmelden und den Mandanten wechseln, sofern Labelwin Mandanten hat und Sie die Berechtigung zum Mandantenwechsel haben.
