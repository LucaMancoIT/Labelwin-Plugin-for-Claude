1.1 Rechnungsliste - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Datei

Drucken

Durch die Anwahl dieser Funktion haben Sie die Möglichkeit, eine Rechnungseingangsliste zu drucken – es werden nur die Rechnungen einbezogen, die durch die Selektion ausgewählt wurden. Dieser Menüpunkt erfüllt die gleiche Funktion wie Knopf [Nr.17].

Protokoll anzeigen

Um uns die Nachfragen bei gelöschten Daten zu ersparen, werden die wichtigsten Löschvorgänge protokolliert. Unter diesem Menüpunkt können Sie nachschauen, wer und wann ein Projekt, eine Adresse, ein Dokument, eine Eingangsrechnung oder eine Kundendienstauftrag gelöscht hat.

Liste aufbauen (F5)

Mit dieser Funktion wird die Rechnungsliste [Nr.12] aktualisiert. Dieser Menüpunkt erfüllt die gleiche Funktion wie Knopf [Nr.14]

Rgeingang Import

Statt Rechnungen manuell einzeln zu erfassen, kann auch eine CSV Datei importiert werden. Diese Funktion dürfte in der Regel nur für Neukunden interessant sein, da alle Rechnungen, die mit Labelwin erzeugt werden automatisch beim Drucken in das Rechnungsausgangsbuch eingetragen werden

Mandanten wechseln (STRG+M)

Durch Anwahl dieses Menüpunktes können Sie den aktuellen Mandanten wechseln.

Beenden

Hiermit beenden Sie das Rechnungseingangsbuch

|

Bearbeiten

Rechnung erfassen (F2)

Durch Anwahl dieser Funktion können Sie eine neue Eingangsrechnung erfassen. Dieser Menüpunkt erfüllt die gleiche Funktion wie Knopf [Nr.15].

Neue Rg. mit Vorlage (F3)

Wenn Sie in der Rechnungsliste [Nr.12] eine Rechnung markieren und diesen Menüpunkt wählen, sind die Felder schon vorbelegt. Sie müssen nur noch das Rechnungsdatum und die Zuordnung zum Projekt vornehmen. Dieser Menüpunkt wurde für Kunden eingeführt, die viele Eingangsrechnungen eines Lieferanten mit gleichem Inhalt auf verschiedene Projekte buchen müssen.

Neue Rg. per ZUGFeRD-PDF (STRG+Z)

Über diesen Menüpunkt können ZUGFeRD Rechnungen importiert werden. Dieser Menüpunkt ist nur anwählbar, wenn das Zusatzmodul Rechnungsimport erworben wurde.

Rechnung stornieren (STRG+S)

Dieser Vorgang ist ähnlich der Vorlage-Kopierfunktion. Allerdings werden alle Summen negiert, sodass Sie damit eine komplette Rechnung sehr einfach stornieren können. Auch hier können Sie die Summen ändern, damit nur ein Teil der Rechnung storniert wird.

Rechnung ändern (F6)

Durch die Anwahl dieser Funktion können Sie eine bereits erfasste Eingangsrechnung ändern. Dieser Menüpunkt erfüllt die gleiche Funktion wie Knopf [Nr.16]

Summen zeigen (F9)

Durch die Anwahl dieser Funktion werden Ihnen sehen Sie eine Zusammenfassung aller Rechnung, die Sie zuvor ausgewählt haben. Dieser Menüpunkt erfüllt die gleiche Funktion wie Knopf [Nr.18]

Zahlungsplan

Über diesen Menüpunkt gelangen Sie direkt zum für die Eingangsrechnung hinterlegten Zahlungsplan.

Rechnungsprüfung

Über diesen Menüpunkt gelangen Sie in die Maske der Rechnungsprüfung. Hier haben Sie die Möglichkeit, unterschiedliche Prüfeingrenzungen vorzunehmen, z.B. auf einen bestimmten Prüfer eingrenzen. Lesen Sie hierzu das Kapitel Rechnungsprüfung (Eingang).

Rechnung löschen

Durch Anwahl dieser Funktion wird die markierte Rechnung aus der Liste entfernt. Das Löschen funktioniert nur dann, wenn die Rechte entsprechend eingerichtet sind.

Scannen (F12)

Wenn Sie das Zusatzmodul Scanarchiv oder die Elo-Anbindung erworben haben, können Sie über diesen Menüpunkt einen Scan zur Rechnung erfassen..

ZUGFeRD/Gaeb/UGL

Über diesen Menüpunkt können Rechnungen per ZUGFeRD-PDF oder über GAEB oder UGL importiert werden. Dieser Menüpunkt ist nur anwählbar, wenn das Zusatzmodul Rechnungsimport erworben wurde.

|

Auslagern

Fibuschnittstelle

Hier kann eine Ausgabe der Rechnungen an eine Finanzbuchhaltung erfolgen. Das Modul muss separat erworben werden. Die Liste der Schnittstellen wird immer größer – falls Sie eine vermissen, sprechen Sie uns bitte an.

Momentan werden Übergaben an folgende Fibu-Programme unterstützt:

· Datev · SBS-Fibu · rhvFibu · HSFibu

· EuroFibu · Telekon · Diamant · KHKFibu

· SQL-Fibu · Top-Fibu · Comet · Szymaniak

· Lexware · Comet · PDS

· GDIFibu · GS-Fibu · CTO-Fibu

(Stand 10/2009)

|

Bitte beachten Sie, dass das Modul FIBUERFASSUNG nicht für alle oben aufgeführten Fibuprogramme zur Verfügung steht. Wenn Sie eine neue Fibu erwerben wollen, sprechen Sie uns bitte an.

PDF-Archiv auslagern

|

Über diesen Menüpunkt wird das PDF-Archiv ausgelagert, d.h. alle gescannten Eingangsrechnungen sowie alle gedruckten Ausgangsrechnungen werden in einen Ordner gespeichert.

Der Ausgabezeitraum kann eingegrenzt werden. Die Exceltabelle wird zusammen mit den PDF’s in einem Verzeichnis abgelegt, dass dann z.B. per USB-Stick befördert werden kann. Wegen der Größe ist ein Transport per Email nicht möglich.

Damit der Steuerberater die Daten besser überprüfen kann und Zugriff auf den Ausdruck der Rechnungen hat, wurde die Funktion der Übergabe an Excel geschaffen. Wenn in Excel eine Rechnung markiert wird, kann die PDF per Knopf angezeigt werden. Da alle relevanten Informationen in der Tabelle sind, kann auch nach Konto eingegrenzt werden. Interessant kann dieser Weg auch bei einer Steuerprüfung sein, weil Sie alle Informationen herausgeben können, ohne das der Prüfer in Ihr System muss.

Der Ausgabezeitraum kann eingegrenzt werden. Die Exceltabelle wird zusammen mit den PDF’s in einem Verzeichnis abgelegt, dass dann z.B. per USB-Stick befördert werden kann. Wegen der Größe ist ein Transport per Email nicht möglich.

Hinweis zu Kassenbücher: Wenn Sie mehr als ein Kassenbuch nutzen, wird eine Excel-Tabelle je Kasse erzeugt.

Zahlungen

Bezahlen offene Rechnungen

Durch Anwahl dieses Menüpunktes, können Sie die Zahlungen durchführen. Die Beschreibung erfolgt im Kapitel Bezahlen.

Bankeinzüge als Zahlungslauf bündeln

Genau wie bei der Bezahlung per Überweisung / Bankdiskette können Rechnungen mit Status ‚Bankeinzug’ zu einem Zahlungslauf gebündelt werden. Diesen Vorgang starten Sie, sobald Sie die Abbuchungsankündigung (Avis) des Lieferanten erhalten.

Die Maske ist die gleiche, wie bei dem ‚normalen’ Zahlungslauf, lediglich die Auswahl der Zahlungsart fehlt. Grenzen Sie auf die entsprechenden Rechnungen ein und markieren diese mit einem ‚z’ .Wenn die Abbuchung stattgefunden hat, wählen Sie den Menüpunkt <Zahlungen> <Bezahlt setzen Zahlungslauf>.

Bezahlt setzen Zahlungslauf

Bei der Zahlung von Eingangsrechnungen wird eine Liste der bezahlten Rechnungen erzeugt. Diese Liste wird bei uns als Zahlungslauf bezeichnet. Die Rechnungen werden jedoch nicht sofort auf bezahlt gesetzt, sondern erst durch Anwahl dieses Menüpunktes. Wir haben diesen Weg gewählt, um auch bei Defekten des Druckers oder der Diskette den kompletten Vorgang wiederholen zu können. Wenn die Rechnungen sofort bei der Zahlungsanweisung auf erledigt gesetzt würden, wäre dies nicht möglich.

Wiederholen Zahlungslauf

Durch Anwahl dieses Punktes ist es möglich, einen Zahlungslauf zu wiederholen. Dies ist z. B. dann notwendig, wenn der Drucker versagt hat oder wenn die Diskette mit den Überweisungen nicht lesbar ist. Der zu wiederholende Zahlungslauf muss in der Tabelle markiert werden. Wenn Sie die Eingabe mit OK bestätigen, erhalten Sie folgende Meldung:

[Bild]

Bestätigen Sie den Knopf ‚Ok, weiter‘ und erzeugen Sie den Zahlungslauf neu.

Löschen Zahlungslauf

Durch diesen Menüpunkt kann ein durchgeführter Zahlungslauf entfernt werden. Der Vorgang ist nur so lange ausführbar, bis der Zahlungslauf zur Erledigtsetzung benutzt worden ist.

Zur Erinnerung: Die Zahlungsausführung und Bezahltsetzung der Rechnungen sind zwei Arbeitsschritte. Das Löschen ist nur möglich, solange die Rechnungen nicht auf Bezahlt gesetzt sind.

Rechnung auf bezahlt setzen

Durch Anwahl dieses Menüpunktes können Sie eine Rechnung manuell auf bezahlt setzen. Diese darf jedoch nicht im Zahlungsplan stehen. Sollten Sie mit unserem Modul FIBUERFASSUNG arbeiten, dürfen Sie eine Rechnung hier nicht auf bezahlt setzen. Dieser Menüpunkt erfüllt die gleiche Funktion wie Knopf [Nr.19].

Rechnung aus Zahlungslauf entfernen

Unter diesem Menüpunkt können Sie aus einem Zahlungslauf eine oder mehrere Rechnungen entfernen (mehrere Einträge, indem Sie diese über die Mehrfachmarkierung markieren – mit gedrückter Strg-Taste in das linke Feld klicken). Die markierten Rechnungen werden dann wieder auf ‚offen’ gesetzt, die Summe des Zahlungslaufes wird korrigiert. Es ist so, als wären die Rechnungen nie zur Zahlung angewiesen worden.

Sollten nach der Umsetzung im Zahlungslauf nur noch bezahlte Rechnungen stehen, wird er automatisch auf ‚erledigt’ gesetzt.

Hintergrund:

1. Es kann passieren, dass eine Bank aus einem Zahlungslauf (bei der Bank heißt das meistens Sammelüberweisung) einen Teilbetrag nicht überweist z.B. wegen einer falschen Bankverbindung.

2. Im Bankprogramm ist es möglich, einzelne Rechnungen aus dem Überweisungsstapel einfach wieder herauszunehmen, weil diese aus irgendwelchen Gründen nicht überwiesen werden sollen.

Auswertungen

Auswertung Verteilung

Die Auswertung des Rechnungseingangsbuches ist so komplex, dass wir die Beschreibung hierzu im Kapitel Auswertung abgelegt haben.

Bild der Rechnung zeigen (F4)

Wenn Sie die Eingangsrechnungen gescannt haben, so können Sie hier die Ansicht aktivieren. Falls es sich um eine unter Elo gescannte Rechnung handelt, müssen Sie zuvor Elo starten.

Liquiditätsliste

Unter diesem Menüpunkt können Sie eine Vorschau der Verbindlichkeiten ausgeben. Auf unseren dafür entwickelten Standardformularen werden die Verbindlichkeiten nach Zahlungsziel 1, 2 oder 3 ausgewertet und anschließend wird eine wochenweise Liste erstellt. Um bei der wochenweisen Betrachtung einen Stichtag zu bekommen, müssen Sie zuvor das Datum eingeben, bei dem die erste Woche aufsetzen soll.

Historische OP Liste drucken

Unter diesem Menüpunkt haben Sie die Möglichkeit, einen OP im Nachhinein zu ermitteln, z. B. zum Jahresanfang den Stand der offenen Posten zum 31.12. Es werden die aktuell immer noch offenen Rechnungen gezeigt und jene, bei denen im Nachhinein Zahlungen eingegangen sind. Bei Zahlungen wird die Rechnungssumme um die Zahlsumme zurückgerechnet.

Bestellung/Eingangsls.

Hier öffnet sich eine Dokumentenliste zur markierten Eingangsrechnung.

|

Optionen

Elo-Postbox abarbeiten

Wenn Sie Ihre Eingangsrechnungen mit Elo im Stapel scannen, so müssen Sie irgendwann diesen Stapel zuordnen. Näheres lesen Sie im Handbuch ELO Dokumentenarchivierung.

Alte Bankeinzüge auf bezahlt setzen

Von Zeit zu Zeit sollten Sie unter diesem Menüpunkt die alten Zahlungsläufe auf bezahlt setzen, einfach per Durchlauf alle bis Datum umsetzen. Diesen Menüpunkt sollten Sie jedoch nur wählen, wenn Sie das Modul FIBUERFASSUNG nicht nutzen.

Liste automatisch aufbauen

Hier handelt es sich um ein Optionsfeld, welches direkt auf der Oberfläche keine Auswirkungen hat. Wenn Sie den Menüpunkt das nächste Mal anwählen, sehen Sie einen kleinen Haken vor dem Eintrag. Durch diese Option wird erreicht, dass beim Start des Rechnungseingangsbuches sofort die Liste aufgebaut wird. Wenn Sie sehr viele Eingangsrechnungen in Ihrem System haben, so sollten Sie diese Option nicht wählen. Der Aufbau der kompletten Rechnungseingangsliste kann ggf. einige Zeit dauern. Besser ist es, Sie treffen nach dem Start eine Eingrenzung z. B. auf das aktive Jahr oder den aktiven Monat. Danach wählen Sie mit dem Knopf ‚Liste aufbauen’ die Tabellenerzeugung an. Dieser Weg ist bei einer großen Menge von Rechnungen wesentlich schneller, als die Liste immer komplett aufbauen zu lassen.

Startdatum festlegen

Legen Sie hier das Startdatum für die Datumseingrenzung [Nr.5] der Rechnungsliste fest.

Reparatur Zahlungslauf

Wenn durch einen Absturz mitten im Buchen des Zahlungslaufes bereits einzelne Rechnungen fälschlicherweise auf ‚Bezahlt' oder ‚Skontozahlung' stehen, können Sie hier die markierte Rechnung auf den vorherigen Status zurücksetzen.

Fibukennzeichen ändern

Manches Mal ist es notwendig, das Fibukennzeichen zu ändern. Bitte bedenken Sie dabei, dass dieses Auswirkungen in der Fibu-Übertragung hat.

Rechnung als Vorlage kennzeichnen

Wenn eine Rechnung eines Lieferanten als Vorlage gekennzeichnet ist, wird bei der Erfaassung einer neuen Rechnung des gleichen Lieferanten die eine (oder mehrere ) Vorlage-Rechnung zum Kopieren angeboten. Wenn Sie dies annehmen, brauchen Sie bei der neuen Rechnung ggf. nur noch die Nummer ändern und sind fertig. Natürlich können Sie auch die Summen, die Zuordnungen usw. ändern.
