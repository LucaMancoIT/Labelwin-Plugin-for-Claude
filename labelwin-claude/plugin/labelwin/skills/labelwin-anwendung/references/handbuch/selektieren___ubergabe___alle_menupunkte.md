Selektieren - Übergabe - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Bearbeiten

SQL zeigen

Diese Funktion ist nur für Programmierer interessant, da damit die Abfrage an die Access-Datenbank kontrolliert werden kann.

Kriterien eintragen (F7)

Hier haben Sie die Möglichkeit, den ausgewählten Adressen ein Kriterium zuzuordnen.

[Bild]

Aktionsteilnahme eintragen

Hier haben Sie die Möglichkeit, den ausgewählten Adresse eine Aktionsteilnahme zuzuordnen. Lesen Sie hierzu auch das Kapitel Marketingaktionen

Aktionsteilnahme löschen

Hier haben Sie die Möglichkeit, bei den ausgewählten Adressen eine Aktionsteilnahme wieder zu löschen.

Beenden

Die Maske wird geschlossen.

|

Tabellen

Einlesen

Die Anzeigetabellen sind vom Anwender frei gestaltbar und können unter einem beliebigen Namen abgespeichert werden. Hier kann eine andere Tabelle aktiviert werden.

Speichern

Die eventuell geänderte Anzeigetabellen wird unter dem gleichen Namen abgespeichert.

Speichern als

Die aktive Anzeigetabelle wird als neue Tabelle dauerhaft gespeichert.

Löschen

Die aktive Tabelle wird gelöscht.

|

Spalten

Eigenschaften

Über diese Funktion wird der Inhalt und die Überschrift einer Spalte festgelegt.

[Bild]

Spalte einfügen

Über diese Funktion wird vor eine markierte Spalte eine weitere Spalte eingefügt.

Spalte anhängen

Über diese Funktion wird rechts an die Tabelle eine neue Spalte angefügt. Markieren Sie anschließend diese Spalte, um die Eigenschaften festzulegen.

Spalte löschen

Die aktive Spalte wird gelöscht.
