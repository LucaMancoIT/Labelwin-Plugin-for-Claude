3. Auftrag drucken

Durch Drücken des Knopfes ‚Drucken’ kann der Kundendienstauftrag ausgedruckt (bzw. ausgegeben) werden. In welcher Form das geschieht, hängt davon ab, welche Auswahl auf diese Maske getroffen wird.

[Bild: 3. Auftrag drucken]

Bild: Druckausgabe Kundendienstauftrag

Um die Druckmaske umfangreich beschreiben zu können, wurden alle Druckvarianten aktiviert. Im Regelfall dürfte nur eine Auswahl verwendet werden.

|
[Bild: 1]

Ausgabe KD-Auftrag

[Bild: 1. Ausgabe KD-Auftrag]

Die Druckausgabe kann auf verschiedenen Formularen erfolgen. Die Formulare können frei gestaltet werden und werden ggf. von uns an Ihre Bedürfnisse angepasst. Über eine Auswahlliste können Sie das gewünschte Formular wählen.

In dem Feld ‚Drucker’ können Sie wählen, wo die Druckausgabe erfolgen soll. Da die Druckausgabe von Monteurzetteln häufig nicht auf dem Standarddrucker erfolgt, kann der Drucker im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Kundendienst> <Grundeinstellungen> vorgewählt werden.

|
[Bild: 2]

Ausgabe PDF

[Bild: 2. Ausgabe PDF]

Dieser Druckbereich ist nur sichtbar, wenn die Funktion "Ausfüllbare PDF" eingerichtet ist. Es geht dabei darum eine ausfüllbare PDF (also eine PDF-Datei mit Eingabefeldern) automatisch mit Daten aus Labelwin (z.B. Auftragsnummer, Adressen, Anlagedaten) zu füllen.

|
[Bild: 3]

Word/Excel Checkliste

[Bild: 3. Word/Excel Checkliste]

Es ist möglich, neben dem Monteurzettel auch eine Checkliste auszudrucken. Diese können auf 2 Arten gedruckt werden. Eine Variante ist das unter [Nr.4] beschriebene Checklisten-Formular. Eine andere Variante ist die Word/Excel Checkliste. Hier haben Sie die Möglichkeit, sich Checklisten mit Word oder Excel selbst zu erstellen. Speichern Sie diese Dokumente im Ordner Labelwin\checklis\ mit einem vorangestellten Unterstrich ab. Nur dann erscheint unter dem Ausgabefenster für den Kundendienstauftrag dieses weitere Fenster. Hier können Sie dann die entsprechende Checkliste auswählen, bearbeiten und drucken. Je nach Dateiextension startet das passende Fremdprogramm.

Der Vorteil der Word/Excel Checkliste gegenüber dem Checklisten-Formular ist der Umstand, dass Sie diese eigenständig anlegen und ändern können. Die Checklisten Formulare müssen von Ihrem Labelwin Vertriebspartner oder der Hotline kostenpflichtig erstellt bzw. angepasst werden. Der Nachteil dieser Checklisten Variante ist dagegen, dass beim Druck des Auftrages die Checkliste nicht automatisch mitgedruckt werden kann. Es öffnet sich immer Word oder Excel und Sie müssen dort den Druck anstossen.

|
[Bild: 4]

Checklisten-Formular

[Bild: 4. Checklisten-Formular]

Es ist möglich, neben dem Monteurzettel auch eine Checkliste auszudrucken. Diese können auf 2 Arten gedruckt werden. Eine Variante ist die unter [Nr.3] beschriebene Word/Excel Checkliste. Eine andere Variante ist die Checkliste als Formular, welches von uns (wie das Auftragsformular) frei nach Ihren Wünschen kostenpflichtig gestaltet werden kann. In unserem Auslieferungsstand finden Sie zurzeit drei Checklisten (CH1, CH2, CHGIB).

Die Checkliste kann bei der Erfassung der Wartungstermine vorbelegt werden.

[Bild]

In diesem Fall ist das Kreuzchen für den Ausdruck der Checkliste automatisch gesetzt.

Hinweis: Da die Druckausgabe der Checkliste auf einem anderen Drucker erfolgen kann, wird diese Ausgabe von einigen unserer Kunden für einen Etikettendruck verwendet. Dazu wurde ein spezielles Formular erstellt, mit dem auf einem kleinen Aufkleber die wichtigsten Auftragsdaten gedruckt werden. Dieser Aufkleber wird auf eine passende Magnetfolie aufgeklebt, die dann auf einer Blechtafel für die Terminierung verschoben werden kann. Nach der Erledigung wird auf die Magnetfolie einfach der nächste Aufkleber aufgeklebt und von Zeit zu Zeit der ganze Stapel abgezogen. Für diese Anwendung der Checkliste haben wir im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Kundendienst> <Grundeinstellungen> die Vorgabe der Checklistenausgabe ermöglicht.

[Bild]

[Bild: 5]

Zusatztext drucken

[Bild: 5. Zusatztext drucken]

Sollten Sie beim Kundendienstauftrag einen Zusatztext erfasst haben, wird dieser separat ausgedruckt, sofern Sie diese Option auswählen.

|
[Bild: 6]

KD-Checkliste

[Bild: 6. KD-Checkliste]

Wenn Sie das Modul KD-Checkliste erworben haben, wird ein weiterer Druckbereich aktiviert, um die KD-Checkliste zum Auftrag drucken zu können.

|
[Bild: 7]

Internet Stadtplan

[Bild: 7. Internet Stadtplan]

Mit Hilfe der Internetseite Google Maps wird der Standort der Objektadresse des Auftrages gezeigt. Voraussetzung ist natürlich, dass Sie eine Internetverbindung besteht. Die Funktionalität ist wie beim Stadtplan im Adressmodul realisiert.

|
[Bild: 8]

Internet Routenplan

[Bild: 8. Internet Routenplan]

Neben dem Internet-Stadtplan kann auch eine Anfahrtsskizze über Google Maps erstellt werden. Die Funktionalität ist wie beim Routenplan im Adressmodul realisiert.

[Bild]

Über ein Ankreuzfeld besteht die Möglichkeit, die Startadresse dauerhaft abzuspeichern. In diesem Fall wird bei der nächsten Benutzung automatisch diese Startadresse vorgeschlagen.

|
[Bild: 9]

SMS

[Bild: 9. SMS]

Wenn das SMS Modul vorhanden ist, können Sie aus der Druckmaske heraus eine SMS versenden. Details finden Sie im Handbuch Kapitel SMS Versand.

|
[Bild: 10]

TomTom

[Bild: 10. TomTom]

Wenn das TomTom Modul vorhanden ist, können Sie aus der Druckmaske heraus den Auftrag an TomTom senden. Details finden Sie im Handbuch Kapitel TomTom / Fahrzeugortung.

|
[Bild: 11]

Export an iDeXs

[Bild: 11. Export an iDeXs]

Wenn Sie iDeXs einsetzen, können Sie aus der Druckmaske heraus den Auftrag an iDeXs senden. Details finden Sie im Handbuch Kapitel iDeXs.

|
[Bild: 12]

Bildschirm

[Bild: 12. Bildschirm]

Wie beim Dokumentendruck kann auch der KD-Auftrag zu Kontrollzwecken auf den Bildschirm gedruckt werden.

|
[Bild: 13]

Abbruch

[Bild: 13. Abbruch]

Mit Abbruch wird die Druckmaske ohne Aktion geschlossen.

|
[Bild: 14]

Drucken

[Bild: 14. Drucken]

Mit Betätigung des Drucken Buttons werden alle aktivierten Druckaufträge ausgeführt. Im Regelfall dürfte das das KD-Formular [Nr.1] sein. Abhängig von Ihrer Arbeitsweise und der Auftragsart werden Sie noch andere Druckvarianten aktivieren.

Um den Arbeitsablauf flüssig zu gestalten, wird unmittelbar nach der erfolgten Druckausgabe das Druckfenster wieder geschlossen.
