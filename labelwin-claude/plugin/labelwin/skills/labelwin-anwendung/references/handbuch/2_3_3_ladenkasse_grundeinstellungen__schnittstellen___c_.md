2.3.3 Ladenkasse Grundeinstellungen „Schnittstellen“ (C)

Wenn Sie mit Zusatzgeräten wie einer Kassenschublade und einem Kundendisplay arbeiten, so müssen Sie hier die Anschlussparameter eingeben.

[Bild]

Als Grundvoraussetzung für den Anschluss muss der Rechner mit insgesamt vier seriellen Schnittstellen ausgerüstet sein. Dabei wird eine serielle Schnittstelle für den Mausanschluss benötigt. In der Regel beschränkt sich Ihre Eingabe auf das Feld ‚Nummer‘. Die hier einzutragende Nummer wird in der EDV üblicherweise auch als COM2, COM3, oder COM4 bezeichnet. Für Geräte, die Sie nicht angeschlossen haben, sollten Sie auf keinen Fall einen Eintrag vornehmen. Bei eingetragenen Nummern versucht das Programm immer wieder diese Schnittstelle anzusteuern und wird daher erheblich langsamer arbeiten.
