3.6 Ersatzteile hinterlegen

In dieser Maske können Sie Ersatzteile festlegen, die üblicherweis bei dem aktiven Anlagenteil zum Einsatz kommen. Typischerweise erfassen Sie hier Stellmotoren, Endschalter, Regelungen usw. Es geht zum einen darum, dass der Techniker bei einer Störung bereits das vermutlich ausgefallene Teil mitnehmen kann, aber auch um eine Bevorratung von häufig benötigten Teilen.

Wenn beispielsweise ein bestimmter Typ von Stellmotor häufig eingebaut ist und pro Jahr immer mal wieder einer ausfällt, so können Sie Ihren Auftraggeber sicher davon überzeugen, bereits im Voraus mindestens einen Stellmotor zu kaufen und bei sich zu lagern.

Die Ausgabe der Gesamt-Ersatzteillisten erfolgt unter dem Menüpunkt ‚Ersatzteilliste erzeugen’ Vor dem Ausdruck können die Listen so verdichtet werden, dass jeder Artikel nur einmal, aber mit der entsprechenden Stückzahl in der Liste erscheint.

Es können lediglich in den Artikelstammdaten gespeicherte Artikel verwendet werden. Eine freie Erfassung haben wir bewusst verhindert, da dann keine Zusammenfassung von gleichen Artikeln möglich ist. Sollte Ihnen Ihr Lieferant also die Artikel nicht per Datanorm zur Verfügung stellen, so müssen Sie diese in Ihrem eigenen Katalog selbst erfassen. Die Erfassung findet wie üblich mit dem Programmmodul ‚Kataloge’ statt.

[Bild]

1 Materialtabelle: Hier sehen Sie eine Liste der bereits hinterlegten Ersatzteile.

2 Katalog: Legen Sie hier fest, in welchem Katalog der anschließend aufzurufende Artikel gespeichert ist.

3 Suchbegriff: Geben Sie hier die Artikelnummer oder beliebige Textbestandteile aus der Artikelbeschreibung ein. Betätigen Sie den Enter-Knopf, um die Suche auszulösen oder betätigen Sie den Knopf Liste (Nr. 4).

4 Liste-Knopf: Wenn Sie einen Suchbegriff eingegeben haben, können Sie durch diesen Knopf oder die Enter-Taste die Suche auslösen.

5 Anzahl: Setzen Sie hier die Anzahl der bei der Wartung erforderlichen Artikel ein.
