3. Arbeiten mit der Bauakte

Projekt und Benutzer ins Web laden

Wenn Sie wieder zurück in der Maske der Projektfreigabe sind, wählen Sie die jeweiligen Ansprechpartner aus und betätigen den Knopf ‚Freigeben‘. Damit werden die Anwender in die Tabelle oben geschrieben.

Wenn Sie alle Personen festgelegt haben, die das Projekt im Web nutzen sollen, laden Sie das Projekt und die Benutzernamen mit dem Knopf <Hochladen> ins Web.

Jetzt bekommen alle freigegebenen Personen eine Email, wenn sie erstmalig im Web freigegeben werden. In dieser Email muss jeder auf den Link klicken und sich ein neues Password ausdenken. Das kann auch 123 sein.

Ab dann ist das Projekt im Web verfügbar. Die generellen Zugangsdaten stehen in der erwähnten Email. Am besten sollte der Anwender den Zugang in den Favoriten auf dem Handy hinterlegen.

Dokumente ins Web schieben

Im nächsten Schritt können nun alle gewünschten Dokumente hochgeladen werden. Es können nur Dokumente hoch geladen werden, die in einem für das Web freigegebenen Register liegen. Die Registerzuordnung kann über 2 Wege erfolgen:

1) die Maske Dokumenteninfo

2) Man kann man einzelnen oder mehreren Dokumenten ein Register zuordnen, indem mn sie markiert und dann mit der rechten Maustaste den Menüpunkt ‚Register zuordnen‘ anwählt. Für das Web freigegebene Register erkennt man am (DB) – das soll ‚digitale Bauakte‘ bedeuten.

Alle Dokumente in einem für das Web freigegebenen Register können auf einen Rutsch hochgeladen werden. Dazu werden sie wieder mit der Mehrfachmarkierung gekennzeichnet und mit der rechten Maustaste der Punkt <Freigabe digitale Bauakte> angewählt.

[Bild]

In dieser Maske können einzelne Personen oder alle für das Projekt zugelassene Anwender gewählt werden. Bei der Freigabe für alle steht das Dokument auch für nachträglich aktivierte Web-Namen zur Verfügung. Wenn Sie in diesem Beispiel die beiden Nutzer wählen, ist das im Moment das gleiche Ergebnis, aber wenn später bei der Projektfreigabe noch jemand dazu kommt, kann derjenige das Dokument nicht sehen.

Es können nicht alle Dokumente ins Web geschoben werden, sondern im Prinzip nur solche, die nicht direkt in der Label-Datenbank liegen. Also keine Dokumente auf Artikelbasis, sondern nur Pdfs, Word, Excel usw. Wenn Dokumente auf Artikelbasis dagegen im Druckarchiv / Scanarchiv abgelegt sind, wird die PDF hochgeladen.

Im Web angelegte Dokumente ins Labelwin importieren

Da Labelwin das führende System sein soll, sollten von Anwendern dort abgelegte Daten wie Fotos, Notizen usw. auch im Labelwin vorhanden sein. Dazu gibt es im Labelwin in der Projektmaske einen Menüpunkt, der alle Dokumente für alle aktiven Projekte abholt. Der Menüpunkt ist unter <Projekt>, <Digitale Bauakte abgleichen> zu finden.
