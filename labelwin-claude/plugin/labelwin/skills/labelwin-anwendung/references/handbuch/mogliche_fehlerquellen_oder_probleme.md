Mögliche Fehlerquellen oder Probleme

Fehler 76: Pfad nicht gefunden

Stellen Sie sicher, dass es folgenden korrekten Eintrag gibt:

In der Datei c:\windows\labelusr.ini muss es folgenden Eintrag geben:

[Grundeinstellungen]

Labelpfad=d:\labelwin\

Dieser Eintrag wird normalerweise bei der Erstinstallation automatisch eingerichtet. Nach einer Uminstallation kann er aber falsch sein.

Fehler 429 oder keine Aktion wird ausgeführt

Prüfen Sie, ob die Verweise zu Microsoft XML und Microsoft Scripting Runtime richtig gesetzt sind, so wie in Punkt 9 beschrieben.
