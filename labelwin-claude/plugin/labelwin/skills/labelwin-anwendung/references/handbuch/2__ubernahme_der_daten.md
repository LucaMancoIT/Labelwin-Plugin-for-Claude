2. Übernahme der Daten

Falls Sie das Modul nicht geöffnet haben, starten Sie die angelegte Verknüpfung ‚Mareon Import‘.

Testlogin

Bevor Sie zum ersten Mal Daten übernehmen, sollten Sie unbedingt den Knopf ‚Testlogin‘ betätigen.

[Bild]

Hier sollten Sie eine Bestätigung erhalten, dass das Testlogin erfolgreich war. Sollte dieses nicht der Fall sein, so überprüfen Sie bitte Ihre Eingaben in der Einstellmaske. Gehen Sie dazu auf den Menüpunkt <Datei> <Grundeinstellun-gen>. Wenn Sie den Fehler so nicht finden können, setzen Sie sich entweder mit Label oder Mareon in Verbindung. Der Fehler wird sicherlich schnell behoben sein.

Kataloge einlesen

Nach erfolgreichem Testlogin müssen nun die Kataloge eingelesen werden. Hierzu betätigen Sie bitte den Knopf ‚Kataloge einlesen‘. Das System holt nun selbstständig die Kataloge aus dem Internet und legt diese im Modul KATALOGE neu an. Dieser Vorgang kann je nach Umfang und Zugangs-geschwindigkeit des Internets einige Zeit in Anspruch nehmen.

Sie brauchen die Kataloge nur einmal einlesen. Den Vorgang müssen Sie nur dann wiederholen, wenn Sie später vom Programm dazu aufgefordert werden.

Aufträge abholen

Mit dem Knopf ‚Aufträge abholen‘ werden alle im Internet hinterlegten Aufträge automatisch in das Kundendienst-Modul übernommen. Sie müssen dabei bei jedem Auftrag entscheiden, ob Sie annehmen wollen oder nicht. Abgelehnt werden in der Regel nur fehlgeleitetet Aufträge, bei denen zum Beispiel das Gewerk falsch angegeben wurde.

[Bild]

Mit ‚Weiter‘ wird der Auftrag weder bestätigt noch abgelehnt, sondern bleibt unverändert im Internet stehen.

Da mit jedem Auftrag eine Objektadresse übermittelt wird und diese unbedingt in das Labelwin-System übernommen werden muss, werden Sie gefragt, ob die übermittelte Adresse neu angelegt oder auf eine bestehende Adresse verweisen soll.

[Bild]

Nachdem eine Adresse einmal übertragen wurde, wird zu dieser Adresse ein unsichtbares Mareon-Kennzeichen hinzu geschrieben. Somit erfolgt keine Adressabfrage beim nächsten Auftrag für diese Adresse.
