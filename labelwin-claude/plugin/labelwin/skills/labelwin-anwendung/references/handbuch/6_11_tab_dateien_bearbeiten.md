6.11 TAB Dateien bearbeiten

Die sogenannten TAB Dateien, mit denen die Spalten einer Tabellenansicht festgelegt werden können, sind relativ einfach vom Anwender selbst zu verändern.

Tipp: Weiter unten auf dieser Seite finden Sie ein Tutorial Video, das Ihnen die Handhabung anschaulich erklärt.

TAB-DATEIEN ERSTELLEN

[Bild: 6.11 TAB Dateien bearbeiten]

Bild: TAB Dateien erstellen

Hinweis: TAB Dateien gelten für alle Mitarbeiter. Möchte man mit einer individuellen TAB Datei arbeiten, ist dies auch möglich (> Button 'Meine' TAB-Datei). Hierbei ist aber zu beachten, dass es zwingend auch eine allgemeine TAB Datei geben muss, da die individuelle TAB Datei sonst nicht wirksam wird.

|
[Bild: 1]

Bereich

[Bild: 1. Bereich]

Hier wählen Sie den Bereich im Programm in dem die Tabellenansicht modifiziert werden soll.

|
[Bild: 2]

Vorlage

[Bild: 2. Vorlage]

Die Vorlage wird automatisch entsprechend der Auswahl in Bereich [Nr.1] gewählt. In der Vorlage befinden sich alle für die TAB-Datei wählbaren Datenfelder. Alle Felder werden unter der Vorlage aufgelistet.

Hinweis: Alle Felder, die das Programm ohne TAB Datei als Standard anzeigt werden, sind in der Spalte "Standard" mit x markiert.

|
[Bild: 3]

TAB-Datei

[Bild: 3. TAB-Datei]

Hier wird die TAB-Datei gewählt, die bearbeitet werden soll. Der Inhalt dieser TAB-Datei wird in Bereich [Nr.6] aufgelistet.

|
[Bild: 4]

Neue TAB Datei

[Bild: 4. Neue TAB Datei]

Sollte noch keine TAB-Datei im gewählten Bereich [Nr.1] existieren, muss eine neue Datei angelegt werden.

|
[Bild: 5]

Meine TAB Datei

[Bild: 5. Meine TAB Datei]

TAB Dateien gelten für alle Mitarbeiter. Möchte man mit einer individuellen TAB Datei arbeiten, ist dies über diesen Button möglich. Dazu erstellt man zuerst eine neue TAB-Datei [Nr.4] und wählt dann mit diesem Button die neue TAB-Datei als die eigene aus.

|
[Bild: 6]

TAB Datei

[Bild: 6. TAB Datei]

Hier werden alle Felder, die in der unter [Nr.3] gewählten TAB-Datei enthaltenen sind, angezeigt.

|
[Bild: 7]

Editieren

[Bild: 7. Editieren]

Durch Aktivieren dieses Feldes, können die Daten im aktiven Feld [Nr.8] bearbeitet werden.

|
[Bild: 8]

Aktives Feld

[Bild: 8. Aktives Feld]

In diesem Bereich werden Details zu dem in der Liste [Nr.6] markierten Eintrag angezeigt. Wird die Option "Editieren" [Nr.7] gesetzt, können die Daten verändert werden.
