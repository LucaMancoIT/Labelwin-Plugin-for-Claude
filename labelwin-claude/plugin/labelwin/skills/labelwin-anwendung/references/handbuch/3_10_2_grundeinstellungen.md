3.10.2 Grundeinstellungen

In diesem Bereich legen Sie fest, wie sich das Programm beim Erledigt setzen von Arbeitsaufgaben. Sie haben hier die Möglichkeit, dass Sie beim Erledigt setzen das Tagesdatum und/oder ein Soll-Mitarbeiten vorgeschlagen werden.

Damit sparen Sie ein paar Tastendrucke, haben aber auch eine mögliche Fehlerquelle, weil Vorgaben sehr leicht ohne Nachdenken übernommen werden.
