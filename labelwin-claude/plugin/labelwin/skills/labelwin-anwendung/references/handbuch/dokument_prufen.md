Dokument prüfen

Hintergrund:

Bei der Bearbeitung von großen Angeboten oder Kalkulation von Fremd-LV`s taucht oft das Problem auf, dass bei einzelnen Positionen die Minuten fehlen, kein Verkaufspreis kalkuliert worden ist, der Einkaufspreis fehlt oder ähnliches. Um hier eine größere Sicherheit hineinzubringen wurde die im Folgenden beschriebene Prüfroutine entwickelt.

Zur Benutzung wählen Sie in der Maske der Dokumentenerstellung dem Menüpunkt <Anzeige> <Dokument prüfen> oder in der Toolbar [Bild] an. In der erscheinenden Maske müssen Sie ankreuzen, welche Funktionen Sie gerne geprüft haben möchten. Da es sich um ein reines Prüfprogramm handelt, findet keinerlei Veränderung des Dokumentes statt. Es wird lediglich ein sehr ausführliches Prüfprotokoll erstellt, dass anschließend abgearbeitet werden kann. Das Prüfprotokoll startet mit dem Windows-Standardprogramm ‚Notepad’ und kann über dessen Menü auch ausgedruckt werden.

Handhabung:

[Bild]

[Bild]

1 Deckungsbeitrag je Stunde: Wenn bei einer einzelnen Position der hier eingesetzte Deckungsbeitrag unterschritten wird, so wird diese Position in das Protokoll übernommen. Sollte eine Position keine Minuten hinterlegt haben, so findet die Prüfung nicht statt.

[Bild]

2 Zuschlag über alle Kosten: Hier legen Sie einen Gesamtzuschlag fest, bei dessen Unterschreiten die Position in das Protokoll aufgenommen wird. Nur wenn Sie diese Prüfung wegschalten, können Sie die unter 2 aufgeführten Zuschläge je Kostenart kontrollieren.

[Bild]

3 Zuschläge je Kostenart: Wenn Sie das Feld 2 nicht angekreuzt haben, können Sie hier die Zuschläge je Kostenart prüfen lassen.

[Bild]

4 Positionen mit Menge 0: Mit diesem Schalter werden alle Positionen in das Protokoll übernommen, deren Menge 0 beträgt.

[Bild]

5 ohne Lohnminuten: Wenn Sie eine Ausschreibung mit ‚liefern und montieren’ kalkuliert haben, so können Sie hier die Positionen heraus filtern, die versehentlich keine Lohnminuten bekommen haben.

[Bild]

6 Positionen ohne oder mit verminderter MwSt.: Wenn Sie bei den Artikeln verminderte oder keine MwSt. hinterlegt haben, können Sie hier diese Positionen herausfiltern.

[Bild]

7 Schlusstext: Bei der Vergabe von Artikelschlusstexten können Sie hier prüfen, welche Positionen anders lautende Schlusstexte haben.

[Bild]

8 Kostenstelle: Dieser Bereich ist nur für Betriebe interessant, die mit Kostenstellen arbeiten. Sie können hiermit prüfen, welche Artikel auf eine anders lautende Kostenstelle laufen.

[Bild]

9 Abgleich bereits bestellt Positionen: Die hier beschriebene Funktion ist nur für Betriebe interessant, die den Wareneingang buchen. Wenn eine neue Bestellung zusammengestellt worden ist, kann geprüft werden, ob Artikel bereits bestellt, aber noch nicht eingegangen sind. Damit kann ggf. eine Doppelbestellung der Lagerartikel verhindert werden. Der Abgleich erfolgt dann mit dem Knopf ‚Bestell Prüfung‘ (Nr. 15)

[Bild]

10 Bieterlücken/-ergänzungen anzeigen: Wenn Sie Ausschreibungen bearbeiten, in denen bei einigen Positionen ergänzende Angaben gemacht werden müssen, können diese per Protokoll angezeigt werden.

[Bild]

11 Gesamtpreise Verkauf: Durch das erste Feld können Sie festlegen, dass Artikel mit Verkaufspreis gleich Null in das Protokoll übernommen werden. Dabei ist es gleichgültig, ob der Artikel mit einem Einkaufspreis versehen worden ist oder nicht. Wenn Sie dieses Feld wegschalten, können Sie auch eine Eingrenzung auf die Positionen machen, deren Verkauf gleich Null und der Einkauf größer als Null ist. Durch einen Haken in dem dritten Feld, finden Sie die Artikel heraus, deren Einkaufswert auf Null und einem Verkaufspreis größer als Null sind. Solche Positionen verfälschen den Deckungsbeitrag enorm, da der Verkaufswert komplett auf die Ertragsseite genommen wird.

[Bild]

12 Verkaufspreise je Kostenart: Die gleichen Möglichkeiten wie unter Gesamtpreise Verkauf können Sie hier auf die Kostenarten Material, Fremdleistung und Sonstige Kosten auswählen.

[Bild]

13 Doppelte Artikel mit unterschiedlichen Preisen: Hier werden die Artikel aufgelistet, die mit der gleichen Artikelnummer und aus dem gleichen Händlerkatalog, aber mit unterschiedlichen Preisen versehen worden sind. Obwohl bei der Dokumentenerstellung hier diverse Warnungen erfolgen, kann hiermit noch einmal das Gesamtdokument geprüft werden.

[Bild]

14 Alle abwählen: Durch Betätigen dieses Knopfes werden alle zuvor getroffenen Auswahlen zurückgesetzt und Sie können eine andere Eingrenzung der Prüfung vornehmen.

[Bild]

15 Bestell Prüfung: Durch Betätigen dieses Knopfes erfolgt der Abgleich mit vorhandenen Bestellungen. Dieses ist nur möglich, wenn der Wareneingang gebucht wird.

[Bild]

16 Start-Knopf: Durch Betätigen dieses Knopfes starten Sie die Prüfung. Nach Ablauf wird automatisch das Prüfprotokoll angezeigt.

[Bild]

17 Abbruch-Knopf: Durch Betätigen dieser Taste beenden Sie die Prüfroutine.
