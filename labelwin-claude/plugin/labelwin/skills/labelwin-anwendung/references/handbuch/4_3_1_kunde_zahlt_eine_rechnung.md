4.3.1 Kunde zahlt eine Rechnung

[Bild]

An der Ladenkasse können Ihre Kunden auch Rechnungen bezahlen. Dies lässt sich einfach über den Menüpunkt <Sonderbelege> <Kunde zahlt Rechnung> (oder F3) realisieren.

Sie werden aufgefordert die Rechnungsnummer einzugeben. Zur Kontrolle werden bei einer gültigen Rechnungsnummer die Adresse und der Rechnungsbetrag angezeigt.

Sollte die Rechnung bereits beglichen sein, wird das gemeldet. Es kann aber eine Stornobuchung vorgenommen werden. Mit Eingabe einer negativen Summe können Sie die Rechnung wieder freigegeben.

Nach Bestätigung mit Ok wird automatisch ein Artikel mit aussagekräftigem Text und der Summe der Rechnung erzeugt. Diese Position muss nur noch in den Beleg übernommen werden. Hierzu wird einmal der Button „Übernehmen“ gedrückt. Abschließend kann der Beleg wie gewohnt gedruckt werden.

Die Rechnung wird automatisch auf bezahlt (bzw. im Falle einer Stornobuchung auf offen) gesetzt.

Da die Einnahmen bei Rechnungen anders verbucht werden als bei Barverkäufen, können keine weiteren Artikel mit abgerechnet werden. Nur die Bezahlung einer weiteren Rechnung ist im gleichen Beleg möglich.
