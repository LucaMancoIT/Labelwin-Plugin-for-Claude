4.3.2 Bargeldentnahmen und Bargeldauffüllung

[Bild]

Von Zeit zu Zeit wird Geld aus der Kasse entnommen und bei der Bank eingezahlt. Eine solche Kassenentnahme muss selbstverständlich erfasst werden, um den korrekten Kassenbestand fortzuschreiben.

Über den Menüpunkt <Sonderbelege>, <Bargeld an Kassenbuch> wird ein Beleg erstellt, der eine Position mit dem Text „Bargeld-Entnahme an Kasse“ enthält. Die Buchung an das Kassenbuch erfolgt in diesem Fall umgehend, also ohne den Menüpunkt die <Übergabe an Kassenbuch (Z-Bon)>.

Durch die Eingabe einer negativen Zahl kann eine Auffüllung der Kasse mit Geldbestand aus der Bar-Kasse erfolgen. Sie können bei Bedarf einen Kommentar erfassen. Dieser erscheint auf dem Beleg, im Logbuch der Ladenkasse und im Buchungstext im Kassenbuch (nur die ersten ca. 25 Zeichen!)

[Bild]

Der Beleg muss noch gedruckt werden, damit die Buchung stattfindet. Bitte beachten Sie, dass die Zahlen in der Druckmaske das umgekehrte Vorzeichen haben. Eine Entnahme wird in dieser Maske positiv eingegeben, sie steht aber auf der Druckmaske und auf dem Beleg negativ.

[Bild]

Über den Menüpunkt <Sonderbelege>, <Bargeld entnehmen> wird ein Beleg erstellt, der eine Position mit dem Text „Sonstige Bargeld-Entnahme“ mit einem zusätzlichen freien Kommentar enthält. Es erfolgt keine sofortige Buchung an das Kassenbuch. Diese Übergabe erfolgt zusammen mit den anderen Umsatz­buchungen.

Durch die Eingabe einer negativen Zahl kann eine Auffüllung der Kasse mit Geldbestand aus der Bar-Kasse erfolgen.

Auch dieser Beleg muss noch gedruckt werden, damit die Buchung stattfindet.

Hinweis: Diese Sonderbelege dürfen immer nur einen Vorgang haben. Sollte der aktuelle Beleg bereits Buchungen haben, müssen Sie die den beleg erst beenden oder die Positionen löschen.
