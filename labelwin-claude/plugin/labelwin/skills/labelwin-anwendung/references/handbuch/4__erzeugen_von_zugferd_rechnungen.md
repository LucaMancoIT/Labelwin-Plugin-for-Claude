4. Erzeugen von ZUGFeRD Rechnungen

Das Erzeugen von ZUGFeRD Rechnungen ist denkbar einfach. Drucken Sie die Rechnung aus der V5 Projektverwaltung heraus (oder aus dem V5-Kundendienst über den Drucken-Knopf in den Zugeordneten Dokumenten) an den eingerichteten speziellen ZUGFeRD-Drucker. Die PDF wird automatisch im PDF/A3 Format mit eingebetteter ZUGFeRD XML-Datei erzeugt.

Wichtig: Bitte beachten Sie, dass der Rechnungsdruck aus der Positionserfassung (V4-Version) heraus keine ZUGFeRD Datei einbettet, auch wenn Sie den richtigen Druckertreiber ausgewählt haben.

Überprüfen der ZUGFeRD PDF

Eine ZUGFeRD PDF sieht genauso aus wie eine normale PDF. Lediglich wenn Sie die Datei mit dem Acrobat Reader (nicht mit dem Webbrowser) öffnen, sehen Sie einen Unterschied in der Anzeige.

Mit einem Klick auf die Büroklammer sehen Sie die „ZUGFeRD-invoice.xml“ als Anlage. Per Doppelklick können Sie sich diese XML-Datei anschauen. Wichtig ist, dass der Dateiname genauso geschrieben ist (Groß-/Kleinschrift beachten!).

Um festzustellen, ob die ZUGFeRD PDF wirklich regelkonform ist, können Sie diese über das Web-Portal https://www.din-zugferd-validation.org prüfen lassen. Dazu müssen Sie sich dort einmalig anmelden. Alles weitere entnehmen Sie bitte der Webseite.
