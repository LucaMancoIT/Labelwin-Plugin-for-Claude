2.4 Nullbeleg für Summenspeicher erzeugen

Wichtig in Österreich:

Der Umsatz der Ladenkasse wird im Hintergrund mitgeführt und kann über Protokolle ausgegeben werden. Der Umsatzzähler kann nie wieder auf Null gesetzt werden, sondern darf und kann je Kasse nur einmalig auf

Null gesetzt werden.

Dieser Menüpunkt muss einmalig angewählt werden, nachdem die Signatureinheit angeschlossen wurde.

|

Info: Die Protokollierung der Umsätze ist eine gesetzliche Anforderung an Registrierkassen aus Österreich,

die ab dem 01.04.2017 gilt. In Deutschland soll eine vergleichbare Gesetzesanforderung folgen.

[Bild]

Den entsprechenden Menüpunkt erreichen Sie in der Ladenkasse über <Optionen> <Sonderfunktionen> <Startbeleg für Summenspeicher erzeugen >.

Durch Anwahl dieses Menüpunktes wird automatisch ein entsprechender Kassenbeleg erzeugt, der wie eine normale Kassenbuchung gedruckt werden muss. Anschließend können Sie die Ladenkasse wie gewohnt nutzen.

Bei einer Ladenkassen-Ersteinrichtung sollte als nächstes noch der Wechselgeld-Bestand eingetragen werden.

Wichtige Info: Der Umsatzzähler zählt in Sonderfällen etwas ungewöhnlich. Ein Gutscheinverkauf findet sich nicht in diesem Umsatz, sondern nur die Einlösung. Eine in Bar bezahlte Rechnung findet sich dagegen im Umsatzzähler.

Übersetzt: Das Protokoll dient eigentlich nur der Finanzbehörde. Für die eigene Auswertung muss man die Erlöskonten betrachten (Kassenbuch).
