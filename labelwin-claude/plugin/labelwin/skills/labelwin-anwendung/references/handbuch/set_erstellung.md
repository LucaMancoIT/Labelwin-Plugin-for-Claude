Set Erstellung

Sets können auf mehrere Arten erzeugt werden. Zum einen ist es möglich, die Sets in den Artikelstammdaten abzulegen, zum anderen können Sets auch frei erfasst werden. Bei der Ablage in den Stammdaten ist es möglich, die Unterartikel des Sets gleich mit abzuspeichern oder nur die Setüberschrift zu speichern und die Unterartikel jeweils per Hand aufzurufen. Beim Aufruf eines Sets mit hinterlegten Bestandteilen werden alle Unterartikel neu aus den Stammdaten aufgerufen und gemäß Ihrer Kalkulationseinstellung kalkuliert.

Set frei erfassen:

Wählen Sie in der Artikelmaske in dem Feld ‚Artikelart’ die gewünschte Setart. Schreiben Sie in das Anzahlfeld die gewünschte Menge hinein. Schreiben Sie in dem Kurztextfeld den gewünschten Überschriftstext wie z.B. Waschtischanlage bestehend aus ... hinein. Durch Betätigen des OK-Knopfes wird in dem Dokument ein Artikel ‚Setanfang’ und ein Artikel ‚Setende’ angelegt. Der Setanfang wird je nach Artikelart Set (Set Art. Liste multi), Sev (Set verborgen multi), Sad (Set. Art. Liste additiv) und Sav (Set verborgen additiv) und SSu (=Setsumme) gekennzeichnet. Die Setbestandteile müssen zwischen diesen beiden Artikeln abgelegt werden. Der Artikel mit der Setsumme wird automatisch markiert, so dass Sie die im Folgenden aufgerufenen Artikel vor die Setsumme einfügen. Zum Beenden des Sets müssen Sie hinter die Setsumme hüpfen. Dies können Sie in der Maske direkt anwählen indem Sie den Knopf ‚Set beenden’ betätigen.

Set in die Stammdaten schreiben:

Aktivieren Sie die Artikelstammdaten und geben als Artikel-Nr. eine beliebige Bezeichnung ein. Wir empfehlen Ihnen, die Artikel-Nr. mit ‚Set’ anfangen zu lassen, damit Sie Ihre Setartikel bequem wieder finden können. Legen Sie die Artikel unbedingt wie alle anderen selbst erfassten Artikel in dem eigenen Artikelkatalog ab. Wählen Sie als Artikelart die gewünschte Setart. Schreiben Sie in den Kurztext den gewünschten Beschreibungstext hinein. Betätigen Sie anschließend den ‚Speichern-Knopf’ oder den Knopf ‚Speichern und übernehmen’ Bis zu diesem Zeitpunkt haben Sie einen Set lediglich mit dem Beschreibungstext erfasst.

Wenn Sie diesem Set auch feste Bestandteile zuordnen wollen, so müssen Sie in den die Karteiseite Sets / Serienartikel anwählen. Wenn einem Set bereits Artikel zugeordnet sind, sind diese in der Tabelle sichtbar. Zum Erfassen und Ändern der Set – Bestandteile müssen Sie den Knopf ‚Set bearbeiten‘ drücken.

In der nun erscheinenden Tabelle geben Sie die Mengen und die gewünschten Artikel ein. Obwohl es auf den ersten Blick nicht sichtbar ist, stehen Ihnen an dieser Stelle wieder die ganz normalen Artikelsuchroutinen zur Verfügung. Geben Sie in der Spalte ‚Artikel-Nr.’ den gewünschten Suchbegriff ein. Wie beim sonstigen Artikelaufruf können Sie die Artikel-Nr., das Suchwort, oder ein beliebiges Textbestandteil eingeben. Falls der Artikel nicht eindeutig beschrieben ist, erscheint eine Liste aus der Sie den gewünschten Artikel auswählen können.

Sie können den aktiven Händlerkatalog jederzeit ändern. Die Verknüpfung der Artikelkataloge für die Suche ist an dieser Stelle weggeschaltet. Sie müssen also eindeutig festlegen, aus welchem Händlerstamm der Artikel hinterlegt werden soll. Nach Verlassen der Maske mit dem OK-Knopf sind dem Set sämtliche Unterartikel zugeordnet.
