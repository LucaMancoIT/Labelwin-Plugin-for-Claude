7.8 FTP Up-/Download Label Support

Mit diesem Menüpunkt können Datei, die größer als 5 MB sind per FTP auf den Label Software Support Server kopiert oder von diesem abgeholt werden. Die Zugangsdaten erhalten Sie bei jedem Datentransfer von der Hotline. Sie können jedoch auch jedes beliebige FTP-Programm dafür benutzen. Jedoch sollten Sie dann mit den Einstellungen für dieses Programm vertraut sein.
