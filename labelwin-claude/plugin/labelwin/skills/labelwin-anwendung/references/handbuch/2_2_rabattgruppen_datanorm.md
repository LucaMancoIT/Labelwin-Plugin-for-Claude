2.2 Rabattgruppen Datanorm

[Bild]

Bild: Rabattgruppen einlesen

Sie gelangen in diesen Bereich durch Wahl des Menüpunkts <Einlesen> <Rabattgruppen Datanorm>. Die Rabattgruppen sollten möglichst vor Einspielung der Datanorm eingelesen werden. In diesem Fall kann das Programm sofort beim Artikeleinlesen die jeweiligen Einkaufspreise ausrechnen. Falls Sie die Rabattgruppen erst im Nachhinein einlesen, so müssen Sie per Durchlauf die Einkaufspreise ausrechnen lassen. Dies geschieht unter dem Menüpunkt <Bearbeiten> <Rabattgruppen> <EK/VK neu rechnen>.

Wenn die Rabattdatei auf der gleichen CD bzw. Im gleichen Ablagepfade die die Datanorm-Artikeldaten ist, kann sie auch beim Einspielen der Artikeldaten (Menüpunkt <Einlesen> <Stammdaten Datanorm und Datpreis> verarbeiten werden.

Sollte Ihr Großhändler die Rabattgruppen nicht per CD übergeben, so können Sie sie auch per Hand erfassen. Dies erledigen Sie unter dem Menüpunkt <Bearbeiten> <Rabattgruppen>. Dort können Sie auch gegebenenfalls eine Liste aller im Artikelstamm verwendeten Rabattgruppen erzeugen. In diesem Fall brauchen Sie lediglich noch Ihre individuellen Rabattsätze eintragen.
