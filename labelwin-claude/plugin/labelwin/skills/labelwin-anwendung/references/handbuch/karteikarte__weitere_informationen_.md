Interne Nr.

[Bild: 5. Interne Nr.]

Innerhalb unseres Programms liegen alle Dokumente in einer Datenbank. Bei der Anlage bekommt jedes Dokument eine einmalig vergebene Nummer. Diese Nummer wird hier für Insider nur angezeigt, die darüber das Dokument in der Datenbank wieder finden können.

Ausgelagert in

[Bild: 6. Ausgelagert in]

Wenn ein Dokument in Bearbeitung genommen wird, wird nur dieses Dokument mit seinen Artikeln aus der Hauptdatenbank herausgelöst und in eine separate Datenbank eingetragen. Da es sich um einen Kopiervorgang handelt, ist das Dokument in der Hauptdatenbank dennoch vorhanden. Solange das Dokument in Bearbeitung ist, bleibt es ausgelagert. Im Netzwerk setzen wir das bearbeitete Dokument häufig auf die lokale Festplatte, da damit das Bearbeitungstempo erheblich erhöht wird. Sollte nun ein Benutzer das Dokument nicht ordnungsgemäß wieder in die Hauptdatenbank einlagern, ist hier nachzulesen, wo das Dokument sich zurzeit befindet.

|

Hinweis: Sollte ein ausgelagertes Dokument aus irgendwelchen Gründen nicht mehr zur Verfügung stehen, so kann über das Menü ‚Sonderfunktionen’ die Auslagerung weggesetzt werden. Bitte bedenken Sie, dass damit evtl. durchgeführte Änderungen auf der lokalen Festplatte verloren gehen. Sinngemäß wird in unserer Hauptdatenbank lediglich das Kennzeichen dafür weggesetzt, dass das Dokument auf einer lokalen Platte bearbeitet wird.

|
[Bild: 7]

Originaldatei

[Bild: 7. Originaldatei]

Bei großen Dokumenten besteht die Möglichkeit, diese außerhalb der Hauptdatenbank stehen zulassen. In diesen Fall ist das Dokument eine eigenständige Datenbank, die im Verzeichnis ‚Labelwin\Fern’ abgelegt wird. Der Vorteil liegt in einer wesentlich höheren Geschwindigkeit beim Aktivieren des Dokumentes. Wir bezeichnen die Ablage in einer separaten Datenbank als ‚Fernauslagerung’. Bei fern ausgelagerten Dokumenten ist hier der Pfad und Dateiname ablesbar. Dies kann ggf. wichtig sein, falls von einer Datensicherung die Datei rekonstruiert werden muss.

Zuordnungen

[Bild: 10. Zuordnungen]

Sie können Dokumente einem Wartungsvertrag, einer Anlage, einem Termin und einem Werkzeug (Werkzeugverwaltung) zuordnen. Üblicherweise geschieht dies, indem Sie in dem entsprechenden Bereich ein neues Dokument beginnen. Sollten Sie irrtümlich ein Dokument über die Projektverwaltung angelegt haben, so können Sie es unter diesem Punkt nachträglich dem entsprechenden Bereich zuordnen. Dazu müssen Sie allerdings die interne Nummer des Wartungsvertrages, die interne Nummer der Anlage, die interne Nummer des Termins und die interne Nummer des Werkzeuges wissen. Diese interne Nummer können Sie in der entsprechenden Maske nachlesen.
