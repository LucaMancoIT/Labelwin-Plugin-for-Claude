Musterrechnungen

Sowohl für die Vermittler-, als auch die Monteurprovision muss jeweils ein Musterdokument angelegt werden. Dies geschieht im Modul EINSTELLUNGEN unter dem Menüpunkt [Programmbereiche - Personal - Provision]. Mit den Knöpfen "Vorlage-Dokument" in dieser Maske gelangen Sie in die Musterrechnungen.

Die Bezeichnung der Musterrechnung ist beliebig. In den Musterrechnungen tragen Sie bitte bei der Vor- und Nachbemerkung die von Ihnen gewünschten Texte ein. In der Musterrechnung muss ein Artikel mit bestimmten Schlüsselworten eingetragen werden. Diese sehen Sie auf Seite 7 in diesem Dokument.

Provisionsgruppen und -sätze

Im ersten Schritt müssen die Bonusgruppen festgelegt werden. Die Eintragung erfolgt im Modul ‚Einstellungen’ unter den Menüpunkten ‚Grundeinstellungen, Bonusgruppen’.

Bonusgruppen eintragen

Über die Menüpunkte ‚Grundeinstellungen, Bonusprovision, Gruppen’ muss mindestens eine Gruppe angelegt werden.

(Grundeinstellungen - Bonusgruppen )

(jedem Artikel kann eine Bonusgruppe hinterlegt werden; jede Bonusgruppe kann unterschiedlich provisioniert werden)

[Bild]

[Bild]

Katalogmodul, Artikel bearbeiten

Dabei müssen mindestens so viele unterschiedliche Gruppen erfasst werden, wie Artikel für einen Vermittler oder einen Monteur mit unterschiedlichen Prozentsätzen beaufschlagt werden sollen. Wenn Sie also z.B. zwei verschiedene Prozentsätze setzen wollen, müssen Sie drei Bonusgruppen erfassen. Eine Bonusgruppe muss sinngemäß ‚keine Provision’ bedeuten.

Bonusprovisiongruppen eintragen

( Grundeinstellungen – Bonusprovision - Gruppen ) diese werden benötigt um den einzelnen Vermittlern / Monteuren / etc. unterschiedliche Provisionen für z.T. gleiche Artikel bezahlen zu können.

Es ist also möglich, dass der Monteur für einen Artikel X eine Prov. von 5%, ein anderer Monteur ggf. 6%, der Vermittler aber 8% bekommt.

[Bild]

Die Gruppenbezeichnung wird später bei den Adressen hinterlegt. Wenn Sie z.B. drei Vermittlertypen haben, die je nach Bonusgruppe unterschiedliche Prozentsätze erhalten, müssen Sie entsprechend drei Gruppen anlegen.

Für die Monteurprovision muss mindestens eine weitere Gruppe angelegt werden, die zwingend den Namen ‚Monteur’ haben muss. Wenn Sie einigen Monteuren eine individuelle Provision zuordnen wollen, so müssen Sie diese Gruppen ebenfalls anlegen. Wir empfehlen die Namen mit ‚Monteur’ anfangen zu lassen, damit sie von den Vermittlersätzen eindeutig getrennt werden können.

Bonusprovision-Sätze eintragen

( Grundeinstellungen – Bonusprovision - Provisionssätze )

Im nächsten Schritt müssen Sie diesen Provisionsgruppen die jeweiligen Prozentsätze zuweisen.

[Bild]

Den einzelnen Bonusprovisionsgruppen (also Monteur, Vermittler, etc.) können jetzt für die unterschiedlichen Bonusgruppen (also Leistungen, Material, TV, etc...) unterschiedliche Provisions-Prozentsätze hinterlegt werden.

Beispiel 1: Provisionsgruppe Monteur

- Monteur bekommt bei Notdienst x%,

- Reparaturen y%,

- Leistungen z%

- etc....

[Bild]

Beispiel 2 Provisionsgruppe Vermittlertyp C:

- Vermittler bekommt bei Notdienst 0%,

- Reparaturen 0%,

- Leistungen 15%

- etc....

Die Eintragung erfolgt unter „BONUSPROVISION“ Provisionssätze.
