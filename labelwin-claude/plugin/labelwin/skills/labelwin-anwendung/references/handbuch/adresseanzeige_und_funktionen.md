Adresseanzeige und Funktionen

Adressen werden im Adressmodul erfasst. Wie das genau funktioniert, wird im nächsten Kapitel Adressen - Stammdaten beschrieben.

Im Programm werden Adressen an diversen Stellen verwendet, z.B. im Projektdatenblatt, im Kundendienstauftrag, bei der Dokumentenanlage etc.

Die Darstellung kann in den verschiedenen Modulen etwas abweichen, es handelt sich aber immer um das (fast) gleiche Adressfenster.

Dieses Fenster beinhaltet neben den reinen Adressdaten auch weitergehende Informationen und Funktionen, die an dieser Stelle erläutert werden.

Adressanzeige

[Bild: Adresseanzeige und Funktionen]

|
[Bild: 1]

Kurzname / Suchwort

[Bild: 1. Kurzname / Suchwort]

Über dieses Feld können Sie eine Adresse aufrufen bzw. suchen. Die Möglichkeiten beim Adressaufruf werden in der Einleitung dieses Kapitels beschrieben.

Wurde eine Adresse gewählt, wird hier der Kurzname der Adresse angezeigt.

|
[Bild: 2]

Smiley

[Bild: 2. Smiley]

Wurde bei der gewählten Adresse ein Smiley hinterlegt, wird es hier angezeigt. Die Smiley Hinterlegung erfolgt auf Adressen Karteikarte 5 ‚Anmerkung’.

Hintergrund: Zusätzlich zur Adressanmerkung, die bei jeder Benutzung automatisch an die Oberfläche kommt, können einzelne Adressen mit einem Smiley versehen werden. Es handelt sich um ein kleines Bildchen, das beim Aufruf einer Adresse automatisch hinter dem Suchwort angezeigt wird, ohne dass automatisch eine Information sichtbar ist. So kann z.B. bei einem Kunden ein gelbes, beim anderen ein blaues Smiley an der Oberfläche erscheinen. Die Bedeutung der Smileys und die jeweiligen Bilder können Sie selbst festlegen. Wenn Sie mit der Maus auf das Smiley fahren, wird eine allgemeine Kurzinformation zu dem Smiley gezeigt. Dieses können z.B. Texte wie ‚wichtiger Kunde’ sein. Sobald Sie mit der Maus auf das Smiley klicken, erscheint ein individueller Text, der speziell für diese Adresse beim Smiley hinterlegt worden ist.

Im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Adressen> <Smiley> können Sie einen Namen festlegen und anschließend wählen Sie aus der Liste das gewünschte Smiley aus. Bitte bedenken Sie, dass Sie ein Smiley nur dann wieder löschen können, wenn es bei keiner Adresse verwendet wird. Sobald Sie einzelne Adressen damit versehen haben, ist das Löschen gesperrt.

|
[Bild: 3]

Suche

[Bild: 3. Suche]

Mit diesem Knopf lösen Sie die Adresssuche aus. Geben Sie dazu zuerst etwas beim Suchwort ein (1).

|
[Bild: 4]

Adressmodul

[Bild: 4. Adressmodul]

Wenn Sie diesen Knopf aktivieren, wird das Modul Adressen gestartet. Hier können dann ggf. Änderungen oder Ergänzungen an der gewählten Adresse vorgenommen werden oder eine ganz neue Adresse angelegt werden.

|
[Bild: 5]

Zugeordnete Adressen

[Bild: 5. Zugeordnete Adressen]

Wenn Sie diesen Knopf aktivieren, gelangen Sie in die Maske der weiteren Adressen und können hier ggf. etwas ergänzen.

|
[Bild: 6]

Adressdaten

[Bild: 6. Adressdaten]

Hier sehen Sie die komplette Anschrift. Es handelt sich hierbei um ein reines Anzeigefeld und dient nur zur Information. Änderungen können hier nicht vorgenommen werden.

|
[Bild: 7]

Aufgaben

[Bild: 7. Aufgaben]

Existieren bei der gewählten Adresse offene Aufgaben, wird hier ein gelbes Dreieck angezeigt.

Gibt es keine offenen Aufgaben, erscheint hier ein Blatt [Bild] über das eine neue Aufgabe zur Adresse angelegt werden kann.

|
[Bild: 8]

DSGVO Einwilligung

[Bild: 8. DSGVO Einwilligung]

Wurde bei der gewählten Adresse der Haken bei DSGVO Einwilligung gesetzt, wird hier ein grüner Haken angezeigt. Ohne Haken erscheint hier nichts.

Aktionen

Per Rechtsklick in das Adressfenster werden die Aktionen sichtbar:

|

[Bild]

|

|

LabelCRM wird mit der Adresse geöffnet.

|

Das Adressmodul öffnet sich mit der Adresse.

|

Die Adresse wird in GoogleMaps angezeigt.

|

Die Routenplanung startet mit der Adresse als Zieladresse.

|

Die angezeigten Adressdaten werden in die Windows Zwischenablage gelegt.

|

Das Aufgabenmodul wird mit dieser Adresse geöffnet. Sollten offenen Aufgaben vorliegen, werden diese angezeigt.

|

Die bei der Adresse hinterlegten weiteren Adressen werden geöffnet.

|

Die Dokumentenliste der Adresse wird angezeigt.

|

Die der Adresse zugeordneten Fotos werden geöffnet.

|

Es öffnet sich ein neuer Kundendienstauftrag zu dieser Adresse.

|

Die bei der Adresse hinterlegten Telefonnummern können direkt angewählt werden.

|

Mit SMS-Modul kann eine SMS an eine hinterlegte Mobilfunknummer gesendet werden.

|

Die Telefonkontakte der Adresse werden angezeigt.

|

Es wird eine Liste der letzten Telefonate mit dieser Adresse angezeigt. Das funktioniert aber nur mit aktivem Tapi-Modul.

|

Es wird eine Liste aktiver Pojekte angezeigt, bei der diese Adresse im Datenblatt hinterlegt ist.

|

Es öffnet sich eine neue E-Mail, die mit der bei der Adresse hinterlegten E-Mail Adresse vorbelegt wird.

|

Ist mindestens ein Weblink bei der Adresse hinterlegt, kann der hier direkt aufgerufen werden.

|

Die Anmerkungen der Adresse können hiermit direkt bearbeitet werden ohne zuvor die Adresse im Adressmodul öffnen zu müssen.

|

Die Adressinfo der Adresse kann hiermit direkt editiert werden ohne zuvor die Adresse im Adressmodul öffnen zu müssen.

Die angebotenen Funktionen finden Sie detaillierter beschrieben im Kapitel Stammdaten wieder.
