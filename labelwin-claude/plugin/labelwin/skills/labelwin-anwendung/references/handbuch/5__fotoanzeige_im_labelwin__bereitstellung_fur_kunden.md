5. Fotoanzeige im Labelwin, Bereitstellung für Kunden

Die Fotos können an allen zugeordneten Vorgängen angezeigt werden. Im maximalen Fall werden die Fotos diesen Daten zugeordnet:

- Kundendienstauftrag

- Projekt

- einer Zeitbuchung

- einer Objektadresse (des Auftrages oder des Projektes)

- einer Rechnungsadresse (des Auftrages oder des Projektes)

- einer Anlage (bei KD-Aufträgen mit zugeordneter Anlage)

- einem Wartungsvertrag (bei zugeordneter Anlage)

In allen angesprochenen Bereichen finden Sie einen Menüpunkt, um die zugeordneten Bilder zu betrachten.

In der Bildanzeige können eine oder mehrere Bilder markiert werden. Über das Menü können mit den markierten Bildern diverse Vorgänge ausgelöst werden:

- sie können per Mail verschickt werden (z.B. an den Kunden)

- sie können kopiert werden (z.B. auf einen USB-Stick für den Kunden)

- sie können in einen Wordtext kopiert werden (z.B. um damit eine kleine Doku zu erstellen)

- sie können einem anderen Auftrag oder Projekt zugeordnet werden, wenn die Zuordnung falsch ist.
