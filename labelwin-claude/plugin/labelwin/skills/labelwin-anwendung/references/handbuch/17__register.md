17. Register

|

Im Rahmen der digitalen Bauakte wurden auch Register im Projektemodul von Labelwin eingeführt. Sie erweitern den Dokumente-Baum, mit dem sich die Anzeige auf bestimmt Dokumenttypen beschränken lässt und bieten eine Möglichkeit die Dokumente in einem Projekt frei zu gruppieren. Um die Registeransicht zu öffnen klicken Sie im Projekte-Modul zunächst auf <Baum- und Registeransicht> und dann auf <Registeransicht aktivieren>. Für die Nutzung der digitalen Bauakte ist das Arbeiten mit Registern eine Grundvoraussetzung, es kann jedoch auch unabhängig davon den Arbeitsalltag erleichtern.

Einrichten

|

Register

Zunächst sind verschiedene Register anzulegen. Für jedes Projekt können dann aus diesem Set an Registern die gewünschten Register ausgewählt werden.

-

Im Einstellungsmodul öffnen Sie den Menüpunkt <Programmbereiche>

-

Unter <Dokumentenerstellung> wählen Sie <Register> und dann <Register erfassen>

-

Klicken Sie auf <Neu>

-

Tragen Sie bei "Registername" die Bezeichnung des Registers ein

-

Mit der Zahl bei Reihenfolge halten Sie fest an welcher Stelle in der Liste der Register das Neue Register erscheinen soll

-

Bestätigen Sie mit <Speichern>

-

Wiederholen Sie die letzten Schritte bis Sie alle Register erstellt haben und klicken Sie dann auf <Ende>

Unterregister

Ein Unterregister verhält sich genau so wie ein Register, in der Registeransicht befindet er sich jedoch nicht auf der selben Ebene wie die anderen Register sondern in dem Register dem er untergeordnet ist. Um ein Unterregister anzulegen gehen Sie wie oben beschrieben vor, setzen aber bei "Unterregister" ein Häkchen und tragen im Feld Reihenfolge die Nummer ein, die auf das Oberrigster folgt. Wenn sie, beispielsweise dem Register mit der Reihenfolge-Nummer 2 ein Unterregister verpassen wollen, dann geben Sie dem Unterregister die Nummer 3.

Grundregister

Jedes Projekt hat ein Grundregister, sogar wenn Sie nicht mit Registern arbeiten. Das Grundregister beinhaltet alle Dokumente, die keinem anderen Register zugeordnet sind. Wird ein Dokument in ein Projekt ohne direkte Registerzupordnung eingefügt landet es also zunächst im Grundregister. Sie können in der Register erfassen-Maske festlegen welches Register das Grundregister sein soll indem sie es anwählen, einen Haken bei "Grundregister" setzen und dann <Speichern> drücken.

Registervorlage

|

Im Einstellungsmodul finden Sie unter <Programmbereiche>, <Dokumentenerstellung> und <Register> ebenfalls den Menüpunkt Registervorlage. Mit einer Registervorlage können Sie sich jedes Mal, wenn Sie einem Projekt Register zuordnen, einige Klicks sparen. Sobald Sie einmal eine passende Registervorlage für ein typisches Projekt erstellt haben, müssen Sie beim erneuten Anlegen eines solchen Projekts nicht mehr die einzelnen Register diesem Projekt zuordnen. Anstelle dessen ordnen Sie die Registervorlage, in der genau diese Register enthalten sind, dem Projekt zu. Sie erstellen eine Registervorlage, indem Sie die Register, die Sie die gewünschten Register mit den Pfeiltasten in das Feld "zugewiesene Register" verschieben und dann auf <Speichern als Neu> klicken.

|

[Bild]

Registervorgaben

Im Einstellungsmodul finden Sie unter <Programmbereiche>, <Dokumentenerstellung> und <Register> den Menüpunkt Registervorgabe. Hier können Sie Vorschläge voreinstellen. Beim Erstellen von neuen Dokumenten wird dann je nach Dokumentenart vorgeschlagen, dass das Dokument diesem Register zugeordnet werden soll. Eine Vorgabe einzurichten gibt nur Sinn, wenn diese Dokumentenart fast immer in einem bestimmten Register zugeordnet werden soll. Solange ohne als Zuordnung ausgewählt ist, wird bei der Dokumentenanlage die Auswahl eines Registers erzwungen.

Anwendung im Projekt

|

Register im Projekt anlegen

Innerhalb eines Projekts können Sie über die Schaltfläche <Datenblatt> und <Register> bestimmen, welche Register für Dokumente in diesem Projekt verfügbar sein sollen.

Tipp: Für die Einführungsphase haben wir eine Möglichkeit geschaffen, für beliebig viele Projekte eine Registervorlage auf einen Rutsch anzuwenden. Wählen Sie dazu die Menüpunkte <Projekte>, <Projektliste>. Markieren Sie dort die entsprechenden Projekte mit der Mehrfachmarkierung (gedrückte Strg-Taste) und wählen die Menüpunkte <Option>, <Registervorlage> an. Wählen Sie dann die gewünschte Vorlage. Es werden nur Projekte mit Registern versehen, die bisher keine hatten.

|

|

Register einem Dokument zuordnen

Sie ordnen die einzelnen Dokumente per Rechtsklick + <Register zuordnen> oder über die Dokument-Info dem jeweiligen Register zu.

Das ganze funktioniert auch für mehrere Dokumente per Mehrfachmarkierung.

Registeransicht aktivieren

Sind alle Dokumente einmal zugewiesen, können Sie im Projekte-Modul links oben über <Baum- und Registeransicht> und <Registeransicht aktivieren> die Projektansicht nach den Registern filterm, um die Anzeige auf die relevante Dokumentenauswahl zu reduzieren.

Register in der Fotoanzeige

Auch Fotos können mit Registern versehen werden. So können auch Fotos aus Labelwin heraus in die digitale Bauakte verschoben werden. Wie bei Dokumenten muss das jeweilige Foto dafür zu einem Register gehören, das in der Bauakte freigegeben ist. Es können dank der Register auch Fotos, die von einem anderen Nutzer in die digitale Bauakte geladen wurden, in Labelwins Fotobereich angezeigt werden. Zuvor waren Fotos aus der digitalen Bauakte in Labelwin nur als Dokumente in Projekten zugänglich. Vor diesem Hintergrund ist auch die Langbeschreibung eingeführt worden. Da man in der Bauakte zu jedem Dokument, also auch zu einem Foto - beliebig viel schreiben kann, wird dieser Text nun im Langtext abgespeichert.
