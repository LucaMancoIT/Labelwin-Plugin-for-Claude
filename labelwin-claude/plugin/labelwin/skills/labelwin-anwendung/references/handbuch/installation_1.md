Installation

Die Installation erfolgt in 3 Schritten:

1. Bitte spielen sie das auf der CD vorliegende Programmversion bzw. das Update ein.

2. Auf der CD existiert ein Verzeichnis ‚instTGM’. Bitte spielen Sie dieses Verzeichnis als Update ein.

[Bild]

3. Hiermit werden die benötigten Datenbanken und Druck-Reports für das TGM-Modul installiert.

4. Nun müssen noch 2 Verknüpfungen zur Programmbenutzung an die Oberfläche geholt werden. Beide Programme liegen im Verzeichnis Labelwin. Es handelt sich um die Datei TGMhaupt.exe und TGMgrund.exe. Mit der TGMhaupt.exe erfassen und verwalten Sie Ihre Anlagen, mit der TGMgrund.exe können Sie die Leistungstexte nach Ihren Wünschen erweitern.

Am besten nennen Sie die Verknüpfungen TGM-Haupt und TGM-Grund.
