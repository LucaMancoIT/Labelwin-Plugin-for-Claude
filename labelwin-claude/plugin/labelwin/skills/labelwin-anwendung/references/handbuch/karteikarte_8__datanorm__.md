Katalogseite

[Bild: 2. Katalogseite]

In diesem Feld kann der Händler die Katalogseite eintragen. Sie wird z. Zt bei uns nicht verwendet.

|
[Bild: 3]

Langtextname

[Bild: 3. Langtextname]

Bei Datanormartikeln gibt es häufig einen Langtext, der für mehrere Artikel gleich verwendet wird. Der Langtextname kann an dieser Stelle weder eingegeben, noch verändert werden. Bei den selbst erfassten Artikeln wird der Langtext bisher für jeden Artikel speziell erfasst. Eine Mehrfachverwendung des gleichen Langtextes ist z.Zt. nicht vorgesehen.

[Bild: 4]

CU-Verarbeitung

[Bild: 4. CU-Verarbeitung]

Über ein Kreuz in diesem Feld wird die Ermittlung des Einkaufspreises mit Hilfe der Kupferanteile aktiviert.

CU-Gewicht: Geben Sie das Gewicht der zuvor festgelegten Mengeneinheiten ein.

CU-Gewicht je: Geben Sie hier die Menge ein, für die das folgende Kupfergewicht gilt. Bei Kabeln wird das Gewicht häufig je 1000 Meter angegeben.

Basis: Wenn im Artikeleinkaufspreis bereits Kupferanteile berücksichtigt sind, so wird hier die berücksichtigte Del-Notiz eingesetzt. Die meisten Großhändlerartikel sind auf der Basis 300 vorkalkuliert.
