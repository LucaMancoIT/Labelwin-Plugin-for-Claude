3.14 Eingangsrechnungen

Um auf jeder TGM-Ebene eine Nachkalkulation zu ermöglichen, ist es zwingend erforderlich, auch direkt zurechenbare Eingangsrechnungen zuzuordnen. Dazu gibt es in der Maske der Verteilung einer Eingangsrechnung ein Eingabefeld für die TGM-Ebene. Wenn Sie einen Kundendienstauftrag zugeordnet haben, der auf ein TGM-Element verweist, so wird dieses automatisch vorgeschlagen.
