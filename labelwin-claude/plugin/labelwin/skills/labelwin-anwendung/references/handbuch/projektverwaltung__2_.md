Nachdem das Modul PROJEKTE gestartet worden ist, erscheint das aktive Projekt mit einer Liste aller dort abgelegten Dokumente auf dem Bildschirm.

Früher haben wir statt von Dokumenten an dieser Stelle von Texten gesprochen. Da dieser Begriff die Möglichkeiten des Programms nicht umfassend genug beschreibt, reden wir nun von Dokumenten. In einem Projektordner kann ein solches Dokument sein: ein Angebot, ein Brief, eine Zeichnung, ein Foto, eine Rechnung usw. Es läuft darauf hinaus, dass ein Projekt bei Labelwin ein Sammelbehälter für alle möglichen Vorgänge darstellt.

Am besten stellt man sich ein Projekt in Labelwin als Ordner vor, so wie er im Regal für die Papierablage genutzt wird.

Alle Dokumente, die mit unserem Programmpaket erstellt werden, müssen einem Projekt zugeordnet werden. Dies gilt für alle Dokumente, egal ob Angebote, Rechnungen, Lieferscheine, Kundendienstaufträge, usw. Jede neue Dokumentenanlage beginnt in diesem Fenster. In der Statusleiste dieses Fensters erkennen Sie das derzeit aktive Projekt. Sollte zu diesem Zeitpunkt kein Projekt aktiv sein, so ist dies ebenfalls in der Titelleiste dieses Fensters sichtbar.

Bei der oben dargestellten Maske handelt es sich quasi um das Hauptprogramm. Aus diesem Programmbereich heraus wird die Erstellung der meisten Dokumente gestartet.
