6.17 Betriebssystem / ADO Liste

Durch die Anwahl dieses Menüpunkts erhalten Sie eine Liste der Computer, die im letzten Monat Labelwin benutzt haben. Sollten Sie hier rot markierte Einträge finden, so handelt es sich um Computer mit einem älteren Betriebssystem, auf dem Labelwin nur eingeschränkt oder unter Umständen bald gar nicht mehr läuft. Wenn Sie den Knopf ‚Online-Hilfe’ betätigen, erhalten Sie über das LabelWiki weitere Informationen zur Betriebssystem-Voraussetzung.
