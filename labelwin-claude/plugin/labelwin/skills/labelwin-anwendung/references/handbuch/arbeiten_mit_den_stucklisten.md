Arbeiten mit den Stücklisten

In einem Dokument wählen Sie z.B. über <Schnellerfassung> den Suchbaum an. Sets/Stücklisten werden in das Dokument mit der Stükzahl „1“ übernommen, wenn Sie sie ohne Eingabe einer Stückzahl doppelt anklicken oder das Set einfach anklicken und dann den Button <OK, Aufrufen> klicken. Alternativ können Sie mehrere Sets gleichzeitig übernehmen, wenn Sie bei mehreren Sets Stückzahlen eintragen und dann auf <OK, Aufrufen> klicken.

Tipp: Schalten Sie in den Kalkulationseinstellungen vor dem Aufruf von Stücklisten auf ‚Vorgabe Langform‘ damit der Endkunde die Texte in voller Prosa lesen kann und auf ‚Eigene, ggf. Fremdminuten‘ wenn Sie die mobile offer –Arbeitszeiten mit nutzen wollen, die in das Feld Fremdminuten der Artikel eingetragen sind.
