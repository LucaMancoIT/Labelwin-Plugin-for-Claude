4. Vom Büro aus arbeiten

|

Um auch aus Labelwin heraus schnell auf die Bauakte-Maske zugreifen zu können, können Sie im Projekt über <Extern> auf <Digitale Bauakte (Web) starten> klicken.

Wenn Sie sich hier mit Ihren Zugangsdaten einloggen, können Sie vom Büro aus die digitale Bauakte genau so wie alle anderen Nutzer nutzen. Der einzige Unterschied ist, dass sie beim Dokumenten-Upload die Möglichkeit haben einen Haken bei nicht an Büro senden zu setzen. Das betreffende Dokument taucht dann nicht, wie alle anderen Dokumente, die über einen Browser in die digitale Bauakte geladen werden, in der Projektansicht in Labelwin auf.

In der Projektmaske von Labelwin gibt es einen Menüpunkt, der alle Dokumente für alle aktiven Projekte vom digitale Bauakte-Server in das jeweilige Projekt lädt. Klicken Sie dafür auf <Projekt> und dann <Digitale Bauakte abgleichen (Download)>.
