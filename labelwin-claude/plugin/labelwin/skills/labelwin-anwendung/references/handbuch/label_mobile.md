Label Mobile

Stand: 15.04.2019

(V5.89)

Label Mobile ermöglicht einen mobilen Zugriff auf die eigenen Daten der Branchensoftware Labelwin. Der Benutzer kann von überall auf seine Datenbank zugreifen, ohne irgendein Sicherheitsrisiko einzugehen. Smartphone, Tablet oder auch Laptop sind direkt mit Labelwin in der Zentrale verbunden. Der Datentransport erfolgt zwar über das Internet, aber verschlüsselt und ohne Speicherung in der Cloud. Trotzdem hat der Benutzer die gewünschten Daten in Echtzeit zur Verfügung.

Wir möchten hier darauf hinweisen, dass unser Webserver nur Postbote spielt. Die Anfragen der App und die Antworten Ihres Labelwin-System liegen nur Sekundenbruchteile auf unserem Webserver und werden nicht ausgewertet und nicht protokolliert.

Label Mobile App für iOS, Android und Web

|

Die Label Mobile App gibt es kostenlos zum Download im App-Store für iOS-Geräte und im Google Play Store für Android Geräte. Außerdem ist sie direkt als Webanwendung per Browser verfügbar.

Zur Benutzung von Label Mobile benötigt man aber eine kostenpflichtige Label Mobile Grundlizenz, sowie weitere kostenpflichtige App-Lizenzen für jeden Benutzer.

Jeder Benutzer kann Label Mobile gleichzeitig auf bis zu 2 Geräten nutzen. Z.B. auf dem Handy und parallel auf einem Tablet.

Der Funktionsumfang der App hängt von den Einstellungen beim Benutzer (Personalstamm) ab. Derzeit kann ein Benutzer für das Basis- oder das Profi-Paket freigeschaltet werden. Wichtig zu wissen ist, dass die App die Berechtigungseinstellungen des Benutzers in Labelwin berücksichtigt.
