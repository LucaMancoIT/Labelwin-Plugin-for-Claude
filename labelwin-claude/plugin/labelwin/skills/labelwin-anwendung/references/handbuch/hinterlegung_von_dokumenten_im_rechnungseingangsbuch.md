Hinterlegung von Dokumenten im Rechnungseingangsbuch

Wenn Ihre Eingangsrechnungen direkt nach dem Posteingang im ELO gescannt werden, können Sie direkt aus der ELO Postbox das Dokument einem neuen Eintrag im Rechnungseingangsbuch zuordnen. Wählen Sie dazu die entsprechende Eingangsrechnung in der Postbox aus und betätigen Sie den Knopf ‚5‘. Es wird dann die Erfassungsmaske der Eingangsrechnungen gestartet und Sie können die Daten zu erfassen. Über den Knopf ‚Rechnung zeigen‘ können Sie sich die gescannte Rechnung ansehen.
