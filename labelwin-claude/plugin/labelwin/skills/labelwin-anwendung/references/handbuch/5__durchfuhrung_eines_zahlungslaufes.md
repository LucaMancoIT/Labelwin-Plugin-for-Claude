5. Durchführung eines Zahlungslaufes

An dieser Stelle möchten wir die Durchführung eines Zahlungslaufes mit der Überweisung per Diskette oder Modem konkret in den einzelnen Abläufen schildern.

·· Wählen Sie im Rechnungseingangsbuch den Menüpunkt <Zahlungen> <Bezahlen offene Rechnungen> an.

·· Wählen Sie bei Zahlungsart ‚Diskette/Modem’ an.

·· Wählen Sie die Option ‚Fällige Rechnungen bis’ und setzen das gewünschte Datum ein. Wenn Sie es möchten, können Sie das Kreuz bei ‚Skontofristen nutzen’ ebenfalls setzen.

·· Betätigen Sie den Knopf ‚Liste bilden’, damit aufgrund der Eingrenzung die entsprechenden Rechnungen in die Tabelle eingetragen werden.

·· Markieren Sie einzelne Zeilen, indem Sie mit der linken Maustaste einmal hinein klicken. In dem Feld Kennzeichen wechselt der Eintrag von O auf Z. Z bedeutet, dass diese Eintragung mit dem nächsten Zahlungslauf bezahlt werden soll. Sie können auch unter dem Menüpunkt <Bearbeiten> <Alle markieren> anwählen. Hierdurch werden alle in der Liste sichtbaren Rechnungen mit dem Z gekennzeichnet.

·· Wählen Sie den Knopf ‚Ok Zahlen’ an.

·· Bei der Zahlung per Diskette/Modem muss nun das Zielverzeichnis festgelegt werden.

[Bild]

Bild: Bankdiskette erstellen

Da die meisten PC’s heute gar nicht mehr über ein Diskettenlaufwerk verfügen, geben Sie hier einen Verzeichnispfad auf Ihrer Festplatte oder Ihr CD-ROM Laufwerk ein. Das Programm merkt sich die Eingabe und schlägt beim nächsten Mal den gleichen Pfad vor. Der Pfad muss von Ihnen selbst angelegt werden – unser Programm hat hierfür keine Vorgabe. Da die Datei später mit einem Modem direkt an die Bank übertragen werden kann, ist für uns der Pfad im Prinzip völlig gleichgültig.

Falls in dem Pfad bereits eine DTAUS1 – Datei ist (der Name ist von den Banken vorgeschrieben), besteht die Möglichkeit sie zu löschen. Löschen Sie nur Daten, die wirklich an die Bank übergeben worden sind.

·· Wählen Sie im nächsten Schritt die Bankverbindung, mit der Sie die Überweisung durchführen möchten.

[Bild]

Bild: Bankdaten

Übergabe der Datei an die Bank:

·· Wenn Sie die Daten per Diskette/CD an die Bank übergeben wollen, müssen Sie den vom Programm angebotenen Bankzettel ausdrucken. Bei der Übergabe per Modem oder Fritz-Karte wird der Bankzettel nicht benötigt, da Sie dort mit sogenannten TAN-Nummern arbeiten. Bei der Übergabe der Daten per Modem können wir Ihnen nur wenig helfen. Sie benötigen ein Programm von der Bank, mit dem Sie Zugriff auf Ihre Konten haben. Solche Programme haben irgendwo immer einen Menüpunkt, mit dem sich die DTAUS1-Datei zur Bank transportieren lässt. Irgendwo wird dabei der Pfad abgefragt, in dem sich die Datei befindet. Geben Sie ihn genau so an, wie bei der Erzeugung der Daten im Labelwin. Wenn Sie Probleme bei der Übergabe haben, so wenden Sie sich bitte an die Betreuer des Bankprogramms. Beim ersten Versuch empfehlen wir die Ausgabe auf Diskette/CD und das Einlesen beim Bankprogramm ebenfalls von der Diskette/CD vorzunehmen. Falls dabei nämlich Probleme auftreten, können Sie notfalls immer die Diskette/CD zur Bank geben. In diesem Fall müssen Sie beim ersten Versuch aber auch einen ‚Bankzettel’ ausdrucken lassen.

Protokoll und Begleitbriefe:

·· Drucken Sie unbedingt das Protokoll des Zahlungslaufes für Ihre eigene Ablage aus.

·· Falls Begleitbriefe für die Großhändler angeboten werden, lassen Sie diese bitte ebenfalls ausdrucken. Über einen Schalter in der Maske „Bezahlen“ unter dem Menüpunkt <Optionen> können Sie erreichen, dass zu jeder Zahlung ein Begleitbrief angeboten wird.

·· Damit ist der Zahlungslauf durchgeführt, und Sie können die erzeugte Datei ggf. an die Bank übergeben.

·· Sobald Sie sicher sind, dass die Überweisungen oder die Diskette/CD ordnungsgemäß erstellt worden sind, können Sie die Zahlungen auf erledigt setzen. Wenn Sie das Modul FIBUERFASSUNG nutzen, erfolgt die Buchung des Zahlungsausganges dort. Anderenfalls geschieht es auf der ersten Maske unter dem Menüpunkt <Zahlungen> <Bezahlt setzen Zahlungslauf>. Dort können Sie aus der Liste der offenen Zahlungsläufe den entsprechenden Zahlungslauf auswählen und diesen in einem Rutsch auf erledigt setzen.
