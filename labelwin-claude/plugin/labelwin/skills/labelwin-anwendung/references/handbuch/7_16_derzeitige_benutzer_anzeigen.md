7.16 Derzeitige Benutzer anzeigen

Wenn Sie ein Update einspielen und anschließend die Datenbank aktualisieren möchten, geht das manches Mal nicht, weil noch ein Benutzer im System ist. Über diesen Menüpunkt können Sie sich anzeigen lassen, welche Benutzer derzeitig im System angemeldet sind.
