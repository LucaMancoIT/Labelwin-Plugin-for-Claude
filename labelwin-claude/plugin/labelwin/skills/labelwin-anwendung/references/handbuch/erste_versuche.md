Erste Versuche

Die meisten Menschen probieren erst mal, bevor sie eine Gebrauchsanleitung lesen. Genauso können Sie sich auch diesem Modul nähern. Spätestens aber wenn Sie Abfragen selbst erstellen wollen, müssen Sie lesen, denn es ist nicht möglich, alle Funktionen an der Oberfläche selbsterklärend zu gestalten.

Starten Sie einfach das Modul ‚Selektieren’ (wie Sie es an die Oberfläche bekommen, steht in der Einleitung) und wählen mit F7 (oder über das Menü ‚Controlling, Abfragen ausgeben’) die Ausgabe an. In der Tabelle finden einige von uns mitgelieferte Einträge. Markieren Sie einen und betätigen den Knopf ‚Abfrage’. Das ist die Anwendung. Probieren Sie einfach nacheinander die ausgelieferten Abfragen aus.

Excel-Makros

Bei der Excel-Abfrage müssen Sie übrigens Makros zulassen. Sollte Ihr System auf einer so hohen Sicherheitsstufe stehen, dass selbst die Frage nach den Makros nicht kommt, so müssen Sie dies im Excel selbst umstellen. Gehen Sie auf die Menüpunkte ‚Extras, Optionen’. Wählen Sie die Karteiseite ‚Sicherheit’ und drücken den Knopf für ‚Makrosicherheit’. Stellen Sie die Sicherheitsstufe auf Mittel, dann werden Sie immer gefragt, ob Sie die in einer Tabelle enthaltenen Makros zulassen wollen. Da Makros Viren enthalten können, sollten Sie auf Fragen stellen. Makros immer zulassen wäre zu gefährlich, wenn Sie Makros nie zulassen, können einzelne Rechnungen ggf. nicht vorgenommen werden.
