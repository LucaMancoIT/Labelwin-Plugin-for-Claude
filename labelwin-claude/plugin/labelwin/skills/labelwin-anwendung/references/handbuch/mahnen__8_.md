Mahnen [8]

Stand: 24.09.2018

(V5.87)

Um das Programm-Modul Mahnen nutzen zu können, ist es erforderlich, dass Sie die Rechnungen in das Rechnungsausgangsbuch eintragen. Die Eintragung kann zwar auch per Hand erfolgen, in der Regel jedoch sollten Sie beim Drucken der Rechnung die Rechnung in das Rechnungsausgangsbuch eintragen lassen. Über die Wahl der Zahlungsbedingung erhält das Programm eine Information über die Fälligkeit der Rechnung. Über das Mahnwesen können nur fällige Rechnungen angemahnt werden. Das Mahnen kann in bis zu 4 Stufen erfolgen. Bei jeder durchgeführten Mahnung wird die Mahnstufe hoch gezählt. Über die Mahnstufe wird festgelegt, welcher Mahntext zum Ausdruck kommen wird.

Bevor Sie die erste Mahnung durchführen, sollten Sie unbedingt den Menüpunkt <Grundeinstellungen> anwählen. Tragen Sie dort ein, unter welchen Bedingungen Ihre Mahnungen durchgeführt werden sollen. Besonders wichtig ist der Mahnabstand, der zwischen den einzelnen Mahnungen liegen soll. Sehr sinnvoll ist die Verwendung der Option ‚Detaillierte Zinsberechnung’.

Zu Verwirrungen führt immer wieder, dass unsere Zahlungsbedingung ‚ohne Text’ ebenfalls Zahlungsziele festlegt. Die Zahlungsbedingungen werden unter dem Modul EINSTELLUNGEN, <Grundeinstellung> <Zahlungsbedingungen> festgelegt. Sollten Sie aufgrund eines Fehlers eine Zahlungsfrist falsch gesetzt haben, so können Sie diese per Hand über das Ändern der Ausgangsrechnung verändern. Dort kann auch eine Mahnstufe zurückgesetzt werden.

Die textliche Ausweisung der Mahnung kann von Ihnen selbst bestimmt werden. Das Programm greift bei jeder Mahnung auf einen bestimmten Mahntext zurück. Die Mahntexte sind wie üblich mit Hilfe unseres Reportgenerators veränderbar. Um die Formulare dennoch schnell an Ihre Bedürfnisse anpassen zu können, können Sie unter dem Modul EINSTELLUNGEN <Vorlagen> <Mahntexte> die Vor- und Nachbemerkung des Mahntextes selbst verändern. Die Formulare sind alle so gestaltet, dass hinter der Anschrift die Vorbemerkung in der von Ihnen vorgesehenen Länge gedruckt wird. Darauf folgt eine fest im Formular hinterlegte Zeile, in der das Programm die Rechnungsnummer, Rechnungssumme und ähnliches automatisch einträgt. Anschließend wird eine Nachbemerkung ausgedruckt, die Sie wiederum in dem Einstellprogramm selbst erfassen können. In diese Nachbemerkung sollten Sie über entsprechende Schlüsselworte die nächsten Zahlungsfristen festsetzen. In diesem Bereich gehören auch Texte wie „Mit freundlichen Grüßen“ usw. hinein.

Mahntexte ggf. mandantenspezifisch: Wenn der Schalter im Modul EINSTELLUNGEN <Grundeinstellungen> <Allgemein> gesetzt ist, können für jeden Mandanten unterschiedliche Mahntexte verwendet werden. Im Standard sind alle Texte für alle Mandanten gleich.

Sammelmahnung mit unterschiedlichen Mahntexten: Je nach der höchsten Mahnstufe der überfälligen Rechnungen kann ein unterschiedlicher Text für die Sammelmahnung genutzt werden. Wenn in einer Sammelmahnung nur Zahlungserinnerungen sind, gibt es Sinn einen anderen Text zu verwenden, als wenn bei einzelnen Rechnungen bereits die 3. Mahnstufe erreicht ist.

Um dieses zu erreichen, müssen Sie weitere Mahntexte anlegen. Sobald z.B. ein Mahntext mit dem Namen Mahnsamm2 existiert und die höchste Mahnstufe der zu mahnenden Rechnung für diesen Kunden die 2 ist, wird dieser Text verwendet. Wenn er fehlt, bleibt alles beim alten und der ‚normale’ Text mit dem Namen ‚Mahnsamm’ wird verwendet.

Wenn Sie sich zu dieser Änderung entscheiden, sollten Sie die Texte mit den Nahmen Mahnsamm1, Mahnsamm2, Mahnsamm3 und Mahnsamm4 anlegen. Die Mahntexte werden im Modul EINSTELLUNGEN unten dem Menüpunkt <Vorlagen> <Mahntexte> erfasst.

Die Mahnungen werden für alle entsprechend markierten Rechnungen durchgeführt. Die Markierungen können sowohl über das Menü komplett gesetzt werden, als auch über das Anklicken einzelner Zeilen in dem leeren Kästchen ganz links. Zum Mahnen gewählte Rechnungen werden blau dargestellt. Gemäß den Windows-Regeln können Sie mit gedrückter STRG-Taste weitere Zeilen markieren oder mit gedrückter Shift-Taste (Groß/Kleinschreib-Taste) einen Bereich markieren. Durch ein erneutes Anklicken kann die Markierung wieder weggesetzt werden.

Der Start des Mahnausdruckes wird über den Knopf ‚Mahnen durchführen‘ oder das Menü <Bearbeiten> <Mahnen durchführen> ausgelöst.

Die Möglichkeiten mit der Mahnart lesen Sie bitte in Kapitel Mahnarten.
