1. Vorlagen anlegen, duplizieren, Import / Export

Vorlagen werden im Modul Einstellungen unter den Menüpunkten <Vorlagen>, <Checklisten> erstellt. Über das Menü können dort auch Vorlagen importiert werden.

Zum Erstellen einer Vorlage muss zunächst der Name und der Verwendungsbereich (Projekt/Kundendienst) festgelegt werden. Betätigen Sie den Knopf ‚Neu ’, um eine neue Vorlage zu erstellen.

Oft ist es sinnvoll, die neue Vorlage auf der Basis einer vorhandenen zu erfassen. Dazu gibt es die Menüpunkte <Vorlage>, <Speichern als Neu>

Import /Export

Vorlage importieren

Wenn Sie von uns, einem anderen Labelwin Anwender oder aus unserem Label-Wiki eine Vorlage bekommen haben, so können Sie diese hier importieren. Wenn bereits eine Vorlage mit dem gleichen Namen existiert, so müssen Sie der importierten Vorlage einen anderen Namen geben.

Die zu importierenden Vorlagen liegen standardmäßig in dem Pfad \Labelwin\Vorlage\Checklis\ und haben die Extension ‚csv’. Um Ihnen den Einstieg zu erleichtern, finden Sie dort auf jeden Fall eine von uns mitgelieferte Vorlage.

Vorlage exportieren

Hiermit können Sie die aktive Vorlage exportieren um sie ggf. einem anderen Labelwin Anwender zur Verfügung zu stellen. Wenn Sie eine ‚schöne’ Vorlage erstellt haben, so würden wir uns freuen, wenn Sie uns diese zur Verfügung stellen würden. Wir legen sie dann gerne im Label-Wiki ab, damit auch andere Labelwin Anwender Nutzen davon haben können.
