Drucken Karteikarte A ‚Ausgabe'

Hinweis: Die Maske kann über die Makros auf die in Ihrem Betrieb vorkommenden Standardfälle eingerichtet werden, damit Sie im Normalfall ohne Änderungen sofort den Druck auslösen können.

[Bild]

Bild: Druckausgabe Seite A ‚Ausgabe’

[Bild]

A1 Formular: Das Programm kann die Ausgabe auf verschiedenen Formularen durchführen. Mitgeliefert haben wir je nach Druckausgabeform manchmal nur eins, manchmal jedoch 4-5 verschiedene Formulare. Sollten für Ihre Firma besondere Bedürfnisse bestehen, so kann die Formularliste unbegrenzt erweitert werden. Um die Auswahl der Formulare möglichst einfach zu gestalten, kann jedes Formular einen größeren Beschreibungstext bekommen. In der Liste dieser Beschreibungstexte können Sie wählen. (EDV-Betreuer: Die Beschreibungstexte und das dazugehörige Formular sind in der Datei report.ini abgelegt)

[Bild]

A2 Drucker: Hier kann der Drucker für die normale Ausgabe gewählt werden. Es stehen sämtliche auf diesem Computer angemeldeten Drucker zur Verfügung. Bitte beachten Sie, dass die Titelzusammenstellung, ein Folgereport, die Überweisungsträger und dergleichen auf andere Drucker ausgeben werden können. Die Wahl erfolgt aus der Karteikarte unter ‚weitere Drucker’.

[Bild]

A3 Anschrift: Der Text wird an die hier eingetragene Anschrift gedruckt. Sie können eine andere Anschrift wählen, indem Sie auf die Karteikarte ‚Adressen’ schalten.

[Bild]

A4 Objektadresse: Es gibt Dokumenten-formen, bei denen eine zweite Adresse erforderlich ist, z B. bei Hauseigentümern, die ihr Haus vermietet haben und für dieses Objekt eine Rechnung erhalten. Ebenso ist es möglich, bei Rechnungen über Kundendienstaufträge die Objektadresse in der Vorbemerkung zu verarbeiten. Die hier gezeigte Adresse wird als zweite Adresse verwendet. Anmerkung: Falls Sie aus der Objektadresse Daten in die Vorbemerkung einfließen lassen wollen, so müssen Sie dies über bestimmte Schlüsselworte erledigen. Die Liste der Schlüsselworte finden Sie im Kapitel Schlüsselworte in Word-Vorlagen. Auf der Karteikarte ‚Adresse’ können Sie eine andere Adresse wählen.

[Bild]

A5 Versandadresse: Beim Drucken von Angeboten, Rechnungen usw. wird eine ggf. gewählte Versandadresse nach der ersten Namenszeile der Anschreibenadresse gedruckt.

[Bild]

A6 Exemplare: Geben Sie hier die gewünschte Anzahl der Exemplare ein.

[Bild]

A7 Ankreuzfelder:

|

Nur Titelzusammenstellung

|

Wenn Sie einen Text mit Titeln erstellt haben, kann das Programm eine Titelzusammenstellung automatisch ausgeben. Durch ein Kreuz in diesem Feld wird nur die Titelzusammenstellung ausgedruckt. Die Druckausgabe sämtlicher Positionen entfällt. Ob überhaupt eine Titelzusammenstellung gedruckt werden kann, ist bei dem normalen Druckformular hinterlegt. Die Titelzusammenstellung erfolgt grundsätzlich auf einem separaten Blatt.

|

Nur Kurzform

|

Durch ein Kreuz an dieser Stelle können Sie erreichen, dass das Programm die Kurzform der Artikel ausdruckt. Dies wird insbesondere bei Bestellungen und Lieferscheinen zur Anwendung kommen. Wenn hier kein Kreuz gesetzt ist, so wird das Programm alle Artikel in der bei der Herstellung vorgesehenen Form ausdrucken. (Beim Artikelaufruf haben Sie die Möglichkeit die Kurz- oder Langform zu wählen)

|

Zahlschein ausgeben

|

Bei einem Kreuz in diesem Feld wird bei Druck einer Rechnung ein Überweisungszettel ausgedruckt. Dieser Überweisungszettel kann der Rechnung beigelegt werden. Die Druckausgabe kann auf einem separaten Drucker erfolgen, der auf der Karteiseite „weitere Drucker“ eingestellt wird.

|

Folgeformular ausgeben

|

Ein Druckformular kann mit einem weiteren Formular verknüpft werden. Diese Verknüpfung wird über die Formularliste (Report.ini) zugeordnet. Eine sinnvolle Anwendung kann z. B. sein, nach der Druckausgabe für den Kunden ein weiteres Formular mit den jeweils hinterlegten Artikelnummern für die eigene Ablage zu erstellen. Eine andere Anwendung könnte sein, neben der Rechnung mit einem separaten Drucker ein Anschriftenetikett auszugeben. Folgeformulare müssen in der Regel mit „FO“ beginnen und der Formularliste eingetragen sein.

|

Folgeseiten auf anderen Drucker

|

Über diese Funktion kann die zweite und weitere Seite auf einem anderen Drucker ausgeben werden, als die erste Seite. Die Anwendung ist häufig bei Drucker mit zwei Einzugsschächten nur die erste Seite auf Firmenpapier und den Rest auf weißem Papier bzw. einem anderen Firmenpapier auszugeben. Die Drucker müssen über den gleichen Druckertreiber angesteuert werden können. Bei Zweischachtdruckern wird der gleiche Drucker zwei mal eingerichtet und einer der Drucker auf den zweiten Schacht voreingestellt. Die Druckernamen dürfen sich am Ende lediglich durch eine nachgestellte Leerstelle und S2 unterscheiden (Beispiel HP4L und HP4L S2)

|

Folgeexemplare auf anderen Drucker

|

Mit dieser Möglichkeit kann das zweite und jedes weitere Druckformular auf einen anderen Drucker ausgeben werden. Einige unserer Kunden benutzen diese Möglichkeit, um die Folgeexemplare auf gelben Papier auszudrucken.

|

Lager abbuchen

|

Diese Option ist nur bei aktiven Lagermodul und der Druckausgabe als Rechnung oder Lieferschein zu wählen.

|

Ausgabe mit Preise (Preis-LV)

|

Die Ausgabe von LV’s erfolgt in der Regel ohne Preise. Die Preise werden standardmäßig bei uns durch einen dünnen Unterstrich ersetzt. Bei Ankreuzen dieses Punktes erfolgt die Ausgabe ausnahmsweise mit Preisen.

|

Ausdruck ohne Bilder

|

Wenn Sie bereits auf die RTF-Formatierung umgestellt haben und in ihrem Artikelkatalog den Artikeln Bilder zugeordnet haben, können Sie durch Ankreuzen dieses Punktes die Druckausgabe ohne Bilder erzeugen.

|

nur Pauschalpreis

|

Durch Ankreuzen dieses Punktes werden keine Einzelpreise ausgegeben. Auch die Summen von Titeln, Losen und Bauteilen werden unterdrückt. Es wird nur der Gesamtpreis ausgedruckt

|

Verborgene Sets ausdrucken

|

Für interne Unterlagen oder für die Aufmaßvorbereitung ist es sinnvoll, auch die Bestandteile von verborgenen Sets mit auszudrucken. Durch Ankreuzen dieses Punktes werden die Bestandteile von verborgenen Sets mit ausgedruckt.

|

Setbestandteile mit Preis ausdrucken

|

In der Regel wird ein Set nur mit dem Gesamtpreis ausgedruckt. Mit dieser Möglichkeit können Sie auch Setbestandteile mit Preis ausdrucken.

A8 Gruppe Artikelschlusstext: Eine ausführliche Beschreibung der hier vorgesehenen Möglichkeiten finden Sie in der Beschreibung des Programms EINSTELLUNGEN, unter ‚Programmbereiche’, ‚Dokumentenerstellung’, ‚Artikelschlusstexte’. Über die Gruppenauswahl an dieser Stelle lässt sich steuern, wie der Artikelschlusstext (z. B. liefern und montieren) auf dem Papier konkret aussieht. Mitgeliefert haben wir standardmäßig folgende Möglichkeiten:

· ohne-Preis-Angebot: Liefern und montieren, nur liefern, nur montieren

· ohne-Preis-Rechnung: Geliefert und montiert, geliefert, nur montiert,

· ,it-Preisen-Angebot: Liefern ‚123,45 €’ montieren ‚25,80 €’

· LV mit: Liefern......, montieren ......, nur liefern, nur montieren

· Ohne-Schlusstext: Hierbei wird die Ausgabe der Artikelschlusstexte komplett unterdrückt.

[Bild]

A9 Buchen: Je nach der gewählten Druckform ist dieser Bereich unterschiedlich einzugeben. Es geht immer darum, ob eine Nummer für das Angebot oder die Rechnung oder ähnliches vergeben werden soll. Grundsätzlich besteht die Möglichkeit, die nächste dafür vorgesehene Nummer zu verwenden oder eine bestimmte Nummer vorzugeben. Über die Wahl von ‚nicht eintragen’ wird erreicht, dass die Angebote und Rechnungen nicht in die dafür vorgesehenen Listen eingetragen werden.

[Bild]

A10 Rechnungsdatum: Bei einigen Rechnungsformularen ist es möglich, neben dem Druckdatum ein separates Rechnungsdatum zu erfassen. Dies ist vorgesehen, damit im Januar Rechnungen auf den Dezember des Vorjahres gedruckt werden können. In diesen Formularen sind zwei Datumsangaben vorgesehen. In der Regel wird hier das aktuelle Tagesdatum vorgeschlagen.

[Bild]

A11 Mahnart: Hier wird die Mahnart angezeigt, die in der Rechnungsadresse hinterlegt ist. Sie haben jedoch die Möglichkeit, hier die Mahnart zu ändern.

[Bild]

A12 Bankeinzug: Wenn Sie mit Ihrem Kunden Bankeinzug vereinbart haben, ist hier generell bereits das Feld aktiviert. Es kann jedoch sein, dass Sie für eine Rechnung einen einmaligen Bankeinzug erhalten haben. Dann können Sie hier das Feld aktivieren.

[Bild]

A13 Zahlungsbedingung: An dieser Stelle schlägt das Programm die bei der Dokumentenherstellung vorgesehene Zahlungsbedingung vor. Die Zahlungsbedingung wird in der Regel aus der Anschreibenadresse abgeleitet. Sie können an dieser Stelle jedoch auch eine andere Zahlungsbedingung wählen. Das Programm greift auf die in dem Modul EINSTELLUNGEN unter dem Menüpunkt <Grundeinstellungen> <Zahlungsbedingungen> erfassten Zahlungsbedingungen zu.

[Bild]

A14 Zahlziel: An dieser Stelle schlägt das Programm die in der Zahlungsbedingung hinterlegten Zahlziele vor. Hier haben Sie die Möglichkeit, für diesen Rechnungsdruck die Zahlziele zu ändern.

[Bild]

A15 Erlöskonto: Wenn Sie mit Erlöskonten arbeiten, wird das Erlöskonto standardmäßig bereits bei der Dokumentenanlage gewählt. Um hier mögliche Bedienfehler auszuschalten, können Sie an dieser Stelle noch einmal das Erlöskonto ändern.

[Bild]

A16 Mehrwertsteuer: Wenn Sie eine Rechnung ohne Mehrwertsteuer ausdrucken wollen, so ist an dieser Stelle ein Kreuz in dem dafür vorgesehenen Feld setzen. In den Feldern MwSt.1 und MwSt.2 schlägt ihnen das Programm die in der Dokumentenerstellung vorgesehene Mehrwertsteuer vor. Um hier mögliche Bedienungsfehler einfach zu korrigieren, haben wir hier ebenfalls eine Eingabe vorgesehen.

Hinweis: Wenn Sie mit Erlöskonten arbeiten sind diese Fehler ausgegraut. Der Mehrwertsteuersatz wird dann über das Erlöskonto bestimmt.

[Bild]

A17 Bemerkung: Hier haben Sie die Möglichkeit, eine kurze Bemerkung einzugeben. Diese wird dann in der Rechnungsliste im Rechnungsausgangsbuch mit angezeigt.

[Bild]

A18 Rechnungs-KZ: Hier wird standardmäßig das bei der Dokumentenerstellung eingetragene Rechnungskennzeichen hinterlegt. Um einen Eingabefehler zu korrigieren, haben wir hier eine Eingabe vorgesehen.
