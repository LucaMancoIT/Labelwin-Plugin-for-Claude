Dokumentendruck V5 - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Datei

Report aktualisieren

Durch die Wahl dieses Menüpunktes können Sie den in der Druckmaske ausgewählten Report aktualisieren.

Report zur Änderung versenden (Email)

Um Ihnen das Suchen nach dem richtigen Report zu erleichtern, haben wir diesen Menüpunkt eingefügt. Unter diesem Menüpunkt wird für den aktuell angewählten Report eine Zip-Datei erzeugt und es öffnet sich das Email-Programm. Hier steht schon ein vorgefertigter Text. Die erzeugte Datei ist bereits im Anhang. Hinweis: Individuelle Reportanpassungen sind kostenpflichtig!

Report zur Änderung auf Desktop packen

Um Ihnen das Suchen nach dem richtigen Report zu erleichtern, haben wir diesen Menüpunkt eingefügt. Unter diesem Menüpunkt wird für den aktuell angewählten Report eine Zip-Datei erzeugt und auf den Desktop abgelegt. Hinweis: Individuelle Reportanpassungen sind kostenpflichtig!

REB (DA11/DA12) Ausgabe

Mit dieser Option lässt sich ein Dokument im DA11 bzw. DA12 Format ausgeben. Diese Ausgabeform wird vorwiegend im Aufmaßbereich verwendet. Wenn Sie diesen Menüpunkt nicht sehen, sprechen Sie bitte die Hotline oder Ihren Label Partner an.

Erweiterte Druckereinstellungen

Dieser Menüpunkt öffnet die erweiteren Druckereinstellungen, die auch um den Label V5 Startbaum zu erreichen sind. Hier sollten Sie keine Veränderungen ohne Rücksprache mit der Hotline vornehmen.

Druck-Reportspeicher zurücksetzen

Beim Druck eines Reportes wird dieser in den Reportspeicher geladen. Wird der gleiche Report erneut verwendet, holt das Programm den Druck aus dem Speicher wodurch der Druck in der Regel schneller ist. Hat man den Report jedoch geändert, muss der Report neu geladen werden und dazu muss er aus dem Reportspeicher gelöscht werden.

Ausfüllbare PDF

Dieser Menüpunkt ist nur sichtbar, wenn die Funktion "Ausfüllbare PDF" eingerichtet ist. Es geht dabei darum eine ausfüllbare PDF (also eine PDF-Datei mit Eingabefeldern) automatisch mit Daten aus Labelwin (z.B. Adressen) zu füllen.

Beenden

Durch die Wahl dieses Menüpunktes wird die Druckmaske geschlossen.

|

Makro bearbeiten

Wenn Sie die Druckmaske entsprechend Ihren Wünschen eingerichtet haben, so können Sie diese Einstellung als Makro abspeichern. Dadurch ist es künftig möglich, bestimmte Einstellungen schnell zu wiederholen. Falls ein Makro eingerichtet ist, so wird das alphabetisch erste automatisch bei der Druckausgabe aktiviert. Bei dem ersten Makro sollte es sich also um die normalerweise verwendete Standardeinstellung handeln. Die Makros sind nicht arbeitsplatzbezogen, sondern gelten für die ganze Firma. Für jeden Druckausgabebereich können separate Makros erstellt werden. Das Makro von Rechnungen hat also mit Makro von Angeboten nichts zu tun.

Speichern

Die eingerichtete Druckmaske wird als Makro abgespeichert. Das Programm fragt nach der Bezeichnung des Makros.

Speichern als

Die gezeigte Druckmaske wird unter einer neuen Makrobezeichnung abgespeichert. Es handelt sich also quasi um die Duplizierung eines Makros.

Löschen

Hierdurch wird das gerade aktive Makro gelöscht.
