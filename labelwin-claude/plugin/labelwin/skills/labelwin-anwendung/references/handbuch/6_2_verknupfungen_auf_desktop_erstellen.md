6.2 Verknüpfungen auf Desktop erstellen

Mit diesem Menüpunkt haben Sie die Möglichkeit, Verknüpfungen von einzelnen Modulen auf dem Desktop anzulegen.

[Bild]

Bild: Verknüpfungen erstellen

Wählen Sie dazu einfach das entsprechende Modul aus und betätigen Sie den Knopf ‚Ok anlgen’ Wenn Sie sich für Labelwin Ordner auf dem Desktop erstellt haben, können Sie dann diese Verknüpfung in den Ordner ziehen.
