2.1.9 Smiley

Zusätzlich zur Adressanmerkung, die bei jeder Benutzung automatisch an die Oberfläche kommt, können einzelne Adressen mit einem Smiley versehen werden. Es handelt sich um ein kleines Bildchen, das beim Aufruf einer Adresse automatisch hinter dem Suchwort angezeigt wird, ohne dass automatisch eine Information sichtbar ist. So kann z.B. bei einem Kunden ein gelbes, beim anderen ein blaues Smiley an der Oberfläche erscheinen. Die Bedeutung der Smileys und die jeweiligen Bilder können Sie hier selbst festlegen.

Legen Sie einen Namen fest und anschließend wählen Sie aus der Liste das gewünschte Smiley aus. Bitte bedenken Sie, dass Sie ein Smiley nur dann wieder löschen können, wenn es bei keiner Adresse verwendet wird. Sobald Sie einzelne Adressen damit versehen haben, ist das Löschen gesperrt.
