2.1 Vorlagen - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Datei

Drucken Checkliste

Gleiche Funktion wie der Knopf ‚Drucken‘.

Beenden

Gleiche Funktion wie der Knopf ‚Ende‘.

|

Bearbeiten

Neue Zeile (F2)

Mit dieser Funktion wird am Ende der Checkliste eine neue Zeile angefügt.

Zeile speichern

Wurden Änderungen an einer Zeile vorgenommen, müssen diese mit dieser Funktion gespeichert werden.

Zeile löschen (STRG+L)

Eine Zeile kann mit dieser Funktion gelöscht werden.

Schriftart

Über diesen Menüpunkt gelangen Sie in das nachstehende Fenster – hier können Sie wie bei Word viele Merkmale einstellen.

[Bild]

Absatzformatierung

Dieser Menüpunkt ist derzeit inaktiv.

Aufzählungen

Unter diesem Menüpunkt können Sie die Nummerierungs- und Aufzählungsvorgaben ändern.

[Bild]

Tabulatoren ändern

Unter diesem Menüpunkt haben Sie die Möglichkeit, die Tabulatoren zu ändern, zu erweitern oder zu löschen.

[Bild]

Sonderzeichen

Hier haben wir die wichtigsten Sonderzeichen hinterlegt, so dass Sie diese schnell im Zugriff haben.

[Bild]

Suchen

Unter diesem Menüpunkt können Sie nach einem bestimmten Wort suchen.

[Bild]

Suchen und Ersetzen

Unter diesem Menüpunkt können Sie ein Wort suchen und durch ein anderes ersetzen

[Bild]

|

Vorlagen

Neue Vorlage (F3)

Gleiche Funktion wie Knopf ‚Neue Vorlage‘ oder F3

Vorlage speichern als neu

Unter diesem Menüpunkt können Sie eine vorhandene Vorlage als neu abspeichern und dann Änderungen vornehmen. Das ist vor allem dann sinnvoll, wenn sich in der Vorlage nur wenige Leistungen ändern.

Vorlage löschen

Unter diesem Menüpunkt können Sie eine Vorlage löschen.

Umbenennen (F7)

Mit diesem Menüpunkt kann eine Vorlage umbenanntn werden.

Vorlage exportieren (Label Format)

Unter diesem Menüpunkt kann eine Vorlage im Labelwin eigenem XML-Format exportiert werden.

Vorlage exportieren (Textdatei)

Unter diesem Menüpunkt kann eine Vorlage als TXT Datei exportiert werden.

Vorlage importieren (Label Format)

Unter diesem Menüpunkt kann eine Vorlage im Labelwin eigenem XML-Format importiert werden.

Vorlage importieren (Textdatei)

Sollten Sie bereits Checklisten im Excel oder Word Format besitzen, so können Sie diese über eine Textdatei importieren. Dazu müssen Sie Ihre Vorlagen zuerst in eine TXT Datei kopieren bzw. als TXT speichern. TXT Dateien können Sie z.B. über den Windows Editor bzw. Wordpad generieren. Anschließend müssen Sie den Aufbau der TXT Datei an folgende Vorgaben anpassen:

- der Name der Checkliste wird durch 2 Doppelpunkte erkannt

- Überschriften / Textzeilen werden durch einen Doppelpunkt erkannt

- Artikelzeilen mit =Artikelnr;KatalogNr;Menge:Beschreibung

- es können beliebig viele Checklisten aus einer Text-Datei angelegt werden.

Beispiel:

::Kesseltyp xyz

:Reinigung

Brenner reinigen

Flammüberwachung säubern

Pumpenfilter reinigen

=Filter1234;9;2;Filter

:Einstellungen

Brenner einstellen

::Brauchwasserspeicher

Opferanode kontrollieren

Probe entnehmen

...

|

Optionen

Checklisten abgleichen/tauschen

Mit dieser Funktion lassen sich Anlagenchecklisten abgleichen oder tauschen. Erklärungen zu jeder möglichen Methode werden im rechten Info-Feld angezeigt, so dass die Funktion selbsterklärend sein sollte.
