3. Postbox-Verteiler

In die Postbox können Sie beliebig viele Dokumente scannen oder per Drag & Drop ablegen. Die Dokumente können dann von dort aus abgelegt werden. Abgelegt heißt, dass Sie die Pdf beim Kundendienstauftrag hinterlegen können, eine Eingangsrechnung damit erfassen können und den Scan bei einem beliebigen Labelwin-Dokument hinterlegen können. Genauso gut können Sie die Pdf aber auch in die Postbox eines anderen Anwenders verschieben, damit der sie ablegt.

Am Besten stellen Sie sich das wie einen Briefkasten vor, aus dem Sie die Post in verschiedene Fächer legen oder sofort abarbeiten. Im Gegensatz zum Briefkasten werden Sie hier die Dokumente allerdings meist selber ‚einwerfen‘, indem Sie das Dokument scannen

Einrichtung:

Zunächst muss im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Archiveinstellungen> <Scannarchiv> der Pfad der Postbox festgelegt werden.

Unter diesem Pfad wird für jeden Mitarbeiter ein spezieller Ordner mit seinem Namen angelegt Wenn Sie die Möglichkeit nutzen wollen, dass jemand PDF’s / Scans in dieses Verzeichnis schiebt, muss der Pfad für alle erreichbar sein.

[Bild]

Anwendung:

|

Hinweis: Der Postbox-Verteiler ist zwar Bestandteil des Scan-Archives, wird aber wie ein eigenständiges Modul in den Programmbaum eingebunden und aufgerufen.

Unter Labelwin V4 wird die Postbox mit der PboxVert.exe gestartet. Richten Sie am Besten eine Verknüpfung auf dieses Programm-Modul ein oder tragen Sie es im V4 Startcenter ein.

[Bild: 1]

Menüleiste

[Bild: 1. Menüleiste]

In der Menüleiste befinden sich alle Funktionen der Postbox gegliedert in vier Bereiche. Alle hier hinterlegten Funktionen werden im nächsten Abschnitt Postbox - Alle Menüpunkte beschrieben.

|
[Bild: 2]

Ablagepfad

[Bild: 2. Ablagepfad]

Tragen Sie hier, ob die eigene Postbox oder ein anderes Verzeichnis gewählt werden soll.

|
[Bild: 3]

Pfad

[Bild: 3. Pfad]

Dieser Pfad ist nur sichtbar, wenn Sie den Verzeichnistyp ‚Freie Verzeichnisauswahl‘ gewählt haben. Tragen Sie hier den Pfad der Postbox ein, die Sie anwählen möchten.

|
[Bild: 4]

Filterzeile

[Bild: 4. Filterzeile]

Die Dateiliste kann durch Eingabe eines Filters eingegrenzt werden. Die genaue Funktionsweise der Filterzeile wird unter Bedienungselemente beschrieben.

|
[Bild: 5]

Dateiliste

[Bild: 5. Dateiliste]

Hier werden die Dokumente angezeigt, die in der ausgewählten Postbox vorhanden sind. Um bei einer großen Anzahl von Dateien den Überblick zu behalten, wird das Dateidatum in der Tabelle angezeigt.

Über einen Doppelklick auf eine Spaltenüberschrift kann sortiert werden. Mit dem Menü der rechten Maustaste [Nr.6] kann eine Datei auch umbenannt und gelöscht werden.

|
[Bild: 6]

Rechtsklick Menü

[Bild: 6. Rechtsklick Menü]

Mit Rechtsklick auf einen Scan-Eintrag öffnet sich ein Kontextmenü mit weiteren Funktionen.

|
[Bild: 7]

Scan-Profil

[Bild: 7. Scan-Profil]

Wenn Sie Dateien in Ihre Postbox scannen möchten, müssen Sie hier ein Scan-Profil auswählen. Die Scan-Profile werden im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Archiveinstellungen> <Scannarchiv> erfasst.

|
[Bild: 8]

Scannen F12

[Bild: 8. Scannen F12]

Durch Betätigen dieses Knopfes wird der Scanvorgang mit dem aktuellen Scan-Profil gestartet.

|
[Bild: 9]

Neues Dokument (F2)

[Bild: 9. Neues Dokument (F2)]

Durch Betätigen dieses Knopfes startet das Fenster der Dokumentenanlage. Hier können Sie wie gewohnt die notwendigen Eingaben wie Projekt-Nr., Adresse, Objektadresse usw. vornehmen. Die Dokumentenart ist bereits vorbelegt und kann nicht geändert werden.

|
[Bild: 10]

Neue Eingangsrechnung (F3)

[Bild: 10. Neue Eingangsrechnung (F3) ]

Wenn Sie eine Eingangsrechnung als pdf-Datei erhalten, können Sie diese in der Postbox speichern. Markieren Sie dann diese Rechnung und betätigen Sie den Knopf ‚Neue Eingangsrechnung‘. Das Rechnungsausgangsbuch wird gestartet und Sie können wie gewohnt die Eingangsrechnung erfassen. Das entsprechende Dokument ist dann bereits hinterlegt.

|
[Bild: 11]

Eingangsrechnung zuordnen

[Bild: 11. Eingangsrechnung zuordnen]

Wenn Sie eine Eingangsrechnung als pdf-Datei erhalten, können Sie diese über die Postbox einer bereits erfassten Eingangsrechnung nachträglich zuordnen. Markieren Sie dazu diese Rechnung und betätigen Sie den Knopf ‚Eingangsrechnung zuordnen‘.

|
[Bild: 12]

Neuer Auftrag, PDF als Scan

[Bild: 12. Neuer Auftrag, PDF als Scan ]

Durch Betätigen dieses Knopfes wird zum gewählten Dokument aus der Auswahlliste ein Auftrag angelegt, z.B. zur Nacherfassung eines Notdienstauftrags. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen.

|
[Bild: 13]

Neuer Auftrag, PDF-Dokument

[Bild: 13. Neuer Auftrag, PDF-Dokument]

Durch Betätigen dieses Knopfes wird ein neuer KD-Auftrag angelegt. Das in der Auswahlliste gewählte pdf-Dokument wird im Auftrag als zugeordnetes Dokument abgelegt.

|
[Bild: 14]

Vorh. Auftrag, Pdf als Scan

[Bild: 14. Vorh. Auftrag, Pdf als Scan ]

Durch Betätigen dieses Knopfes wird die gewählte Pdf-Datei einem vorhandenen Auftrag als Bild zugeordnet. Im KD-Auftrag können Sie das Dokument mit der Taste F4 anschauen.

|
[Bild: 15]

An Dokument eines Projektes

[Bild: 15. An Dokument eines Projektes]

Durch Betätigen dieses Knopfes können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im Projekt zuordnen (z. B. zu einer Auftragsbestätigung, zu der Sie nun das unterschriebene Dokument erhalten haben).

|
[Bild: 16]

An Dokument eines Auftrages

[Bild: 16. An Dokument eines Auftrages]

Durch Betätigen dieses Knopfes können Sie die gewählte Datei aus der Auswahlliste einem vorhandenen Dokument im KD-Auftrag zuordnen (z.B. zu einem Lieferschein, zu dem Sie das unterschriebene Dokument vom Kunden erhalten haben).

|
[Bild: 17]

Wareneingang

[Bild: 17. Wareneingang]

Durch Betätigen dieses Knopfes können Sie einen Wareneingang erfassen. Die markierte PDF wird als Lieferschein automatisch zugeordnet.

Dieser Menüpunkt ist nur sichtbar, wenn das Modul LAGER oder BESTELLÜBERWACHUNG im Einsatz ist.

|
[Bild: 18]

Neue Kassenbuchung

[Bild: 18. Neue Kassenbuchung]

Bei Nutzung des Moduls KASSENBUCH kann über diesen Weg eine neue Kassenbuchung mit direkter Zuordnung der gewählten PDF generiert werden.

Achtung: Bitte beachten Sie, dass Sie unbedingt die richtige Reihenfolge der Belege einhalten. Ein nachträgliches Verschieben oder Löschen ist im Kassenbuch nicht möglich.

|
[Bild: 19]

Kassenbuchung zuordnen

[Bild: 19. Kassenbuchung zuordnen]

Bei Nutzung des Moduls KASSENBUCH kann über diesen Weg eine PDF einer bereits vorhandenen Kassenbuchung zugeordnet werden.

|
[Bild: 20]

In andere Postbox (F7)

[Bild: 20. In andere Postbox (F7)]

Durch die Wahl dieses Knopfes erhalten Sie eine Auswahl der vorhandenen Postboxen. Durch die Wahl einer Postbox wird unterhalb dieses Knopfes ein weiterer Knopf sichtbar.

|
[Bild: 21]

Datei anzeigen

[Bild: 21. Datei anzeigen]

Dieser Knopf ist nur sichtbar, wenn Sie das Feld ‚Automatisch zeigen‘ deaktiviert haben. Sie können sich damit die in der Liste gewählte Pdf-Datei anschauen.

|
[Bild: 22]

PDF automatisch öffnen

[Bild: 22. PDF automatisch öffnen]

Standardmäßig ist dieses Feld aktiviert, damit die Dokumene sofort angezeigt werden können. Dazu ist jedoch erforderlich dass Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Vorlagen> <Andere Dokumente> <Dokumententypen erfassen> das entsprechende Programm für eine PDF-Datei hinterlegt haben.

|
[Bild: 23]

Ende

[Bild: 23. Ende]

Durch Betätigen dieses Knopfes wird die Maske geschlossen.

|
[Bild: 24]

Statusleiste

[Bild: 24. Statusleiste]

In der Statusleiste werden verschiedene Informationen angezeigt, deren Bedeutung Sie im Kapitel Bedienungselemente nachlesen können.
