3. Auswertung Verteilung

Unter der Voraussetzung, dass Sie die Eingangsrechnungen bestimmten Projekten und/oder KD-Aufträgen oder Kostenstellen zugeordnet haben, lassen sich über den Menüpunkt [Auswerten - Auswertung Verteilung] umfangreiche Auswertungen durchführen. Über die frei generierbaren Formularfunktionen lassen sich Listen in jeder nur denkbaren Aufteilung erzeugen. Sofern unsere mitgelieferten Formulare nicht Ihren Bedürfnissen entsprechen, sprechen Sie uns bitte auf weitere Auswertungen an.

[Bild: 3. Auswertung Verteilung]

Bild: Auswertung Verteilung Eingangsrechnungen

Im oberen Drittel der Maske befinden sich Eingabefelder, mit denen die Anzahl der gezeigten Einträge eingeschränkt werden kann. Die Eingrenzung wirkt jedoch nicht sofort, sondern erst nach Betätigen des Knopfes ‚Liste aufbauen’. [Nr.5].

|
[Bild: 1]

Zeiteingrenzung

[Bild: 1. Zeiteingrenzung]

Hier können Sie eine zeitliche Begrenzung treffen. Je nach Wahl der Begrenzung müssen Sie dann im nebenstehenden Feld den gewünschten Zeitraum eintragen (entweder ‚bestimmter Monat’ oder ‚Datum von – bis’)

|
[Bild: 2]

Weitere Eingrenzungen

[Bild: 2. Weitere Eingrenzungen]

Hier können Sie weitere Eingrenzungen zur Auswertung der Verteilung vornehmen.

-

Abteilung: Wenn Sie die Auswertung für eine bestimmte Abteilung durchführen möchten, müssen Sie hier ein Kreuz setzen. Wählen Sie dann aus der Auswahlbox die entsprechende Abteilung aus.

Voraussetzung für die Auswahl ist natürlich, dass Sie im Modul EINSTELLUNGEN unter dem Menüpunkt [Grundeinstellungen - Abteilungen] Abteilungen erfasst haben.

-

Projekt: Wenn Sie die Auswertung für ein bestimmtes Projekt/Baustelle durchführen möchten, so müssen Sie hier ein Kreuz setzen. Geben Sie anschließend die Projektnummer ein oder wählen über die Projektauswahl das gewünschte Projekt aus.

-

KD-Auftrag: Wenn Sie die Auswertung für einen bestimmten KD-Auftrag durchführen möchten, so müssen Sie hier ein Kreuz setzen. Geben Sie anschließend die KD-Auftragsnummer ein oder wählen mit dem Knopf ‚KD-Auftrag‘ den gewünschten KD-Auftrag aus.

-

Kostenstelle: Wenn Sie die Auswertung für eine bestimmte Kostenstelle durchführen möchten, so können Sie die Kostenstelle hier auswählen. Die Kostenstellenauswahl ist nur dann möglich, wenn bei der Rechnungserfassung Kostenstellen zugeordnet worden sind. Voraussetzung ist, dass Sie im Modul EINSTELLUNGEN unter dem Menüpunkt [Programmbereiche - Buchhaltung - Kostenstellen] Kostenstellen erfasst haben.

-

Lieferant: Wenn Sie die Eingangsrechnungen eines bestimmten Lieferanten sehen möchten, so müssen Sie hier das Kreuz setzen. Geben Sie im nebenstehenden Feld den Adresskurznamen ein.

-

Hersteller: Wenn Sie die Eingangsrechnungen eines bestimmten Herstellers sehen möchten, so müssen Sie hier das Kreuz setzen. Anschließend geben Sie im nebenstehenden Feld den Adresskurznamen ein.

-

Objekt: Wenn Sie die Eingangsrechnungen eines bestimmten Objekt sehen möchten, so müssen Sie hier das Kreuz setzen. . Anschließend geben Sie im nebenstehenden Feld den Adresskurznamen ein.

-

Warenkonto: Wenn Sie die Eingangsrechnungen über ein bestimmtes Warenkonto selektieren möchten, so müssen Sie hier das Kreuz setzen.. Wählen SIe anschließend das gewünschte Warenkonto aus der Liste oder nutzen Sie die freie Eingabe. Wenn Sie ein Konto auswählen möchten, dass nicht im Kontenplan hinterlegt ist, müssen Sie hier ein Kreuz setzen und die Kontonummer eintippen.

|
[Bild: 3]

Rechnungsliste

[Bild: 3. Rechnungsliste]

In dieser Liste sehen Sie alle Eingangsrechnungen, die aufgrund der oben getroffenen Eingrenzungen aktiv sind. Durch Klick auf eine Spaltenüberschrift kann die Sortierung der Liste verändert werden.

|
[Bild: 4]

Gesamtsummen

[Bild: 4. Gesamtsummen]

In diesem Feld werden die Summen aller aufgrund der Eingrenzungen gewählten Rechnungen angezeigt.

|
[Bild: 5]

Liste aufbauen

[Bild: 5. Liste aufbauen]

Wenn Sie diesen Knopf betätigen, so wird aufgrund der zuvor getroffenen Eingrenzungen die Liste der Eingangsrechnungen erzeugt. Um Zeiten zu sparen, wird die Liste nicht bei jedem Wechsel der Eingrenzung automatisch aktualisiert, sondern erst nach Betätigung dieses Knopfes.

|
[Bild: 6]

Rechnungsartikel

[Bild: 6. Rechnungsartikel]

Diese Funktion öffnet eine Liste aller Positionen, die sich in der zugehörigen Eingangsrechnung (bei RG-Import mit ZUGFeRD) oder im Eingangslieferschein (bei Buchung des Wareneingangs) oder in der Bestellung (bei Bestellung aus Labelwin) befinden.

|
[Bild: 7]

Rechnung zeigen

[Bild: 7. Rechnung zeigen]

Durch Betätigung dieses Knopfes können Sie sich die markierte Rechnung anzeigen lassen, sofern Sie Ihre Eingangsrechnungen einscannen.

|
[Bild: 8]

Eing.-LS zeigen

[Bild: 8. Eing.-LS zeigen]

Wenn Sie das Modul BESTELLÜBERWACHUNG oder LAGERVERWALTUNG erworben haben, ist dieser Knopf sichtbar. Hier können Sie sich zu der in der Liste markierten Rechnung den/die dazu gehörenden Eingangslieferscheine anzeigen lassen.

|
[Bild: 9]

Bestellung zeigen

[Bild: 9. Bestellung zeigen]

Wenn es zu der in der Liste markierten Rechnung eine Bestellung gibt, können Sie sich durch Betätigen dieses Knopfes die Bestellung anzeigen lassen.

|
[Bild: 10]

KD-Auftrag zeigen

[Bild: 10. KD-Auftrag zeigen]

Ist der Verteilsatz einem KD-Auftrag zugeordnet, wird dieser über diesen Button geöffnet.

|
[Bild: 11]

Zahlungsplan

[Bild: 11. Zahlungsplan]

Wenn Sie in der Rechnungsliste eine Rechnung markieren, gelangen Sie durch Betätigen dieses Knopfes in den entsprechenden Zahlungsplan.

|
[Bild: 12]

Anmerkung

[Bild: 12. Anmerkung]

Wenn Sie zu einer Eingangsrechnung eine Anmerkung hinterlegt haben, ist dieser Knopf rot, wenn Sie die entsprechende Rechnung in der Liste markieren. Sie können hier ggf. noch Ergänzungen zur Anmerkung vornehmen.

|
[Bild: 13]

Drucken

[Bild: 13. Drucken]

Durch Betätigung dieses Knopfes fährt die Druckausgabe hoch. In der Druckausgabe können Sie die Auswertung aufgrund verschiedener Formulare beeinflussen.

|
[Bild: 14]

Ende

[Bild: 14. Ende]

Durch Betätigung des Ende-Knopfes wird die Auswertung beendet.
