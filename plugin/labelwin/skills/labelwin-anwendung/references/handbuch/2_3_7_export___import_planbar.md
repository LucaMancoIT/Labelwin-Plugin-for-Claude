2.3.7 Export / Import planbar

Diesen Menüpunkt können Sie nur anwählen, wenn Sie die Schnittstelle zum Programm planbar der Fa. Syntax erworben haben.

[Bild]

Bild: Schnittstelle planbar

Mit dem Programm planbar haben Sie die Möglichkeit, Stundenverrechnungssätze zu ermitteln und betriebliche Kostensituationen durchzuspielen.

Mit der Schnittstelle können Personaldaten und Verrechnungssätze ausgetauscht werden.

Eine nähere Beschreibung zu der Schnittstelle finden Sie im Handbuch unter planbar (Syntax) - Schnittstelle.
