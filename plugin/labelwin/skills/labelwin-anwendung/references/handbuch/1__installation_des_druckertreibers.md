1. Installation des Druckertreibers

Erwerben des Druckertreibers

Das Erzeugen von ZUGFeRD Rechnungen aus Labelwin heraus ist nur mit diesem speziellen ZUGFeRD Druckertreiber der Firma May Computer möglich. Sie bekommen ihn über folgenden Link:

https://shop.xkey.at/shop/edocprintpro/edocprintpro-pdfa-zugferd-arbeitsplatz/

Die Preise und Konditionen entnehmen sie bitte der Webseite. Wir möchten klarstellen, dass Label mit dieser Firma in keinster Weise verbunden ist.

Installation des Druckertreibers

Die Installation läuft ganz typisch ab. Zu Beachten ist lediglich, dass man die Option "30 Tage Demo Version anfordern" abhaken sollte, wenn man bereits Lizenzen erworben hat. Die Registrierung des Treibers erfolgt nach der Installation über den Product Activation Manager.

[Bild] [Bild] [Bild]

Registrierung des Druckertreibers

Durch die Installation des Druckertreibers wurde gleich der Product Activation Manager von XKey installiert.

[Bild]

Über "Activate application" können Sie eine Online Registrierung durchführen. Dazu müssen Sie nur Ihre Zugangsdaten für Ihr Lizenzkonto eintragen.

[Bild]

Anschließend wird Ihnen eine Liste Ihre freien Lizenzen angezeigt, aus der Sie dann die Lizenz auswählen müssen, die Sie an diesem Arbeitsplatz registrieren möchten.
