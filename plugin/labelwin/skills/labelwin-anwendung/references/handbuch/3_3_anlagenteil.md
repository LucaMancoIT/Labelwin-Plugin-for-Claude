3.3 Anlagenteil

In dieser Form werden nun die eigentlichen Bauelemente wie Ventilatoren, Motoren, Filter usw. erfasst. Über die Zuordnung der VDMA - Nummer , AMEV Nummer oder der Nummer der selbst erfassten Wartungsvorschrift werden hier die auszuführenden Arbeiten festgelegt. Obwohl über diese Nummer der ganze Block der Leistungsbeschreibungen zugeordnet wird, können Sie in der nachgeschalteten Maske einzelne Leistungen speziell für dieses Bauelement abwählen oder hinzufügen. Leistungen können allerdings nicht gelöscht werden, sondern über einen Schalter werden sie nur unwirksam gesetzt. Damit besteht die Möglichkeit bei der Dokumentation des Vertragsumfanges die abgewählten Leistungen dennoch mit aufzulisten, damit der Auftraggeber dieses ‚Abwählen’ bewusst wahrnehmen kann. Wenn Sie nämlich aus baulichen Gründen eine an sich erforderliche Tätigkeit nicht ausführen können, so sollten Sie die Verantwortung dafür auf den Auftraggeber abschieben. Aus diesem Grunde ist ggf. auch eine separate Auflistung der abgewählten Standard-leistungen sinnvoll.

[Bild]

1 Teilenummer: Hier müssen Sie jedem Anlagenteil eine eindeutige Nummer zuordnen. Die Nummern können zwischen 1 und 9999 liegen. Je Anlage sind also maximal 9999 Anlagenteile bzw. Bauelemente zuzuordnen.

2 Gerät: Geben Sie hier bei der Neuanlage eines Anlagenteils die Vorlage-Gerätenummer ein. Von diesem Gerät werden dann die Leistungstexte / Tätigkeiten und ggf. auf die Meßwerteinträge kopiert. Das Wort ‚kopiert ist wichtig, da Sie nach dem Kopiervorgang hier Änderungen speziell für diesen Anlagenteil vornehmen können. Das bedeutet aber auch, dass eine nachträgliche Änderung der Grunddaten keine Auswirkung auf die bereits angelegten Anlagenteile hat.

Wie bereits weiter vorne beschrieben kann es sich bei der Nummer auch um die VDMA oder AMEV-Nummer handeln. Allerdings ist eine Erweiterung der VDMA-Nummer um eine weitere Stufe vorgenommen worden.

3 Gerät suchen: Durch Betätigen des Knopfes Nr. 3 können Sie das Vorlagegerät heraus suchen.

4 Anzahl: Sollten Sie von einem Bauteil bei der gleichen Anlage mehrere Stück haben, so müssen Sie diese nicht separat erfassen, sondern können hier einfach die Menge eingeben. Eventuell hinterlegte Zeiten werden für die nächsthöhere Ebene mit dieser Menge ausmultipliziert.

5 Matrix starten: Statt die Anlagenteile einzeln aufzurufen, können Sie diese auch mit unserer Matrix sehr schnell aufrufen. Dazu müssen Sie allerdings erst eine Matrix anlegen, die als Artikel jene Vorlagengeräte enthält. Dazu müssen Sie im Modul TGM-Grunddaten einen Artikelkatalog erzeugen und dann diese Artikel in einer Matrix verarbeiten.

6 Bezeichnung: Geben Sie hier eine eindeutige Bezeichnung des Bauteiles ein. Als Vorgabe wird die in der Vorlage hinterlegte Bezeichnung verwendet.

7 Fabrikat: Geben Sie hier den Hersteller des Bauteiles ein.

8 Typ: Geben Sie hier den Typ des Bauteils und gegebenenfalls auch dessen Seriennummer ein.

9 Leistung: Hier können Sie die Leistung des Bauteiles eingeben, sofern hier eine Leistungseingabe Sinn gibt.

10 Standort: Hier können Sie den Einbauort eintragen, damit die Techniker bei der Wartung das Bauteil eindeutig identifizieren können.

11 Einbaudatum: ...

12 Sicherheitscode: Bei diesem Sicherheitscode handelt es sich um einen Trick, um festzustellen, ob die Techniker das zu wartende Bauteil wirklich gewartet haben. Die hier einzugebende Nummer kann gegebenenfalls als Strichcodeetikett ausgedruckt und auf dem entsprechenden Bauteil befestigt werden. Sie müssen von Ihren Technikern verlangen, dass sie in ihrem Wartungsprotokoll den vorgefundenen Sicherheitscode eintragen. Gegebenenfalls gibt es auch Sinn, den Sicherheitscode innerhalb der Geräte unterzubringen, so dass dieser nur abgelesen werden kann, wenn die für die Wartung erforderliche Demontage erfolgt ist. Natürlich müssen Sie dafür sorgen, dass dieser Sicherheitscode nicht bereits beim Druck des Auftrages dem Techniker mitgegeben wird.

13 Funktionales Hauptelement: Lesen Sie hierzu bitte im Kapitel Funktionale Verbindung

14 Bemerkung: Hier können Sie zu dem Anlagenteil eine bis zu 32.000 Buchstaben lange Bemerkung erfassen. Diese Bemerkung kann jedoch bei einer Selektion nicht verwendet werden – sie kann jedoch auf Papier bzw. beim Auftrag gedruckt werden.

14 Anmerkung: Die hier hinterlegten Texte werden in der Regel beim Wartungsauftrag mitgedruckt. Damit können Sie dem Techniker speziell für dieses Bauteil Hinweise geben.

15 Neu-Knopf: Durch Betätigen dieses Knopfes können Sie ein neues Anlagenteil erfassen.

16 Speichern-Knopf: Durch Betätigen dieses Knopfes speichern Sie Ihre erfassten Informationen ab.

17 Wartungsartikel hinterlegen-Knopf: Nach Betätigen dieses Knopfes können Sie in einer separaten Maske die für die Wartung regelmäßig erforderlichen Bauteile hinterlegen.

18 Ersatzteile hinterlegen-Knopf: Hier können Sie einem Anlageteil bestimmte Ersatzteile hinterlegen, die mehr oder weniger regelmäßig zum Einsatz kommen werden. Wenn Sie später auf der Vertragsebene eine Verdichtung aller hinterlegten Ersatzteile durchführen, so können Sie daraus gegebenenfalls eine Vorratshaltung von einzelnen Elementen ableiten. Wenn sich z.B. herausstellt, dass bei einem Kunden ein wichtiges Ersatzteil 50-mal eingebaut ist, so können Sie Ihrem Kunden empfehlen, sich einige von diesen Teilen auf Lager zu legen, damit bei einer Störung eine kurzfristige Reparatur möglich ist.

Lesen Sie hierzu bitte Kapitel Ersatzteile hinterlegen

Weitere Karteikarten: Bei den weiteren, in dieser Maske auf den Karteikarten zu hinterlegenden Informationen lesen Sie bitte im Kapitel TGM, Vertrag und Ortsbeschreibung bei der Beschreibung der Objektmaske nach. Hier handelt es sich exakt um die gleichen Informationen, die auch in jener Maske hinterlegt werden können.
