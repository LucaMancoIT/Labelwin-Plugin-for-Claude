Start

[Bild]

Auftrag

Neuer Auftrag (F2)

Durch Betätigen des Knopfes ‚Neuer Auftrag’ kommen Sie in die Erfassmaske.

Ändern / Zeigen (STRG +Z)

Wenn Sie einen bestimmten Auftrag komplett sehen oder ändern möchten, so erreichen Sie dies, in dem Sie den entsprechenden Auftrag mit der linken Maustaste markieren und den Knopf ‚Ändern/Zeigen’ drücken oder indem Sie den markierten Kundendienstauftrag mit einem Doppelklick anwählen. In beiden Fällen gelangen Sie in die Erfassmaske des Kundendienstauftrages und können dort alle Werte ändern. Dort können Sie dann auch die Rechnung schreiben, Zeiten erfassen, Material zuordnen usw.

Drucken (STRG+P)

Über diesen Knopf kann der markierte Auftrag sehr schnell gedruckt werden. Es handelt sich um die gleiche Funktion, die auch in der Auftragserfassungsmaske verwendet wird. Sollte der Auftrag bereits einmal gedruckt worden sein, so wird dies in der folgenden Maske angezeigt. Sobald ein Auftrag gedruckt ist, wird dieses über ein X in der Auftragsliste gekennzeichnet.

|

Tipp: Mehrfachdruck / KD-Sammeldruck

Wenn Sie in der Kundendienst-Hauptmaske mehrere Aufträge markieren, können diese auf einen Rutsch gedruckt werden. Hinter dem Drucken Icon wird die Anzahl der markierten Aufträge angezeigt.

Als Druckformular kann entweder eins für alle vorgegeben werden, oder das jeweils im Auftrag gewählte Formular wird verwendet. Es kommt eine entsprechende Abfrage.

Folgeauftrag anlegen (STRG+F2)

Diese Funktion können Sie nutzen, wenn für den ursprünglichen Auftrag weitergehende Arbeiten erforderlich werden. Die Abrechnung erfolgt über den Hauptauftrag. Näheres im Kapitel Folgeaufträge

Erledigt / Rechnung (F3)

Hier haben Sie die Möglichkeit, für den markierten Auftrag eine Rechnung zu schreiben. Es startet die gleiche Funktion, als wenn Sie den Knopf Nr. 22 betätigen.

Zugeordnete Dokumente (ALT+G)

Über diesen Menüpunkt können Sie eine Auflistung der zugehörigen Dokumente des gewählten Auftrags. Es ist die gleiche Funktion wie Knopf Nr. 21.

Fotos

Sollten zu dem in der Auftragsliste markierten Auftrag Fotos hinterlegt sein, können diese über diesen Menüpunkt aufgerufen werden.

Kalender

Balkendiagramm

Durch Betätigen dieses Knopfes startet das Balekndiagramm. Wegen der umfangreichen Möglichkeiten finden Sie die Beschreibung dieser Maske im Kapitel Kalender / Balkendiagramm.

Kalender

Durch Betätigen dieses Knopfes starten Sie den Kalender. Wegen der umfangreichen Möglichkeiten finden Sie die Beschreibung im Kapitel Kalender / Balkendiagramm.

Blockanzeige

Durch Betätigung dieses Knopfes starten Sie die Blockanzeige. Lesen Sie hierzu das Kapitel Blockanzeige

Tagesliste

Mit diesem Knopf kommen Sie in die gleiche Terminübersicht, wie über die Auftragserfassung. Wegen der umfangreichen Möglichkeiten finden Sie die Beschreibung dieser Maske im Kapitel Terminübersicht.

Archiv

Scannen (F12 )

Dieser Menüpunkt ist nur anwählbar, wenn Sie das Zusatzmodul Elo-Anbindung erworben haben.

Scan zeigen (F4)

Diesen Menüpunkt können Sie nur anwählen, wenn Sie das Zusatzmodul Elo-Anbindung oder Scanarchiv erworben haben.

Sonderfall Folgeaufträge:

Wenn der Scan eines Kundendienstauftrages gezeigt werden soll, können nun auch die Scans von Folgeaufträgen mit gezeigt werden. Um das Verhalten zu steuern, gibt es eine individuelle Einstellung.

Der neue Standard ist, dass bei vorhandenen Folgeaufträgen eine Auswahlliste mit den verbundenen Aufträgen gezeigt wird und man per Knopf einen oder auch alle auf einen Rutsch zeigen kann.

Per Schalter kann man festlegen, dass das alte Verhalten wieder greifen soll und nur der einzelne, gerade markierte Auftrag gezeigt wird.

Am sinnvollsten ist unserer Meinung nach die Einstellung, dass immer alle Scans gezeigt werden sollen. Die heute üblichen PDF-Anzeigeprogramme zeigen dann Karteireiter, in denen die jeweiligen PDF‘s sichtbar sind.

Die Schaltereinstellung finden Sie im Modul Einstellungen unter den Menüpunkten <Programmbereiche>, <Kundendienst>, <Grundeinstellungen> unten im Bereich ‚Anzeige‘

PDF zuordnen (Strg + F4)

Dieser Menüpunkt ist nur sichtbar, wenn Sie das Zusatzmodul Scanarchiv erworben haben. Wenn Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Archiveinstellungen> <Scanarchiv> bei den stationsabhängigen Einstellungen einen twainfahigen Scanner hinterlegt haben, können Sie über diesen Menüpunkt dem markierten Kundendienstauftrag eine pdf-Datei zuordnen.

Optionen

KD-Mobil Import

Dieser Punkt ist nur sichtbar, wenn das Zusatzmodul KD-Mobil im Einsatz ist und ein Auftrag per Cloud zum Import bereit liegt.

Ansicht aktualisieren (F5)

Wenn Sie im oberen Drittel der Maske eine Änderung der Auswahlkriterien vorgenommen haben, so wird dieser Knopf rot dargestellt. Die rote Farbe signalisiert, dass die Liste der angezeigten Aufträge nicht mit der obigen Selektion übereinstimmt. Durch Betätigen des Knopfes wird die Liste neu aufgebaut, und der Knopf wird wieder in Normalfarbe dargestellt.

Wenn Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Kundendienst> <Grundeinstellungen> auf der Karteikarte ‚Benutzer Einstellungen’ das Feld ‚Kundendienst mit automatischer Aktualisierung’ aktiviert haben, ändert sich der Knopf auf ‚Liste aktualis.’

Dokumente

[Bild]

Dokumente anlegen

neues Dokument

Über diesen Menüpunkt kann ein neues Dokument zu dem markierten KD-Auftrag erzeugt werden.

Lieferschein anlegen

Über diesen Menüpunkt können Sie einen Lieferschein für den KD-Auftrag anlegen. Ein Lieferschein wird dann angelegt, wenn die Artikel bereits auf das Projekt oder den Auftrag gebucht wurden.

Lagerentnahme anlegen

Über diesen Menüpunkt können Sie eine Lagerentnahme anlegen. Damit wird das Projekt oder der KD-Auftrag mit den EK-Preisen belastet.

Rücknahmen

Wenn Artikel von einer Baustelle zurück kommen, müssen diese an den Lieferanten zurück gegeben oder als negative Lagerentnahme eingebucht werden. Bei dieser Methode können nur Artikel zurück gebucht werden, die auch zur Baustelle geliefert worden sind.

Gesamtlieferschein erzeugen

Er enthält alles zur Baustelle gelieferte Material, eine Liste der Zeitbuchungen und Werkzeugbuchungen. Er dient zur Kontrolle und kann ggf. auch bei der Rechnungsstellung als Vorlage genutzt werden. Für Auswertungen (Projekt- oder Kundendienststatistik) hat er keine Bedeutung, da er mit der Dokumentart ‚Freier Text‘ angelegt wird.

Aktivierung: Die Funktionen Rücknamen und Gesamtlieferschein werden im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Projektverwaltung> <Grundeinstellungen/Zusatzfelder> aktiviert. Dort gibt es eine Option ‚Rücknahmen‘, in der die gewünschten Einstellungen festgelegt werden.

vorhandene Dokumente

Zugeordnete Dokumente

Über diesen Menüpunkt können Sie eine Auflistung der zugehörigen Dokumente des gewählten Auftrags. Es ist die gleiche Funktion wie Knopf Nr. 21.

Dokument zuordnen

ber diesen Menüpunkt haben Sie die Möglichkeit, einem markierten Auftrag ein im System gespeichertes Dokument zuzuordnen.

Offene Lagerentnahmen buchen

Wenn über ‚Zugeordnete Dokumente’ hinter dem gerade markierten KD-Auftrag eine Lagerentnahme mit Status offen liegt, kann diese über diesen Menüpunkt vom Lager abgebucht werden. Anschließend wird der Status der Lagerentnahme auf erledigt gesetzt.

Auftrag

[Bild]

Auftragsoptionen

Wandeln Folgeauftrag/Hauptauftrag

Hier haben Sie die Möglichkeit einen ‚normalen’ Auftrag einem anderen Auftrag zuzuordnen. Damit wird dann dieser Auftrag zu einem Folgeauftrag. Wichtig hierbei ist nur, dass die Rechnungsanschrift gleich ist, sonst ist eine Zuordnung nicht möglich.

Sie haben aber auch die Möglichkeit, mit diesem Menüpunkt einen Folgeauftrag vom Hauptauftrag zu trennen, so dass der Folgeauftrag ein ganz ‚normaler’ Auftrag wird und somit separat abgerechnet werden kann.

Telefonnummern

Unter diesem Menüpunkt werden Ihnen die Telefonnummern aller Adressen angezeigt, deren mit der aktiven Adresse verbunden sind.

Büroinfo

Dieser Menüpunkt öffnet die Büro-Information des markierten Auftrages.

Bearbeiter Kennzeichen entfernen

Sollte ein Auftrag durch einen anderen Benutzer gesperrt sein, haben Sie hier die Möglichkeit das Bearbeiterkennzeichen zu entfernen und können somit den entsprechenden Auftrag in Bearbeitung nehmen.

Löschen

Um diese Funktion nutzen zu können, muss die Berechtigung dazu vorhanden sein. Einen Auftrag kann man nur löschen, wenn kein Materialzettel und keine Rechnung begonnen wurden. Falls über die Zeiterfassung schon Daten erfasst worden sind, kann der Auftrag ebenfalls nicht gelöscht werden.

Status ändern

Um diese Funktion nutzen zu können, muss das Recht freigegeben sein. Diese Funktion gibt es auch im geöffneten Auftrag unter den Menüpunkten

[Bild]

Bild: Kundendienst – Status umsetzen

Priorität zuordnen

Mit diesem Menüpunkt kann man einem oder mehreren markierten Aufträgen eine Priorität zuweisen.

Projekt ändern

Dieser Menüpunkt ermöglicht das Verschieben von mehreren Aufträgen in ein anderes Projekt. Markieren Sie einfach die gewünschten Aufträge udn wählen diesen Menüpunkt an. Folgeaufträge und zugeordnete Dokumente werden automatisch mit verschoben.

Sperren

Markierte Aufträge sperren

Mit diesem Menüpunkt können Sie bestimmte Aufträge sperren, die Sie zuvor in der Auftragsliste markiert haben. Damit besteht dann keine Möglichkeit mehr, bei diesen Aufträgen, Änderungen wie z. B. Material eintragen, Zeiten buchen usw. vorzunehmen.

Markierte Aufträge entsperren

Mit diesem Menüpunkt können gesperrte Aufträge wieder frei gegeben werden. Damit sind wieder alle Eingabefunktionen verfügbar.

Internet

Stadtplan

Neben dem Internet-Stadtplan kann nun auch eine Anfahrtsskizze über das Internet erstellt werden. Die Funktionalität ist wie beim Stadtplan im Adressmodul und in der Druckmaske des Kundendienstes realisiert. Betätigen Sie dort die Menüpunkte bzw. den Knopf ‚Route’, so erscheint eine Maske, in der Sie die Start- und die Zieladresse wählen können. Über ein Ankreuzfeld besteht die Möglichkeit, die Startadresse dauerhaft abzuspeichern. In diesem Fall wird bei der nächsten Benutzung automatisch diese Startadresse vorgeschlagen.

Routenplan

Mit Hilfe der Internetseite Google Maps kann direkt aus Labelwin heraus der Standort einer Adresse gezeigt werden. Voraussetzung ist natürlich, dass Sie eine Internetverbindung automatisch aufbauen können oder zuvor das Internet aktiviert haben.

Aufträge / Techniker

Mit diesem Menüpunkt startet die Google Kartenansicht mit den Standorten aller markierten Aufträge. So lässt sich anschaulich darstellen wo sich die Monteure befinden. Voraussetzung ist der Erwerb des Moduls "Google Karte".

Mareon

Daten aus anderem KD

Dieser Menüpunkt ist nur sichtbar, wenn Sie das Zusatzmodul MAREON-Schnittstelle erworben haben. Eine ausführliche Beschreibung zur Mareon-Schnittstelle finden Sie im Handbuch unter Mareon Schnittstelle.

Auftrag parken

Dieser Menüpunkt ist ebenfalls nur sichtbar, wenn Sie das Zusatzmodul MAREON-Schnittstelle erworben haben.

Auswerten

[Bild]

Auftragsauswertung

Auftragsliste drucken

Mit dieser Funktion werden die gerade selektierten Auftrage in einer übersichtlichen Liste ausgedruckt. Bitte achten Sie unbedingt darauf, zuvor die richtige Eingrenzung getroffen zu haben. Wir haben schon einige Anrufe mit der Frage bekommen, wie der Drucker anzuhalten sei, weil er die komplette Auftragsliste ausdruckt.

Tagesplan drucken

Hier haben Sie die Möglichkeit einen Tagesplan zu drucken für ein bestimmtes Datum – entweder nur für einen bestimmten Monteur oder für alle Monteure.

Auswertung einzelner Auftrag

Mit dieser Funktion kann der gerade markierte Auftrag ausgewertet werden. Es wird die Summe der Rechnungen, der eingebuchten Zeiten und der zugeordneten Eingangsrechnungen gezeigt.

Auswertung alle Aufträge

Hier können über alle Aufträge hinweg Analysen erstellt werden. Bitte lesen Sie hierzu Kapitel Auswertung der Kundendienstaufträge.

Eingangsrechnungen

Hier werden Ihnen die erfassten Eingangsrechnungen zum markierten Kundendienstauftrag angezeigt.

Bestellüberwachung

Hier haben Sie die Möglichkeit, die ausgeführten Bestellungen zu überwachen. Sie sehen diesen Menüpunkt allerdings nur, wenn Sie das Modul BESTELLÜBERWACHUNG oder LAGER erworben haben.

Rechnungslaufzeit

Hier haben Sie die Möglichkeit, den Zeitraum zwischen der letzten Zeitbuchung und der Rechnungsschreibung zu kontrollieren. Es sollte gelten heute die Zeit gebucht, morgen die Rechnung geschrieben. Je länger Sie sich mit der Rechnungsschreibung Zeit lassen, desto mehr Geld verschenken Sie

Mengenüberwachung

Hier haben Sie die Möglichkeit, die detaillierte Mengenüberwachung zu starten. Eine genaue Beschreibung hierzu finden Sie im Kapitel zur Projektverwaltung.

Protokoll KD-Änderungen

Wenn Sie im Modul EINSTELLUNGEN unter dem Menpunkt <Grundeinstellungen> <Allgemein> bei den allgemeinen Einstellungen für die Auswertungen das Änderungsprotokoll für KD-Aufträge aktiviert haben, können Sie unter diesem Menüpunkt sehen, was im Kundendienst geändert wurde (z.B. Auftrag gelöscht, Auftrag geändert). Wenn Sie die Protokollfunktion aktiviert haben, sollten Sie Ihre Mitarbeiter darüber informieren.

TomTom Auswertung

Wenn Sie mit dem Zusatzmodul TomTom arbeiten, haben Sie hier die Möglichkeit eine Webfleet Aufwertung für alles Monteure, für einen bestimmten Monteur oder ein bestimmtes Team für einen Tag oder einen Zeitraum auszudrucken.

Ansicht/Zeigen

[Bild]

Zeigen

Grundsortierung (Strg+G)

Wenn die Sortierung der Aufträge geändert wurde, haben Sie durch die Wahl dieses Menüpunktes die Möglichkeit, die Grundsortierung der Erfassreihenfolge wieder herzustellen. Die Sortierung erfolgt durch einen Klick auf die Spaltenüberschrift.

Auftragstext groß anzeigen (F6)

Hier haben Sie die Möglichkeit, sich den Auftragstext in einem separaten Fenster anzeigen zu lassen. Hier ist es auch möglich, den Auftragstext zu ändern bzw. zu ergänzen.

Aufträge aktiver Adresse (F8)

Mit diesem Menüpunkt haben Sie die Möglichkeit, sich alle Aufträge der aktiven Adresse (Baustellenadresse) in der Auftragsliste anzeigen zu lassen.

Aktive Adresse mit Liegenschaft (STRG+F8)

Dieser Menüpunkt zeigt alle Aufträge zu der aktiven Adresse und alle Aufträge zu der Adresse, die als Liegenschaft in der aktiven Adresse eingetragen ist, unabhängig vom Status in der Liste an. Damit kann man z.B. alle Aufträge zu einem Mietshaus sehen, unabhängig von den Mieteradressen.

Eingrenzung per Adresse (F9)

Wenn Sie diesen Menüpunkt anwählen, springt der Cursor in der Maske der Auftragsliste automatisch in das Feld der Baustellenadresse.

Eingabe Auftragsnummer. (F7)

Wenn Sie diesen Menüpunkt anwählen, springt der Cursor in der Maske der Auftragsliste automatisch in das Feld der Auftrags-Nr.

Nur Monteure der Abteilung

Wenn Sie mit Abteilungen arbeiten, haben Sie über diesen Menüpunkt die Möglichkeit, dass Ihnen nur die Monteure vorgeschlagen werden, die einer bestimmten Abteilung zugeordnet wurden. Die Zuordnung der Abteilung muss im Modul EINSTELLUNGEN unter dem Menüpunkt <Porgrammbereiche> <Personal> <Personal erfassen> auf der Karteikarte ‚Zusatz’ beim jeweiligen Monteur erfolgen

Wartungstermine nach Planquadrat

Wenn Sie mit Planquadraten arbeiten (hierzu finden Sie eine nähere Beschreibung im Kapitel Farbgestaltung mit Prioritäten und Fahrzonen), können Sie aufgrund der Planquadrate Aufträge mit Monats- oder Wochenterminen suchen.

Es geht um die Situation, dass Sie in einem bestimmten Planquadrat einen Auftrag suchen, der ggf. gleich mit erledigt werden kann, wenn ein Kundendiensttechniker in der Gegend ist.

[Bild]

Folgeaufträge

Folgeauftrag anlegen (STRG+F2)

Zugehörige Folgeaufträge (Strg+F)

Hier haben Sie die Möglichkeit, sich eine Liste der zum Hauptauftrag gehörenden Aufträge anzeigen zu lassen. Sie können die Aufträge aus der Liste heraus auch in Bearbeitung nehmen.

Folgeaufträge ausblenden (Strg+B)

Wenn Sie viel mit Folgeaufträgen arbeiten, kann es manches Mal sehr störend sein, wenn alle Aufträge angezeigt werden. Mit diesem Menüpunkt haben Sie die Möglichkeit, die Folgeaufträge auszublenden, so dass nur noch Hauptaufträge in der Auftragsliste angezeigt werden.

Einblenden

Eingrenzung sichtbar

Dieser Menüpunkt blendet die Möglichkeit zur Auftragseingrenzung ein bzw. aus. Diese Funktion ist auch über den kleinen Knopf mit dem Fernrohr im Schnellzugriff erreichbar.

Kurzinfo

Die Kurzinfo blendet die Objektadresse, den Auftragstext und die Anmerkung des markierten Auftrages unter der Auftragsliste ein bzw. aus.

Zugeord. Doku.Tabelle

Dieser Menüpunkt blendet eine Tabelle mit den zugeordneten Dokumente am unteren Rand des Fensters ein bzw. aus. Diese Funktion ist nur aktiv, wenn die Kurzinfo eingeblendet ist.

Optionen

[Bild]

Selektion

Wartungstermine Selektieren

Wenn Sie Anlagen - Termine erfasst haben, so können Sie durch diesen Menüpunkt alle fälligen Aufträge heraussuchen lassen. Details lesen Sie bitte unter Kapitel Selektieren von Wartungsterminen nach.

Wartungsrechnungen schreiben

An dieser Stelle können Wartungsrechnungen automatisch (also als Stapel) gedruckt werden. Dazu ist es erforderlich, dass bei den Wartungsverträgen die entsprechenden Termine und ggf. auch Summen hinterlegt sind. Die detaillierte Beschreibung finden Sie unter Kapitel Wartungsrechnungen schreiben.

Mandant

Mandanten wechseln

Über diesen Menüpunkt können Sie den Mandanten wechseln. Er ist allerdings nur sichtbar, wenn Sie das Modul MANDANTENFÄHIGKEIT erworben haben.

Sonstige Optionen

Auftragsverteilung (Strg+O)

Hier können Sie einen Auftrag / mehrere Aufträge direkt einem Monteur zuordnen, ohne den Auftrag zu öffnen. Wenn Sie über diesen Menüpunkt einen Auftrag einem Monteur zuweisen, bekommt der Auftrag den Status ‚In Arbeit’.

Fixpreise bearbeiten

Wenn Sie das Modul Kundenspezifische Preise erworben haben und mit Fixpreisen arbeiten, haben Sie hier die Möglichkeit für den entsprechenden Kundendienstauftrag die Fixpreise zu hinterlegen.

Focus auf Tabelle (STRG+ U)

Hiermit wird der Focus auf die Tabelle mit den Aufträgen gelegt, damit dann direkt mit den Pfeiltasten weiter navigiert werden kann. Dieser Punkt macht nur Sinn bei Tastaturbedienung.

Fehlzeiten eintragen

Für die Terminanzeige der Mitarbeiter können hier die Urlaubs-, Krank- und Schulzeiten eingetragen werden.

[Bild]

Die eingetragenen Zeiten werden in der Terminmaske mit einem farbigen Balken gekennzeichnet.

Eine ausführlichere Beschreibung finden Sie im Kapitel Fehlzeiten.

Fehlzeiten haben keine Auswirkungen auf die Zeiterfassung. Dort müssen die tatsächlichen Fehlzeiten eingetragen werden, während es sich hier ja nur um die zu erwartenden Fehlzeiten handelt.

Von der Nutzung der Buchung auf Projekte an dieser Stelle raten wir ab. Erfassen Sie besser einzelne Montageaufträge, deren Abrechnung dann trotzdem über das Projekt erfolgt.

Intervall automatische Aktualisierung

Hier können Sie den Intervall in Minuten eintragen, in der die automatische Aktualisierung der Auftragsliste erfolgen soll. Steht hier eine Null, findet keine Automatisierung statt.

KD-Mobil Zentrale

Importieren

Nachricht senden

Über diesen Menüpunkt können Sie eine Nachricht an ein SkyePad senden. Dazu ist das Modul KD-Mobil in der PDA Variante erforderlich.

Auslagerkennz. löschen

Wenn Sie das Zusatzmodul KD-Mobil erworben haben, können Sie über diesen Menüpunkt die Kennzeichnung der Aufträge, die an ein Notebook ausgelagert wurden, löschen.

iDeXs

Exportieren

Dieser Menüpunkt ist nur sichtbar, wenn Sie das Modul IdeXs erworben haben. Hiermit werden Aufträge an IdeXs übertragen.

Statusmeldungen

Statusmeldungen Auftrag

Statusmeldungen Monteur

Hier werden Ihnen die Meldungen eines Monteurs angezeigt, die über die Statusmeldungen abgerufen wurden. Dieser Menüpunkt ist nur sichtbar, wenn Sie mit KD-Mobil und dem Cloud-Datenabgleich arbeiten.

Statusmeldungen alle

Hier werden Ihnen alle Meldungen angezeigt, die über kdmobil.de abgerufen wurden. Dieser Menüpunkt ist nur sichtbar, wenn Sie mit KD-Mobil und dem Internet-Datenabgleich arbeiten.

Senden

Über diesen Menüpunkt können Sie eine Nachricht an ein Laptop senden. Dazu ist das Modul KD-Mobil erforderlich und die Statusmeldungen müssen aktiviert sein.

TomTom

Export an TomTom

Über diesen Menüpunkt können Sie einen markierten Auftrag aus der Auftragsliste einen Auftrag an ein TomTom Gerät senden. Voraussetzung dafür ist das Modul TomTom

Nachricht an TomTom

Über diesen Menüpunkt können Sie eine Nachricht an ein TomTom Gerät senden. Dazu benötigen Sie das Modul TomTom

Virtic

Hierbei handelt es sich um eine Schnittstelle zu Virtic. Dieser Menüpunkt ist nur sichtbar, wenn die Schnittstelle erworben wurde.

Messdaten einlesen (Ziv 2000)
