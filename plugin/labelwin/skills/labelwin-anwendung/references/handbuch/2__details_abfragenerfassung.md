2. Details Abfragenerfassung

Angewählt wird die Erfassung mit den Menüpunkten ‚Controlling, Abfragen erfassen (F5)’.

Die Abfragenerstellung beginnt auf der Ebene der Liste aller vorhandenen Abfragen.Diese Liste können Sie ggf. durch eine Abfragegruppe eingrenzen oder durch das Ankreuzfeld ‚Grundabfragen’ umschalten.

Um unteren Teil der Maske werden einige Details der gerade markierten Abfrage gezeigt, die Sie hier jedoch nicht ändern können. Das Ändern geschieht immer über den Knopf ‚Bearbeiten’.

Interessant sind hier die Menüpunkte unter ‚Option’. Dort können Sie Musterabfragen importieren, eine von Ihnen erstellte Abfrage exportieren oder eine von anderen erstellte Abfrage in Ihr System importieren.

[Bild]

Menüpunkte

|

|

Abfragen

Bearbeiten

Hier handelt es sich um die gleiche Funktionalität, als wenn Sie den Bearbeiten-Knopf betätigen. Die gerade markierte Abfrage kann in der aufgerufenen Maske komplett verändert werden.

Testen

Mit der gerade markierten Abfrage kann eine Ausgabe erfolgen. Es ist die gleiche Funktion, als wenn Sie die Abfrage unter dem Hauptmenüpunkt ‚Controlling, Abfrage ausgeben’ wählen würden.

Neue Abfrage

Nach Wahl dieses Menüpunktes erstellen Sie eine neue Abfrage. Es ist die gleiche Funktionalität, als wenn Sie den entsprechenden Knopf betätigen.

Ende

Die Maske der Abfragenerfassung wird geschlossen

|

|

Anzeigen

Grundabfragen aktivieren

Hier handelt es sich um die gleiche Funktionalität, als wenn Sie den Haken bei ‚Grundanzeigen aktiv’ setzen würden. In der Tabelle werden nur noch die Grundabfragen gezeigt. Eine Grundabfrage liefert als Ergebnis immer nur einen Wert, der dann in Crystal-Reports und Excel-Tabellen verwendet werden kann. Dabei werden viele Grundabfragen aus unserem Hause geliefert, Sie können jedoch auch eigene Abfragen dazu erfassen. Ein Abfragename muss einmalig sein. Damit unsere mitgelieferten Abfragen am Ende der Anzeige stehen und sofort erkennbar sind, fangen sie immer mit zz_ an. Verwenden Sie bei eigenen Grundabfragen unbedingt einen Namen, der nicht so anfängt. Sonst kann es passieren, dass bei einem Update von Ihnen erstellte Grundabfragen überschrieben werden.

Strukturanzeige

Hier wird der Abfragetext in einem großen Fenster strukturiert dargestellt. Ein Zeilenumbruch befindet sich dann bei den Schlüsselworten From und Where und bei jedem Klammer öffnen und Klammer schließen. Es handelt sich einfach um eine andere Art der Darstellung, bei der die Struktur der SQL-Abfrage besser sichtbar ist.

Text groß

Dieser Menüpunkt hat die gleiche Funktionalität, wie der Knopf an der Oberfläche. Der Abfragetext erscheint in einem großen Fenster und kann damit besser eingesehen werden.

|

|

Option

Einfügen aus Vorlage

Um Ihnen gerade in der Anfangsphase behilflich zu sein, liefert Label einige Musterabfragen aus. Durch Wahl dieses Menüpunktes erscheint eine Liste aller Mustervorlagen und Sie können einzelne markieren und kopieren. Wenn es sich um eine Vorlage für eine Excel-Datei handelt, müssen Sie auch die entsprechende Excel-Datei zur Verfügung haben.

Die Anzahl der Mustervorlagen wird im Laufe der Zeit sicherlich umfangreicher werden.

Abfragen importieren

Wenn Sie von uns eine speziell für Sie erstellte Abfrage erhalten, können Sie diese hier in Ihr System kopieren. Sinngemäß ist es die gleiche Funktionalität, als wenn Sie eine Abfrage aus der Musterdatenbank übernehmen.

Abfragen exportieren

Hier können Sie eine von Ihnen erstellte Abfrage in eine Textdatei auslagern, um sie gegebenenfalls uns zur Kontrolle oder einem Kollegen, der ebenfalls Labelwin einsetzt, zur Verfügung zu stellen.
