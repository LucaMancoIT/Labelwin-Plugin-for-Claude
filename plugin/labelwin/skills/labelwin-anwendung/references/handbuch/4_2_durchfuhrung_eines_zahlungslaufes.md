4.2 Durchführung eines Zahlungslaufes

An dieser Stelle möchten wir die Durchführung eines Zahlungslaufes mit der Überweisung per Bankdatei konkret in den einzelnen Abläufen schildern:

-

Wählen Sie im Rechnungseingangsbuch den Menüpunkt [Zahlungen - Bezahlen offene Rechnungen] an.

-

Wählen Sie bei Zahlungsart "Datei/Online" an.

-

Wählen Sie im nächsten Schritt die Bankverbindung, mit der Sie die Überweisung durchführen möchten.

-

Wählen Sie die Option "Nächster Zahlunsglauf am" und setzen das gewünschte Datum ein. Wenn Sie es möchten, können Sie das Kreuz bei "Skontofristen nutzen" ebenfalls setzen.

-

Betätigen Sie den Knopf "Liste aufbauen (F5)", damit aufgrund der Eingrenzung die entsprechenden Rechnungen in die Tabelle eingetragen werden.

-

Markieren Sie einzelne Zeilen, indem Sie mit der linken Maustaste einen Doppelklick machen. In dem Feld "Ok" erscheint ein "Z". "Z" bedeutet, dass diese Eintragung mit dem nächsten Zahlungslauf bezahlt werden soll. Sie können auch unter dem Menüpunkt [Bearbeiten - Alle markieren] anwählen. Hierdurch werden alle in der Liste sichtbaren Rechnungen mit dem "Z" gekennzeichnet.

-

Wählen Sie den Knopf "OK Zahlen" an.

-

Bei der Zahlung per Bankdatei muss nun das Zielverzeichnis festgelegt werden.

Bild: Bankdiskette erstellen

Das Programm merkt sich die Eingabe und schlägt beim nächsten Mal den gleichen Pfad vor. Der Pfad muss von Ihnen selbst angelegt werden – unser Programm hat hierfür keine Vorgabe. Da die Datei in Labelwin nicht weiterverarbeitet wird, sondern später n Ihr Bankprogramm eingelesen wird, ist für Labelwin der Pfad im Prinzip völlig gleichgültig. Sie müssen ihn nur wissen, um ihn im Bankprogramm hinterlegen zu können.

In den angegebenen Pfad wird eine SEPA.XML Datei mit fortlaufender Nummer geschrieben. In dem Ordner sammeln sich somit mit der Zeit Dateien an, die von Zeit zu Zeit gelöscht werden können. Löschen Sie nur Daten, die wirklich in das Bankprogramm eingelesen wurden.

Übergabe der Datei an die Bank:

Wenn Sie die Daten noch als Datei (per USB-Stick, Diskette o.ä.) an die Bank übergeben wollen, müssen Sie den vom Programm angebotenen Bankzettel ausdrucken und beilegen. Bei der Übergabe an ein Bankprogramm wird der Bankzettel nicht benötigt, da Sie dort mit sogenannten TAN-Nummern arbeiten.

Hinweis: Bei der Übergabe der Daten an ein Bankprogramm oder per Online-Zugang können wir Ihnen nur wenig helfen. Sie benötigen ein Programm von der Bank (z.B. S-Firm, VR-Networld etc.), mit dem Sie Zugriff auf Ihre Konten haben. Solche Programme haben irgendwo immer einen Menüpunkt, mit dem sich die SEPA.XML Datei einlesen lässt. Irgendwo wird dabei der Pfad abgefragt, in dem sich die Datei befindet. Geben Sie ihn genau so an, wie bei der Erzeugung der Daten im Labelwin. Wenn Sie Probleme bei der Übergabe haben, so wenden Sie sich bitte an die Betreuer des Bankprogramms.

Protokoll und Begleitbriefe:

-

Drucken Sie unbedingt das Protokoll des Zahlungslaufes für Ihre eigene Ablage aus.

-

Falls Begleitbriefe für die Großhändler angeboten werden, können Sie diese bei Bedarf ausdrucken. Das Programm bietet den Ausdruck immer dann an, wenn mehr als eine Rechung für einen Großhändler im Zahlungslauf enthalten ist.

[Bild]

Über einen Schalter in der Maske „Bezahlen“ unter dem Menüpunkt [Optionen] können Sie erreichen, dass zu jeder Zahlung eine Zahlungsankündigung angeboten wird.

[Bild]

Damit ist der Zahlungslauf durchgeführt, und Sie können die erzeugte Datei ggf. an die Bank bzw. ins Bankprogramm übergeben.

Zahlungslauf auf bezahlt setzen:

Sobald Sie sicher sind, dass die Überweisungen oder die Bankdatei ordnungsgemäß erstellt worden sind, können Sie die Zahlungen auf erledigt setzen. Wenn Sie das Modul FIBUERFASSUNG nutzen, erfolgt die Buchung des Zahlungsausganges dort. Anderenfalls geschieht es auf der ersten Maske im Rechnungseingangsbuch unter dem Menüpunkt [Zahlungen - Bezahlt setzen Zahlungslauf]. Dort können Sie aus der Liste der offenen Zahlungsläufe den entsprechenden Zahlungslauf auswählen und diesen in einem Rutsch auf erledigt setzen.
