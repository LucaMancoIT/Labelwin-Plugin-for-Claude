7.6 Import / Doppelklick-Funktion

1. Steht ein Auftrag per Cloud-Abgleich bereit, wird dies im mobilen Kundendienst durch einen gelben Button „Auftrag holen“ angezeigt. Klickt man auf diesen Button, wird der Auftrag automatisch eingelesen.

[Bild]

Nach Import des Auftrages wird der gelbe Button wieder ausgeblendet und erst wieder eingeblendet, wenn eine neue Datei im Import-Pfad liegt.

2. Kommt der Auftrag per E-Mail (oder als Datei) auf das mobile Gerät, so sollte der Rechner so eingerichtet werden, dass ein Doppelklick auf die Transportdatei den Import startet. Die Transportdatei hat immer die Extension .labelnb.

Die einfachste Variante der Einrichtung ist ein Doppelklick auf den Dateianhang der E-Mail (alternativ kann man die Transportdatei auch zuerst auf den Desktop kopieren). Windows fragt dann beim erstmaligen Öffnen mit welchem Programm die Datei geöffnet werden soll.

[Bild]

Tragen Sie in das Feld „Beschreibung“ Notebook Importdatei ein. Betätigen Sie dann den Button „Durchsuchen“ (bei älteren Windows-Versionen heißt der Button „Andere“ ) und stellen die Verbindung zu dem Programm kdimport.exe her. Wenn Sie dann die obige Maske mit OK verlassen, können Sie zukünftig in der E-Mail mit einem Doppelklick die Daten einspielen.

[Bild]

Der Import ist natürlich auch ohne Doppelklick möglich.

Wenn Sie ohne E-Mail arbeiten (z.B. bei Einbindung des Notebooks ins Netz) sollten Sie das Programm KDIMPORT.exe mit einer Verknüpfung an die Oberfläche holen. Nach dem Start müssen Sie die Datei mit dem Durchsuchen-Button heraussuchen.

Der Pfad muss nur beim ersten Mal gewählt werden – beim nächsten Mal wird er passend vorgeschlagen. Im Dateinamen wird das Tagesdatum und Uhrzeit verwendet. Wenn eine Datei übernommen worden ist, wird die Endung umbenannt (.sic) und damit in der Auswahl nicht mehr angezeigt.
