[Bild: 1]

Überweisungsträger

[Bild: 1. Überweisungsträger]

Überweisungsträger-Formular: Falls Sie mehrere Formulare für die Zahlscheine/Überweisungsträger eingerichtet haben, können Sie hier das entsprechende Formular wählen. Die Ausgabe erfolgt ohnehin nur dann, wenn auf der ersten Karteiseite die Ausgabe von Zahlungsscheinen aktiviert ist.

Überweisungsträger-Drucker: Wählen Sie hier den Drucker, auf dem die Überweisungsträger ausgegeben werden.

Durch Aktivieren des Feldes Bildschirm erfolgt die Druckausgabe auf dem Bildschirm. Die Option ist in der Regel sicherlich sinnlos, beim Text kann es jedoch nützlich sein.

Report aktualisieren: Durch Betätigen dieses Knopfes wird das ausgewählte Formular (C1) aktualisiert. Die gleiche Funktion steht Ihnen auch für das Folgeformular (C5) zur Verfügung.

Anzahl Exemplare: Wählen Sie die Anzahl der zu druckenden Überweisungsträger bzw. der zu druckenden Formulare.

|
[Bild: 2]

Folgeformular

[Bild: 2. Folgeformular]

Folgeformular-Formular: Falls auf Ihren Rechner Folgeformulare eingerichtet sind, kann hier das entsprechende Formular gewählt werden. Folgeformulare werden z. B. für eine besondere Druckausgabe für die eigene Ablage, für Etikettenausdrucke, für nachgeschaltete Kalkulationsausdrucke und dergleichen verwendet. Die Formulare müssen standardmäßig mit den Buchstaben „FO“ angestellt worden sein. Sollten Sie bei dem ersten Druckformular ein Folgeformular hinterlegt haben, so wird dieses ebenfalls (unabhängig vom Namen) in dieser Liste angeboten. Lesen Sie hierzu bitte im Kapitel Folgeformulare / Rechnungsprüfung.

Folgeformular-Drucker: Wählen Sie hier den Drucker auf dem ggf. das Folgeformular ausgeben werden soll.

Durch Aktivieren des Feldes Bildschirm erfolgt die Ausgabe des Folgeformulars auf dem Bildschirm. Dieses kann höchstens zu Textzwecken sinnvoll sein.

|
[Bild: 3]

Folgeexemplare

[Bild: 3. Folgeexemplare]

Wenn auf der Karteiseite die Druckausgabe von Folgeexemplaren auf einem anderem Drucker installiert ist, so kann hier der Drucker gewählt werden.

|
[Bild: 4]

2. und folgende Seiten

[Bild: 4. 2. und folgende Seiten]

Bei entsprechender Einrichtung der Drucker (Namensgebung mit S2 am Ende) können die Seitenzahlen 2ff auf einen anderem Drucker ausgeben werden. Bei Zweischachtdruckern besteht die Möglichkeit, einen weiteren Drucker mit dem zweiten Papierfach anzulegen. Auf diesem simulierten Drucker kann dann ggf. die Druckausgabe erfolgen.
