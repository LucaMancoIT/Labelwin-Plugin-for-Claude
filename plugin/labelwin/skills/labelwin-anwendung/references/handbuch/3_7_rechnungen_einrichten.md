3.7 Rechnungen einrichten

Sie erreichen diesen Bereich aus der Menümaske der Vertragserfassung durch Anwahl der Menüpunkte ‚Vertrag, Rechnungsbeträge’. Sie können zu einem Vertrag beliebig viele Musterrechnungen anlegen, die auf Grund der bei Ihnen hinterlegten Periode relativ einfach regelmäßig gedruckt werden können. Durch diese Konstruktion ist es auch möglich, z.B. eine halbjährliche Rechnungsstellung mit unterschiedlichen Beträgen einzurichten. In diesem Fall werden nämlich zwei Musterrechnungen hinterlegt, deren Periode jeweils auf 12 Monate steht und das Datum der Rechnungsstellung 6 Monate auseinander liegt.

[Bild]

1 Tabelle: In dieser Tabelle werden alle bei dem Vertrag hinterlegten Rechnungen aufgelistet.

2 Vorbemerkung: Hier können Sie eine Vorbemerkung speziell zu dieser Rechnung erfassen. Über den Knopf ‚Vorbemerkung’ (Nr. 3) können Sie auf die im Programm hinterlegten Standardvorbemerkungen zurückgreifen. Diese Standardvorbemerkungen werden im Einstellprogramm unter den Menüpunkten ‚Vorlagen, Vor- und Nachbemerkungen’ hinterlegt.

3 Vorbemerkung-Knopf: Durch Betätigen dieses Knopfes gelangen Sie in die Liste der Standardvorbemerkungen und können eine für diese Wartungsrechnung auswählen. Mit einem erneuten Druck auf den Vorbemerkungs-Knopf können Sie beliebig viele weitere Vorbemerkungen anhängen, falls Sie sich ein System von einzelnen Bausteinen zusammengesetzt haben.

4 Nachbemerkung: Hier gilt sinngemäß das gleiche wie bei der Vorbemerkung. Der hier eingegebene Text wird allerdings hinter der eigentlichen Rechnung und vor der Zahlungsbedingung ausgegeben.

5 Nachbemerkung-Knopf: Genau wie bei der Vorbemerkung können Sie hier auf hinterlegte Standardnachbemerkungen zugreifen.

6 Positionstext: Geben Sie hier den eigentlichen Artikeltext der Rechnung ein. Eine Wartungsrechnung besteht hier nur aus einer einzigen Position und dem dazugehörigen Preis. Verzichten Sie bei der Erfassung auf einen Zeilenumbruch, da dieser über das Formular gesteuert automatisch nach 40 Buchstaben bzw. der letzten passenden Leerstelle erfolgt.

7 Formular: Legen Sie hier fest, mit welchem Druckformular die Rechnungsausgabe erfolgen soll.

8 Exemplare: Tragen Sie hier ein, in wie viel Exemplaren die Rechnung gedruckt werden soll.

9 Zahlungsbedingung: Legen Sie hier die Zahlungsbedingung fest. Die verschiedenen Zahlungsbedingungen werden im Programm ‚Einstellungen’ unter den Menüpunkten ‚Grundeinstellungen, Zahlungsbedingungen’ erfasst.

10 Erlöskonto: Legen Sie hier fest, mit welchem Erlöskonto Ihre Rechnung im Rechnungsausgangsbuch eingetragen werden soll.

11 Überweisungsträger ausgeben: Ein Häkchen in diesem Feld bewirkt, dass neben dem eigentlichen Rechnungsdruck ein Überweisungsträger ausgegeben wird. Dabei sollten Sie es sinnvollerweise so einrichten, dass dieser auf einem anderen Drucker ausgedruckt wird. Diese Einrichtung erfolgt im Programmmodul ‚Einstellungen’ unter den Menüpunkten ‚Programmbereiche, Druckausgabe’.

12 TGM Element: Eine Eingabe in diesem Feld bewirkt, dass die Rechnung nicht unmittelbar dem Vertrag, sondern einer beliebigen anderen Ebene zugeordnet wird. Wenn Sie beispielsweise Ihre Rechnungen für jedes Objekt oder jeden Komplex einzeln stellen wollen, können Sie hier die Ordnungsnummer dieses Elementes eintragen.

13 nächste Rechnung: Tragen Sie hier ein, wann die nächste Rechnungsstellung erfolgen soll. Die Rechnungsstellung erfolgt allerdings nicht automatisch an diesem Datum, sondern wird durch eine von Ihnen anzustoßende Selektion mit Eingrenzung auf das hier hinterlegte Datum durchgeführt.

14 letzte Rechnung: Hier können Sie keine Eingabe treffen, sondern lediglich das Datum der letzten Rechnungsstellung nachlesen.

15 Rechnungsperiode: Geben Sie hier die Periode in Monaten ein, in der die Rechnungsstellung erfolgen soll. Wenn Sie beispielsweise eine vierteljährliche Rechnungsstellung wünschen, so müssen Sie hier die Ziffer 3 eingeben.

16 Rechnungsbetrag: Geben Sie hier die Nettosumme ein, über die sich die Rechnung belaufen soll. Die Mehrwertsteuer wird bei der Druckausgabe automatisch ermittelt.

17 Neu-Knopf: Durch Betätigen dieses Knopfes können Sie eine neue (weitere) Rechnung hinterlegen.

18 Speichern-Knopf: Mit diesem Knopf speichern Sie Ihre getroffenen Eingaben ab.

19 Löschen-Knopf: Mit diesem Knopf können Sie die in der Tabelle (Nr. 1) markierte Rechnung löschen.

20 Ende-Knopf: Durch Betätigen dieses Knopfes schließen Sie die Maske ohne gegebenenfalls vorgenommene Änderungen abgespeichert zu haben.
