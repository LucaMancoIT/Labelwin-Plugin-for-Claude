3.4 Zeiterfassung

Die Erfassung der Arbeitszeiten sieht ein wenig anders aus als im Büro. Es werden nur die im mobilen Einsatz benötigten Funktionen angeboten und in einer Touch-Bildschirm optimierten Weise dargestellt.

Wie im Büro können nicht benötigte Bereiche (wie z.B. eine 2. Stunden- oder Tageszulage) über das Einstellmodul unter <Programmbereiche> <Zeitwirtschaft><Grundeinstellungen><Sichtbare Elemente> ausgeblendet werden.

Die Maske ist so eingerichtet, dass in der Regel alle Eingaben auf der Hauptseite stattfinden. Sollten der Platz für alle Eingabefelder doch einmal nicht ausreichen, findet man diese hinter dem Button „Zusatz buchen“. Alle Eingaben können über eine Tastatur oder durch Betätigung der Pfeiltasten erfolgen.

Die Eingaben können automatisch in die Rechnung übernommen werden.

[Bild]

|

Bei jeder Auftragsübermittlung ans Büro werden alle Zeitbuchungen mit übertragen – unabhängig vom Auftragsstatus. Damit wird erreicht, dass die Mitarbeiter-Monatsabrechnung auf jeden Fall erfolgen kann.

In der Regel genügt die mobile Zeiterfassungsmaske allen Ansprüchen. Sollte die Reihenfolge der Elemente jedoch nicht gefallen, kann sie auch komplett flexibel selbst gestaltet werden. In Kapitel Zeiterfassung, flexible Maske V5 wird die Einrichtung einer eigenen Zeiterfassungsmaske beschrieben.

Zeitbuchungen für Projekte

Bewusst können hier nur Zeitbuchungen auf Aufträge erfolgen. Wir empfehlen, auch für Arbeiten, die über ein Projekt abgerechnet werden, einen oder mehrere Aufträge anzulegen. Dies kann sehr schnell aus dem Projekt heraus geschehen (rechte Maustaste bei geöffnetem Projekt). Diese Aufträge bekommen den Status „über Projekt abzurechnen“. Dieses Verfahren hat den Vorteil, dass der Mitarbeiter immer einen Zettel bzw. den Auftrag auf dem Notebook dabei hat. Er weiß wohin und was er zu tun hat.

Wenn Sie nur einen Sammelauftrag wg. der Zeiterfassung haben wollen, gehen Sie so vor:

In der Zentrale wird ein KD-Auftrag für dieses Projekt angelegt und unter „weitere Monteure“ werden alle beteiligten Monteure ausgewählt. Dann wird der Auftrag mit der Option „Auftrag an alle Monteure“ verschickt. Dadurch entsteht für jeden Mitarbeiter eine E-Mail bzw. Datei. Diese Datei wird auf den Notebooks der beteiligten Mitarbeiter eingelesen. Diese Aufträge verbleiben dort solange als offen, bis das Projekt erledigt ist und kann dann auf dem Notebook „gelöscht“ werden. Gelöscht wird in der Auftragsmaske mit dem Button neben der Objektadresse
