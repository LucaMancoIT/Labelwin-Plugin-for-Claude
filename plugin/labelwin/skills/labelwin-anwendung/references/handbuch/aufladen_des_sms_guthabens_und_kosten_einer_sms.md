Aufladen des SMS Guthabens und Kosten einer SMS

Aufladen des Guthabens

Zum Versenden von SMS über das Labelwin SMS Internet Gateway benötigen Sie ein SMS Guthaben bei Label. Das Guthaben kann über das Internet per Lastschrifteinzug aufgeladen werden. Die Gutschrift des Betrages erfolgt sofort.

Zum Aufladen drücken Sie im Modul SMS auf den Knopf ‚Guthaben/Kosten’. Im folgenden Fenster bekommen Sie Ihr aktuelles Guthaben gezeigt und gelangen per Knopf ‚SMS Konto aufladen’ auf einer Internetseite von Label, wo Sie beim ersten Aufruf ggf. Ihre Bankverbindung eingeben müssen. Bei einem erneuten Besuch sind die Bankdaten bereits ausgefüllt, können aber korrigiert werden.

Derzeit können Sie auswählen, ob Sie eine einmalige Einzugsermächtigung für 30 €, 45 € oder 60 € erteilen wollen. Bei 45 € erhalten Sie eine Gutschrift in Höhe von 47 €, bei 60 € eine Gutschrift in Höhe von 65 €. Diese Beträge können sich allerdings jederzeit ändern.

Nachdem Sie den Betrag, die Bankverbindungsdaten und Ihren Namen (sehr wichtig!) eingetragen haben, müssen Sie noch per Ankreuzfeld bestätigen, dass Sie berechtigt sind, eine Abbuchung zu veranlassen.

Hinweis: Am Ende der Seite stellen Sie fest, dass wir bestimmte Nutzerdaten, wie IP Adresse, Ihren Windows Login- und Computernamen sicherheitshalber protokollieren.

Der Geldbetrag wird sofort Ihrem SMS Guthaben gutgeschrieben. Eine Rechnung geht Ihnen etwa ein Tag später per Post zu und der Betrag wird wenige Tage später eingezogen.

Dauer und Kosten einer SMS Mitteilung

Die SMS wird sofort an den entsprechenden Provider weitergeleitet. Eine deutsche SMS an D1/D2/O2/E+ dauert normalerweise ca.5 Sekunden. Eine SMS an einen internationalen Empfänger dauert normalerweise maximal 60 Sekunden. In Ausnahmenfällen kann es aber schon mal deutlich länger dauern. Eine Garantie für die Zustellung gibt es nicht.

Die Kosten der SMS erfahren Sie durch Drücken auf den Knopf ‚Guthaben/Kosten’. Die genannten Preise werden online aus dem Internet geholt. Sie können sich jederzeit ändern.

Folgende ca. Kosten entstehen für eine SMS:

· € 0,1508 (€ 0,13 netto) für eine internationale SMS

· € 0,1508 (€ 0,13 netto) für eine D1/D2/E+/O2 SMS

· € 0,2320 (€ 0,20 netto) für eine dt. Festnetz SMS
