3. Erfassen einer Checkliste für eine Anlage

Wenn ein Kundendienstauftrag mit einer Anlage und einem Wartungstermin erstellt wird, dann wird eine bei der Anlage hinterlegte Checkliste automatisch zum Auftrag kopiert. Die Anlagen-Checkliste dient also als Vorlage zur Kundendienst-Checkliste. Dieser Weg ist sinnvoll, weil dann bei jeder Wartung der Anlage automatisch die gleiche Checkliste zum Auftrag hinzukommt. Ohne Wartungstermin kann die Anlagencheckliste manuell aktiviert werden.

Die Anlagen-Checkliste wird einer bestehenden Anlage zugeordnet. Hier gibt es den Knopf ‚Anlagen-Checkliste‘

[Bild]

Wählen Sie nun die entsprechende Anlage oder das entsprechende Gerät aus und betätigen Sie den Knopf ‚Anlagen-Checkliste‘.

Wählen Sie aus dem aufsteigenden Fenster die entsprechende Vorlage aus.

Im folgenden Bild fehlt bewusst eine Kleinigkeit. Sobald zu der Anlage eine Karteikarte hinterlegt ist, kann diese hier zusätzlich erscheinen. Da dies die Erklärung aber erschwert, lesen Sie dazu bitte im Kapitel Verknüpfung der Anlagen-Checkliste mit der Anlagen-Karteikarte.

[Bild]

Wenn erforderlich können Sie in dieser Maske weitere Vorlagen-Bausteine anhängen. Wählen Sie dazu den Menüpunkt <Bearbeiten> oder den Knopf ‚Vorlage anhängen‘. Die weiteren Vorlagen werden automatisch durch eine farbige Trennzeile mit der Überschrift gekennzeichnet. Man erkennt sie auch durch das Merkmal ‚Vorlg‘

Das Feld ‚aktiv‘ dient dazu, einzelne Zeilen später in der Kd-Checkliste nicht zu zeigen, sie sind aber trotzdem vorhanden. Bei Bedarf können sie später aktiviert werden. Sinnvoll ist dieses beispielsweise bei einer Prüfung. Wenn üblicherweise ein Bauteil per Hand bedient wird, kann die Prüfung der elektronischen Steuerung nicht anwählbar sein. Nach einem späteren Umbau kann man diese Zeile auch vor Ort aktivieren.
