1.4 iDeXs-Stammdaten

Die folgende Maske findet sich im Modul EINSTELLUNGEN unter dem Menüpunkt [Mobil - iDeXs- Stammdaten] oder über die Tastenkombination STRG+I.

Da diese Maske an allen möglicherweise nicht sofort verständlichen Stellen einen kleinen Erklärungstext mit dem Fragezeichen anbietet, haben wir hier auf die Wiederholung weitgehend verzichtet.

Knopf "Speichern + übertragen":

Damit werden alle Grunddaten an das iDeXs-Web und von dort an die App transportiert.

Hier wird übertragen:

- Personalstammdaten

- Wer mit welcher Version und welchen Optionen die App nutzt

- Die Arbeitsbereiche, Stundenarten, Zulagen

- Die beiden im iDeXs mindestens benötigten Projekte KUNDENDIENST und das Projekt für diverse Kundendienstaufträge

Dieser Schritt muss immer dann wiederholt werden, wenn sich irgendwelche Daten geändert haben. Die App erhält die Änderungen anschließend automatisch, wenn die nächste Verbindung zum Internet genutzt wird.

Knopf "DiFa-Art übertragen":

Für die mobile Materialerfassung sollten so genannte DiFa Artikel an das iDeXs-Web übergeben werden. Die Hintergründe und Einrichtung können Sie im Kapitel DiFa - Direktfakturierung nachlesen.

Über diesen Button werden die festgelegten DiFa- Artikel ans Web übergeben.
