TecWeb

|

[Bild]

|

Über die Zusatzfunktion TecWeb kann der Mitarbeiter seine gebuchten Zeiten pro Tag oder Monat sich anschauen.

Als normale User kann er nur seine Zeiten überprüfen. Wenn der User Admin rechte hat, kann er sogar auch die Zeiten von weiteren Monturen sich anschauen. So eine Funktion ist z.B. für den Bauleiter oder Chef interessant.
