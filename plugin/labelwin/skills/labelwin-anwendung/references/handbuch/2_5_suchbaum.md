2.5 Suchbaum

[Bild]

Einlesen des Suchbaums

Daten im Label Format

Diese Daten können erzeugt werden, indem Sie im Suchbaum an einen beliebigen Knoten markieren und den Menüpunkt <Option> <Ebene exportieren> anwählen. Die Möglichkeit wurde geschaffen, damit sich Labelwin-Anwender ggf. austauschen können oder wir Ihnen einen neuen Suchbaumbereich zukommen lassen können.

Der Suchbaum von TGP (wird auf CD mit ausgeliefert)

Die Datei befindet sich auf der TGP-CD und sollte immer komplett eingelesen werden. Da eigene Änderungen beim Suchbaum einspielen verloren gehen, sollten Sie im TGP-Bereich keine Änderungen vornehmen.

Der mit Excel erzeugte KD-Mobil Suchbaum

Damit der für die mobile Lösung erzeugte Suchbaum auch im Büro verwendet werden kann, können Sie hier die CSV-Datei einspielen.

Der Suchbaum von Nesdata

Hierbei handelt es sich um den Suchbaum des Elektroherstellers Nesdata, den Sie komplett einlesen können.

Daten im mobile offer Format

Hierbei handelt es sich um die Stücklisten des Zusatzmoduls mobile offer.
