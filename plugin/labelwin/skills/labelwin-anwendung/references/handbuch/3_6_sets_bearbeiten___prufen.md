3.6 Sets bearbeiten / prüfen

3.6.1 Set, Bestandteile prüfen

Durch die Wahl dieses Menüpunkts alle Bestandteile aufgelistet, die in einem Set/Serienartikel enthalten, aber in keinem Katalog vorhanden sind. Dieses kann z.B. durch Löschung eines Katalogs oder einzelner Artikel geschehen sein.

3.6.2 Set, Bestandteile tauschen

Mit der Wahl dieses Menüpunkts haben Sie die Möglichkeit, nicht mehr vorhandene Artikel in Sets/Serienartikel gegen einen anderen Artikel zu tauschen. Dazu müssen Sie den ursprünglichen Katalog und die ursprüngliche Artikelnummer eintragen sowie den neuen Katalog und die neue Artikelnummer. Mit OK starten Sie den Vorgang.

[Bild]

3.6.3 Set, Katalogzuordnung

Durch die Wahl dieses Menüpunkts haben Sie die Möglichkeit, Setbestandteile auf einen anderen Katalog verweisen zu lassen. Dabei werden nur die Artikel auf den anderen Katalog umgesetzt, die dort vorhanden sind. Dazu müssen Sie den bisherigen Verweis auf einen Katalog und den Katalog eintragen, auf den der Verweis geändert werden soll. Mit OK starten Sie die Zuordnung.

3.6.4 Setbeschriftung kopieren

Mit diesen Menüpunkt haben Sie die Möglichkeit, Beschriftungen von Sets auf einen anderen Katalog zu übertragen.

Entwickelt wurde dieses, um nach Einspielen der Meta-Datei Beschriftungen des Sets aus dem ZVEH-Katalog zu verwenden. Wählen Sie dazu die Quell-Katalog aus und starten Sie mit OK den Vorgang.

3.6.5 Set-Summen rechnen

Mit diesem Menüpunkt haben Sie die Möglichkeit, für die Sets die Brutto- und Nettosummen zu ermitteln. Diese Summen werden nur bei der Suche angezeigt - das Set wird bei der Verwendung immer neu aufgrund der Bestandteile gerechnet.

Wenn Bestandteile des Sets fehlen oder keinen Preis haben, so ist der Gesamtpreis falsch.

Prozentuale Zuschläge im Set werden nicht eingerechnet

Wenn Sets aus einem anderen Katalog im Set sind (Set im Set geschachtelt), so werden dessen (ggf. falschen) Summen gewertet.

Sie sollten die Sets zuvor auf das Vorhandensein aller Bestandteile prüfen. Wählen Sie dazu den Menüpunkt <Bearbeiten> <Sets bearbeiten/prüfen> <Set, Bestandteile prüfen>
