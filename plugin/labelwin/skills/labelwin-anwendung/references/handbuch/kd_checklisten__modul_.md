KD-Checklisten [Modul]

26.04.2019

(V5.88)

THEMA

|

Die Kundendienst-Checkliste ist für alle Firmen wichtig, die Wartungen und Inspektionen vornehmen. Im KFZ-Handwerk gibt es schon seit Jahren keine Inspektion ohne Checkliste. Auch in der Haustechnik wird sich dies zum Standard entwickeln. Hier wird es immer wichtiger, die Arbeiten nachzuweisen. Zum einen, damit der Kunde weiß, für was er Geld bezahlt, zum anderen auch, um im Schadensfall einen Nachweis führen zu können.

Ein großer Unterschied zum KFZ-Handwerk ist jedoch, dass in der Haustechnik jede Anlage individuell ist.

Bei der Vielzahl der heute vorzufindenden Geräte hat ein Kundendiensttechniker kaum eine Chance, alle erforderlichen Reinigungsarbeiten und Prüfarbeiten zu kennen. Falls das Handbuch vom Hersteller vorhanden ist, so ist dies in der Regel nicht auf die Wartungssituation angepasst. Hierbei können spezielle Vorlagen helfen, die auf die Besonderheiten der Geräte eingehen.

Mit den Kundendienst-Checklisten ist eine übersichtliche Wartung und Instandhaltung von kleinen und großen Anlagen möglich. Das Prüfprotokoll sorgt dafür, dass der Kundendienst-Techniker nichts vergisst. Auch umfangreiche Checklisten können auf einem Laptop, Netbook oder Tablet-PC usw. abgearbeitet werden. Auch mit einem iPad kann gearbeitet werden, wenn per Fernzugriff mit einem Terminalserver gearbeitet wird.

Schon lange kann neben dem Kundendienstauftrag auch eine Checkliste ausgedruckt werden. Dies ist aber ein festes Formular oder muss per Excel oder Word separat gedruckt werden.

MIt dem Modul KD-CHECKLISTEN können Checklisten an den Auftrag geklammert werden, die sehr schnell und flexibel erstellbar sind. Diese Checklisten können sowohl gedruckt, als auch direkt am Bildschirm abgearbeitet werden. Das Ankreuzen am Bildschirm bedeutet aber, dass entweder die Laptoplösung eingesetzt wird oder per ‚Fernbedienung‘ gearbeitet wird. Natürlich ist auch das Nacharbeiten im Büro möglich. Die ausgefüllte Checkliste bleibt als Protokoll dauerhaft am Auftrag. Wenn die Checkliste mit einer Anlage verbunden ist, werden die letzten Kreuze und Anmerkungen bei der Anlage sichtbar.

VORAUSSETZUNGEN

|

-

Um Zeitbuchungen prüfen zu können, muss die Zeiterfassung eingesetzt werden und die Zeitprüfung aktiviert sein.

-

Außerdem müssen der oder die Prüfer in der Rechteverwaltung passend belegt werden.

EINRICHTUNG

Die Checklisten werden immer aus Bausteinen erstellt, die individuell erfassbar sind. In der Regel wird genau eine Vorlage übernommen, man kann eine Checkliste aber auch aus mehreren Vorlagen erstellen. Jede weitere Vorlage wird am Ende angehangen.

1. Über Anlagen-Checkliste

In der Regel wird eine Checkliste zur Anlage angelegt. Wenn dann eine Wartung per Kundendienstauftrag geplant wird, wird die Checkliste der Anlage zum Auftrag dazu kopiert. Kopiert deshalb, weil so die Checkliste von jeder Wartung auch Jahre später noch eingesehen werden kann. Allerdings automatisch nur dann, wenn ein Wartungstermin gewählt wurde. Ohne Wartungstermin kann auch die Anlagencheckliste gewählt werden, aber nur manuell über den Knopf ‚Kd-Check‘

2. Direkte Einbindung

Eine Checkliste kann direkt zu einem einzelnen Auftrag angelegt werden. Auch hier wird auf Vorlage-Bausteine zugegriffen. Diese Möglichkeit ist unabhängig davon, ob eine Anlage zum Auftrag gehört oder nicht. Die einzige Einschränkung ist, dass man eine freie KD-Checkliste und eine Anlagencheckliste nicht kombinieren kann.

Denkbare Situationen sind alle Aufträge, bei denen viele Dinge zu beachten / abzuhaken sind. So z.B. ein Abnahmeprotokoll, eine komplexe Fehlersuche oder eine Bestandsaufnahme einer Anlage.

|

Hinweis: Die Anlagen-Checkliste ist eine KD-Checkliste, die bei einer Anlage hinterlegt wurde. So eine Anlagen-Checkliste wird automatisch bei einem Kundendienstauftrag mit Wartungstermin gezogen. Die Anlagen-Checkliste wird zur KD-Checkliste des Auftrages kopiert. Wird so eine KD-Auftrag erledigt, werden alle Kreuze und Bemerkungen der KD-Checkliste zurück in die Anlagen-Checkliste überführt, so dass in der Anlagen-Checkliste immer der letzte Stand sichtbar ist.
