3. Rückübertragung zum Büro

Zur Rückübertragung betätigen Sie in der Startmaske den Knopf ‚Zurück ans Büro‘. Die markierte Datei wird gezippt (komprimiert) und es besteht wieder die Möglichkeit sie als Email-Anhang zu transportieren.

Die Extension ‚zipaufmBuero‘ der Datei ist absichtlich so ungewöhnlich, damit man beim Emailempfang per Doppelklick den Import automatisch starten kann.

[Bild]

Beim Transport per USB-Stick oder über ein Netzwerk starten Sie das Modul ‚Import‘ (ggf. über das Modul Projekte und Wahl der Menüpunkte <Extern> <Dokument importieren>) und wählen die Datei aus.

[Bild]

Sie erhalten dann nachstehende Meldung und müssen entscheiden, ob Sie das vorhandene Dokument überschreiben möchten oder nicht.

[Bild]

Beim Transport per Email-Anhang markieren Sie in der Email den Anhang, betätigen die rechte Maustaste und wählen ‚Öffnen mit’ an. Legen Sie dann das Programm Labelwin\import.exe als Standardprogramm fest. Damit wird künftig immer die Datei per Klick auf den Anhang automatisch importiert.
