Erfassen einer Finanzierung

Szenario: Sie haben eine Rechnung vom Autohaus erhalten, die Finanzierung läuft aber über eine Bank.

-

Erfassen Sie die Rechnung gegen das Konto "Fahrzeuge" (z.B. 0320) in voller Höhe gegen das Autohaus.

-

Die Zahlung wird komplett gebucht, weil das Autohaus ja sofort das Geld erhält.

-

Danach erfasst man eine zweite Rechnung gegen die Bank. Im Zahlplan erfasst man einen negativen Betrag über die reinen Kosten des Autos und danach die einzelnen Raten, die an die Bank bezahlt wird
