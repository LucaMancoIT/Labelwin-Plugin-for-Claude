2.3.1 Ladenkasse Grundeinstellungen „Drucker / Formulare“ (A)

[Bild]

[Bild] 1 Ok: Durch Betätigen dieses Knopfes werden die Einstellungen übernommen. Bitte beachten Sie auch die weiteren Karteikartenreiter.

[Bild] 2 Abbruch: Durch Betätigen dieses Knopfes werden die ggf. vorgenommenen Änderungen verworfen und die Maske geschlossen.

Standard-Drucker (arbeitsplatzbezogen)

[Bild]

A1 Kassenbeleg Exemplare: Legen Sie hier die Anzahl der Exemplare fest, die bei der Druckausgabe vorgeschlagen werden sollen.

[Bild]

A2 Formular: Je nach verwendetem Drucker und Papier können Sie verschiedene Formulare verwenden. In dieser Einstellung legen Sie fest, auf welchem Formular der Ausdruck erfolgen soll, wenn der Druckvariante „Ok, Standard-Druck“ gewählt wird.

[Bild]

A3 Drucker: Legen Sie hier fest, auf welchem Drucker die Kassenzettel herauslaufen sollen. Das Kassenmodul kann jeden beliebigen Drucker ansteuern. Es muss lediglich gewährleistet sein, dass das Formular entsprechend dem verwendeten Papier eingerichtet ist. Legen Sie hier fest, auf welchem Drucker standardmäßig der Ausdruck erfolgen soll.

[Bild]

A4 Drucker Folgeexemplar: Legen Sie hier fest, auf welchem Drucker das Folgeexemplar des Kassenzettels gedruckt werden soll.

[Bild]

A5 Druckausgabe auf DOS-Bondrucker: Wenn Sie einen DOS-Bondrucker verwenden möchten, müssen Sie dieses Feld aktivieren. Die Aufteilung des Druckes ist dann fest mit dem Programm verankert Lediglich der Firmenkopf ist frei einstellbar. Mit der Einstellung „Vorschubzeilen vor Schneiden (platzabhängig)“ kann das Bon Ende beeinflusst werden. Zum Thema DOS-Bondrucker lesen Sie bitte das Kapitel Bon-Drucker.

A4 Drucker (arbeitsplatzbezogen)

[Bild]

A7 Formular: In dieser Einstellung legen Sie fest, auf welchem Formular der Ausdruck erfolgen soll, wenn beim Druck die „A4 Druckausgabe“ gewählt wird.

[Bild]

A8 Drucker: Hier legen Sie den Drucker für die „A4 Druckausgabe“ fest.

[Bild]

A9 Drucker Folgeexemplar: Legen Sie hier fest, auf welchem Drucker das Folgeexemplar des A4 Druckes gedruckt werden soll.

[Bild]

A10 Handbuch: Durch Betätigen dieses Knopfes gelangen Sie in das Handbuch Kapitel zur Ladenkasse.
