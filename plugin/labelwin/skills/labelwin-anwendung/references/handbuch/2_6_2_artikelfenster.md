2.6.2 Artikelfenster

[Bild]

Bild Artikelfenster-Einstellungen in der Dokumentenerstellung

In diesem Bereich stellen Sie ein, welche Datenfelder beim Artikelaufruf gezeigt werden sollen. Wenn Sie alle möglichen Eingaben beim Artikelaufruf frei geschaltet haben, so finden Sie eine sehr voll gestopfte Maske vor. Für Datenfelder, die Sie persönlich nicht benötigen, besteht die Möglichkeit, diese auf nicht anwählbar oder unsichtbar zu setzen. Ein Datenfeld auf nicht anwählbar zu setzen hat den Vorteil, dass Sie zwar die Information sehen können, jedoch mit der Enter-Taste direkt darüber hinweg hüpfen. Dadurch ist es möglich, sich die Maske so einzustellen, dass z. B. lediglich die Stückzahl und der Gesamtpreis angesprungen werden.

Diese Funktion ist insbesondere für solche Arbeitsplätze wichtig, bei denen der Endkunde auf den Bildschirm sehen kann. In diesem Falle können Sie über die Fenstereinstellung Einkaufspreise, Zuschlagssätze und dergleichen unsichtbar schalten. Da die Fenstereinstellung sehr viele Kombinationen zulässt, ist es möglich, die Einstellung unter einem Namen abzuspeichern. Wir haben einige Fenstereinstellungen mitgeliefert, die Sie nach eigenem Wunsch verändern und erweitern können.

Die Fenstereinstellungen können in der Artikelaufrufmaske unter dem Menüpunkt <Optionen> umgeschaltet und verändert werden.

[Bild]

1 Einstellung: In dieser Liste wählen Sie, welche Fenstereinstellung Sie verändern möchten. Um neue Fenstereinstellungen zu erzeugen, müssen Sie unter dem Menüpunkt <Datei> <Speichern als> eine vorhandene Einstellung unter einem neuen Namen abspeichern.

[Bild]

2 Sichtbar/Anwählbar: In diesen Feldern kreuzen Sie mit der Maus an, ob ein Eingabefeld nur sichtbar oder auch anwählbar sein soll. Wenn Sie Felder auf nicht anwählbar setzen, so hat dies den Vorteil, dass Sie die Daten mittels der Enter-Taste sehr schnell erfassen können. Wenn Sie in einem Eingabefeld die Enter-Taste betätigen, so läuft das Programm zum nächsten aktiven Eingabefeld. Wenn Sie hier nun einige auf nicht anwählbar setzen so läuft das Programm darüber hinweg und bleibt erst beim nächsten aktiven Eingabefeld stehen.

Wenn Sie Felder auf anwählbar setzen, so bedeutet dies automatisch, dass sie auch sichtbar sind. Wenn Sie Felder auf nicht sichtbar und nicht anwählbar setzen, so erscheinen Sie beim Artikelaufruf überhaupt nicht.

[Bild]

3 Speichern als: Die aktuelle Fenstereinstellung wird unter einem neuen Namen abgespeichert. Die zuvor aufgerufene Fenstereinstellung bleibt dabei unverändert.

[Bild]

4 Speichern: Durch Wahl dieses Menüpunktes wird die gerade aktive Fenstereinstellung abgespeichert. Dabei besteht die Möglichkeit den Namen der Fenstereinstellung zu wechseln.

[Bild]

5 Abbruch: Durch Betätigung dieses Knopfes wird die Maske geschlossen. Eventuelle Änderungen werden nicht abgespeichert. Wenn die Änderungen abgespeichert werden sollen, so müssen Sie im Menü <Datei> <Speichern> oder <Speichern als neu> anwählen.

Datei

Neu

Durch die Wahl dieses Menüpunktes haben Sie die Möglichkeit, eine neue Fenstereinstellung festzulegen. Dabei werden alle Felder aktiviert. Deaktivieren Sie dann die Felder, die Sie nicht sehen oder anwählen möchten und speichern Sie diese Einstellung unter einem neuen Namen ab.

Speichern

Durch Wahl dieses Menüpunktes wird die gerade aktive Fenstereinstellung abgespeichert. Dabei besteht die Möglichkeit den Namen der Fenstereinstellung zu wechseln.

Speichern als neu

Die aktuelle Fenstereinstellung wird unter einem neuen Namen abgespeichert. Die zuvor aufgerufene Fenstereinstellung bleibt dabei unverändert.

Löschen

Die aktuelle Fenstereinstellung wird gelöscht.

Beenden

Genau wie bei der Wahl des Abbruch-Knopfes wird das Programm geschlossen. Sollten Sie die letzten Änderungen nicht abgespeichert haben, so gehen diese verloren.
