Bildschirmausgabe

Sie erreichen diese Maske, wenn Sie im Feld "Ausgabe auf" die Bildschirmausgabe wählen. Einige der unten abgebildeten Funktionen stehen nur bei Installation der Vollversion des Reportgenerators zur Verfügung.

[Bild]

Bild: Bildschirmausgabe

Die Elemente im Einzelnen:

[Bild] 1 Dokumentenanfang: Wenn Sie diesen Knopf betätigen, wird der Anfang des Dokumentes gezeigt.

[Bild] 2 Seite zurück: Wenn Sie diesen Knopf betätigen, wird die vorherige Seite gezeigt.

[Bild] 3 Stop: Bei großen Dokumenten kann durch die Betätigung dieses Knopfes der Druckaufbau gestoppt werden.

[Bild] 4 Seite vor: Wenn Sie diesen Knopf betätigen, wird die nächste Seite gezeigt.

[Bild] 5 Dokumentende: Wenn Sie diesen Knopf betätigen, wird das Ende des Dokumentes gezeigt.

[Bild] 6 Drucken: Wenn Sie diesen Knopf betätigen, wird die Bildschirmausgabe ausgedruckt. Hierbei wird dem Dokument allerdings keine Nummer zugeordnet. Deshalb ist von der Benutzung dieses Knopfes abzuraten.

[Bild] 7 Auslagern in Datei: Wenn Sie diesen Knopf betätigen, können Sie das Dokument in ein anderes Datei-Format (z.B. Word) auslagern.

[Bild] 8 Zoom: Durch Betätigen dieses Knopfes kann die Druckausgabe vergrößert oder verkleinert werden. An dieser Stelle möchten wir noch darauf hinweisen, dass ein Vollbild nicht nur durch den kleinen Knopf oben rechts, sondern auch über einen Doppelklick auf die blaue Fensterleiste erreicht werden kann.
