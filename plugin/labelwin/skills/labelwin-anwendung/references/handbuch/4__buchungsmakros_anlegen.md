4. Buchungsmakros anlegen

Das Programm arbeitet bei einer Kontobuchung grundsätzlich mit Buchungsmakros. In dieser Maske können die Buchungsmakros erfasst und geändert werden. Ein Buchungsmakro kann man sich im Grunde genommen wie eine Musterbuchung vorstellen. Bei der Buchung wird diese Musterbuchung angewählt, ggf. werden Daten aktualisiert und die Buchung wird abgespeichert. Auf diese Art ist es möglich, die Standardfälle im Betrieb sehr schnell erfassen.

Durch Markieren in der Tabelle wird ein Buchungsmakro in die Eingabefelder eingetragen. Dort kann es ggf. geändert und erneut abgespeichert werden.

Bild: Buchungsmakro anlegen

|
[Bild: 1]

Menüleiste

[Bild: 1. Menüleiste]

Neues Buchungsmakro: Genau wie bei der Betätigung des Knopfes ‚Neu’ wird hiermit ein neues Buchungsmakro angelegt.

Speichern: Genau wie bei der Betätigung des Knopfes ‚Speichern’ wird durch diesen Menüpunkt die Eintragung abgespeichert.

Löschen: Unter diesem Menüpunkt wird die in der Tabelle (Nr. 1) markierte Buchungsart gelöscht.

Drucken: Durch Anwahl dieses Menüpunktes kann die Liste der Buchungsmakros ausgedruckt werden. Das Programm greift wie immer auf ein mit dem Crystal Report angelegtes Formular zu.

Beenden: Durch Anwahl dieses Menüpunktes wird die Maske Buchungsmakro geschlossen.

|
[Bild: 2]

Buchungsmakro Tabelle

[Bild: 2. Buchungsmakro Tabelle]

In dieser Tabelle werden die Buchungsmakros lediglich angezeigt. Eine Änderung ist in dieser Tabelle nicht möglich. Geändert werden kann ein Buchungsmakro, indem es mit der linken Maustaste markiert wird. In diesem Falle werden die Daten in die Ausfüllfelder eingetragen und durch Betätigen des Knopfes ‚Speichern’ wird die Änderung zurück geschrieben.

|
[Bild: 3]

Bezeichnung

[Bild: 3. Bezeichnung]

Geben Sie hier den Namen des Buchungsmakros ein, unter der Sie es später beim Buchungsvorgang aufrufen.

|
[Bild: 4]

Buchungstext

[Bild: 4. Buchungstext]

Geben Sie hier den gewünschten Buchungs-text ein, der bei den späteren Kassenbuchungen vorgeschlagen werden soll.

Tipp: Sie können mit einem Dollarzeichen $ eine Haltestelle setzen. Beispiel: ‚Tanken bei $’. In diesem Falle hält das Programm bei dem $-Zeichen an und Sie können den Tankstellennamen bei der Buchung eintragen.

|
[Bild: 5]

Konto

[Bild: 5. Konto]

Wählen Sie in dieser Liste das entsprechende Konto aus. Konten können hier nicht eingegeben werden, sondern müssen im Modul EINSTELLUNGEN unter dem Menüpunkt <Grundeinstellungen> <Kontenplan> erfasst werden.

|
[Bild: 6]

Projekt

[Bild: 6. Projekt]

Wenn ein bestimmtes Buchungsmakro immer nur auf ein bestimmtes Projekt gebucht werden soll, haben Sie hier die Möglichkeit, dieses dem Buchungsmakro zu hinterlegen. Bei einer neuen Buchung in der Kasse wird dann automatisch dieses Projekt vorgeschlagen.

|
[Bild: 7]

Kostenstelle

[Bild: 7. Kostenstelle]

Wenn Sie mit Kostenstellen arbeiten, können Sie hier einem Buchungsmakro eine Kostenstelle vorgeben. Die Kostenstellen werden im Modul EINSTELLUNGEN unter dem Menüpunkt <Grundeinstellungen> <Kostenstellen> erfasst.

|
[Bild: 8]

Neues Makro

[Bild: 8. Neues Makro]

Bei Betätigen dieses Knopfes wird die Maske geleert und Sie können ein neues Buchungsmakro erfassen. Sie wird erst durch Betätigen des Knopfes ‚Speichern’ übernommen.

|
[Bild: 9]

Löschen

[Bild: 9. Löschen]

Hier haben Sie die Möglichkeit ein Buchungsmakros wieder zu löschen.

|
[Bild: 10]

Drucken

[Bild: 10. Drucken]

Hier haben Sie die Möglichkeit, alles erfassten Buchungsmakros auszudrucken.

|
[Bild: 11]

Speichern

[Bild: 11. Speichern]

Die in den Eingabefeldern eingetragenen Werte werden abgespeichert. Falls Sie eine Belegart zur Änderung aufgerufen haben, so wird die bisherige Zeile überschrieben. Wenn Sie eine neue Belegart angewählt haben, so wird diese zusätzlich eingetragen.

|
[Bild: 12]

Ende

[Bild: 12. Ende]

Durch Betätigen dieses Knopfes wird die Maske ‚Buchungsmakro anlegen’ geschlossen.
