Gaeb bepreisen

Mit Änderungslauf bepreisen

Bei dieser Methode werden die Preise und ggf. Minuten per Änderungslauf, einem so genannten Schnellerfassungsmodus, direkt Position für Position eingetragen.

Sie oder ein Sachbearbeiter die Preise vorher manuell ausgerechnet.

Diese Methode geht am schnellsten. Sie ist allerdings für die spätere Weiterbearbeitung, sollten Sie den Zuschlag erhalten haben, sehr ungeeignet, da im Dokument keine echten Artikel und keine Einkaufspreise sind.

Ablauf

Öffnen Sie das Dokument und stellen Sie sich auf die erste zu bepreisende Position. Wählen Sie im Menü <Durchläufe> <Änderungslauf > oder drücken Sie die Taste Strg+N.

Kreuzen Sie im folgenden Fenster nur die Felder an, die Sie ändern möchten (Das linke Kreuz bedeutet, dass Sie das Feld sehen können, das rechte Kreuz bedeutet, dass Sie das Feld ändern können). In den meisten Fällen also ‚Material Einkauf’ oder ‚Material VK’, sowie ‚Minuten’ bzw. ‚Lohnfestpreis’. Sie können diese Auswahl unter einen Namen speichern.

[Bild]

Nach dem Klick auf OK kommt man in die Artikelaufruf Maske. Es sind nur die ausgewählten Felder freigegeben. Mit der Return/Enter-Taste kann man die Daten erfassen und am Ende kommt man automatisch zur nächsten Position.

Mit Artikeln bepreisen

Um ein LV korrekt zu bepreisen, müssen Sie hinter jeder Position mindestens einen Artikel (mit EK-Preis, Aufschlag, VK- Preis, Lohnminuten, etc.) hinterlegen. Dabei ergeben sich allerdings zwei zu lösende Probleme:

Beim Ersetzen einer Position durch einen Artikel darf der Originaltext nicht überschrieben werden. Oft benötigt man mehr als nur einen Artikel, um die Position zu bepreisen

[Bild]

Methode 1: Artikeltexte beim Tausch erhalten (nicht unbedingt empfohlen) Um das erste Problem, das Überschreiben des Artikeltextes zu lösen, gibt es in der Positionserfassung den Menüpunkt <Optionen> <Artikeltexte beim Tausch erhalten>. Nach dem Klick steht vor dem Menüpunkt ein Haken und am unteren Bildschirmrand steht der Text ‚Artikeltexte beim Tausch erhalten’.

[Bild]

Wenn Sie jetzt einen Artikel aufrufen, werden bis auf den Text alle Informationen aus dem Katalog übernommen.

[Bild]

Damit Sie nicht versehentlich LV-Texte überschreiben, können Sie schon der Kalkulationseinstellung ein Kreuz setzen, was dieses verhindert. Speichern Sie diese Option am besten in Ihrer Kalkulations-einstellung für ‚Fremd-LVs’.

Problem: Bei dieser Art der LV Bepreisung können Sie immer nur einen Artikel aufrufen, und die Über-sichtlichkeit und Nachprüfbarkeit fehlt. Denn Sie wissen nicht, ob Sie tatsächlich den richtigen Artikel und damit den richtigen Preis hinterlegt haben, da Sie es nur an der Artikelnummer erkennen können.

[Bild]

Methode 2: In verborgenen Set wandeln (die empfohlene Methode) Um beide oben genannten Probleme zu lösen, sollten Sie die Original LV Positionen in verborgene Sets wandeln. Alle notwendigen Artikel können Sie dann samt Originaltext aus dem Katalog als verborgene Setbestandteile einfügen. Der Preis des Setkopfes (also der Original LV Position) ist immer die Summe der Bestandteile. Ausnahme. Sie deklarieren dem Set als ‚vorkalkuliert’, dann können Sie den VK Preis selbst festlegen, er wird dann nicht aus den Bestandteilen des Sets errechnet. Für die Nachkalkulation gelten weiterhin die EK Preise der einzelnen Bestandteile.

LV Bepreisung mit STRG-I: Um eine Position schnell und einfach in einen verborgenen Set zu wandeln, gibt es den Menüpunkt <Bearbeiten> <Leistungspos. in Set wandeln>, den Sie auch mit der Tastenkombination STRG-I aufrufen können. Damit wird die markierte Position in einen verborgenen Set gewandelt und der Artikelaufruf öffnet sich. Sie können jetzt der Reihe nach die Artikel aufrufen. Die Artikelaufrufmaske bleibt aktiv. Wenn Sie die Artikelaufrufmaske schließen, wird der Set beendet und die nächste LV Position ist markiert.

Sie können auch mehrere Artikel über die Blockbearbeitung in verborgene Sets wandeln. Allerdings müssen Sie sich dann immer wieder neu positionieren, was viel aufwändiger ist.
