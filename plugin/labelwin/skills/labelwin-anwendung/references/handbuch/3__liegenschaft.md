3. Liegenschaft

Neben den Verknüpfungen zur Rechnungsanschrift, der Eigentümeradresse usw. kann auch eine Verknüpfung zu einer Liegenschaft hergestellt werden. Dabei geht es darum, die Wohnungsadressen von einem Häuserblock zu verbinden. Wenn bei einem 4-Familienhaus eine gemeinsame Heizungsanlage existiert, ist es sinnvoll, das Haus als eigene Adresse anzulegen und die Objekt-/Mieteradressen darauf verweisen zu lassen. Wenn nun ein Mieter meldet, dass es bei ihm kalt ist, so kann man über den Verweis auf die Liegenschaft die gemeinsame Heizungsanlage finden.

[Bild]

Bevor einer Objektadresse die Liegenschaft zugewiesen werden kann, muss diese angelegt werden. Dabei muss auf der ersten Karteikarte das Feld ‚Adresse ist Liegenschaft’ aktiviert werden.

Nun kann bei den entsprechenden Objekt-/Mieteradressen auf der Karteikarte ‚Zugeordnete Adressen’ der Verweis auf die Liegenschaft eingetragen werden.

[Bild]

Der Rechnungsempfänger für eine Liegenschaft kann z.B. eine Gemeinnützige Genossenschaft sein, die wiederum mehrere Liegenschaften verwaltet.

[Bild]

Unter dem Menüpunkt <Suchen> <Liegenschaft dieser Rg.-Adresse> werden Ihnen die Liegenschaften zu der ausgewählten Rechnungsadresse angezeigt.

[Bild]

Unter dem Menüpunkt <Suchen> <Objekte dieser Liegenschaft> werden Ihnen die Mieteradressen der Liegenschaft angezeigt.

[Bild]

Wenn nun ein Mieter einer Liegenschaft anruft, weil die Heizung ausgefallen ist, so wird beim Aufruf der Objektadresse (Mieteradresse), die Anschrift der Liegenschaft automatisch unter der Rechnungsadresse angezeigt.

[Bild]

Über das Logbuch können neben den Aufträgen der Objektadresse auch alle Aufträge der Liegenschaft angezeigt werden. Also nicht nur die Aufträge der Liegenschaft selbst, sondern gleichzeitig alle Aufträge der Objektadressen, die zur gleichen Liegenschaft gehören.

[Bild]
