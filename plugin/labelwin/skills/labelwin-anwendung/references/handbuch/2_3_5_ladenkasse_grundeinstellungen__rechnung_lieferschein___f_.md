2.3.5 Ladenkasse Grundeinstellungen „Rechnung/Lieferschein“ (F)

Bei der Druckausgabe aus der Ladenkasse kann auch eine Rechnung oder ein Lieferschein gedruckt werden. Dazu müssen in den Grundeinstellungen der Ladenkasse die Formulare, der Drucker und ähnliche Dinge eingestellt werden.

Hintergrund: Wenn sich herausstellt, dass ein Kunde nicht genug Geld dabei hat und man ihm die Ware trotzdem mitgeben will, kann man eine Rechnung oder einen Lieferschein drucken.

|

Tipp: Wenn Sie dem Kunden das vorhandene Geld abnehmen wollen, erfassen Sie sofort danach eine neue Ladenkassen-Abrechnung, in der Sie auf diese Rechnung die Funktion ‚Kunde zahlt Rechnung‘ (F3) anwählen und die vorhandene Summe als Zahlungseingang buchen.

[Bild]

[Bild] F1 Überweisungsträger ausgeben: Aktivieren Sie dieses Feld, wenn Sie zur Rechnung auch einen Überweisungsträger mit ausgeben möchten. Die Druckereinstellungen hierfür werden im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Druckausgabe> <Grundeinstellungen> festgelegt.

[Bild] F2 Exemplare: Legen Sie hier die Anzahl der Exemplare fest, die bei der Druckausgabe vorgeschlagen werden sollen.

[Bild] F3 Formular: Legen Sie hier fest, mit welchem Formular eine Rechnung standardmäßig gedruckt werden soll.

[Bild] F4 Drucker: Legen Sie hier fest, auf welchem Drucker die Rechnung ausgegeben werden soll.

[Bild] F5 Drucker Folgeformular: Legen Sie hier fest, auf welchem Drucker das Folgeexemplar der Rechnung gedruckt werden soll.

[Bild] F6 Lieferschein Exemplare: Geben Sie hier die Anzahl der Exemplare ein, die beim Drucken von Lieferscheinen vorgeschlagen werden.

[Bild] F7 Formular Lieferschein: Wenn Sie bei der Druckausgabe statt des Kassenbelegs einen Lieferschein anwählen, so wird das hier eingetragene Formular vorgeschlagen.

[Bild] F8 Drucker Lieferschein: Legen Sie hier fest, auf welchem Drucker ein Lieferschein ausgegeben werden soll.

[Bild] F9 Drucker Lieferschein Folge-exemplar: Legen Sie hier fest, auf welchem Drucker das Folgeexemplar des Lieferscheins gedruckt werden soll.
