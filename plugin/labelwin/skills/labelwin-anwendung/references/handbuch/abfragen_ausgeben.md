Abfragen ausgeben

Die ganzen oben beschriebenen Eingaben dazu dienen, die Anwendung besonders einfach zu machen, Sie brauchen hier nur die entsprechende Anzeigegruppe zu wählen und den Knopf ‚Anzeigegruppe’ betätigen. Sie können auch eine einzelne Abfrage ausgeben, wenn Sie nach der Markierung der Abfrage in der Tabelle den Knopf ‚Abfrage’ betätigen. Falls Sie in einer der Abfragen Variable verwendet haben, müssen Sie diese zunächst mit Inhalt füllen. Tragen Sie den gewünschten Wert direkt in die Tabelle ein.

Bei der Druckausgabe von mehreren Abfragen kann es passieren, dass sowohl Formulare für Hoch- als auch Querformat ausgegeben werden sollen. Wählen Sie bitte ein Mal den Menüpunkt ‚Drucken’ an und hinterlegen den Querdrucker. Das Programm merkt sich diesen Eintrag dauerhaft für den gerade benutzten Pc.

Die Kennzeichnung, ob es sich um ein Querformular handelt, hinterlegen Sie in der Abfrage selbst. Bei ‚Ausgabe als Report’ befindet sich rechts neben dem Reportnamen dafür ein Ankreuzfeld.

[Bild]

1 Anzeigegruppe: Hier können Sie eine Eingrenzung auf eine bestimmte Anzeigegruppe vornehmen. Nur die Abfragen einer Anzeigegruppe lassen sich auf einen Rutsch ausgeben. Die Anzeigegruppen organisieren Sie von der obersten Programmebene aus über die Menüpunkt ‚Controlling, Anzeigegruppen bearbeiten’ und ‚Anzeige organisieren’

|

Wenn Sie die Auswahl auf ‚Alle’ stellen, werden alle vorhandenen Abfragen gelistet, auch solche, die keiner Anzeigegruppe zugeordnet sind.

2 Abfragen-Tabelle: Angezeigt werden alle Abfragen der oben eingestellten Anzeigegruppe. Wenn Sie eine einzelne Abfrage markieren, können Sie diese mit dem Ausführen-Knopf (Nr.12) ausgeben. Der Knopf ‚Alle Abfragen ausführen’ greift unabhängig von der Markierung auf alle angezeigten Abfragen.

3 Bemerkung: Wenn Sie einer Abfrage eine Bemerkung hinterlegt haben, so wird sie hier angezeigt. Es gilt die in der Tabelle gerade markierte Abfrage.

4 Zeitraum von bis: Setzen Sie hier den Zeitraum, auf den Ihre Abfragen greifen sollen. Ob das Datum tatsächlich genutzt wird, oder ob es auf die Ausgabe keinen Einfluss hat, hängt von der Abfrage selber ab. Das Datum wird über bestimmte Schlüsselworte an die Abfrage übergeben.

5 Jahr: Wenn Ihre Abfragen auf ein ganzer Jahr greifen soll, so können Sie dies hier festlegen. Ob das Datum tatsächlich genutzt wird, oder ob es auf die Ausgabe keinen Einfluss hat, hängt von der Abfrage selber ab. Das Datum wird über bestimmte Schlüsselworte an die Abfrage übergeben.

6 +7 Datumsknöpfe: Mit diesen Knöpfen können Sie sehr schnell die Von-Bis-Felder füllen. Die Wirkung ist die gleiche, als wenn Sie das Datum manuell eingeben.

8 Parameter der ganzen Gruppe: Wenn in Abfragen Eingabeparameter definiert sind, so müssen sie bei der Ausgabe mit Inhalt gefüllt bzw. die Vorgabe ggf. geändert werden. Um eine komplette Anzeigegruppe ausgeben zu können, müssen alle Eingaben der Abfragen gefüllt werden. Mit diesem Ankreuzfeld werden alle Parameter gezeigt und können belegt werden.

9 Parametertabelle: Wenn Sie einen Wert eingeben möchten, klicken Sie in die Spalte ‚Wert’ und geben ihn direkt ein.

10 Drucker: Bei einer einzelnen Abfrage ‚merkt’ sich das Programm den Drucker . Falls Sie eine Abfrage zum falschen Drucker geschickt haben, können Sie hier vor dem nächsten Versuch den Drucker umsetzen. Bei der normalen Nutzung wird der Knopf sonst nicht gebraucht, da die Druckerabfrage automatisch erfolgt. Zur Druckausgabe in Querformat beachten Sie bitte den Menüpunkt ‚Drucken’.

11 Anzeigegruppe-Knopf: Mit diesem Knopf werden alle gerade angezeigten Abfragen auf einen Rutsch ausgegeben. Um sicher alle Eingaben geprüft zu haben, sollten Sie das Ankreuzfeld ‚Parameter der ganzen Gruppe’ zuvor setzen und die eventuell vorhandenen Eingabefelder füllen.

12 Abfragen-Knopf: Angezeigt Mit diesem Knopf wird die in der oberen Tabelle markierte Abrage ausgegeben.

13 Ende-Knopf: Die Anzeigenmaske wird geschlossen.
