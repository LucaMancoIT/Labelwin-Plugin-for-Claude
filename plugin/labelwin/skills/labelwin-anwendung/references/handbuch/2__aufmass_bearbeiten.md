2. Aufmaß bearbeiten

Im Startbild werden alle im Verzeichnis vorhandenen Aufmass-Dateien in einer Tabelle gezeigt. Durch einen Doppelklick oder der Betätigung des Knopfes ‚Okay‘ wird das Aufmaß in Bearbeitung genommen. Bei der Bearbeitung erfolgt eine ständige Speicherung, so dass auch bei einem Problem alle erfassten Daten gesichert sind.
