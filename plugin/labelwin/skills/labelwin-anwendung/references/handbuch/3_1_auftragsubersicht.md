3.1 Auftragsübersicht

[Bild]

Bei Start des mobilen Kundendienstes aus dem Labelwin V5 Programmbaum heraus erscheint die oben abgebildete Maske. Hier sieht der Techniker alle vorhandenen Aufträge. Da es in der Regel eine überschaubare Anzahl ist, werden keine Eingrenzungen benötigt. Mit dem Button „Eingrenzung sichtbar" kann gesteuert werden, ob die Eingrenzungen ausgeblendet werden. Mit dem Button "Kurzinfo" kann man festlegen, ob im unteren Bereich der Auftragsmaske eine Kurzinfo des markierten Auftrages angezeigt werden soll.

[Bild]

Mit einer TAB-Datei kann festgelegt werden, welche Informationen in der Tabelle angezeigt werden sollen. In unserem Beispiel ist die Tabelle so gestaltet, dass der Techniker alle wichtigen Auftragsinformationen bereits in dieser Maske sehen kann.

Gegenüber der „normalen“ Auftragsmaske im Büro fehlen diverse Menüpunkte, die für die mobile Auftragsbearbeitung nicht erforderlich sind. So fehlt z.B. der Bereich „Auswerten“ komplett.
