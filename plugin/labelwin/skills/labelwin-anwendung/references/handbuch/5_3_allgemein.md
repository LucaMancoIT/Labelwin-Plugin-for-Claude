5.3 Allgemein

In dieser Maske legen Sie einige allgemeine Grundeinstellungen fest.

Allgemeine Einstellungen

[Bild]

Bild: Allgemeine Einstellungen – Allgemein

Tempverzeichnis ohne Frage löschen: Beim ersten Start des Programms erfolgt eine Frage, ob die Temp-Dateien im Windowsbereich gelöscht werden sollen. Diese Frage erfolgt, weil es uns eigentlich nicht zusteht, dies zu tun. Nachdem wir jedoch festgestellt haben, dass Windows mit solchen ‚Leichen’ wesentlich instabiler läuft, bieten wir diese Löschfunktion an. Durch ein Kreuz erreichen Sie, dass die Dateien ohne Nachfrage gelöscht werden.

Kalkulation mit Vollkosten: Wenn Sie dieses Feld aktivieren, müssen Sie sich über die Auswirkungen im Klaren sein. Dazu gibt es im LabelWiki einen ausführlichen Text.

Materiallistennummer verwenden: Wenn Sie dieses Feld aktivieren, können Bestellungen nur aufgrund von Bedarfsanforderungen erstellt werden. Jede Bedarfsanforderung innerhalb eines Projektes erhält dann eine Materiallistennummer. Bei der Erstellung von Bestellungen können nur auf diese Materiallisten zugegriffen werden. Diese Funktion ist für einen normalen Handwerksbetrieb unsinnig und gibt nur bei Betrieben mit Einkaufsabteilungen einen Sinn.

Outlookabgleich (benötigt Outlook): Mit dieser Option können im Kundendienst und im Kalender geplanten Termine entweder vollautomatisch an Outlook zu übergeben oder bei Bedarf durch einen manuellen Start alle bis dahin durchgeführten Terminänderungen übertragen. Voraussetzung hierfür ist eine installierte Outlookversion auf den entsprechenden Rechnern.

Wenn Sie einen Exchangeserver einsetzen, kann der Abgleich automatisch bei jeder Änderung im Kundendienstmodul erfolgen.

Der Abgleich ist eine Einbahnstraße, es werden nur die Termine von Labelwin an Outlook übergeben. Bei einer Verschiebung im Outlook bleibt der Termin im Label unverändert. Wenn der Auftrag in Label neu gespeichert wird, wird eine ggf. stattgefundene Verschiebung wieder vernichtet.

Eine Verschiebung im Labelwin bewirkt auch eine Verschiebung im Outloo.

Programmbaum: Über diesen Knopf können Sie den Programmbaum für das Startcenter bearbeiten. Eine nähere Beschreibung hierzu finden Sie hier.

Abbruch: Bei Betätigen des Abbruch-Knopfes wird die Maske geschlossen.

Ok: Bei Betätigen des OK-Knopfes werden die Änderungen übernommen und die Maske wird geschlossen.

Auswertungen

[Bild]

Bild: Allgemeine Einstellungen – Auswertungen

Änderungsprotokolle führen: Um Änderungen zu protokollieren, können Sie hier festlegen, welche Protokolle geführt werden sollen. Protokolliert wird vorher, nachher, wann und wer. In den jeweiligen Modulen gibt es einen Menüpunkt, unter dem die Protokolle angesehen werden können.

Liquidität: Es handelt sich um ein kostenpflichtiges Zusatzmodul, mit dem aus einer Planung, dem letzten Kontostand, den geschriebenen Rechnungen und den erfassten Eingangsrechnungen eine Liquiditätsvorschau für die nächsten Wochen erstellt werden kann.

Gestartet wird die Auswertung im Modul Selektieren unter den Menüpunkt <Controlling>

Bei beiden nachfolgend beschriebenen Varianten werden die Grundkosten wie Miete, Telefon usw.im gleichen Modul unter dem Punkt ‚Gemeinkosten‘ (Liquidität) erfasst.

Liquidität ohne Plandaten nutzen

In diesem Fall werden nur die Grunddaten, Ausgangsrechnungen und Eingangsrechnungen ausgewertet. Die Auswertung gibt also nur für die unmittelbar nächsten Wochen sinnvolle Werte. Per Vorgabe werden die Daten der nächsten 8 Wochen vorgeschlagen.

Kostenplan nutzen

Das bedeutet, dass Sie die geplanten Rechnungen, Bestellungen und erwarteten Eingangsrechnungen im Planungsmodul erfassen.

Schriftarten

[Bild]

Bildschirmschriftart für Artikeltexte: Um die Darstellung von Artikel-Texten, ähnlich der späteren Druckausgabe zu gestalten, muss das Programm die Schriftart des Druckformulars kennen. Unsere Standardformulare werden mit der Schriftart „Times New Roman“ ausgegeben. Sollten Ihre Formulare auf eine andere Schriftart eingestellt sein, so müssen Sie hier diese einrichten. Das betrifft jedoch nur die Darstellung der Artikeltexte auf dem Bildschirm. Durch Betätigen des Knopfes ‚Ändern’ können Sie die Schriftart ändern.

Bildschirmschriftart für Vor- und Nachbemerkungen: Um die Darstellung von Vor- und Nachbemerkungen ähnlich der späteren Druckausgabe zu gestalten, muss das Programm die Schriftart des Druckformulars kennen. Unsere Standardformulare werden mit der Schriftart „Times New Roman“ ausgegeben. Sollten Ihre Formulare auf eine andere Schriftart eingestellt sein, so müssen Sie hier diese einrichten. Das betrifft jedoch nur die Darstellung der Vor- und Nachbemerkungen auf dem Bildschirm. Durch Betätigen des Knopfes ‚Ändern’ können Sie die Schriftart ändern.

Benutzereinstellung

[Bild]

Adressanmerkung: In vielen Teilen im Programm können Sie eine Anmerkung hinterlegen. Legen Sie hier, ob diese Anmerkungen mit Datum und Uhrzeit sowie mit einem Namenskürzel versehen werden sollen. Der komplette Name wird an einigen Stellen im Programm verwendet, um nicht den Windows-Anmeldenamen zu zeigen. Dieses ist z.B. in der Ladenkasse, in Emails aus der Aufgabenverwaltung, beim Angebotsdruck der Bearbeiter usw. der Fall.

Keine Prüfung der Festplattengröße: In seltenen Fällen kommt es vor, dass die im Programm eingebauten Prüfungen auf freie Plattenspeicher versagen und unser Programm angeblich nicht genug Speicher vorfindet. Durch diesen Schalter wird die Prüfung ausgeschaltet. Er sollte nur in Absprache mit Ihrem Softwarebetreuer gesetzt werden.

Bei aktuellen Wiki-News KEINE Meldung bringen: Wenn es aktuelle News im LabelWiki gibt, erhalten Sie standardmäßig eine Meldung beim ersten Start des Programms. Wenn Sie diese Meldung nicht haben möchten, können Sie sie hier deaktivieren.

Einstellungen bei der Verwendung von Proxy Servern

Wenn in Ihrem Netzwerk der Zugang ins Internet nur über einen Proxy Server möglich ist, dann können Sie hierüber versuchen über die Eingabe von Proxyservern einen Internetzugang trotzdem zu realisieren. Die Betonung liegt auf ‚versuchen‘, weil Labelwin nicht in der Lage ist, alle Proxyserver Varianten zu unterstützen.

HTTP Zugang (z.B. Webshop Schnittstelle, Internet Update, Labelwiki, SMS, GoogleMap, etc.)

· Erfassen Sie hier den HTTP Proxy und den entsprechenden Port, z.B. als "192.168.20.123" mit Port "3128"

· Prüfen Sie ggf. noch, ob die Portnummer auch in der Windows Firewall freigegeben ist

· Ggf. können Sie noch die Proxy-eigenen Zugangsdaten hinterlegen. Diese können aus sicherheitstechnischen Gründen aber nicht unbedingt durchgereicht werden. Ggf. müssen Sie immer kurz vorher einen Internet Broswer öffnen und sich manuell einloggen. Manchmal genügt es aber auch, den HTTP Proxy Server in den Internet Explorer Einstellungen zu hinterlegen

FTP Zugang (z.B. UGL FTP)

· Bei Problemen mit dem FTP Zugang genügt es oft schon, den Haken bei "FTP Transfer passiv" zu setzen.

· Sollte das nicht klappen, dann erfassen Sie den FTP Proxy und den entsprechenden Port, z.B. als "192.168.20.123" mit Port "2121"

· Prüfen Sie ggf. noch, ob die Portnummer auch in der Windows Firewall freigegeben ist

Labelwiki Zugang

Wenn der Labelwiki Zugang durch einen Proxyserver gesperrt ist, versuchen Sie es mit dem Haken bei "Labelwiki direkt". Dann werden Sie über ein Zwischenfenster in das Labelwiki geleitet. Die Erfassung des HTTP Proxyservers muss gfgf. zusätzlich erfolgen.

Firewall

Häufig steckt hinter den Internet Zugangsproblemen aus Labelwin heraus gar nicht der Proxyserver, sondern die Firewall. Bitte sorgen Sie dafür, dass die Firewall für folgende Ports geöffnet wird (Bei Fragen konsultieren Sie bitte Ihren Systembetreuer)

· Port 21 für FTP

· Port 80 für HTTP

· Port 433 für HTTPS

Webbrowser für die Benutzung des IDS: Der IDS Shop startet normalerweise mit dem Webbrowser Programm, welches bei Windows für .HTM Dateien als Standard eingetragen ist.

Wenn Sie für IDS einen anderen Browser benutzen wollen, aber den Standard Browser Ihres Rechners nicht ändern wollen, dann können Sie hier den Pfad und Dateinamen zum alternativen Browser angeben.

z.B. C:\Programme\Mozilla Firefox\firefox.exe oder C:\Programme\Internet Explorer\iexplore.exe

Maschinen-Einstellungen

[Bild]

Handbuch: Da wir die Handbuchtexte als PDF-Dateien ablegen, gibt es je nach Betriebssystem manches Mal Anzeigeprobleme. Aktuelle wird es mit der gezeigten Einstellung sicherlich immer klappen.

Anzahl Monitore: Seitdem die Bildschirme so preiswert geworden sind, schließen immer mehr Kunden 2 oder 3 Monitore an. Wenn Sie eintragen, mit wie vielen Monitoren Sie arbeiten, merkt sich Labelwin die Einstellungen. Legen Sie auch fest, welches Ihr Hauptmonitor ist. Als Standard gilt links.

Sonstiges - DDE Timeout: Der Austausch von einigen Informationen innerhalb des Programms erfolgt über eine sogenannte DDE-Verbindung. Wenn in einem System die Antwortzeiten besonders lang sind, können wir hier eine Einstellung vornehmen. Geben Sie bitte nichts ein.
