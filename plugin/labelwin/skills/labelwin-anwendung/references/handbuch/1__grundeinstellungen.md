1. Grundeinstellungen

Vor der allerersten Anwendung sollten die Preiseinstellungen vorgenommen werden. Wählen Sie dazu den Menüpunkt <Optionen> <Einstellungen> an.

Es erscheint folgende Maske:

[Bild]

Bild: Preisinfo Grundeinstellungen

[Bild] 1 Zusätzliche Anzeige: Hier können Sie festlegen, ob Sie eine zusätzliche Anzeige des Suchworts oder der alternativen Artikelnummer in der Artikelliste haben möchten oder nicht.

[Bild] 2 Artikelanmerkung als Hinweisbox anzeigen: Wenn Sie dieses Feld aktivieren, wird Ihnen eine ggf. beim Artikel hinterlegte Anmerkung als Hinweisbox angezeigt.

[Bild] 3 Zeilenhöhe: Legen Sie hier fest, wie viele Zeilen in der Artikelliste angezeigt werden sollen. Die Zeilenhöhe kann max. 10 Zeilen sein.

[Bild] 4 Preisfeld: Legen Sie hier fest, welches Preisfeld Sie anzeigen möchten. Statt eines Preises können Sie auch eine Kalkulationseinstellung festlegen (Beispiel Preis 3 und 4).

[Bild] 5 Multiplikator: Wenn Sie einen Preis zur Anzeige gewählt haben, so können Sie hier einen Multiplikator festlegen.

[Bild] 6 inkl. MwSt.: Bei einem Kreuz in diesem Feld wird der MwSt- Satz in den Anzeigepreis mit eingerechnet.

[Bild] 7 Überschrift: Legen Sie hier fest, welche Beschriftung der angezeigt Preis an der Oberfläche haben soll.

[Bild] 8 Kalk. Einstellung: Wenn Sie im Feld 1 das Arbeiten mit einer Kalkulationseinstellung aktiviert haben, so müssen Sie hier festlegen, mit welcher Einstellung Sie arbeiten möchten.

[Bild] 9 Kupfer: Falls Sie einen Katalog mit Kupfer-Tagespreisen verwenden, so müssen Sie hier den aktuellen Kupferpreis und den gewünschten Zuschlag auf den Kupferanteil bei der Verwendung von Listenpreisen festlegen.

[Bild]

10 Ok: Mit diesem Knopf wird die getroffene Einstellung abgespeichert. Bitte beachten Sie, dass die Einstellungen benutzerspezifisch sind, im Netzwerk also für jeden Benutzer vorzunehmen ist.

[Bild]

11 Abbruch: Mit diesem Knopf brechen Sie die Einstellung ab.
