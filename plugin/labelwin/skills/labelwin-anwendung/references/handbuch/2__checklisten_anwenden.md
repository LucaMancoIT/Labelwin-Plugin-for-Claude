2. Checklisten anwenden

Wie schon im Bereich der Vorlagenerstellung sichtbar, können Checklisten an 3 Stellen im Labelwin eingesetzt werden.

1) Im Projektbereich: Eine Checkliste an 2 Stellen angelegt und bearbeitet werden. Im Datenblatt gibt es dazu den Knopf ‚Checklisten und in der Dokumentenansicht gibt es die Menüpunkte <Projekt>, <Checklisten (Strg-F9)>

2) Kundendienst: In der Maske der Auftragserfassung gibt es rechts den Knopf ‚Checkliste’.

3) Zu einer Aufgabe: In der Maske der Aufgabenerfassung gibt es unten de Knopf ‚Checkliste’

Egal über welchen Weg Sie in die Maske der Checkliste gelangen, finden Sie anschließend immer die gleiche Funktionalität vor. Die einzige Ausnahme ist, dass Sie einer Tätigkeit keine Aufgabe zuordnen können, wenn Sie über die Aufgabenverwaltung gekommen sind.

Wenn Sie den Checklistenbereich anwählen und bisher keine Checkliste hinterlegt ist, kommt automatisch das Angebot, eine Vorlage zu wählen. Welche Vorlagen angeboten werden hängt von der Einrichtung ab. Dort legen Sie fest, ob eine Vorlage in einem bestimmten Bereich oder überall angeboten wird.

[Bild]

- wenn Sie die Vorlagenauswahl mit Abbruch verlassen, können Sie alle Tätigkeiten frei erfassen.

- wenn Sie eine Vorlage verwenden, können Sie dennoch individuelle Anpassungen vornehmen oder eine weitere Vorlage anhängen.

Das Wichtigste:

· Die Anpassung / Änderung einer Checkliste geht sinngemäß so wie im Modul Einstellungen die Erstellung der Vorlagen. Sobald Sie den Haken bei ‚Editiermodus’ setzen, sind alle Felder veränderbar. Wenn Sie nach der Wahl einer Vorlage den Soll-Mitarbeiter festlegen wollen, müssen Sie dazu den Editiermodus aktivieren.

· Um einem Mitarbeiter viele Tätigkeiten auf einen Rutsch zuzuordnen, können Sie die Mehrfachmarkierung nutzen und dann den Menüpunkt <Bearbeiten>, <Soll-Person zuordnen> anwählen. In der dann erscheinenden Maske wählen Sie den Mitarbeiter. Bei der Mehrfachzuordnung stört es übrigens nicht, wenn auch Überschriftzeilen mit markiert sind. Wenn also einer sich um alles kümmern soll, markieren Sie die ganze Liste und wählen dann den Menüpunkt an.

Wenn Sie mit Qualifikationen gearbeitet haben, erfolgt die Zuordnung der Personen ebenfalls über das Menü. Die ausführliche Beschreibung erfolgt weiter hinten.

· In der Rechteverwaltung kann das Recht zur Änderung der Checklisten je Benutzer eingeschränkt werden.
