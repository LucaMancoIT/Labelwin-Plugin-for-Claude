7.7 Einrichtung Notdienstlösung Server

Bevor Sie die hier beschriebenen Einrichtungsarbeiten vornehmen, sollten Sie bitte das Kapitel Notdienstabwicklung, neue Aufträge mobil anlegen lesen. Dort werden alle Varianten der Notdienstabwicklung dargestellt. Gegebenenfalls erübrigt sich dann die hier beschriebene Installation.

Um Aufträge automatisch aufgrund einer eingehenden E-Mail einzulesen, muss auf einem immer eingeschalteten Rechner (also meist einem Server) das Programm kdmail.exe eingerichtet und immer aktiv sein. Damit es läuft, muss für den Rechner einmalig eine Labelwin Arbeitsplatz-Installation gelaufen sein.

[Bild]

Ein Klick auf „Start“ bewirkt eine einmalige direkte Abfrage des hinterlegten E-Mail Kontos.

Man muss also „Start Zeitsteuerung“ anklicken, damit ein regelmäßiger Abruf im angegebenen Zeitabstand erfolgt

Die Einstellungen zum Abruf der Notdienst E-Mails finden Sie im Bereich Einstellungen - Mobil - KD-Notdienst.
