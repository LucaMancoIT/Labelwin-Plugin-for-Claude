2.1.3 Kriteriengruppen

Neben den zehn Marketingschlüsseln können Sie einer Adresse beliebig viele weitere Merkmale mitgeben. Allerdings handelt es sich hierbei nicht um Eingabefelder, sondern die Merkmale werden aus einer Liste heraus gewählt. Die Liste der Adresskriterien ist unbegrenzt, so dass wir eine Gruppierung eingeführt haben. So kann z.B. unter einer Gruppierung ‚Privat’ eine Information wie Hundebesitzer, Golfspieler und unter der Gruppierung ‚Interesse an’ Solaranlagen, Blockheizkraftwerk usw. eingetragen sein.

Unter diesem Menüpunkt werden die Kritieriengruppen erfasst. Einer Gruppe können beliebig viele Kritierien zugewiesen werden.
