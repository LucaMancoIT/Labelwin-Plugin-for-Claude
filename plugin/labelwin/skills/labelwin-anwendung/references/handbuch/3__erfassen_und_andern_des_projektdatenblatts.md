3. Erfassen und Ändern des Projektdatenblatts

Sie erreichen diese Maske im Modul PROJEKTE bei der Neuanlage eines Projektes oder über den Menüpunkt <Projekt> <Projekt Datenblatt>.

In der Einleitung sprachen wir davon, dass man sich ein Projekt am Besten als Aktenordner vorstellen soll. Analog dazu handelt es sich bei dem im Folgenden beschriebenen Datenblatt um die Beschriftung des Ordnerrückens. Wie bei einem richtigen Ordner bleibt es Ihnen überlassen, ob Sie eine ausführliche Beschriftung oder lediglich die Baustellenbeschreibung eingeben. Die einzig verbindliche Eingabe ist die Vergabe einer Projektnummer und eines Projektnamens. Diese erfolgt in der Regel jedoch automatisch. In Ihrem eigenen Interesse sollten Sie unbedingt bei der Projektbezeichnung einen Arbeitsnamen eingeben. Über diesen Arbeitsnamen ist das Projekt innerhalb des Betriebes einfacher zu identifizieren. Auf den Ausdrucken wird in der Regel lediglich die Projektnummer ausgegeben.

[Bild: 6. Rechnungsplan]

Mit dieser Funktion können Sie geplante Rechnungstermine hinterlegen. Die Rechnungen werden nicht automatisiert erzeugt, sondern der Rechnungsplan liefert nur eine Liste mit den zu schreibenden Rechnungen. Lesen Sie hierzu das Kapitel Rechnungsplan

Zahlungsvereinbarung

[Bild: 7. Zahlungsvereinbarung]

Wenn Sie mit Ihren Großhändlern nur für ein Projekt besondere Zahlungsbedingungen vereinbart haben, können Sie diese hier hinterlegen. Beim Erfassen einer Eingangsrechnung wird diese dann vorgeschlagen, statt einer der in der Adresse hinterlegten Zahlungsbedingung (Eine Beschreibung dazu finden Sie im Handbuch unter Erfassen einer Eingangsrechnung).

Betätigen Sie den Knopf ‚Neu‘ und geben Sie im Adressfeld das Suchwort des Lieferanten ein. Hinterlegen Sie dann die entsprechend vereinbarte Zahlungsbedingung und speichern Sie den Eintrag. Dieser erscheint dann in der Liste. Sie können beliebig viele Großhändler eintragen.

Projektaufträge

[Bild: 9. Projektaufträge]

Wenn im Kundendienst ein Auftrag zu dem aktiven Projekt in der Auftragsmaske das Kreuz erhalten hat ‚Abrechnung über Projekt‘, haben Sie über diesen Knopf die Möglichkeit, den Status auf ‚Projektabrechnung’ umzusetzen.

[Bild: 10]

Nachweise

[Bild: 10. Nachweise]

Hier können gewisse Bescheinigungen für Sub-Unternehmer hinterlegt werden wie z.B. Schweißzeugnisse, Personallisten usw. Ein konkretes Beispiel ist die Freistellungsbescheinigung des Finanzamtes. Wenn diese von einem Subunternehmer nicht vorliegt, müssen Sie 15% der Lohnrechnung an das Finanzamt direkt überweisen. Wenn Sie hier einen Fehler machen, kann das viel Geld kosten.

Nachweise sind immer mit einer Adresse verbunden und können zusätzlich auf ein Projekt greifen. Nachweise werden mit einem Gültigkeitsdatum versehen. Wenn überfällige Nachweise anstehen, wird der Knopf ‚Nachweise‘ rot.

Die Nachweise werden im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Projektverwaltung> <Nachweise, Muster bearbeiten> erfasst.

Der Knopf hat die gleiche Funktion wie in der Projektmaske.

Details zur Nachweis-Verwaltung können Sie im Kapitel Nachweis-Verwaltung nachlesen.

|
[Bild: 11]

Projekt-Ordner anlegen

[Bild: 11. Projekt-Ordner anlegen]

Über diesen Menüpunkt können Sie bei bestehenden Projekten zur Ablage von beliebigen Dateien einen oder mehrere Windows-Ordner automatisiert anlegen. Es ist möglich, einen Ordner mit mehreren Unterordnern (Archivstruktur) anzulegen. Es können verschiedene solcher Strukturen vorbereitet werden. Dann kommt beim Anlegen eines neuen Projekts die Frage, welche genommen werden soll. Dadurch kann man z.B. bei Heizung, Sanitär, Elektro, Klima usw. Andere Ablageregister wählen.

In jeder Ebene können Vorlagedateien hinterlegt werden wie z.B. eine Excel-Tabelle oder Wordtexte, die dann gleich mit kopiert werden.

Die Struktur wird über eine einfache Textdatei definiert. Die Erfassung und Beschreibung finden Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Projektverwaltung> <Grundeinstellungen/Zusatzfelder> im Bereich ‚Diverse Einstellungen‘. Dort gibt es eine ausführliche Erklärung.

Die Ordner können im Datenblatt über diesen Menüpunkt auch für vorhandene Projekte nachträglich angelegt werden.

[Bild: 12]

Räume (Aufmass)

[Bild: 12. Räume (Aufmass)]

Hier können Sie Räume anlegen, die bei der Aufmasserfassung eine wichtige Rolle spielen.

Hintergrund ist, dass damit die Räume im Excel-Aufmass bereits vorgegeben werden können. Die Tabelle ist identisch mit den Eingaben in der Aufmass-Erfassung selbst.

Register

[Bild: 13. Register]

Über diesen Button können Sie die Register des Projektes verwalten.

|
[Bild: 14]

Digitale Bauakte

[Bild: 14. Digitale Bauakte]

Dieser Button ist nur sichtbar, wenn Sie das Modul "Digitale Bauakte" erworben haben.

|
[Bild: 15]

Drucken

[Bild: 15. Drucken]

Hiermit kann das Projekt-Datenblatt gedruckt werden. Falls Sie Änderungen vorgenommen haben, werden diese automatisch gespeichert, bevor der Ausdruck erfolgt.

Ein Datenblatt lässt sich mit und ohne Dokumente ausdrucken. Die Festlegung erfolgt über das Formular. Der Druck als Ordnerrücken ist mit speziellen Etiketten (Zweckform) möglich.

|
[Bild: 16]

Abbruch

[Bild: 16. Abbruch]

Mit dem Knopf ‚Abbruch’ brechen Sie die Erstellung eines neuen Projektes ab, das Projekt wird nicht angelegt.

|
[Bild: 17]

OK

[Bild: 17. OK]

Mit dem Knopf ‚OK’ speichern Sie das Projektdatenblatt ab. Bei neuen Projekten wird in diesem Augenblick die Projektnummer ermittelt. Sollten Sie die Projektnummer eingegeben haben und sie existiert bereits, so weist das Programm diese Projektnummer ab und fordert Sie auf eine andere Nummer einzugeben.
