Verkaufsprovision

[Bild: 1. Verkaufsprovision]

Hier geht es um die Prämienberechnung für den Zusatzverkauf von Mitarbeitern. Legen Sie hier fest, nach welcher Methode die Provisionsabrechnung erfolgen soll.

[Bild: 2. Vorlage-Dokument (1)]

Mitarbeiterprovision aktiv

[Bild: 3. Mitarbeiterprovision aktiv]

Aktivieren Sie dieses Feld, wenn Sie eine Provision im Kundendienst an die Monteure ausschütten möchten.

|
[Bild: 4]

Vermittlerprovision aktiv

[Bild: 4. Vermittlerprovision aktiv]

Aktivieren Sie dieses Feld, wenn Sie eine Provision im Kundendienst an einen Vermittler ausschütten möchten.

|
[Bild: 5]

Provision immer anbieten

[Bild: 5. Provision immer anbieten]

Wenn dieses Feld aktiviert ist, werden bei der Provision alle Rechnungen angeboten. Dann ist es gleichgültig, ob ein Auftrag das Kennzeichen für die Provision hat oder nicht.

|
[Bild: 6]

neue Aufträge sofort auf Provision setzen

[Bild: 6. neue Aufträge sofort auf Provision setzen]

Aktivieren Sie dieses Feld, wenn neue Aufträge generell für die Monteurprovision berücksichtigt werden sollen.

|
[Bild: 7]

nur bezahlte Rechnungen anbieten

[Bild: 7. nur bezahlte Rechnungen anbieten]

Wenn dieses Feld aktiviert ist, werden nur bezahlte Rechnungen zur Provisionsabrechnung angeboten. Es ist Ansichtssache, ob die Mitarbeiterprovision unabhängig vom Zahlungseingang ist oder nicht.

|
[Bild: 8]

Verteilart

[Bild: 8. Verteilart]

Hier wird festgelegt, wie die Berechnung erfolgt und wie eine Aufteilung stattfindet, wenn mehrere Mitarbeiter an einem Auftrag beteiligt waren.

Im Prinzip gibt es 3 Methoden der Aufteilung:

· Aufgrund der auf den Auftrag gebuchten Zeiten (bei z.B. 2 Leuten und einer Zeit von 3 Std zu 5 Stunden wird die Prov. im Verhältnis 3 zu 5 aufgeteilt.

· Aufgrund der Anzahl der Monteure bei einem Auftrag: bei 3 Monteuren bekommt jeder ein Drittel der Prämie.

· Aufgrund der Einträge im Dokument : mit speziellen Artikel kann im Rechnungs-Dokument festgelegt werden, wer wie viel Prämie bekommt

Der Rest sind Kombinationen über einen zweiten Schritt, wenn der erste nicht erfolgreich ist, also im Dokument keine Provisionspositionen vorhanden sind.
