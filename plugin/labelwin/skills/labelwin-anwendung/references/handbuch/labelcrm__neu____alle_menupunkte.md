Start

[Bild]

Dokumentenliste Anschreibenadresse (F9)

Durch die Wahl dieses Menüpunkts erhalten Sie die Dokumentenliste, bei der die gewählte Adresse als Anschreibenadresse hinterlegt ist.

Dokumentenliste Baustellenadresse (Umschalt+F9)

Durch die Wahl dieses Menüpunkts erhalten Sie die Dokumentenliste, bei der die gewählte Adresse als Baustellenadresse hinterlegt ist.

Dokumentenliste Versandadresse (Strg+F9)

Durch die Wahl dieses Menüpunkts erhalten Sie die Dokumentenliste, bei der die gewählte Adresse als Versandadresse hinterlegt ist.

Neues Dokument

Durch die Wahl dieses Menüpunkts können Sie einen neuen KD-Auftrag anlegen. Es ist die gleiche Funktion wie der Knopf ‚Neues Dokument‘

Fotos

Sollten zu der Adresse Fotos hinterlegt sein, können diese über diesen Menüpunkt aufgerufen werden.

Rg.-Artikel-Liste Anschreibenadresse (F8 )

Bei der Wahl dieses Menüpunkts erhalten Sie eine Liste der berechneten Artikel, bei denen die gewählte Adresse als Anschreibenadresse (Rechnungsempfänger) hinterlegt ist.

Rg.-Artikel-Liste Baustellenadresse (Umschalt+F8)

Bei der Wahl dieses Menüpunkts erhalten Sie eine Liste der berechneten Artikel, bei denen die gewählte Adresse als Baustellenadresse (Baustelle) hinterlegt ist.

Rg.-Artikel-Liste Versandadresse (Strg+F8 )

Bei der Wahl dieses Menüpunkts erhalten Sie eine Liste der berechneten Artikel, bei denen die gewählte Adresse als Versandadresse hinterlegt ist.

KD-Logbuch (F11)

Durch die Wahl dieses Menüpunkts gelangen Sie ins Kundendienst-Logbuch. Es ist die gleiche Funktion wie der Knopf ‚KD-Logbuch‘.

Neuer KD-Auftrag

Durch die Wahl dieses Menüpunkts können Sie einen neuen KD-Auftrag anlegen. Es ist die gleiche Funktion wie der Knopf ‚Neuen KD-Auftrag‘

Anlagen

Durch die Wahl dieses Menüpunkts gelangen Sie in die Anlagenmaske. Dort können Sie eine neue Anlage anlegen oder eine vorhandene Anlage ändern. Es ist die gleiche Funktion wie der Knopf ‚Anlagen‘.

Verträge

Durch die Wahl dieses Menüpunkt gelangen Sie Maske Wartungsverträge. Hier können Sie einen neuen Vertrag anlegen oder zu einem bestehenden Vertrag Änderungen vornehmen. Es ist die gleiche Funktion wie der Knopf ‚Verträge‘.

TGM

Dieser Menüpunkt steht nur zur Verfügung, wenn das Zusatzmodul TGM vorhanden ist. Hier werden dann alle TGM Elemente zu dieser Adresse angezeigt.

Aufgaben Aktive Adresse

Durch die Wahl dieses Menüpunkt erhalten Sie eine Liste der Aufgaben zu der gewählten Adresse. Es ist die gleiche Funktion wie der Knopf ‚Aufgaben‘.

Aufgaben Objektadresse

Durch die Wahl dieses Menüpunkt erhalten Sie eine Liste der Aufgaben, bei denen die gewählte Adresse als Objektadresse hinterlegt ist.

Neue Aufgabe

Durch die Wahl dieses Menüpunkts kann eine neue Aufgabe für die Rechnungsadresse angelegt werden.

Projekte Anschreibenadresse

Durch die Wahl dieses Menüpunkts gelangen Sie in die Maske der Projektliste, bei denen die gewählte Adresse im Datenblatt als Auftraggeber hinterlegt ist. Es ist die gleiche Funktion wie der Knopf ‚Anschreibenadresse‘.

Projekte Objektadresse

Durch die Wahl dieses Menüpunkts gelangen Sie in die Maske der Projektliste, bei denen die gewählte Adresse im Datenblatt als Objektadresse hinterlegt ist. Es ist die gleiche Funktion wie der Knopf ‚Baustellenadresse‘.

Suchen

[Bild]

Objekte dieser Rg Adresse (Mieter)

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste der Objekte, in denen die gewählte Adresse als Rechnungsadresse hinterlegt wurde.

Objekte dieser Eigentümeradresse

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste der Objekte, in denen die gewählte Adresse als Eigentümeradresse hinterlegt wurde.

Objekte dieser Versandadresse

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste der Objekte, in denen die gewählte Adresse als Versandadresse hinterlegt wurde.

Objekte dieser Hausmeisteradresse

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste der Objekte, in denen die gewählte Adresse als Hausmeisteradresse hinterlegt wurde.

Objekte dieser Liegenschaft

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste aller Adressen, die dieser Liegenschaft (gewählte Adresse) zugeordnet sind.

Beispiel: Hier wurde die Adresse Hubertus gewählt. Die Adresse Hubertus ist die Liegenschaft für die nachstehenden Adressen.

[Bild]

Liegenschaft dieser Rg.-Adresse

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste aller Adressen, bei der die gewählte Adresse als Rechnungsempfänger eingetragen wurde.

Beispiel: Hier wurde die Adresse Gemeinnützige Genossenschaft aufgerufen. Diese ist bei 3 Liegenschaften als Rechnungsanschrift hinterlegt.

[Bild]

Liegenschaft dieser Eigentümeradresse

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste aller Adressen, bei der die gewählte Adresse als Eigentümerr eingetragen wurde.

Bespiel: Hier wurde die Adresse Gemeinnützige Genossenschaft aufgerufen. Diese ist bei einer Liegenschaft als Eigentümer eingetragen.

[Bild]

Eine ausführliche Beschreibung zu den Liegenschaften finden Sie in unserem Handbuch im Kapitel Liegenschaft.

Telefonnummern (Strg+W)

Durch die Wahl dieses Menüpunkt erhalten Sie die Telefonnummern, die bei der gewählten Adresse unter zugeordnete Adressen und weitere Adressen hinterlegt wurden.

Verbundene Adressen

Dieser Menüpunkt zeigt alle mit dieser Adresse verbundenen Adressen an.

Anlage suchen

Über diesen Menüpunkt können Sie eine Adresse aufgrund des Anlagennamens, der Anlagennummer sowie der Zusatzfelder finden.

In Karteikarte suchen

Durch die Wahl dieses Menüpunkt können Sie nach einem Suchbegriff oder Kennzeichen in der Karteikarte suchen. Neben diesen Einträgen kann auch nach Anlagen gesucht werden. Ein Doppelklick auf dien gefundenen Karteikarteneintrag oder die gefundene Anlage öffnet die Objektadresse.

Suche wiederholen

Wenn Sie z.B. nach @Bahnhof suchen, erhalten Sie ggf. eine Auswahlliste, aus der Sie dann eine Adresse wählen. Das Suchwort @Bahnhof wird dann durch das Suchwort der Adresse ersetzt. Wenn Sie aber versehentlich doch die falsche Adresse gewählt haben, können Sie mit der Wahl dieses Menüpunkts die Suche wiederholen – Sie erhalten dann erneut die Auswahlliste und können die richtige Adresse wählen.

Ausgangsrechnungen

Hier wird Ihnen eine Liste alle bisher geschriebenen Ausgangsrechnungen zur gewählten Adresse angezeigt.

Eingangsrechnungen

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste aller Eingangsrechnungen zur gewählten Adresse.

Eingangsrechnungen Objektadresse

Durch die Wahl dieses Menüpunkts erhalten Sie eine Liste der Eingangsrechnungen, bei denen die gewählte Adresse als Objektadresse hinterlegt ist.

Optionen

[Bild]

Internet Stadtplan

Neben dem Internet-Stadtplan kann nun auch eine Anfahrtsskizze über das Internet erstellt werden. Die Funktionalität ist wie beim Stadtplan im Adressmodul und in der Druckmaske des Kundendienstes realisiert. Betätigen Sie dort die Menüpunkte bzw. den Knopf ‚Route’, so erscheint eine Maske, in der Sie die Start- und die Zieladresse wählen können. Über ein Ankreuzfeld besteht die Möglichkeit, die Startadresse dauerhaft abzuspeichern. In diesem Fall wird bei der nächsten Benutzung automatisch diese Startadresse vorgeschlagen.

Internet Routenplan

Mit Hilfe der Internetseite Google Maps kann direkt aus Labelwin heraus der Standort einer Adresse gezeigt werden. Voraussetzung ist natürlich, dass Sie eine Internetverbindung automatisch aufbauen können oder zuvor das Internet aktiviert haben.

Mandantenwechsel (Strg + M )

Durch die Wahl dieses Menüpunkts erhalten Sie eine Auswahlliste der bei Ihnen geführten Mandanten. Wählen Sie den Mandanten aus, in dem Sie weiterarbeiten möchten.

Nächster Mandant (Strg + N)

Durch die Wahl dieses Menüpunkts wird zum nächsten Mandanten gewechselt.

SMS Versenden

Sollte das SMS Modul vorhanden sein, lässt sich über diesen Menüpunkt eine SMS an die aufgerufene Adresse versenden.

Wareneingang Objekt

Über diesen Menüpunkt kann man eine Artikelliste alle Eingangslieferscheine zur aufgerufenen Adresse aufrufen.

Ansicht anpassen

Über diesen Menüpunkt kann die LabelCRM Maske konfiguriert werden.

Nur Grunddaten zeigen

Wird dieser Menüpunkt angewählt, reduziert sich die LabelCRM Maske auf die Grunddaten.

Ansicht aktualisieren

Durch Wahl dieses Menüpunktes wird die LabelCRM Maske neu aufgebaut und somit alle angezeigten Informationen aktualisiert.
