9. Protokoll

Sie erreichen diese Maske über den Menüpunkt <Listen> <Protokoll>.

Im Lager wird jede Veränderung protokolliert, sei es ein neuer Artikel, eine Umbuchung oder das Löschen eines Artikels. Über diese Maske können Sie festlegen, welche Änderung Sie sehen und ausdrucken möchten.

[Bild]

Bild: Protokoll drucken

[Bild]

1 Markierter Artikel: Wenn Sie dieses Feld aktivieren, wird der in der Liste der Hauptmaske markierte Artikel gewählt.

[Bild]

2 Artikel: Wenn Sie die Option ‚Markierte Artikel’ gewählt haben, wird Ihnen hier die im Lager hinterlegte Artikel-Nr. angezeigt.

[Bild]

3 Bestimmtes Lager / Projekt: Wenn Sie dieses Feld aktivieren, können Sie das Protokoll auf ein bestimmtes Lager eingrenzen.

[Bild]

4 Lager: Wenn Sie die Option ‚Bestimmtes Lager / Projekt’ gewählt haben, könnten Sie aus der Liste das entsprechende Lager auswählen.

[Bild]

5 Bestimmter Mitarbeiter: Wenn Sie dieses Feld aktivieren, können Sie das Protokoll für einen bestimmten Mitarbeiter erzeugen.

[Bild]

6 Mitarbeiter: Wenn Sie die Option ‚Bestimmter Mitarbeiter’ gewählt haben, wird hier die Liste der Mitarbeiter sichtbar, aus der Sie dann den gewünschten Mitarbeiter auswählen.

[Bild]

7 Bestimmter Protokoll-Typ: Wenn Sie dieses Feld aktivieren, können Sie nach einem bestimmten Protokolltyp auswählen, z.B. nur Korrekturen. Ist das Feld nicht aktiviert, werden alle Protokolltypen für das Protokoll genommen.

[Bild]

8 Protokoll-Typen: Durch das Aktivieren des Feldes ‚Bestimmter Protokoll-Typ, haben Sie hier die Möglichkeit, auf einzelne Protokoll-Typen einzugrenzen.

[Bild]

9 von bis Datum: Legen Sie hier den Zeitraum fest, für den Sie das Protokoll erstellen möchten.

[Bild]

10 Sortierung: Legen Sie hier fest, wie das Protokoll sortiert werden soll – ob nach der Erfassreihenfolge oder nach Datum.

[Bild]

11 Drucken: Durch Betätigen dieses Knopfes erzeugen Sie den Druck des Protokolls gemäß der von Ihnen getroffenen Eingrenzung.

[Bild]

12 Ende: Durch Betätigen dieses Knopfes wird die Maske geschlossen.
