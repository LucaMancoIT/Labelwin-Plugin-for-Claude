1. Auslagern und Transport eines Aufmaßes zum Laptop

1.1 Aufmaß anlegen und Mengen auf Null

Das Aufmaß muss im Büro angelegt werden. In der Regel wird dazu das Basis-Dokument oder das Angebot kopiert. Anschließend müssen die Mengeneinträge im Dokument auf Null gesetzt werden. Nehmen Sie dazu das Dokument in Bearbeitung und wählen die Menüpunkte <Optionen> <Alle Mengen auf Null> an. 1.2 Exportieren zum Laptop

[Bild]

Markieren Sie im Projektmodul das Aufmaß-Dokument und wählen die Menüpunkte <Extern> <Dokument exportieren> an. Damit wird das Aufmaß in eine Datei übertragen, die anschließend sofort gezippt (komprimiert) wird. Die Extension der Datei ist absichtlich so ungewöhnlich, damit man sie beim Emailempfang per Doppelklick den Import und die Aufmaßerfassung automatisch starten kann.

Wenn Sie die Datei per USB-Stick transportieren möchten, müssen Sie die angegebene Datei kopieren und auf dem Laptop in das Aufmaß-Verzeichnis übertragen.

[Bild]

Beim Versand per Emailanhang werden alle Mitarbeiter angeboten, bei denen im Personalstamm eine Emailadresse hinterlegt ist.

1.3 Importieren auf Laptop

Wenn die Aufmaß-Datei per USB oder über ein Netzwerk transportiert wird, muss sie im Verzeichnis Labelwin\aufmass abgelegt werden. Bei Start der Aufmass.exe wird die Datei automatisch entpackt und das Aufmaß kann erfasst / geändert werden.

Bei Transport per Email markieren Sie den Anhang und wählen einmalig mit der rechten Maustaste die Funktion ‚Öffnen mit‘ an. Wählen Sie dann die Datei c:\labelAuf\aufmass.exe an. Kreuzen Sie an, dass dieses Programm bei dieser Extension immer genutzt werden soll.

Damit wird das Programm Aufmass.exe gestartet, die Datei kopiert und entpackt und das Aufmaß kann bearbeitet werden.

Wenn die Zuordnung einmal erfolgt ist, kann man künftig den Email-Anhang per Doppelklick importieren.
