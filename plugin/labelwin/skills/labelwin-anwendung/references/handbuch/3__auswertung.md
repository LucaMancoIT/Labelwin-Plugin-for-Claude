3. Auswertung

Unter der Voraussetzung, dass Sie die Eingangsrechnungen bestimmten Projekten zugeordnet haben, lassen sich mit diesem Programm umfangreiche Auswertungen durchführen. Über die frei generierbaren Formularfunktionen lassen sich Listen in jeder nur denkbaren Aufteilung erzeugen. Sofern unsere mitgelieferten Formulare nicht Ihren Bedürfnissen entsprechen, sprechen Sie uns bitte auf weitere Auswertungen an.

[Bild]

Bild: Auswertung Eingangsrechnungen

Anmerkung: Bei der oben abgebildeten Einstellung haben wir ein wenig gemogelt, damit alle Felder sichtbar sind.

Im oberen Drittel des Bildes befinden sich Eingabefelder, mit denen die Anzahl der gezeigten Einträge eingeschränkt werden kann. Die Eingrenzung wirkt jedoch nicht sofort, sondern erst nach Betätigen des Knopfes ‚Liste aufbauen’. (Nr.19)

[Bild]

1 RG-Liste komplett: Hier können Sie eine zeitliche Begrenzung treffen. Je nach Wahl der Begrenzung müssen Sie dann im nebenstehenden Feld den gewünschten Zeitraum eintragen (entweder ‚bestimmter Monat’ oder ‚Datum von – bis’)

[Bild]

2 Abteilung: Wenn Sie die Auswertung für eine bestimmte Abteilung durchführen möchten, müssen Sie hier ein Kreuz setzen. Für die Auswertung nach Abteilungen müssen Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Grundeinstellungen> <Abteilungen> die Abteilungen erfasst haben. Die Eingangsrechnungen müssen dann den entsprechenden Abteilungen zugeordnet werden.

[Bild]

3 Abteilung: Wählen Sie aus der Auswahlbox die entsprechende Abteilung aus. Voraussetzung für die Auswahl ist, dass Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Grundeinstellungen> <Abteilungen> Abteilungen erfasst haben.

[Bild]

4 Projekt: Wenn Sie die Auswertung für ein bestimmtes Projekt/Baustelle durchführen möchten, so müssen Sie hier ein Kreuz setzen. Geben Sie anschließend in dem Feld 11 die Projektnummer ein oder wählen mit dem Knopf Nr. 12 das gewünschte Projekt aus.

[Bild]

5 Projektnummer: Geben Sie hier die gewünschte Projektnummer ein, oder wählen durch Betätigung des Knopfes ‚Projektauswahl‘ das entsprechende Projekt aus.

[Bild]

6 KD-Auftrag: Wenn Sie die Auswertung für einen bestimmten KD-Auftrag durchführen möchten, so müssen Sie hier ein Kreuz setzen. Geben Sie anschließend in dem Feld 8 die KD-Auftragsnr. ein oder wählen mit dem Knopf ‚KD-Auftrag‘ den gewünschten KD-Auftrag aus.

[Bild]

7 KD-Auftrag-Nr.: Geben Sie hier die gewünschte KD-Auftragsnr. ein oder wählen Sie durch Betätigen des Knopfs ‚KD-Auftrag‘ den KD-Auftrag aus.

[Bild]

8 Kostenstelle: Wenn Sie die Auswertung für eine bestimmte Kostenstelle durchführen möchten, so können Sie die Kostenstelle anschließend auswählen. Die Kostenstellenauswahl ist nur dann möglich, wenn bei der Rechnungserfassung Kostenstellen zugeordnet worden sind.

[Bild]

9 Kostenstelle: In dieser Liste können Sie Kostenstellen auswählen. Voraussetzung ist jedoch die Buchung auf verschiedene Kostenstellen.

[Bild]

10 Lieferant: Wenn Sie die Eingangsrechnungen eines bestimmten Lieferanten sehen möchten, so müssen Sie hier das Kreuz setzen. Geben Sie im nebenstehenden Feld den Adresskurznamen ein.

[Bild]

11 Hersteller: Wenn Sie die Eingangsrechnungen eines bestimmten Herstellers sehen möchten, so müssen Sie hier das Kreuz setzen. Anschließend geben Sie im nebenstehenden Feld den Adresskurznamen ein.

[Bild]

12 Objekt: Wenn Sie die Eingangsrechnungen eines bestimmten Objekt sehen möchten, so müssen Sie hier das Kreuz setzen. . Anschließend geben Sie im nebenstehenden Feld den Adresskurznamen ein.

[Bild]

13 Konto: Wenn Sie die Eingangsrechnungen über ein bestimmtes Warenkonto selektieren möchten, so müssen Sie hier das Kreuz setzen.

[Bild]

14 Warenkonto: Wenn Sie im Feld 13 ein Kreuz gesetzt haben, können Sie hier das Warenkonto auswählen, über das selektiert werden soll.

[Bild]

15 Adresskurzname: Geben Sie hier wie bei allen anderen Adressaufrufen auch den Adresskurznamen ein. Sollte der Kurzname nicht eindeutig sein, so erscheint automatisch eine Liste, aus der Sie die gewünschte Adresse auswählen können.

[Bild]

16 Suche: Wenn Sie einen Kurznamen oder auch nur die Anfangsbuchstaben eingetragen haben, erhalten Sie durch Betätigen des Knopfes eine Auswahlliste.

[Bild]

17 Adresse: Durch Betätigung dieses Knopfes wird das Adressprogramm hochgefahren und Sie können die gewünschte Adresse heraussuchen lassen.

[Bild]

18 freie Eingabe: Wenn Sie ausnahmsweise ein Konto anbuchen müssen, dass nicht im Kontenplan hinterlegt ist, müssen Sie hier ein Kreuz setzen.

[Bild]

19 Liste aufbauen: Wenn Sie diesen Knopf betätigen, so wird aufgrund der zuvor getroffenen Eingrenzungen die Liste der Eingangsrechnungen erzeugt. Um Zeiten zu sparen, wird die Liste nicht bei jedem Wechsel der Eingrenzung automatisch aktualisiert,

sondern erst nach Betätigung dieses Knopfes.

[Bild]

20 Rechnungsliste: In dieser Liste sehen Sie alle Eingangsrechnungen, die aufgrund der oben getroffenen Eingrenzungen aktiv sind.

[Bild]

21 Gesamtsumme: In diesem Feld werden die Summen aller aufgrund der Eingrenzungen gewählten Rechnungen angezeigt.

[Bild]

22 Rechnung zeigen: Durch Betätigung dieses Knopfes können Sie sich die markierte Rechnung anzeigen lassen, sofern Sie Ihre Eingangsrechnungen einscannen.

[Bild]

23 Eing.-LS zeigen: Wenn Sie das Modul BESTELLÜBERWACHUNG oder LAGERVERWALTUNG erworben haben, ist dieser Knopf sichtbar. Hier können Sie sich zu der in der Liste (Nr. 20) markierten Rechnung den/die dazu gehörenden Eingangslieferscheine anzeigen lassen.

[Bild]

24 Bestellung zeigen: Wenn es zu der in der Liste (Nr. 20) markierten Rechnung eine Bestellung gibt, können Sie sich durch Betätigen dieses Knopfes die Bestellung anzeigen lassen.

[Bild]

25 Zahlungsplan: Wenn Sie in der Rechnungsliste eine Rechnung markieren, gelangen Sie durch Betätigen dieses Knopfes in den entsprechenden Zahlungsplan.

[Bild]

26 Anmerkung: Wenn Sie zu einer Eingangsrechnung eine Anmerkung hinterlegt haben, ist dieser Knopf rot, wenn Sie die entsprechende Rechnung in der Liste markieren. Sie können hier ggf. noch Ergänzungen zur Anmerkung vornehmen.

[Bild]

27 Druck: Durch Betätigung dieses Knopfes fährt die Druckausgabe hoch. In der Druckausgabe können Sie die Auswertung aufgrund verschiedener Formulare beeinflussen.

[Bild]

28 Ende-Knopf: Durch Betätigung des Ende-Knopfes wird die Auswertung beendet.
