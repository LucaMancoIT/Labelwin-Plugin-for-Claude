PDFTK einrichten

Das Programm PDF Toolkit (kurz PDFTK) wird benötigt, wenn PDF-Dateien an bereits vorhandene Scans oder PDF's angehängt werden sollen.

|

Dazu muss das PDFTK bei jedem Anwender (oder einmalig auf dem Terminalserver) installiert werden. Das Programm selbst ist eine kostenlose Freeware. Sie können es im LabelWiki von unseren Servern herunterladen. Suchen Sie im Labelwiki nach dem Stichwort "PDFTK" oder klicken auf das Fragezeichen rechts neben dem Pfad der pdftk.exe im Einstellmodul (siehe Screenshot).

Speichern Sie die heruntergeladene Datei irgendwo ab und führen Sie sie aus. Bitte fragen Sie ggf. VORHER Ihren System-Administrator.

Nach der Installation muss im Labelwin der Pfad eingetragen werden, in welchem Verzeichnis sich die Datei pdftk.exe befindet. Die Eintragung muss im Modul Einstellungen unter <Programmbereiche - Archiveinstellung - Scannarchiv> oder <Programmbereiche - Druckausgabe - Pdf-Druckarchiv> erfolgen. Dieser Eintrag muss für jeden Anwender separat erfolgen.
