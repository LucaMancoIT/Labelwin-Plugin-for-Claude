6.2 Termindarstellung und Änderungsmöglichkeiten

[Bild]

In dieser Maske werden die vorhandenen Termine angezeigt. Beachten Sie oben die Eingrenzungsmöglichkeiten auf die KD-Monteure (wird im Modul EINSTELLUINGEN unter dem Menüpunkt <Programmbereiche> <Personal> <Personal erfassen> festgelegt) und die Teams (Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Personal> <Team>)

Bei der Anlage von neuen Aufträgen kann durch einen Doppelklick auf einen Monteur an der bestimmten Uhrzeit ein Vorschlag in die Auftragsmaske übernommen werden.

Wenn Sie die Maus einen Moment über einen Terminbalken stellen, wird der Text dieses Auftrages gezeigt.

Ein Doppelklick auf einen Auftrag öffnet eine Maske, in der Sie die Zeiten, den zugeordneten Monteure, die Priorität, den Auftragstext ändern können. Sie haben auch die Möglichkeit, noch weitere Monteure hinzuzufügen.

Es sind auch die Termine sichtbar, die vor der normalen Arbeitszeit liegen, also wegen ungenauer Eingabe auf 0:00 Uhr liegen. Dadurch sind sie auch in dieser Maske veränderbar. Bitte beachten Sie, dass auch diese Maske nicht ganz verhindern kann, dass Termine abgedeckt sind. Sobald Sie einen Termin über den ganzen Tag haben, so wird dieser ggf. einen anderen abdecken. Schalten Sie im Zweifelsfall auf die Tagesliste, indem Sie unten links den Knopf ‚Tagesliste’ betätigen.

Zur besseren Übersicht werden die Termine farblich gekennzeichnet, wenn es sich um Urlaub, Krankheit, Schule oder Onlinetermine handelt. Solange Sie ohne Prioritäten arbeiten, ändert sich daran nichts.

Wenn Sie mit Planquadraten arbeiten, haben Sie die Möglichkeit zusätzlich benachbarte Planquadrate einzugeben. Damit können dann die Kundendienstaufträge der Nachbarbezirke bei der Eingrenzung auf ein bestimmtes Planquadrat in einer anderen Farbe angezeigt werden.

[Bild]

Aktivieren Sie hierzu das Feld ‚Farbe je Planquadrat’.

Bei der Suche der Aufträge in einem bestimmten Planquadrat werden die Aufträge im gesuchten Planquadrat in lila, die in den benachbarten Planquadraten in gelb und die außerhalb liegenden in weiß dargestellt. Die Suche nach einem bestimmten Planquadrat aktivieren Sie in der Maske Terminanzeige über das Feld ‚Planquadrat farblich markieren’. Es erscheint dann ein Eingabefeld, in das Sie das gewünschte Planquadrat eintragen können.

Um die Vergabe der Planquadrate einfacher zu gestalten, ist es möglich dies aufgrund der Postleitzahl vorzugeben. Dieses funktioniert je nach Gebiet unterschiedlich gut.

Wenn Sie bei der Neuanlage eines Auftrags in die Terminmaske gehen, so ist das Planquadrat der Baustellenadresse automatisch aktiv. Das heißt, Sie sehen dann auf einen Blick alle anderen Termine im gleichen Planquadrat in Lila angezeigt.

[Bild]

Terminmaske

Wenn die Monteure nicht alle auf den Bildschirm passen, kann die Anzeige mit einem Schiebebalken verstellt werden.

Bei der Eingrenzung auf einen einzelnen Monteur wird nun eine ganze Woche im Voraus angezeigt. Das Umschalten auf einen bestimmten Monteur geschieht zusätzlich durch einen Doppelklick auf den Namen in der Anzeigetabelle.

Durch Anklicken und Verschieben kann ein Termin umgesetzt werden. Dabei ist die Verschiebung auf einen anderen Mitarbeiter und eine andere Zeit möglich.

Durch einen Klick mit der rechten Maustaste auf einen Eintrag können Sie den Termin ändern. Die Änderung eines Termins und das Hinzufügen weiterer Monteure wurde so gestaltet, dass der vorhandene Termin sofort in den Eingabefeldern steht. Weitere Monteure werden mit dem Knopf ‚Speichern als Neu’ hinzugefügt.

Verschieben von Terminen (Drag and Drop)

[Bild]

Um einen Termin visuell zu verschieben müssen Sie zunächst in die Maske ‚Terminübersicht’ gehen.

Klicken Sie dann den zu verschiebenden Termin an und halten die linke Maustaste gedrückt. Verschieben Sie den Terminbalken an die gewünschte Stelle. Sie müssen dabei darauf achten, dass die linke obere Ecke auf dem Balken des gewünschten Monteurs und der richtigen Uhrzeit steht. Beim Loslassen der Maustaste muss diese Ecke zwingend auf einem freien Bereich der Maske zeigen. Wenn die Ecke auf einen anderen Terminbalken steht, passiert nichts.

In diesem Fall wird der Termin von Hans Meier 8:30 Uhr auf den Monteur Reiner Abraham auf 7:00 Uhr gezogen.

Wenn Sie auf die Ansicht eines Monteurs umgeschaltet haben, so können Sie den Termin beim gleichen Monteur auf einen anderen Tag schieben.

Wochenansicht eines Monteurs

Nach Umschalten auf einen bestimmten Monteur wird nun eine Woche im Voraus gezeigt.

Das Umschalten geht wie bisher, in dem Sie in der Auswahlbox wählen oder in dem Sie in der Tabelle selbst einen Doppelklick auf den Monteurnamen durchführen
