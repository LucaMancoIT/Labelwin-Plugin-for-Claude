1. Wie kommen die Checklisten an den Auftrag?

Die Checklisten werden immer aus Bausteinen erstellt, die individuell erfassbar sind. In der Regel wird genau eine Vorlage übernommen, man kann eine Checkliste aber auch aus mehreren Vorlagen erstellen. Jede weitere Vorlage wird am Ende angehangen.

1. Über Anlagen-Checkliste

In der Regel wird eine Checkliste zur Anlage angelegt. Wenn dann eine Wartung per Kundendienstauftrag geplant wird, wird die Checkliste der Anlage zum Auftrag dazu kopiert. Kopiert deshalb, weil so die Checkliste von jeder Wartung auch Jahre später noch eingesehen werden kann. Allerdings automatisch nur dann, wenn ein Wartungstermin gewählt wurde. Ohne Wartungstermin kann auch die Anlagencheckliste gewählt werden, aber nur manuell über den Knopf ‚Kd-Check‘

2. Direkte Einbindung

Eine Checkliste kann direkt zu einem einzelnen Auftrag angelegt werden. Auch hier wird auf Vorlage-Bausteine zugegriffen. Diese Möglichkeit ist unabhängig davon, ob eine Anlage zum Auftrag gehört oder nicht. Die einzige Einschränkung ist, dass man eine freie KD-Checkliste und eine Anlagencheckliste nicht kombinieren kann.

Denkbare Situationen sind alle Aufträge, bei denen viele Dinge zu beachten / abzuhaken sind. So z.B. ein Abnahmeprotokoll, eine komplexe Fehlersuche oder eine Bestandsaufnahme einer Anlage.

|

Hinweis: Die Anlagen-Checkliste ist eine KD-Checkliste, die bei einer Anlage hinterlegt wurde. So eine Anlagen-Checkliste wird automatisch bei einem Kundendienstauftrag mit Wartungstermin gezogen. Die Anlagen-Checkliste wird zur KD-Checkliste des Auftrages kopiert. Wird so eine KD-Auftrag erledigt, werden alle Kreuze und Bemerkungen der KD-Checkliste zurück in die Anlagen-Checkliste überführt, so dass in der Anlagen-Checkliste immer der letzte Stand sichtbar ist.
