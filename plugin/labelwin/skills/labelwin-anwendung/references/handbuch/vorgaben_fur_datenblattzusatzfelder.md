Vorgaben für Datenblattzusatzfelder

|

Hier können Vorgaben für die Zusatzfelder bei der Anlage von neuen Projekten hinterlegt werden. Die Einträge können natürlich im Datenblatt geändert werden, aber eine sinnige Vorgabe spart Arbeit. Beim abgebildeten Beispiel kann das Feld mit der Beschriftung Sachbearbeiter mit beliebigen Vorschlagswerten versehen werden.

Bitte beachten Sie, dass bei solchen Informationen später relativ schlecht selektiert werden kann, weil Unterschiede in der Schreibweise auftreten werden (Groß-, Kleinschrift, Schreibfehler). In allen übrigen Feldern ist keine freie Eingabe möglich, sondern hier kann nur aus der Auswahlliste ein Eintrag gewählt werden. Über diesen Weg sichern wir bei der späteren Erfassung mögliche Fehleingaben ab.

Wenn Sie das Feld ‚Eingrenzung auf Dokumententypen sichtbar’ aktivieren, so wird in der Projektmaske dauerhaft ein Suchbaum dargestellt, mit dem Sie schnell eine Eingrenzung auf einen bestimmten Dokumententyp erreichen können.
