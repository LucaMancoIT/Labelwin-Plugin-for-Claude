Gaeb einlesen

Über den Menüpunkt <Vorlagen> <GAEB Datei einlesen> im Dokument starten Sie das GAEB-Einlesen.

Sollte das Dokument schon Positionen beinhalten, wird ein Abgleich, z.B. Preisabgleich, durchgeführt. Es werden dann nur Positionen eingelesen, die über die Positionsnummer zugeordnet werden können. Positionen, die nicht zugeordnet werden können, erscheinen im GAEB Protokoll. Es ist daher wichtig es am Ende sich genau anzuschauen.

[Bild]

Beachten Sie die kleinen ?-Knöpfe. Überall, wo Sie einen solchen Knopf vorfinden, erhalten Sie einen Hilfetext zu dem Eingabe-/Auwahlfeld.

[Bild]

1 Pfad und Dateiname: Wählen Sie als erstes die GAEB Datei zum Einlesen aus. Sowie Sie eine Datei ausgewählt haben wird sie geöffnet und sofort auf Korrektheit geprüft. Die in der GAEB Datei definierte Austauschphase wird angezeigt. Sie sollte, muss aber nicht, mit der Dateiendung übereinstimmen.

[Bild]

2 Durchsuchen-Knopf: Hiermit können Sie Gaeb-Datei suchen, die Sie gespeichert haben.

3 GAEB Austauschphase: Im ersten großen Block erhalten Sie allgemeine technische Informationen zur GAEB Datei, z.B. Version (hier GAEB2000 Format), den Namen Software mit der sie erstellt wurde (in diesem Fall die Software SSS2000) und ggf. enthaltene Fehler. Sollten Fehler, wie im nächsten Beispiel, vorhanden sein, werden der Kasten und der Aktions-Protokoll-Knopf rot.

[Bild]

Bitte prüfen Sie das Aktions-Protokoll und schauen Sie sich die Fehler an. Manche sind schwerwiegend, andere kann man getrost ignorieren.

Hier ein Ausschnitt aus dem Protokoll:

[Bild]

Das Programm kann den Schweregrad nicht selbst entscheiden, d.h. hier müssen Sie eine Entscheidung fällen.

Übrigens, fehlerhafte GAEB Dateien sind keine Seltenheit. Wir bekommen von unseren Anwendern immer wieder GAEB Dateien zur Prüfung, die nicht normgerecht sind.

[Bild]

4 Drag & Drop: Wenn Sie im Modul EINSTELLUNGEN unter dem Menüpunkt <Vorlagen> <Andere Dokumente> eine entsprechende Eintragung vorgenommen haben, können Sie eine Datei aus dem Explorer in diesen Bereich ziehen und fallen lassen. Der Pfad wird im Feld 1 automatisch eingetragen.

[Bild]

5 Hinweis in der Datei: Manche GAEB Dateien, speziell in der 90er Phase, beinhalten einen Hinweistext, z.B. „Hier die ersten Preise, eine aktualisierte Datei erhalten Sie, wenn weitere Preise vorliegen“. Dieser Text wird ggf. hier angezeigt.

6 Verarbeitungsoptionen: Diese Anzeige variiert ein wenig je nachdem, welcher Austauschphase die Datei angehört und welche Informationen enthalten sind.
