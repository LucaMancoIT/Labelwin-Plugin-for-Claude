2. Nachricht an TomTom senden

In einem geöffnetem Auftrag können Sie mit dem Menüpunkt ‚Nachricht an TomTom’ einen beliebigen Text an jedes Fahrzeug senden.

[Bild]

Wählen Sie hierzu das Fahrzeug aus und schreiben Sie Ihren Text. Danach versenden Sie die Nachricht an das ausgewählte Fahrzeug.
