8. Zeiterfassung, flexible Maske V5

Für eine unbestimmte Übergangszeit gibt es die Maske der mobilen Zeiterfassung doppelt. Standardmäßig ist die „alte“ aktiv. Die neue flexible Maske wird mit einem Schalter aktiviert. Dabei sind aber ggf. weitere Einstellungen notwendig, um die Vorteile der neuen Maske auszunutzen.

Die neue Maske wird über einen manuellen Eintrag in der Datei Labelwin\global.ini aktiviert. Dort muss unter der Gruppenüberschrift [Grundeinstellungen] (Vorsicht, nicht unter Grund…1) eine neue Zeile mit

ZeitwirtFlex=1 eingetragen werden.

Die anschließenden noch erforderlichen Anpassungsarbeiten werden im folgenden Kapitel Einrichtungsarbeiten erläutert.

Die wesentlichen Vorteile der flexiblen Zeiterfassmaske:

- Die Maske ist frei gestaltbar, die Anwender können selbst festlegen, welche Elemente sie nutzen möchten und in welcher Reihenfolge die Eingabe stattfinden soll.

- Die Buchung für 2 Mitarbeiter kann gleichzeitig erfolgen. Wenn ein Mitarbeiter üblicherweise einen Azubi dabei hat, kann die Zeitbuchung gleichzeitig für ihn mit erfolgen.

- Eine separate Buchung der Anfahrt mit einer speziellen Stundenart kann auf einen Rutsch mit gebucht werden.
