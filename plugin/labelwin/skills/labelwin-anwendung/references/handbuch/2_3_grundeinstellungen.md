2.3 Grundeinstellungen

Nachdem die Konteneinstellungen vorgenommen wurden, müssen zwingend die Grundeinstellungen für die Ladenkasse vorgenommen werden. Über <Optionen> <Grundeinstellungen> erreichen Sie die nachfolgenden Masken.
