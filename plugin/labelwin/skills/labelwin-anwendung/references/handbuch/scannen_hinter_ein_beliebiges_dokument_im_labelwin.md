Scannen hinter ein beliebiges Dokument im Labelwin

Wenn z.B. eine Auftragsbestätigung im Labelwin erfasst worden ist, und diesem Dokument dann ein gescannter Beleg (mit Unterschrift) im ELO hinterlegt werden soll, so können Sie von der Projektoberfläche mit dem Menüpunkt „Dokumente“ „In Elo scannen“ oder der Taste F12 den Beleg direkt in ELO erfassen. Es erscheint folgende Maske:

[Bild]

Sie können nun das Ablageregister, den Schlüssel, und das Scan-Profil auswählen. Zusätzlich können Sie entscheiden, ob das Dokument in den Volltext aufgenommen werden soll.

Mit ‚OK scannen‘ starten Sie dann den Scan-Vorgang.
