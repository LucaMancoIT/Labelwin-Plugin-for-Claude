Aufmaß-Erfassung per Excel-Tabelle

15.10.2016

Nachfolgend wird beschrieben, wie ein Aufmaß in eine Excel-Tabelle übertragen werden kann und diese später wieder mit den eingetragenen Mengen importiert werden kann.

Beim Export wird in einer Maske festgelegt, welche Positionen und welche Räume in die Excel-Tabelle eingetragen werden sollen. Welche Informationen in der Tabelle stehen sollen (Vorgabemenge Ja/Nein) kann über die Wahl einer Vorlage –Excel-Tabelle festgelegt. Der Anwender kann die Tabellen innerhalb gewisser Regeln selbst gestalten.

|

Die Funktion steht nur bei erworbenem Modul ‚Aufmaßmobil‘ zur Verfügung. Zum Testen kann sie wie viele andere Module auch für 30 Tage kostenlos freigeschaltet und genutzt werden. Die 30-Tage Freischaltung finden Sie im Einstellmodul unter <Optionen>, <Modulfreigaben>

Neben der reinen Mengenerfassung können auch nicht geplante neue Positionen angelegt werden.

Es sind keine Einrichtungsarbeiten erforderlich!
