4. Installation Laptop

Auf dem Laptop muss eine minimale Installation vorgenommen werden, damit die Aufmaße dort bearbeitet werden können. Um Ihnen die Zusendung einer speziellen CD zu ersparen und damit Sie das ganze auch mal testweise installieren können, kann mit dem Modul ‚Update einspielen‘ (heißt intern labelwinEinricht.exe) ein Verzeichnis mit den erforderlichen Dateien erzeugt werden. Dies Verzeichnis legt man am einfachsten auf einem USB-Stick an, damit man damit auf dem Laptop installieren kann.

[Bild]

Nach dem Start des Moduls ‚Update einspielen‘ wählen Sie dort die Menüpunkte <Datei>, <Aufmass Mobil Installation> an.

Nach der Erzeugung des Installationspfades können Sie einen Hilfe-Knopf betätigen, der folgenden Text zeigt:

Aufmass Mobil Installation - Die nächsten Schritte

Stecken Sie den USB Stick jetzt in den Laptop.

Erstinstallation auf dem Laptop

· Öffnen Sie den Windows Explorer und gehen Sie in das "aufmassinst" Verzeichnis auf dem USB Stick.

· Starten Sie die Datei LabelwinSetup.exe per Doppelklick und folgen Sie den Anweisungen

· Starten Sie die Datei LabelwinSetupZ.exe per Doppelklick und folgen Sie den Anweisungen

· Starten Sie die Datei LabelwinEinricht.exe per Doppelklick

· Wählen Sie ein Zielverzeichnis auf dem Laptop aus, wo das Aufmaß Mobil Programm installiert werden soll.

· Drücken Sie "Start"

Die Installation ist abgeschlossen. Sie sollten nun einen Startmenü Eintrag "Labelwin Aufmaß" und ggf. ein Programm Icon "Aufmass" auf dem Desktop haben.

Update auf dem Laptop einspielen

· Öffnen Sie den Windows Explorer und starten Sie im "Aufmass" Verzeichnis auf dem Laptop das Programm "Labelwineinricht.exe"

· Wählen Sie als Update Pfad das "aufmassinst" Verzeichnis des USB Sticks aus

· Drücken Sie "Start"

Das Update wurde erfolgreich eingespielt.
