1.1 Erfassmaske - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Optionen

Neu (F2)

Mit diesem Menüpunkt leert sich die Maske und Sie können eine neue Zeitbuchung vornehmen.

Speichern (F3)

Gleiche Funktion wie Knopf ‚Speichern OK‘

Auftrag auf in Arbeit (F6)

Gleiche Funktion wie Knopf ‚Auftrag in Arbeit‘

Übernahme Mobil-Zeit (F7 )

Dieser Menüpunkt ist nur sichtbar, wenn Sie die Schnittstelle zu Mobil-Zeit erworben haben. Hiermit können Sie die Zeiten aus Mobil-Zeit übernehmen.

Übernahme von Digi-Time

Auch dieser Menüpunkt ist nur bei vorhandener Schnittstelle verfügbar. Hiermit können Sie die Zeiten von Digi-Time übernehmen.

Übernahme von BMobile

Auch dieser Menüpunkt ist nur bei vorhandener Schnittstelle verfügbar. Hiermit können Sie die Zeiten von BMobile übernehmen.

Übernahme von TomTom

Wenn Sie die Schnittstelle zu TomTom erworben haben, gibt es hier die Möglichkeit, die Zeiten vom TomTom-Gerät zu übernehmen.

Übernahme aus iDeXs (STRG+I)

Wenn Sie die Smartphone-App IdeXs einsetzen, gibt es hier die Möglichkeit, die Daten aus dem IdeXs-Web zu übernehmen.

Übernahme aus 123erfasst.de

Auch dieser Menüpunkt ist nur bei vorhandener Schnittstelle verfügbar. Hiermit können Sie die Zeiten von 123erfasst.de übernehmen.

Auftrag scannen (F12)

Wenn Sie über das Zusatzmodul Scan-Archiv oder ELO-Anbindung verfügen, haben Sie hier die Möglichkeit, einen Kundendienstauftrag einzuscannen.

Auftrag-Scann anzeigen (F4)

Wenn Sie über das Zusatzmodul Scan-Archiv oder ELO-Anbindung verfügen, haben Sie hier die Möglichkeit, sich einen gescannten Auftrag anzeigen zu lassen.

Auftrag bearbeiten / Ändern (Strg+K)

Hier haben Sie die Möglichkeit, einen Kundendienstauftrag direkt in Bearbeitung zu nehmen. Das klappt natürlich nicht, wenn der Auftrag bereits aktiv ist. Wenn Sie vom Auftrag in die Zeitwirtschaft gehen und dort diese Funktion anwählen, werden Sie darauf hingewiesen, dass der Auftrag bereits in Nutzung ist.

Zulage verteilen (Strg+T)

Wenn an einem Tag auf mehreren Projekten gearbeitet wurde und eine Tages-Zulage wie z.B. Auslösung gebucht wird, muss diese korrekterweise für die Projektbelastung aufgeteilt werden. Bei einem Verhältnis von z.B. 5 Std. zu 3 Std. muss also auf dem einen Projekt 5/8 Zulage = 0, 625 Zulage gebucht werden, auf dem anderen 0,375 Zulage. Über diesen Menüunkt kann das Programm die Zulagen selbst aufteilen. Bucen Sie zunächst nur die Stunden auf die Projekte und tragen dann die Zulage ein, ohne sie zu speichern. Wählen Sie dann diesen Menüpunkt oder die Tastenkombination Strg+T. Es werden so viele Buchung mit den jeweiligen Mengenanteilen erzeugt, wie Projektbuchungen für diesen Tag und Mitarbeiter existieren. Die Mengen werden auf 2 Nachkommastellen gerundet. Die letzte Buchung bekommt den Rest, damit der Mitarbeiter auf jeden Fall die volle Zulage erhält.

Es können auch 2 Zulagen gleichzeitig verteilt werden.

Preislisteninfo

Durch die Anwahl dieses Menüpunktes wird Ihnen angezeigt, welche Preisliste gerade aktiv ist.

Projektfreigabe Zeitbuchen

Projekte, in denen die Zeitbuchung bisher nicht frei gegeben wurde, können Sie mit diesem Menüpunkt direkt frei geben. Wenn Sie ein solches Projekt anwählen, werden Sie gefragt, ob es jetzt für die Zeitbuchung frei gegeben werden soll oder nicht.

Es erscheint eine Maske, in der zusätzlich der Status des Projekts umgesetzt werden kann.

[Bild]

Allerdings sind wie im Datenblatt die Sperren wirksam, wenn ein Benutzer nicht über die entsprechenden Rechte verfügt.

Bei der Projektsuche werden zunächst nur die Projekte gezeigt, für die Zeitbuchungen zulässig sind. Wenn Sie das Kreuz bei ‚nur Projekte mit Zeitfreigabe’ wegnehmen, stehen alle Projekte zur Verfügung.

Mobile Erfassung

Diese Maske wurde für die mobile Erfassung programmiert (Zusatzmodul KD-Mobil). Sie kann jedoch auch für die vereinfachte Zeitbuchung genutzt werden.

Mandant wechseln

Dies Feld ist nur bei der Mandantenversion aktiv

Arbeitszeit wegen Mindestlohn

Über diesen Menüpunkt können Arbeitszeiten gemäß Mindestlohngesetz (MiLoG) erfasst werden. Die genaue Beschreibung finden Sie unter Arbeitszeiten nach MiLoG.

Ende

Hiermit beenden Sie die Zeiterfassung.

|

Auswerten

Monteur / Projekt Auswertung

In diesem Programmbereich können Sie die Auswertungen für einen bestimmten Monteur oder ein bestimmtes Projekt fahren. Sie finden die Beschreibung im Kapitel Monteur / Projektauswertung.

Verdichtete Lohndaten

Dieser Bereich dient zur Ausgabe der Daten zur Eintragung in ein Lohnprogramm. Sie finden die Beschreibung im Kapitel Verdichtete Lohndaten.

Produktivitätsauswertung

Dieser Bereich dient zur Ausgabe der Produktivitätsauswertung. Voraussetzung ist, dass Sie bei den Stundenarten jeweils festgelegt haben, ob sie produktiv oder unproduktiv ist. Da es auch um die mögliche Steigerung der Produktivität geht, haben wir die unproduktiven Zeiten in gearbeitet und Ausfall unterteilt. In der Regel sind nur die unproduktiv gearbeiteten Stunden durch eine bessere Betriebsorganisation zu verringern. Bei den Ausfallstunden kann man nur den Krankheitsausfall durch Verbesserung des Betriebsklimas oder durch Entlassungen etwas ändern.

Zeitkonto / Urlaub auswerten

Dieser Bereich ist nur bei vorhandenen Modul ZEITKONTO anwählbar. Sie finden die Beschreibung im Kapitel Zeitkonto.

Monatsübersicht Monteur (F8)

Hier werden die bisher gebuchten Zeiten des Monteurs im Anzeigemonat der Tabelle dargestellt. Sie können zwischen den einzelnen Monteuren umschalten. Über farbige Balken können Sie die Stundenarten Normal, Urlaub, Krankheit, Zeitkonto und unproduktiv unterscheiden. Verschiedene Stundengruppen werden am gleichen Tag hintereinander dargestellt, so dass mit der Balkenlänge die gesamte Arbeitszeit des Tages sichtbar ist. Die Sollstunden werden aus den Vorgaben für das Zeitkonto ermittelt.

Sollten Sie das Produktivkennzeichen noch nicht festgelegt haben, so können Sie das problemlos im Nachhinein tun. Bearbeiten Sie die Stundenarten im Modul EINSTELLUNGEN unter dem Menüpunkt <Programmbereiche> <Zeitwirtschaft> <Stundenarten> und ordnen Sie das richtige Produktivkennzeichen zu.

[Bild]

Es ist auch eine Druckausgabe möglich. Diese sieht jedoch nicht genauso aus wie die Bildschirmansicht. Wer es genauso haben möchte, muss weiterhin eine Hardcopy machen.

Mit dem Knopf ‚alle Monteure‘ erfogt die Ausgabe für den Monat und alle in der Auswahl anwählbaren Monteure. Da dazu das gleiche Formular genutzt wird, wird für jeden Mitarbeiten ein separates Blatt gedruckt.

Wenn Sie in der Monatsübersicht auf einen Tag klicken, werden Details der Buchungen gezeigt.

[Bild]

Buchungen TomTom (F9)

Dieser Menüpunkt ist nur sichtbar, wenn Sie das Zusatzmodul TomTom erworben haben. Eine nähere Beschreibung finden Sie im Handbuch TomTom / Fahrzeugortung.

Arbeitstext zeigen (UMSCHALT+F2)

|

Dieser Menüpunkt öffnet ein separates Fenster mit dem Arbeitstext. In der Zeiterfassmaske ist nur ein Zeile des Arbeitstextes sichtbar, was vielleicht nicht immer ausreicht.

Dieser Menüpunkt hat die gleiche Funktion wie der "Text groß" Button rechts neben dem Feld "Arbeit" in der Zeiterfassmaske.

|

[Bild]

Zeitkonto Monatsabschluss (STRG+O)

Hier wird die monatliche Übertragung der zuviel oder zuwenig gearbeiteten Stunden auf das Zeitkonto vorgenommen. Sie finden die Beschreibung im Kapitel Zeitkonto.

Zeitkonto Manteltarif

Hier wird die wöchentliche Übertragung der zuviel oder zuwenig gearbeiteten Stunden lt. Manteltarif vorgenommen.

Überstunden buchen

Dieser Menüpunkt ermittelt die automatischen Stundenzulagen. Es öffnet sich eine Maske in der der Zeitraum und der Monteur für die Zulagenermittlung festgelegt werden muss. Man kann die Zulagenermittlung für einen einzelnen Monteur oder gleich für alle machen. Bei Betätigung der OK-Taste startet ein Durchlauf, der die Ermittlung der Zulagen gemäß den hinterlegten Vorgaben übernimmt.

Protokoll Buchungsänderungen

Über diesen Menüpunkt lassen sich Änderungen an der markierten Zeitbuchung auflisten. Jede Änderung einer Zeitbuchung wird inzwischen protokolliert, um die Vorschriften der GoBD zu genügen.

Luftlinie (STRG+L)

Hiermit kann die Luftlinie zwischen der Objektadresse und der Firmenadresse angezeigt werden. Der Hintergrund ist eine Firma, bei denen die Auslösungen aufgrund der Luftlinien-Entfernung berechnet werden. Langfristig wird es eine Lösung geben, bei den die Auslösungen dann automatisiert gebucht werden können.
