10.2 Inventurtext aktualisieren

Nach der erfolgten Zählung müssen im Inventurtext die tatsächlich vorgefundenen Mengen eingetragen werden. Holen Sie sich dazu den Inventurtext in die Dokumenterstellungsmaske. Falls Ihr Inventurtext bereits Mengen enthält, so können Sie diese ggfs. hier noch entfernen. Das Entfernen ist jedoch nicht zwingend erforderlich. Die Mengen werden entfernt durch Anwahl des Menüpunkts <Durchläufe> <bei allen/markierten Positionen Menge auf 0 setzen>.

Sie müssen entscheiden, ob Sie die Mengen jeweils in einer Summe eintragen möchten oder mit Hilfe der Aufmaßfunktion mehrere Einzelmengen aufaddieren wollen. Bei letzterem aktivieren Sie die Aufmaßmaske durch Anwahl des Menüpunkts <Optionen> <Aufmaßerfassung per Doppelklick>. Der erste per Doppelklick aktivierte Artikel wird dann in die Aufmaßmaske eingetragen, und Sie können die dazugehörigen Mengen eingeben. In der Aufmaßmaske können Sie durch die Pfeiltasten vorwärts und rückwärts blättern. Die Addition der Einzelmengen wird automatisch als Gesamtsumme eingetragen.

In den meisten Fällen wird es ausreichend sein, lediglich die Gesamtmenge für jeden Artikel einzugeben. Aktivieren Sie dazu einen Änderungslauf, bei dem lediglich die Stückzahl verändert wird. Dies geschieht durch Anwahl des Menüpunkts <Durchläufe> <Änderungslauf>. Falls dort bereits ein Muster für die Mengenänderung vorgesehen ist, aktivieren Sie dieses. Anderenfalls legen Sie ein neues Muster an. Lesen Sie hierzu bitte die Details das Kapitel Änderungslauf.

Das erzeugt Dokument mit den tatsächlich vorhandenen Mengen können Sie nun als Inventurbeleg verwenden. Drucken Sie ihn dazu wieder als Stückliste oder ähnlichem aus. Falls Sie zuvor den Wert der Artikel verändern möchten, können Sie dies über die Kalkulationsänderung erreichen. Lesen Sie hierzu bitte das Kapitel Kalkulation ändern.
