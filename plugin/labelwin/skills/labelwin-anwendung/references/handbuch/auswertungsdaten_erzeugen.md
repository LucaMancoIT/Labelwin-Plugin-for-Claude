Auswertungsdaten erzeugen

Bevor Sie eine Projektauswertung erzeugen können, müssen Sie im Modul PROJEKTE unter dem Menüpunkt <Projekt> <Globale Auswertung> <Übersichtsdaten erzeugen> einen Durchlauf starten. Bei diesem Durchlauf werden alle Datensätze nach den aktuellen Informationen durchsucht. Bei der Datenerzeugung ist es möglich, auf einen bestimmten Auswertungszeitraum und Projekte mit bestimmten Merkmalen einzugrenzen. Bei der Datenerzeugung werden von jedem einzelnen Projekt diverse Summen gebildet. Die erzeugten Daten werden in einer Tabelle eingetragen, so dass auch eine Auswertung über bereits abgelaufene Zeiten möglich ist. Wir haben die Erzeugung der Daten und der Auswertung voneinander getrennt, da die Datenerzeugung bei vielen vorhandenen Projekten einige Zeit in Anspruch nehmen wird. Über unser Verfahren ist es möglich, beispielsweise die Datenerzeugung abends ablaufen zu lassen und tagsüber dann jede beliebige Auswertung sehr schnell erstellen zu können. Insbesondere ist es hierdurch möglich, verschiedene Auswertung zu erzeugen ohne jeweils den Vorgang der Datenerzeugung wiederholen zu müssen.

[Bild]

Vorhandene Auswertungen

Im oberen Bereich der Maske sehen Sie die Liste der bisher erzeugten Auswertungen. Die Liste dient nur der Information darüber, wann in der Vergangenheit Auswertungen erzeugt wurden. Nicht mehr benötigte Auswertungen können (und sollten) hier gelöscht werden. Eine Mehrfachmarkierung ist möglich.

[Bild]

1 Bereich: Wählen Sie hier den Bereich für eine bereits vorhandene Auswertung aus.

[Bild]

2 Liste der vorhandenen Auswertungen: Hier werden Ihnen bereits vorhandene Auswertungen aufgelistet. Entscheidend für die Liste ist die zuvor getroffene Auswahl (Nr. 1), aus welchem Bereich die Auswertungen angezeigt werden sollen.

[Bild]

3 Auswertung löschen: Durch Betätigen dieses Knopfes kann eine in der Liste (Nr. 2) gewählte Auswertung gelöscht werden.

Auswertung erzeugen für:

[Bild]

4 Projektauswertung: Sie können über dieses Feld nach wie vor die Projektauswertung starten. Sie sollten jedoch den Menüpunkt <Globale Auswertung> <Projektauswertung> nutzen, da hier die Übersichtsdaten unmittelbar vor einer Auswertung erzeugt werden können. Lesen Sie hierzu das Kapitel 21.2

[Bild]

5 Kundendienst: Aktivieren Sie dieses Feld, wenn Sie die Daten für eine Kundendienstauswertung erzeugen möchten. Grenzen Sie hier ggf. auf das Datum ein. Wenn Sie nichts eintragen, wird der gesamte Datenbestand ausgewertet Das Datum greift auf das Anlagedatum, solange der Kundendienstauftrag noch nicht erledigt ist, anderenfalls gilt das Erledigt-Datum.

[Bild]

6 Artikelumsatz: Aktivieren Sie dieses Feld, wenn Sie die Daten für eine Auswertung der Artikelumsätze erzeugen möchten. Grenzen Sie hier ggf. auf das Datum ein. Wenn Sie nichts eintragen, wird der gesamte Zeitraum genommen. Sie haben hier außerdem noch die Möglichkeit, die Sammelrechnungen mit einzubeziehen und die Auswertungsbereiche einzugrenzen.

[Bild]

7 TGM-Daten: Wenn Sie das Zusatz-modul TGM erworben haben, können Sie eine Auswertung der TGM-Daten erzeugen. Auch hier können Sie auf das Datum eingrenzen. Eine ausführliche Beschreibung finden Sie im TGM-Handbuch.

[Bild]

8 Kontensalden: Aktivieren Sie dieses Feld, wenn Sie eine Auswertung der Kontensalden erzeugen möchten. Diese Daten werden für eine BWA oder Liquiditätsübersicht benötigt.

[Bild]

9 Alle Mandanten: Aktivieren Sie dieses Feld, wenn Sie eine Auswertung über alle Mandanten erzeugen wollen. Eine Eingrenzung auf bestimmte Projekte ist dann jedoch nicht möglich.

[Bild]

10 Datum übertragen: Wenn Sie diesen Knopf betätigen, wird das bei der Projektauswertung eingetragene Datum auf die anderen Datumsfelder übertragen, sofern die Felder aktiviert wurden.

[Bild]

11 Starten: Durch Betätigen dieses Knopfes werden die Auswertungsdaten erzeugt.

[Bild]

12 Ende: Durch Betätigen dieses Knopfes wird die Maske geschlossen.

Die Datenbank wird bei der täglichen Arbeit immer größer. Wenn Sie in Ihrer Datenbank viele Daten erfasst haben, kann die Auswertung möglicherweise einige Stunden dauern. In diesem Fall starten Sie den Vorgang am besten zu Feierabend und schalten nur den Monitor aus oder benutzen Sie den Taskmanager. In der ersten Zeit dauert die Erzeugung nur wenige Sekunden, so dass die Anwahl zu jeder Zeit erfolgen kann.

Die Daten-Erzeugungsdurchläufe werden alle abgespeichert, so dass Sie auch im Nachhinein mit alten Daten Auswertungslisten erzeugen können.

Wir empfehlen Ihnen, die Projektsummen jede Woche oder jeden Monat zum gleichen Tag zu bilden. Die Auswertungen sollten Sie längere Zeit stehen lassen und nicht frühzeitig löschen. Sie lassen sich zwar theoretisch über die Funktion ‘von-bis Datum’ jederzeit neu erzeugen, in der Praxis kann dies jedoch misslingen, wenn noch Werte auf vergangene Zeiten gebucht werden. Beispiel: Am 1. April Daten bis zum 1.April erzeugt, am 10.April noch einen Monteurzettel auf März gebucht. Auswertung am 15.April erzeugt bis zum 1.April würden andere Werte ergeben als die Auswertung, die am 1. April erzeugt wurde.

Datei

Mandanten wechseln

Wenn Sie das Modul Mandantenfähigkeit erworben haben, ist dieser Menüpunkt sichtbar und Sie können hier den Mandanten wechseln

Beenden

Durch Betätigen dieses Menüpunkts wird die Maske der Auswertungsdaten geschlossen. Es ist die gleiche Funktion wie der Knopf ‚Ende’.

Optionen

Terminierte Auswertungen

Unter diesem Menüpunkt können Sie terminierte Auswertungen anlegen. Dieses ist vor allem dann sinnvoll, wenn Sie bereits viele Daten in Ihrer Datenbank erfasst haben. Somit könnte eine Auswertung z.B. zum Feierabend oder nachts gestartet werden. Dazu ist es notwendig, dass Sie in der Windows Aufgabenplanung (<Start> <Systemsteuerung> <Verwaltung> <Aufgabenplanung>) folgendes eintragen:

Auszuführendes Programm: c:\labelwin\projaus.exe TASK

Arbeitsverzeichnis: c:\labelwin\ (hier müssen Sie den Plattenbuchstaben einsetzen, unter dem Labelwin bei Ihnen installiert ist)

Des Weiteren noch Startzeit, Windows Benutzer und Login Informationen, etc.

Taskplan testen

Unter diesem Menüpunkt kann der gewählte Taskplan getestet werden. Bei Test wird dann gefragt, ob die Auswertung gestartet werden soll.

|

Suchschema

Neues Suchschema

Wählen Sie diesen Menüpunkt an, wenn Sie ein eigenes Suchschema mit einem SQL-Befehl anlegen möchten. Dieses ist jedoch ein Sonderfall und kann eigentlich nur von einem Spezialisten angelegt werden.

|

Hier folgen Hinweise für diese Spezialisten:

Der Befehl muss mit FROM anfangen, weil der Select-Teil fest steht. Im FROM-Teil muss die Tabelle projgrund eingebunden sein, da aus nur aus dieser die Daten gezogen werden.

Beispiel: Eingrenzung auf Erlöskonto

FROM projgrund WHERE erloeskonto='8400' AND mandand=2

Beispiel: Eingrenzung auf Projekte eines Rechnungsempängers

FROM adstamm INNER JOIN projgrund ON adstamm.adnr = projgrund.ad2nr

WHERE mandand=2 AND adstamm.Suchwort1 LIKE 'wohnb*'

Suchschema ändern

Wenn Sie diesen Menüpunkt anwählen, haben Sie die Möglichkeit ein Suchschema, das mit einem SQL-Befehl erstellt wurde, zu ändern.

Suchschema löschen

Unter diesem Menüpunkt können Sie ein Suchschema, das mit einem SQL-Befehl erstellt wurde, zu löschen. Die Suchschemen für Eingrenzung/Auswahl in der Projektsuche können nur dort gelöscht werden.
