6.3 Update Automatisierung

Unter diesem Menüpunkt können die Punkte Internet Update holen, Update einspielen und Datenbank aktualisieren miteinander so verkettet werden, dass sie automatisch hintereinander ablaufen und ggf. mit einem Timer nachts gestartet werden können.

Dazu müssen Sie hier einige Einstellungen vornehmen.

[Bild]

Bild: Einstellungen Update Aktualisierung

[Bild]

1 Email testen: Durch Betätigen dieses Knopfes können Sie die unter Vorgaben (D) hinterlegten Emailadressen testen.

[Bild]

2 SMS testen: Durch Betätigen dieses Knopfes können Sie die unter Vorgaben (D) hinterlegte Handy-Nr. testen.

[Bild]

3 Hilfe: Durch Betätigen dieses Knopfes gelangen Sie in den Hilfetext. Hier finden Sie einen weiteren Knopf, über den Sie ins LabelWiki gelangen.

[Bild]

4 Protokoll zeigen: Durch Betätigen dieses Knopfes wird Ihnen das Protokoll des Updates gezeigt.

[Bild]

5 Speichern: Durch Betätigen dieses Knopfes werden alle zuvor getroffenen Einstellungen gespeichert.

[Bild]

6 Ende: Durch Betätigen dieses Knopfes wird die Maske geschlossen.

Internet Update abholen

[Bild]

A1 Lautlos ausführen: Aktivieren Sie dieses Feld, wenn das Internet Update ohne Meldungen und nur mit einer Protokollausgabe abgeholt werden soll.

[Bild]

A2 Bei Erfolg: Legen Sie hier fest, wie sich das Programm verhalten soll, wenn das Internet Update erfolgreich abgeholt wurde.

[Bild]

A3 Im Fehlerfall: Legen Sie hier fest, wie sich das Programm verhalten soll, wenn es beim Holen des Updates einen Fehler gegeben hat.

Update Einspielen/Datenbank aktualisieren

[Bild]

Bild: Update einspielen/ Datenbank aktualisieren

[Bild]

B1 Lautlos ausführen: Durch Aktivieren dieses Feldes wird das Update einspielen gestartet. Es erfolgen keine Meldungen, lediglich eine Protokollausgabe.

[Bild]

B2 Datenbank vor dem Aktualisieren autom. Sichern: Wenn Sie dieses Feld aktivieren, wir Ihre Datenbank vor der Datenbankaktualisierung als zip-Datei gesichert.

[Bild]

B3 Bei Erfolg: Legen Sie hier fest, wie sich das Programm verhalten soll, wenn das wenn das Einspielen des Updates und die Datenbankaktualisierung erfolgreich war.

[Bild]

B4 Im Fehlerfall: Legen Sie hier fest, wie sich das Programm verhalten soll, wenn das wenn das Einspielen des Updates und die Datenbankaktualisierung fehlerhaft verlaufen sind.

Verhalten bei Datenbank Sperre

[Bild]

C1 Datenbanksperre: Legen Sie hier fest, wie sich das Programm verhalten soll, wenn es eine Datenbanksperre gibt.

[Bild]

C2 Wiederholung: Legen Sie hier den Zeitraum fest, wann erneut versucht werden soll, die Datenbanksperre aufzuheben und wie sich das Programm verhalten soll, wenn die Datenbank nach der Pause weiterhin gesperrt ist.

Vorgaben

[Bild]

Bild: Vorgaben

[Bild]

D1 Email Adresse: Tragen Sie hier ein oder mehrer Emailadressen ein, wenn Sie per Email bei einem Internet Update oder beim Update einspielen / Datenbankaktualisierung benachrichtigt werden möchten.

[Bild]

D2 Email Betreff Vortext: Tragen Sie hier einen sinnigen Text ein. Diesen Text können Sie in Ihrem Email-Programm mit einem Filter belegen. Damit wird sichergestellt, dass diese Emails nicht im Spam-Ordner landen.

[Bild]

D3 SMS-Empfänger: Tragen Sie hier die Handy-Nr. des Mitarbeiters ein, der per SMS über ein Internet Update oder über ein Update einspielen / Datenbankaktualisierung benachrichtigt werden soll.

[Bild]

D4 SMS Text: Tragen Sie hier einen SMS Text ein. Wenn Sie auf den Knopf Standardtext klicken, wird automatisch der von uns vorgefertigte Text in diese Zeile geschrieben.

[Bild]

D5 Update Verzeichnis: Tragen Sie hier Ihr Labelwin Update Verzeichnis ein.
