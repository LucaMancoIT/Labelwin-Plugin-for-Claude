2.2 KD-Mobil: Import der Daten vom Büro

Zunächst müssen die Daten irgendwie zum mobilen Gerät transportiert werden. Die Wege sind im vorigen Kapitel Büro: Export der Aufträge beschrieben und werden im Grunde genommen bei der Einrichtung festgelegt.

Die Art der Übernahme in den mobilen Kundendienst hängt von dem gewählten Transportweg ab.

Variante 1: Cloud-Abgleich

Der mobile Kundendienst prüft beim Start (und bei jedem Klick auf „Liste neu aufbauen“), ob ein Auftrag im Import-Pfad des Laptops liegt und bietet nur im positiven Fall in der unteren Statusleiste einen gelben Button „NEUE AUFTRÄGE" an.

[Bild]

Anmerkung: Bevor die Menüleiste auf die neue Ribbon Optik umgestellt wurde (seit Version V5.84), wurde in der oberen Menüleiste ein gelber Button "Auftrag holen" angezeigt.

[Bild]

Nach Import des Auftrages wird der gelbe Button wieder ausgeblendet und erst wieder eingeblendet, wenn eine neue Datei im Import-Pfad liegt.

Am Ende eines jeden Importes wird ein Einlese-Protokoll angezeigt.

[Bild]

Wenn eine Auftragsdatei (.labelnb) übernommen worden ist, wird die Dateiendung automatisch umbenannt (.sic) und somit in der Auswahl nicht mehr berücksichtigt. Ein versehentliches doppeltes Einlesen ist somit ausgeschlossen. Die Auftragsdatei steht aber als Sicherung noch zur Verfügung.

Variante 2: E-Mail

Wurde der Auftrag per E-Mail übermittelt, muss ein Doppelklick auf den Dateianhang gemacht werden. Der Dateianhang hat die Dateiendung labelnb.

[Bild]

Mit dem Doppelklick startet das Importmodul und die Daten werden in den mobilen Kundendienst eingetragen. Die Doppelklick-Funktion muss allerdings zunächst eingerichtet werden (siehe Import / Doppelklick-Funktion).

[Bild]

Variante 3: Datei

Wird die Export-Datei nicht per E-Mail, sondern manuell - z.B. per USB-Stick - auf das mobile Gerät übertragen, reicht ebenfalls ein Doppelklick auf die Datei.
