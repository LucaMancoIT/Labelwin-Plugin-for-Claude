2.1.7 SMS Versand

[Bild]

Das Versenden einer SMS ist maschinenabhängig und muss auf jedem PC, von dem SMS verschickt werden sollen, frei gegeben sein.

Des Weiteren ist eine Absendererkennung erforderlich. Geben Sie dazu die Landesvorwahl, eine gültige Mobiltelefonnummer und einen Absendernamen ein.

Als Versandart wird nur noch via Internet Gateway benutzt.
