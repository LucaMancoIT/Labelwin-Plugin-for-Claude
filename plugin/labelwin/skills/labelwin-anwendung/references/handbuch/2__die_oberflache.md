2. Die Oberfläche

Wenn Sie das Programm starten, erscheint zunächst folgende Oberfläche:

[Bild]

Bild: Fibuschnittstelle

[Bild]

1 Schnittstellen-Anzeige: In diesem Feld wird angezeigt, welche Fibu-Schnittstelle bei Ihnen installiert ist. Die Umstellung auf eine andere Schnittstelle ist vom Programm aus gesperrt.

[Bild]

2 Wirtschaftsjahr: Tragen Sie hier das Wirtschaftsjahr ein – es werden nur die beiden letzten Stellen eingetragen.

[Bild]

3 Letzte Übertragung: In diesem Anzeigebereich wird angezeigt, wann die letzte Übertragung stattgefunden hat. Die Lauf-Nr. ist eine interne, eindeutige Nummer in der Fibuschnittstelle. Diese Nummer ist für zwei Dinge wichtig:

· Sie können unter der Lauf-Nummer im Protokoll (Knopf Nr. 14) nachschauen, welche Daten bei dieser Auslagerung übertragen wurden.

· Falls ausgelagerte Daten aus irgendeinem Grunde verloren gegangen sind, z.B. wenn Ihre Fibu-Software sie nicht richtig eingelesen hat, können Sie anhand der Lauf-Nr. eine komplette Auslagerung rekonstruieren. Dies geschieht über die Auswahl Nr. 4 „Lauf wiederholen“.

[Bild]

4 Neuer Lauf / Lauf wiederholen: In diesem Auswahlfeld können Sie wählen, ob eine neue Auslagerung durchgeführt werden soll, oder ob Sie eine alte Auslagerung rekonstruieren möchten. Bei einer neuen Auslagerung wird im Feld 5 angezeigt, welche Nummer dieser Lauf bekommen wird. Diese Nummer wird vom Programm vorgegeben, da sie immer eindeutig ist. Wenn Sie „Lauf wiederholen“ wählen, verschwindet das Feld Nr. 10 und es erscheint ein Eingabefeld, in dem Sie die Nummer des zu wiederholenden Laufes eintragen können. Wenn Sie eine gültige Nummer gewählt haben und mit der Enter-Taste bestätigt haben, wird unten angezeigt, wie viele Ein- bzw. Ausgangs-Rechnungen dieser Lauf hatte. Im Protokoll (Knopf Nr. 14) können Sie im Einzelnen nachschlagen, welche Rechnungen bei diesem Lauf dabei waren. Um den Wiederholungslauf zu starten, drücken Sie den „Lauf durchführen“-Knopf.

[Bild]

5 Zeitraum von / bis: Hier können Sie die Datumseingrenzung für den neuen Lauf wählen. Das Feld „Zeitraum von“ ist hier für die Eingabe gesperrt. Es kann aus Sicherheitsgründen nur auf der Einstell-Maske (Knopf Nr. 14) geändert werden.

[Bild]

6 Ausgangsrechnungen-Ankreuzfeld: Wenn Sie das Kreuz in diesem Feld entfernen, dann wird die Auslagerung der Ausgangsrechnungen deaktiviert. Das Anzeigefeld (Anzahl der Ausgangsrechnungen, die ausgelagert werden)und der Eingrenzungs-Knopf (Nr. 11) verschwinden.

[Bild]

7 Eingangsrechnungen-Ankreuzfeld: Wenn Sie das Kreuz in diesem Feld entfernen, dann wird die Auslagerung der Eingangsrechnungen deaktiviert. Das Anzeigefeld (Anzahl der Eingangsrechnungen, die ausgelagert werden) und der Eingrenzungs-Knopf (Nr. 11) verschwinden.

[Bild]

8 Journal-Ankreuzfeld: Wenn Sie das Kreuz in diesem Feld entfernen, dann wird die Auslagerung des Journals deaktiviert. Das Anzeigefeld (Anzahl der Journalbuchungen, die ausgelagert werden) und Knopf Jorunal anzeigen (Nr. 12) verschwinden

[Bild]

9 Testlauf: Wenn Sie hier ein Häkchen setzen, haben Sie die Möglichkeit für die zuvor getroffenen Auslagerungen einen Testlauf durchzuführen. Es wird dann kein Übergabekennzeichen gesetzt.

[Bild]

10 Neue Lauf-Nr: In diesem Feld wird angezeigt, welche Lauf-Nummer die Auslagerung bekommen wird, wenn Sie im Feld 4 „neuer Lauf“ gewählt haben. Die Nummer ist für das Protokoll und für Wiederholungs-Läufe wichtig.

[Bild]

11 ‚Eingrenzung Ändern‘ - Knöpfe: Wenn Sie diesen Knopf drücken, erscheint eine Maske, mit Hilfe derer Sie u. a. einzelne Rechnungen hinzu- oder herausnehmen können. Eine detaillierte Beschreibung der Maske finden Sie in Kapitel 24.2.1. Wenn Sie die Eingrenzung geändert haben und zur Hauptmaske zurückkehren, dann wird der Knopf rot, um anzuzeigen, dass die angezeigte Anzahl nicht mehr unbedingt zu dem in Feld 6/7 angegebenen Zeitraum passt. Wenn Sie die Eingrenzung wieder aufheben wollen, gehen Sie einfach in das Feld ‚Zeitraum bis‘ und bestätigen das dort eingetragene Datum mit der Enter-Taste. Dadurch werden die evtl. gemachten Eingrenzungen wieder rückgängig gemacht.

[Bild]

12 Journal anzeigen: Wenn Sie diesen Knopf drücken, haben Sie die Möglichkeit, sich die Buchungen aus der Fibuerfassung anzuschauen.

[Bild]

13 Einstellungen: Durch Betätigung dieses Knopfes erscheint die Einstell-Maske für die im Feld Nr 1 angezeigte Fibu-Schnittstelle. Die genaue Beschreibung dazu finden Sie in Kapitel 24.3.

[Bild]

14 Einstellungen allgemein: Die Einstellungen, die in diese Maske gemacht werden, sind für alle Schnittstellen gleich.

[Bild]

15 Protokoll: Eine detaillierte Beschreibung der Protokoll-Maske finden Sie in Kapitel 24.2.2.

[Bild]

16 Lauf durchführen: Durch Betätigung dieses Knopfes wird die Auslagerung gemäß der getroffenen Auswahl gestartet. Wenn es sich um einen neuen Lauf handelt, wird im Protokoll (Knopf 15) ein neuer Eintrag unter der in Feld 10 angezeigten Lauf-Nr. angelegt. Hilfe der Laufnummer ist es auch möglich, die Übertragung später zu wiederholen.

[Bild]

17 Ende: Durch Betätigung des Ende-Knopfes wird das Programm beendet.

Die Menüpunkte im Einzelnen:

Datei

Mandantenwechsel

Durch Betätigung des Menüpunktes kann der aktuelle Mandant gewechselt werden. Der aktive Mandant wird in der Titelleiste der Hauptmaske angezeigt.

Sammelkonten

Dieser Menüpunkt ist ausschließlich für die Datev-Schnittstelle gedacht.

Sperrdatum ändern

Bei vorhandenem Sperrdatum werden Eingangsrechnungen ggf. mit einem separaten Belegdatum versehen und auf das Tagesdatum gebucht. Die Übergabe erfolgt dann dennoch mit dem Belegdatum, wird jedoch im Zeitraum der Erfassung ausgewertet. Wenn z.B. das Sperrdatum am 31.7.2012 steht und am 3.8. eine Eingangsrechnung mit Datum 30.7.2012 gebucht wird, so landet sie dennoch im Stapel für den Monat 8. Als Belegdatum hat sie dann zwar den 30.7, wird aber fiskalisch im Monat 8 berücksichtigt. Bei den Auswertungen im Labelwin wird sie ebenfalls im Monat 8 berücksichtigt. Weitere Informationen können Sie im Handbuch der Eingangsrechnungen lesen.

Beenden

Durch Betätigung dieses Menüpunktes wird das Programm beendet.
