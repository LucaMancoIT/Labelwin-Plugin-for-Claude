3.1 Aufgabenverfolgung - Alle Menüpunkte

Die Menüpunkte im Einzelnen:

|

Datei

Neue Aufgabe (F2)

Durch die Wahl dieses Menüpunktes können Sie eine neue Aufgabe anlegen. Es ist die gleiche Funktion wie beim Knopf [Nr.17].

Aufgabe ändern / zeigen (F6)

Über diesen Menüpunkt können Sie eine bestehende Aufgabe ansehen bzw. ändern. Es ist die gleiche Funktion wie beim Knopf [Nr.18].

Auf erledigt setzen (Strg+E)

Bei Kunden, die die Aufgabenverwaltung intensiv nutzen, sammeln sich sehr viele Aufgaben. Gegebenenfalls wurde diese schon von der Bauleitern von unterwegs erledigt. Mit dieser Funktion können Sie mehrere Aufgaben markieren und auf einmal auf erledigt setzen. Es fehlt dann jedoch die Protokollierung.

Fälligkeit ändern

Über diesen Menüpunkt können Sie die Fälligkeit einer (oder mehrerer) Aufgabe(n) ändern ohne die Aufgabe(n) öffnen zu müssen.

Zuordnen zu anderem Mitarbeiter/Team

Über diesen Menüpunkt können Sie eine (oder mehrere) Aufgabe(n) einem anderen Mitarbeiter bzw. Team zuordnen ohne die Aufgabe(n) öffnen zu müssen.

Drucken Liste

Über diesen Menüpunkt haben Sie die Möglichkeit, sich die Aufgabenliste auszudrucken. Es ist die gleiche Funktion wie beim Knopf [Nr.19].

Drucken markierte Aufgabe

Über diesen Menüpunkt haben Sie die Möglichkeit, die in der Liste markierte Aufgabe auszudrucken.

Liste neu aufbauen (F5)

Über diesen Menüpunkt haben Sie die Möglichkeit, die Anzeigentabelle entsprechend der von Ihnen getroffenen Selektion zu aktualisieren. Es ist die gleiche Funktion wie beim Knopf [Nr.16].

Mandanten wechseln

Wenn Sie das Modul Mandantenfähigkeit erworben haben, können Sie über diesen Menüpunkt den Mandanten wechseln.

Beenden

Über diesen Menüpunkt schließen Sie die Terminverwaltung. Es ist die gleiche Funktion wie beim Knopf [Nr.20].

|

Anzeige

Meine Aufgaben (F7)

Über diesen Menüpunkt können Sie sich nur die Aufgaben anzeigen lassen, die für Sie angelegt wurden.

Alle Aufgaben

Durch die Wahl dieses Menüpunktes werden Ihnen alle Aufgaben angezeigt.

Heute angelegte Aufgaben

Über diesen Menüpunkt werden Ihnen alle Aufgaben angezeigt, die heute angelegt wurden.

Liste automatisch aufbauen

Wenn Sie diese Option wählen, wird die Aufgabenliste immer automatisch aktualisiert.

Aktualisierung mit Zeitintervall

Wenn Sie diesen Menüpunkt wählen, können Sie ein Zeitintervall in Minuten für die automatische Aktualisierung hinterlegen.

Aufgaben incl. Team

Wenn dieser Menüpunkt gewählt ist, werden auch die Aufgaben von Teams angezeigt. Diese Option ist standardmäßig gesetzt.
